# アートディレクション

アートディレクションとは、画面サイズなどに合わせて、単に画像を拡大・縮小するのではなく、**構図や画像内容そのものを変えるために別の画像候補へ切り替えること**。

```text
同じ画像を小さくする
→ アートディレクションではない

同じ画像をobject-fitで切り取って見せる
→ アートディレクションではない

SP/PC向けに別構図の画像を用意する
→ アートディレクション
→ このWikiでは画像切替型として扱う
```

たとえば、SPとPCで人物の配置、文字の配置、画像ファイル自体に写っている範囲、構図などを変える場合が該当する。

なお、同じ内容の画像を高解像度版へ切り替えるだけの場合も画像ファイルの切替ではあるが、アートディレクションとは区別する。

アートディレクションは第五の表示領域タイプではなく、**使用する画像候補を決める側の判断**である。
