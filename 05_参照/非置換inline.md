# 非置換inline

## 定義

非置換inlineは、次の二つの条件を分けて考えるための言い方。

- 非置換：表示内容が、画像などの置換内容へ置き換わっていない
- inline：生成する箱が、通常の文章の流れに沿って行内へ並ぶ

既定の表示に近い、文字を含む`span`や`a`が代表例になる。

```html
<span>こんにちは</span>
<a href="#">リンク</a>
```

ただし、要素名だけで決まる分類ではない。CSSで`display`を変更すれば、`span`や`a`もblockなど別の箱を生成できる。

## 確認すること

通常の非置換inlineが作るinline boxでは、`width`や`height`を指定しても、通常フローのblock boxと同じようには箱の寸法を決められない。

```css
span {
  width: 300px;
  height: 100px;
}
```

この指定だけで、文字を含む`span`が幅300px・高さ100pxの矩形になるわけではない。文字は行の中へ流れ、inline boxは内容や改行に沿って作られる。

これは「inlineにはCSSが効かない」という意味ではない。文字の指定や`padding`、`border`など、inline boxへ関係する指定は別に確認する。

## 置換要素と混同しない

`inline`と`非置換`は同じ分類ではない。

正常に画像を表している`img`は行内へ並ぶが、置換要素である。画像自身の自然寸法やCSSの`width`・`height`がサイズ計算に関係するため、通常の非置換inlineと同じ扱いにはならない。

```text
非置換inline
文字を含むspanやaなど
→ 内容を行の中へ流す

置換要素
画像を表すimgなど
→ 置換内容と固有の寸法を持つ
```

`input`や`video`などを含む詳しい条件は、[置換要素（img・input・video）](./置換要素（img・input・video）.md)で確認する。
