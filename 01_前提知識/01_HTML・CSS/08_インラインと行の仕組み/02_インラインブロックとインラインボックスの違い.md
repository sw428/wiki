## インラインブロックとインラインボックスの違い

まず最初に、この2つは名前が似ていますが別物です。



**インラインブロック**は、
```css
display: inline-block;
```

というCSSの指定によって作るものです。



これは別の記事で説明するので、今回はいったん忘れてください。



今回のテーマは**インラインボックス**です。



こっちはCSSに
```css
inline-box
```

のように書くものではありません。



ブラウザが文字やインライン要素を画面に並べるときに内部で作る、**描画上の箱**だと考えると分かりやすいです。

---

## 普段見えていないブラウザ側の仕組み

HTMLにこう書いたとします。
```html
<p>テキスト</p>
```

`p`要素は通常、
```css
display: block;
```

です。



なので、`p`からはブロックボックスが作られます。



でも、その中にある「テキスト」は、ブロックのように縦へ積まれるわけではありません。



文字は横方向へ並んでいきます。



つまり、
```text
p
└─ テキスト
```

というHTMLだけを見ている裏側で、ブラウザは文字を並べるためのインラインのレイアウト処理も行っています。



イメージとしては、
```text
ブロックボックス
└─ インラインの領域
   └─ テキスト
```

です。



このとき、文字や`span`などのインライン要素の描画に関係してくる箱が**インラインボックス**です。

---

## なぜこんなものを知る必要があるのか

普段HTMLとCSSを書いていると、



「ちゃんとCSSを書いているのに、なんでこうなるの？」



という現象が出てきます。



たとえば、



- 文字の高さ
- `line-height`
- ベースライン
- 画像の下にできる謎の隙間
- インライン要素の上下位置
- 一行の高さ



などです。



これらは、HTMLタグと`display`だけを見ていると説明しにくいことがあります。



そこで、

> ブラウザは文字を並べるために、見えないレイアウト上の箱も作っている

と知っておくと、少しずつ辻褄が合ってきます。

---

## CSSで直接触る箱ではない

インラインボックスは、
```css
.inline-box {
}
```

のように直接選択して操作するものではありません。



こちらがHTMLやCSSを書くと、それをもとにブラウザが内部で作ります。



ただし、まったく影響を与えられないわけではありません。



たとえば、
```css
p {
  font-size: 20px;
  line-height: 2;
}
```

とすると、中の文字の表示や行の高さにも影響します。



これはCSSの継承やインラインレイアウトのルールによって、最終的な描画結果が変わるためです。



つまり、
```text
自分がHTML・CSSを書く
        ↓
ブラウザがそれを解釈する
        ↓
内部でボックスや行を作る
        ↓
画面に描画される
```

という流れがあります。



普段私たちが書いているコードと、実際に画面へ描かれるまでの間には、ブラウザ側の処理が存在します。



インラインボックスはその一つです。

---

## 最初から全部理解しなくていい

インラインボックスは、最初に一度説明を読んだだけで全部理解する必要はありません。



今の段階では、

> 文字やインライン要素を並べるとき、ブラウザ内部では見えない箱や行が作られている

ということだけ覚えておけば十分です。



今後、
```css
line-height
vertical-align
display: inline
display: inline-block
```

などを扱ったときに、



「あ、前に出てきたインラインの内部処理がここにも関係しているのか」



と少しずつつながってきます。



その状態になれば、HTML・CSSで起きていることがかなり見えやすくなってきます。
