# GitHubログ整理マップ

> [!NOTE]
> Codex用の内部ルーター。Git・GitHubの作業記録と、対象・判断・適用結果の確認先を選ぶ。

## このフォルダの役割

Git履歴の修正やGitHubへの反映について、作業対象、変更前後、承認、適用・プッシュ結果を残す。現在の再開位置は[CURRENT](../../CURRENT.md)、Wiki全体の運用変更は[CHANGELOG](../../CHANGELOG.md)で確認する。

学習記事の内容を点検した指摘・改善案は[レビュー一覧](../03_レビュー/03_レビュー一覧.md)、コミットメッセージの使い方・生成規約の参考内容は[運用思想の生成規約](../01_Wikiの運用思想/03_コミットメッセージの生成規約.md)へ分担する。
