# 外部知識基盤と正本管理

## 正本を一つにする

長期的に使う知識・採用理由・現在の判断はWikiの適切な記事を正本とします。途中の仮説や未採用案を含む会話を、そのまま現行ルールにはしません。

| 保存場所 | 役割 |
| --- | --- |
| Wiki本文・各規約 | 現在使う知識と判断、その条件・理由 |
| `CURRENT.md` | 進行中の作業と未確認事項 |
| `CHANGELOG.md` | 変更の記録 |
| ChatGPTのメモリ | 必要な正本や判断の参照先を思い出す補助 |
| 会話 | 検討・仮説・言い直しの過程 |

## 会話を取り込むとき

会話や実装の区切りで、採用した判断、再利用できる原則、一時的な条件、採用しなかった案を区別します。検証を終えていない内容を確定事項として保存しません。採用する説明は既存の正本と照合し、同じ内容の正本を増やさないようにします。

## 対話ログを残す場合

対話過程そのものに検証・提示する価値がある場合だけ、[AI対話ログ（一部抜粋）](../AI対話ログ%28一部抜粋%29/00_AI対話ログ整理マップ.md)に原文を残します。ラフな入力、誤字、言い直しも検証対象となるため、ログ本文を後から校正・要約しません。

ログは正本でも、AIの回答が正しいことの証拠でもありません。ログから知識やルールを自動抽出して反映せず、明示的に指定された内容だけを別作業として照合します。

目標は情報を増やすことではなく、少ない参照先から判断の条件・理由・現在の状態を再構成できることです。
