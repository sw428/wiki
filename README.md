## 公開目的について

このWikiは、HTML/CSSコーディング練習を通じて得た学習プロセス、実装判断、設計メモを整理するものです。

このWikiの一部の学習メモは、あらゆる情報媒体でのコーディング練習を通じて得た気づきを、自分の言葉で一般化して整理したものです。

CodeJump / CodeJump Proの課題文、デザインカンプ、提供素材、サンプルコード、解説本文は転載していません。
また、課題内容や解答を再現できる形での掲載は行いません。

その他の教材についても、課題文、デザインカンプ、提供素材、サンプルコード、解説本文を転載・再配布するものではありません。

制作物をポートフォリオとして掲載する場合も、目的は企業・採用担当者に実装力や学習過程を確認してもらうことであり、教材内容や提供素材をコピー・配布することではありません。
