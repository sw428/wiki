# Web制作・学習Wiki

> [!TIP]
> 初めて読む方は、下の[読み方](#読み方)から、今理解したいことや作りたいものに近いカテゴリへ進んでください。
> 普段は`02_基礎`を中心に読み、分からない前提は`01_前提知識`、基本を理解した後の疑問は`03_詳細`で確認します。

このWikiは、HTML / CSS / JavaScriptの学習や制作、GPTとの対話から得た情報を、実務で再利用できる知識として整理する学習ノートです。企業や採用担当者に実装力、学習過程、判断理由を確認してもらい、採用判断の材料にしてもらう目的でも公開しています。

読者が「何の話か」「どこで使うか」「何を基準に選ぶか」をつかみ、説明から実装と確認へ進めることを重視しています。同じ目的を持つ学習者との知識共有にも役立てます。

## 読み方

人間向けの学習経路は、可能な限りカテゴリフォルダと、その配下のファイルの番号順で追えるようにしています。複数の記事を束ねるカテゴリでは、`00_...整理マップ.md`をCodex用の内部ルーター、`01_...md`を人間向けの入口にしています。

| 置き場所 | 役割 |
| --- | --- |
| [01_前提知識](./01_前提知識/) | 何も知らない状態から、基礎本文や最小例を読めるところまでをつなぐ |
| [02_基礎](./02_基礎/) | 普段の学習・実装の中心。基本の仕組み、使いどころ、実装、確認を一続きに読む |
| [03_詳細](./03_詳細/) | 基本を理解した後に必要になる理由、異なる条件での動き、仕様、例外を調べる |

01をすべて先に読む必要はありません。02を中心に進み、本文を読むための前提が不足しているときだけ01へ戻ります。さらに詳しい理由や例外が必要になったら03へ進みます。

- [04_検証](./04_検証/00_ケース検証運用.md): 制作中の具体例、案件条件、検証過程を確認する
- [05_参照](./05_参照/参照元インデックス.md): 用語や短い前提をすぐ確認する

## このWikiで扱う内容

- HTML / CSS / JavaScriptの基礎概念と実装
- Web制作中に出た疑問と検証結果
- ポートフォリオ制作・検証で得た判断基準と設計ルール
- 実装時につまずいた箇所と、後から修正された認識
- GPT / Codexとの対話を材料に整理した学習ログ

## 整理と運用

具体例や未確認の判断は、まず04で検証します。一般性を確認できた内容は、読むための前提を01、学習・実装の中心を02、基本理解後の掘り下げを03へ反映します。

GPTとの会話は、そのまま正解や記事にはしません。今回残す疑問・判断を一つ選び、既存の記事と照合してから必要な箇所へ反映します。原文を掲載する対話ログは、整理済みの本文や確認済みの知識とは分けて扱います。

詳しい方針や現在の状態は、次の文書で確認できます。

- [Wikiの運用思想](./Wikiの運用思想/00_Wikiの運用思想.md): ChatGPT・Codex・自分の役割と正本管理
- [AIモデルと構造レビュー](./Wikiの運用思想/06_AIモデルと構造レビュー.md): 通常運用と定期的な構造レビューの分担
- [AI対話ログ整理マップ](./AI対話ログ%28一部抜粋%29/00_AI対話ログ整理マップ.md): 原文ログの目的と、本文との区別
- [AGENTS](./AGENTS.md): Codexの行動・判断ルール
- [CURRENT](./CURRENT.md): 現在の構造、作業状況、保留事項
- [CHANGELOG](./CHANGELOG.md): 運用変更と判断理由の履歴
