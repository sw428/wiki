## AIモデルの使い分け

このWikiでは、普段の対話・整理・本文修正には、ChatGPTとCodexのGPT-5.6 Solを推論レベルHighで使います。利用するモデルをそろえ、ユーザーが確認しながら一つずつ判断と修正を進めるための通常運用です。

GPT-6 Astraの推論レベルHighは、定期的な構造レビューに限定して使います。OpenAI公式では、GPT-5.6 Solを複雑な専門作業向けの主力モデル、Astraを特に難しい一連の作業に対応する最も高性能なモデルと位置付けています。また、Astraは出力が詳細で書式の多い表現になりやすく、`AGENTS.md`など参照できる指示にも敏感だと説明されています。この特性を、Wiki本文を直接書くことではなく、広い範囲を見渡す確認と精査に使います。

- [OpenAI公式：GPT-6 Astraのモデルガイド](https://developers.openai.com/api/docs/guides/latest-model)
- [OpenAI公式：GPT-5.6 Sol](https://developers.openai.com/api/docs/models/gpt-5.6-sol)

### Astraによる構造レビュー

Astraには、通常運用で使っている各分野の`00_...整理マップ.md`を入口として読ませます。そこからフォルダ同士の関係と既存の正本を把握させたうえで、毎回レビュー目的と対象範囲を明示します。

レビューは、大きな目次にあたるフォルダ名・順序・役割から始めます。次に、全体のストーリー、実際に触る学習手順、復習時の戻りやすさ、知識の重複や不足を確認し、必要な回だけ対象をファイル間のつながりや本文へ絞ります。一度に全体を書き換えるためには使いません。

Astraのレビュー結果は、日付を付けた独立ファイルとしてWiki直下に保存します。`AGENTS.md`、`CURRENT.md`、通常運用の00系、学習本文へレビュー手順を混ぜず、Astraの出力を人に読ませる本文の正本にも扱いません。レビューで見つかった内容は判断材料とし、ユーザー、CodexのGPT-5.6 Sol、ChatGPTのGPT-5.6 Solで一項目ずつ確認してから、必要な修正だけを通常の本文や構造へ反映します。

最初の実施記録は、[2026-09-14*HTML・CSS*マッピングと構造レビュー](./2026-09-14_HTML・CSS_マッピングと構造レビュー.md)です。レビュー資料が増えて直下で探しにくくなった場合は、その時点で専用フォルダへまとめます。

目的は、教材内容や提供素材をコピー・配布することではなく、企業・採用担当者に実装力、学習過程、判断理由を確認してもらうことです。

また、同じ目的を持つ学習者との知識共有も目的としています。

このWikiは、学習・制作中に得た知見や経験をリアルタイムで蓄積し、その後、自分で内容を精査しながら各ページを継続的に修正・整理しています。

そのため、精査や再構成が追いついていない時点では、バージョンによって内容の重複、構成のばらつき、十分に整理されていない文章などが含まれる場合があります。これらは認識したうえで、学習過程そのものを含む記録として公開しています。

正確性には注意していますが、内容を利用・参照する際は、必要に応じて一次資料や公式ドキュメント等と照合し、各自で内容を確認してください。

## 基礎を三つに分けることにした経緯

当初は、学習や制作中に検証した内容から、再利用できる知識を「基礎」へ残していました。この「検証から基礎へ残す」という流れは、今も大切にしています。

ただ、基礎に情報が蓄積するにつれて、先に理解したいこと、実務で繰り返し使うこと、必要なときに調べることが同じ場所に増えていきました。その結果、学習の優先順位や、復習するときにどの説明からどこへ戻ればよいかが分かりにくくなってきました。

そこで、中心となる「基礎」を読み返しやすくするために、理解の前提を補う情報は「前提知識」へ、例外や掘り下げた説明は「詳細」へ分けて置く設計にしました。知識を減らすためではなく、そのとき必要な情報を、話のつながりを保って読み直すための分担です。

分けることで、置き場所や重複、前提への戻り先を確認する手間は増えます。その分、今読むことと後で調べることを整理しやすくする狙いがあります。現在はこの設計への移行中で、既存の記事すべてを振り分け直したわけではありません。

## 読み方

情報は、「基礎かどうか」「難しいかどうか」ではなく、読者の理解と実践をつなぐために、次の3つへ分けています。

| 置き場所                       | ここでできるようにすること                                                                       |
| ------------------------------ | ------------------------------------------------------------------------------------------------ |
| [01\_前提知識](./01_前提知識/) | 対象や性質のつながりを理解し、新しい基礎へ入りやすく、状況が変わっても混乱しない認識の土台を作る |
| [02\_基礎](./02_基礎/)         | 普段の学習・実装の中心。基本の仕組み、使いどころ、作り方と確認方法を一続きに読む                 |
| [03\_詳細](./03_詳細/)         | 読んだり作ったりしても残った疑問について、詳しい理由、例外、異なる条件での動きを調べる           |

`01_前提知識`は、学習順序の先頭に置く初級知識の一覧ではありません。個別の知識を並べるのではなく、「何が先に決まり、次に何がそれを参照するか」のように、対象の性質をストーリーとして理解する場所です。新しい基礎や実装へ入りやすくし、画面やコードの条件が変わっても、暗記した形に引っ張られず考え直せる認識ルートを作ります。

02を中心に読み、認識の土台から組み直したいときは01、さらに気になる理由や例外は03で確認します。01を全部読み終える必要はありません。短い前提や注意点は本文にも残し、何度も別ページを往復しなくてよいようにします。

従来のノートは02\_基礎に集約しました。01は今後、独立して説明する必要がある前提を取り出す場所です。既存本文には前提や詳細も混在しているため、01・03への整理は対象を絞って進めます。

各記事の題名や導入も、具体的な場面や疑問から入ります。説明が長すぎたり、一度に話が増えすぎたりして流れを追えなくなる場合は、順番や一度に読む範囲を見直します。

検証の経緯は[04\_検証](./04_検証/00_ケース検証運用.md)、短く確認したい言葉は[05\_参照](./05_参照/参照元インデックス.md)に置いています。

## GPTとの会話をどう整理するか

学習・制作についてのGPTとの会話をこのWikiの整理用に貼り付けたら、Codexがユーザーの意図を読み取り、今回の核となる疑問・判断を一つ選んでから整理を始めます。会話に関連する話題が複数含まれていても、一度にすべてを反映しません。

会話の順番をそのまま記事にするのではなく、「ここを理解するには何を先に知る必要があるか」を確認し、読者が話を追える順番へ整えます。既存の記事と照合し、同じ説明を増やさず、必要な箇所へ反映します。

事前に自分で全部を分類する必要はありません。今回残したいことが決まっていれば一つだけ示し、決まっていなければCodexが会話から核を読み取ります。候補が複数あり、どれを選ぶかで反映内容が変わる場合だけ確認します。別の疑問は同時に広げず、必要になったとき一つずつ扱います。

Codexが会話からつまずきを推測して整理した後、読み手は「ここで分からなくなった」と返すことで調整できます。ただし、推測や文章の点検だけでは、実際に理解できたとは確認できません。新しい整理方法は少量の記事で試し、その反応を次の改善に使います。

分類したことと、内容の正しさを確認できたことは区別します。未確認の主張や配置に迷う内容は、[04\_検証](./04_検証/00_ケース検証運用.md)に候補と理由を残し、精査してから確定します。「保存だけ」「まだ編集しない」と指定された会話は、その指示を優先します。

## AIとの対話例

このWikiでは、通常の解説・整理された本文とは別に、ChatGPTやCodexとの実際の対話ログを一部掲載しています。

以下の説明は、あくまでこの「対話ログ」として掲載している箇所についてのものです。

対話ログでは、誤字や省略を含むラフな日本語から、ChatGPTやCodexが意図をどう受け取り、回答や判断整理を進めたかが分かるよう、実際のやり取りを原文のまま残しています。

これらの会話では、過去のやり取りを踏まえてChatGPTに意図が通じると判断したうえで、最も伝えたい箇所と、それに対する返答に重点を置いています。そのため、会話の効率性を優先し、日本語として必要な文法や表現を意図的に省略している場合があります。

これはWiki全体の文章方針ではありません。Wiki本文や知識整理では内容を整理したうえで記述し、対話ログについてのみ、実際にどのような入力から意図が伝わり、回答や判断整理につながったかを残す目的で原文を掲載しています。

- [Codexの推論レベル・Ultra・AGENTS運用についての会話ログ](./AI対話ログ%28一部抜粋%29/ChatGPT（High）/2026-09-05_Codexの推論レベル・Ultra・AGENTS運用.md)

対話ログは、過去のAIとのやり取りや理解過程を見るための記録です。ログ内の説明を、確認済み事実や現在の運用ルールとして示すものではありません。
原文を掲載する `AI対話ログ(一部抜粋)` は `04_検証` と分けています。ここへ保存済みのログは、存在するだけでは分類・抽出の対象にしません。上の「整理用に貼り付けた会話」とは扱いが異なります。
