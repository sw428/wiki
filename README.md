このWikiは、HTML / CSS / JavaScript の学習中に出た疑問、実装判断、設計メモを整理するための学習記録です。

目的は、教材内容や提供素材をコピー・配布することではなく、企業・採用担当者に実装力、学習過程、判断理由を確認してもらうことです。

## このWikiで扱う内容

- HTML / CSS / JavaScript の基礎概念
- Web制作中に出た疑問と検証結果
- ポートフォリオ制作・検証で得た判断基準と、設計ルール
- 実装時につまずいた箇所と、あとから修正された認識
- GPT / Codex との対話を通して整理した学習ログ

このWikiとポートフォリオの公開目的は、素材や教材内容の配布ではなく、自分の学習過程、実装力、判断理由を確認してもらうことです。
