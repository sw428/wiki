# 画像整理マップ

Wiki共用画像の保存先・規約・一覧を選ぶ内部ルーター。画像の作業があるときだけ、対象に必要な参照先を確認する。

| 確認したいこと | 正本・保存先 |
| --- | --- |
| 本文用画像の保存先 | [img](./img/)。HTML・CSSの図は`html-css/`へ置く |
| 保存・命名・参照や形式別の規約 | [画像規約ルーター](./image-rules/00_画像規約ルーター.md)から今回必要な規約を選ぶ |
| 画像と記事・採用版の対応 | [画像一覧（Codex用）](../00_Wiki共通/02_再整理/04_画像一覧%28Codex用%29.md)、[画像一覧（ユーザー用）](../00_Wiki共通/02_再整理/03_画像一覧%28ユーザー用%29.md) |

このマップは所在の案内とし、保存・命名の規則は画像共通規約、r・uや状態の意味は[再整理マップ](../00_Wiki共通/02_再整理/00_再整理マップ.md#用語と状態の意味)へ集約する。毎回の全規約・全画像の走査は行わない。
