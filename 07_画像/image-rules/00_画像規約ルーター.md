# 画像規約ルーター

Wiki本文用の画像を作成・追加・使用・編集するときだけ使う内部ルーター。画像の作業がないときは読まない。

## 作業から読む規約を選ぶ

最初に[画像共通規約](./01_画像共通規約.md)を読む。GPT作成のSVGや完成図をそのまま取り込む場合は、[取り込みの確認範囲](./01_画像共通規約.md#提供されたsvg完成図の取り込み)だけを使い、描き直し用の規約は追加で読まない。それ以外は下表の該当する行だけを追加し、対象本文と照合する。自作の説明図は[図の種類と見た目](./02_説明図共通規約.md#図の種類と見た目)で、配置・寸法を示す図と、情報・処理・比較を整理する図や表を区別する。

| 今回の作業 | 追加で読む規約 |
| --- | --- |
| 画像の保存先・命名・参照リンク・代替テキスト・未使用ファイルの整理だけを扱う | 追加なし |
| PNGのスクリーンショットを保存・掲載する | [PNG規約](./04_PNG規約.md) |
| 情報の多い説明図を分割・再構成する | [説明図共通規約](./02_説明図共通規約.md#一つずつ理解するための図)。SVGでは[静止図とアニメーションの選択](./03_SVG規約.md#静止図とアニメーションの選択)も確認する |
| 自作の静止説明図をSVGで作る・内容を直す | [説明図共通規約](./02_説明図共通規約.md)と[SVG規約](./03_SVG規約.md)。動きの節は不要 |
| 自作の説明図にSVGアニメーションを付ける・直す | [説明図共通規約](./02_説明図共通規約.md)と[SVG規約](./03_SVG規約.md)の動きの節まで |
| 自作の説明図をPNGで扱う・SVGから書き出す | [説明図共通規約](./02_説明図共通規約.md)と[PNG規約](./04_PNG規約.md)。書き出し元のSVGも編集する場合だけSVG規約を追加 |
| スクリーンショットへ説明用の文字・矢印を加える | [PNG規約](./04_PNG規約.md)と[説明図共通規約](./02_説明図共通規約.md)の文字・補助線の節。実際のUIへ説明図の配色を適用しない |

HTML・CSSの親子・兄弟の箱、margin・padding・border、Gridの行・列・gapを自作の図に描く場合だけ、形式を問わず[HTML・CSSの箱と余白](./05_HTML・CSSの箱と余白.md)も読む。高さ・画像の切り抜き・疑似要素の配置などで専用規約がなければ、説明図共通規約と対象本文を使い、未採用の設計判断で穴埋めしない。

## 規約の担当

- 保存・命名・形式選択・本文との対応は画像共通規約、説明の仕方と静止した見た目は説明図共通規約、形式固有の条件はPNG規約・SVG規約、題材に依存する配色や関係は分野別規約を正本とする。同じ規則を複製しない。
- 安全・権利・変更権限・例示数値と規約化の委任は[AGENTS](../../AGENTS.md)を優先する。画像規約を追加・整理するときだけ[規約更新の手順](./01_画像共通規約.md#規約を更新するとき)を使い、配置を変えた場合はこの表と関係する参照を同時に直す。
- 参照リンクは必要な条件の確認先であり、リンク先を再帰的にすべて読む指示ではない。
- 全規約を順番に読み直さず、今回の作業・形式・題材で選ぶ。通常作業で毎回全repo・全画像を走査しない。
