# 画像規約ルーター

Wiki本文用の画像の配置・数値調整・再評価を行うときに、必要な確認先だけを選ぶ内部ルーター。画像の作業がないときは読まない。

## 作業から読む規約を選ぶ

最初に[画像共通規約](./01_画像共通規約.md)を読む。GPT／Workが図の基本の制作を担当し、Codexは採用候補の再評価・整合確認、保存・命名・参照と数値調整を担当する。確認と制作を分け、形・構成・色を既存の規約へ合わせ直さない。

| 今回の作業 | 追加で読む規約 |
| --- | --- |
| 提供されたSVG・完成図の取り込み、保存先・命名・相対リンクの整備 | 追加なし。[取り込み手順](./01_画像共通規約.md#提供されたsvg完成図の取り込み)を使う |
| 例示数値を切りのよい値へ調整し、本文・コード・図を同期する | [AGENTSの例示数値の置換](../../AGENTS.md#例示数値の置換)。描き直し用の規約は追加しない |
| 本文・図の説明や可読性を再評価する | [説明図共通規約](./02_説明図共通規約.md)の必要な項目。再評価を修正許可と扱わない |
| SVGの代替説明、表示、アニメーションを確認する | [SVG規約](./03_SVG規約.md)の対象部分 |
| PNGの画面記録・静止画書き出しを扱う | [PNG規約](./04_PNG規約.md) |
| HTML・CSSの箱・余白・Gridの図の数値や関係を確認する | [HTML・CSSの箱と余白](./05_HTML・CSSの箱と余白.md)の必要な項目 |

## 規約の担当

- 基本の制作方針は[GPT／Work用指示文](../../00_Wiki共通/01_Wikiの運用思想/AGENTS_Work.md#本文コード図をどう作るか)、Codexの変更権限と数値調整は[AGENTS](../../AGENTS.md#変更権限と同期)を正本とする。
- 保存・命名・提供図の扱いは画像共通規約、図の再評価は説明図共通規約、形式固有の確認はSVG・PNG規約、HTML・CSSの関係の確認は分野別規約へ分ける。同じ規則を複製しない。
- 参照先を再帰的にすべて読む指示ではない。今回の対象と確認内容から必要な部分だけを読み、毎回の全規約・全repo・全画像の走査は増やさない。
