# 下へ寄せるときはどの箱の余った高さを使うか

たとえば高さ500pxのカードがあって、中身を入れてもまだ場所が余っているとする。

画像は200px、タイトル・文章・日付を合わせた中身は150px。残りの150pxが空いているものとする。

日付を下にそろえたときのイメージは、こんな形。
```text
┌────── card 500px ──────┐
│ 画像 200px             │
├────────────────────────┤
│ タイトル               │
│ 文章                   │
│ 文字・日付で150px      │
│                        │
│ あまり 150px           │
│                        │
│ 日付                   │
└────────────────────────┘
```

日付を一番下に置きたい。

そこで、
```css
.meta {
  margin-top: auto;
}
```

を付ける。

これはまず、

> **日付より上に、余っている場所を全部入れる**

くらいで理解していい。

すると、
```text
┌────── card 500px ──────┐
│ 画像 200px             │
├────────────────────────┤
│ タイトル               │
│ 文章                   │
│ 文字・日付で150px      │
│                        │
│ ↑                      │
│ 余り150pxを            │
│ 日付の上へ             │
│                        │
│ 日付                   │
└────────────────────────┘
```

になる。

---

問題は `.body` が増えたとき。

最初はこれだった。
```text
.card
├─ image
├─ title
├─ text
└─ meta
```

つまり全部が同じ箱 `.card` に直接入っている。

だから、

> `.card` に余っている場所を `.meta` の上へ入れる

でいい。

でもこう変える。
```text
.card
├─ image
└─ body
   ├─ title
   ├─ text
   └─ meta
```

ここが大事。

今、日付 `.meta` がいるのは、
```text
.card
```

の中に直接ではなく、
```text
.body
```

の中。

箱で描くと、
```text
┌─────────── card 500px ───────────┐
│ 画像 200px                       │
│                                  │
│ ┌────── body 150px ──────┐       │
│ │ タイトル               │       │
│ │ 文章                   │       │
│ │ 日付                   │       │
│ └────────────────────────┘       │
│                                  │
│ 余り150px（bodyの外）            │
└──────────────────────────────────┘
```

ここで `.body` が中身ぴったりの小さい箱だったら、
```text
┌────── body 150px ──────┐
│ タイトル               │
│ 文章                   │
│ 日付                   │
└────────────────────────┘
```

**余っている場所がない。**

だから、
```css
.meta {
  margin-top: auto;
}
```

と言われても、

> 「日付の上に入れる余りがないよ」

となる。

そこでまず、
```css
.body {
  flex: 1;
}
```

で `.body` を下まで伸ばす。

[flex: 1とは？どこがどう伸びるの？](../../../06_疑問/01_HTML・CSS/09_レイアウト/flex1とは・どこがどう伸びるのか.md)

```text
┌────── body 300px ──────┐
│ タイトル               │
│ 文章                   │
│ 日付                   │
│                        │
│ 余り150px（bodyの中）  │
│                        │
└────────────────────────┘
```

これで `.body` の中に余る場所ができる。箱が伸びただけなので、日付を下へ寄せるのは次の指定。

そのあと、
```css
.meta {
  margin-top: auto;
}
```

で、その余りを日付の上へ入れる。

## 覚えることは2個だけ
```text
① 日付は、どの箱の中にいる？
② その箱には、余っている高さがある？
```

これだけ。

`.meta` が `.card` の中に直接いるなら、
```text
.card の余りを使う
```

`.meta` が `.body` の中にいるなら、
```text
.body の余りを使う
```

でも `.body` に余りがないなら、
```css
.body {
  flex: 1;
}
```

などで、まず `.body` を伸ばす。

## 一言でいうと

> **下へ寄せたいものが「どの箱の中にいるか」を見る。その箱に空いている場所があれば、その空きを上に入れて下へ押せる。**

ここでは箱の中身を縦Flexで並べているものとする。必要な設定は、[02のカード下寄せのコード](../../../02_基礎/01_HTML・CSS/15_UI部品の実装判断/07_カードの可変本文と下寄せ要素を両立する.md)で確認できる。
