# 05_line-heightの算出値と継承を区別する

**算出値は、すべてをpxにした値とは限りません。** `line-height: 1.5`では、算出値も`1.5`です。親で行高が30pxになっていても、子へは倍率の`1.5`が渡ります。

[基礎の「line-heightの指定値と継承」](../../02_基礎/01_HTML・CSS/08_インラインと行の仕組み/02_line-heightの指定値と継承.md)では、単位なし・％・emで子の行高がどう変わるかを確認しました。ここでは、その違いを「指定値」「算出値」「使用値」と、親から子への継承に分けて追います。

## 算出値は、どこまで決まった値なのか

CSSの値には、決まる段階に応じた名前があります。今回の比較では、次の三つを区別します。

| 名前 | 今回確認すること |
| --- | --- |
| 指定値 | カスケードと、継承・初期値などによる補完を経て、その要素に定まった値 |
| 算出値 | プロパティの規則に従い、指定値から必要な依存関係を解決した値。継承では、この値が親から子へ渡る |
| 使用値 | 算出値から残りの計算を行い、表示の組み立てに使う値 |

算出値は「計算式そのもの」という意味ではありません。ただし、「算出」という名前だからといって、すべてのプロパティがこの段階でpxの長さになるわけでもありません。**何を算出値とするかは、各プロパティの規則で決まります。**

`line-height`では、単位なしの数値はその数値のまま、％やemによる長さは計算した長さが算出値になります。

## 親では同じ30pxでも、子へ渡る値が違う

次の図では、親の文字サイズは20px、子は32pxです。子自身には`line-height`を指定せず、親から継承する条件で比べます。

![親20px・子32pxで比較。line-heightが1.5なら親の算出値1.5を子へ継承して使用値48px、150%なら親の算出値30pxを子へ継承して使用値30pxになる](../../07_画像/img/html-css/03_01_05_算出値と継承値の違い.svg)

### 単位なしの1.5は、算出値も1.5

親に`line-height: 1.5`を指定した場合、親の指定値は`1.5`、算出値も`1.5`です。行高として使うときに、親の文字サイズ20pxと掛け合わせます。

親の使用値は`20px × 1.5 = 30px`です。しかし、継承で渡すのは使用値の30pxではなく、**親の算出値である1.5**です。

子は`1.5`を受け取り、子自身の文字サイズ32pxを使うため、使用値は`32px × 1.5 = 48px`になります。親と子で倍率は同じでも、掛け合わせる文字サイズが違います。

### 150%は、親の算出値が30pxになる

親に`line-height: 150%`を指定した場合、親の指定値は`150%`です。`line-height`の％は、その要素自身の文字サイズを基準に計算するため、親では`20px × 150% = 30px`が算出値になります。今回の使用値も30pxです。

子へ渡るのは、**親の算出値である30pxという長さ**です。子が受け取った時点で倍率ではないので、子の32pxへ改めて150%を掛けることはありません。子の使用値も30pxのままです。

このため、親ではどちらも30pxだった行高が、子では48pxと30pxに分かれます。

## 継承値と算出値は、何が違うのか

「継承値」は、子から見て、親から受け継ぐ値を指します。**子の継承値は、親の算出値です。** 算出値と無関係な、別の値が用意されるわけではありません。

図の左側なら、親の算出値は`1.5`で、子の継承値も`1.5`です。右側なら、親の算出値は`30px`で、子の継承値も`30px`です。親側での値の段階と、子がどこから受け取ったかを分けて呼んでいます。

また、子自身に`line-height`の指定があれば、通常はその指定が使われます。今回の図は、子にその指定がなく、親から受け継ぐ条件の比較です。

図の48px・30pxは`line-height`の使用値であり、文字の字形の高さや、どんな内容でも必ずそうなる行ボックス全体の高さを表すものではありません。画像や異なる大きさの文字が行内にある場合などは、行全体に必要な高さが変わることがあります。

## DevToolsのpx表示だけで、継承値を決めつけない

`getComputedStyle()`は、名前にcomputedとあっても、仕様上の算出値を常にその形のまま返すAPIではありません。プロパティに応じた「解決値」を返し、`line-height`では`normal`以外の場合、使用値が返ります。

そのため、親で30pxと表示されたことだけを根拠に「子へ30pxが継承された」とは判断できません。親に書いた指定が単位なしの`1.5`なのか、`150%`などなのかを併せて確認します。図の左側では、親で使用する行高は30pxでも、子へ渡る算出値は`1.5`です。
