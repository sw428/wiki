# 00_JavaScript設計整理マップ

## 目的

このフォルダは、JavaScriptで実装判断が分かれやすい設計方針をまとめる場所。

文法やDOM APIそのものの説明ではなく、関数、モジュール、イベント、UI状態をどう分けるかという自分の採用判断を置く。

- [関数設計](../../JS/07_関数設計.md)
- [モジュール分割](../../JS/09_モジュール分割.md)
- [UI実装パターン](../../JS/03_UI実装パターン.md)
- [DOMとイベント](../../JS/02_DOMとイベント.md)

## 置くもの

- 関数をどの粒度で分けるか
- DOM取得、イベント登録、状態更新、描画反映の責務分離
- モジュール分割の単位
- UIコンポーネントごとの状態管理
- ケース検証から戻した、案件を超えて使うJavaScript設計判断

## 置かないもの

- 文法の一般説明だけで済む内容
- そのAPIの仕様確認
- 案件固有のDOM構造や一回限りの実装手順
- WordPressやPHP側の都合で決まる内容

## 現時点の扱い

既存のJSノートはすぐに移動しない。
設計として再利用する判断が増えたものから、このフォルダへ正本化する。
