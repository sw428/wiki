# 箱の中央に文字を重ねる

## 0. そもそも

操作するのは、HTMLに書いた2つの要素。外側のdivが表示する場所、内側のpが文字を入れる箱になる。

```text
div.demo       ← 幅と高さを決める場所
└─ p.demo__text ← この箱を広げ、中の文字を中央へ置く
```

## 1. やること

横300px・縦180pxの色付きの箱に、「お知らせ」を重ねて中央に置く。まずは画像なしで、どの指定がどこに効くか試す。

## 2. 作り方

HTMLには、次の2要素を書く。

```html
<div class="demo">
  <p class="demo__text">お知らせ</p>
</div>
```

CSSには、クラス名に対応する次の指定を書く。

```css
.demo {
  position: relative; /* 文字を重ねる位置の基準 */
  width: 300px;
  height: 180px;
  background: #dceeff;
}

.demo__text {
  margin: 0;          /* pの初期余白をなくす */
  position: absolute;
  inset: 0;           /* pの箱を上下左右の端まで広げる */
  display: grid;
  place-items: center; /* pの中の文字を中央へ置く */
}
```

色付きの箱の中央に「お知らせ」が出れば、この例は成功。

どちらの指定が効いているか分からなくなったら、`.demo__text`の`display: grid`と`place-items: center`を一時的に外す。pの箱は全面のまま、文字は左上に戻る。確認したら2行を戻す。

## 3. なぜ

`.demo`の`position: relative`で、ここを重ねる位置の基準にする。

`.demo__text`の`absolute`と`inset: 0`は、pの箱をその範囲に広げる。この例ではpの幅・高さを固定していないため、端の位置からサイズが決まる。文字の大きさは変わらない。

その後、`grid`と`place-items: center`で、箱の中の文字を中央に置く。仕様上の条件は[絶対配置のサイズ計算](https://www.w3.org/TR/CSS22/visudet.html#abs-non-replaced-width)を参照。

## 4. 困ったとき

| 画面の状態 | この例で確認する場所 |
| --- | --- |
| pが別の場所に重なる | `.demo`に`position: relative`が付いているか |
| 色付きの箱に高さがない | `.demo`の`height: 180px`が効いているか |
| 上下に隙間がある | `.demo__text`の`margin: 0`が効いているか |
| 文字が中央に来ない | `grid`と`place-items`をp側に書いたか |
| pの箱が小さい | 既存CSSでpに幅・高さが指定されていないか |

次へ進む目安は、pの箱を広げる指定と、中の文字を中央にする指定を区別して確認できること。

画像へ重ねたい場合は[画像の上に文字を重ねる基本形](../01_読めるようにする/HTML・CSS/10_メディア設計（img・video・object-fit・aspect-ratio）.md#画像の上に文字を重ねる基本形)へ進む。画像が通常の配置に残って外側の高さを作るので、この練習用の固定高さはそのまま持ち込まない。

imgだけ広がらない場合は[条件の違い](../03_深く分かる・詰まった時に調べる/insetで広がる条件を調べる.md)を見る。
