# 画像共通規約

Wiki本文で使うSVG・PNG・JPEGなどの管理と形式選択、本文との対応を扱う。安全・変更権限・権利・例示数値は[AGENTS](../AGENTS.md)を優先する。

## 保存・命名・参照

- Wiki本文で使う画像・図は、トップ階層の `img/` に集約し、`img/html-css/` など主な内容の分野ごとに分ける。分野フォルダは画像が必要になったときに作り、増えて探しにくくなった分野だけ下位分類を追加する
- 同じ画像を01・02・03などで使う場合も、画像ファイルは一つにして各本文から参照する。最初の使用先で付けた番号・名前を保ち、本文の移動・再分類に合わせて画像の保存先を変更しない
- SVG・PNGは、作成・追加・使用・編集時に `学習区分番号_章フォルダ番号_記事番号_内容名.拡張子` の名前にそろえる。図だけでなく、DevToolsやFigmaのスクリーンショットのPNGにも適用する。番号は最初に使用する記事の学習区分・章フォルダ・記事ファイル先頭の番号にそろえてゼロ埋めする。例：`02_06_01_DevTools_Stylesペイン.png`。使用先が分からない場合は番号を推測せず確認する
- 本文から画像へは、本文ファイルからの相対パスで参照する。画像だけのフォルダには00系の整理マップを作らない
- 保存対象の公開可否は[AGENTSの守秘義務・著作権・素材の扱い](../AGENTS.md#守秘義務著作権素材の扱い)に従う。コード例に登場する制作サイト側の `img/` や案件の素材構成は、このWikiの画像配置ルールによって変更しない
- 同じテーマの比較図は、内容名に `paddingあり` や `指定前` などの違いを示す。改名時は参照元を確認し、対応するPNGがあれば同時に改名して画像リンクを更新する。同名ファイルは上書きせず、内容名で区別する

## 未使用ファイルの整理

- ユーザーの委任により、図を規約に沿って修正・作り直し・差し替えた後は、不要になった元図・旧版・中間生成物・予備PNGを、その作業内で随時削除する。この範囲では削除の都度確認を求めない。
- 削除前に、採用する図が保存され必要な参照が切り替わっていることと、対象ファイルにほかの記事・コード・設定からの参照や独立した利用目的がないことを確認する。参照がなくても、使用中のPNGの編集元SVGや、閲覧・検証・納品などに必要なファイルは残す。用途が不明なものは、参照がないことだけを理由に削除しない。
- 削除したファイルと理由はCHANGELOGへ記録し、残した図と参照リンクを確認する。過去のCHANGELOGや保存専用のAI対話ログは書き換えない。
- 通常は今回の対象図と、その差し替えで不要になる関連ファイルを確認する。全画像の点検は明示依頼時だけ行い、毎回の全repo走査や定期削除の処理は増やさない。

## 図と画面画像の形式を選ぶ

| 用途 | 形式 | 理由 |
| --- | --- | --- |
| CSSの仕組みを説明する図 | SVG | 線・文字・枠を編集できる |
| Grid・Flexboxの配置図 | SVG | サイズを変えても鮮明 |
| グリフ・ベースラインの図 | SVG | 座標や補助線を表現しやすい |
| 動きのあるCSS解説図 | SVG | アニメーションを付けられる |
| DevToolsのスクリーンショット | PNG | 画面のピクセル情報を保持できる |
| Figmaの操作画面 | PNG | UIの状態をそのまま記録できる |

編集できる説明図はSVGを元ファイルとして保存する。PNGでの画面記録と、SVGからの必要な書き出しは[PNG規約](./04_PNG規約.md)に従う。PNGを用意することだけを目的に、SVGと同じ図の予備を増やさない。

## 本文・画像・代替説明の対応

- 図に載せるCSSのpx指定値は、[AGENTSの例示数値の置換](../AGENTS.md#例示数値の置換)にある10px刻みの基準に従い、本文・コード・計算式・図を同期する。計算結果や、表示用の文字サイズ・線幅・描画座標は指定値と区別して同じ基準を機械的に当てない。既存例の修正も、依頼された範囲で同じように同期する。
- Wiki本文に掲載する図・画面画像は、SVG・PNG・JPEGなどの形式を問わず、代替テキスト（Markdownの画像説明・HTMLの`alt`）を、掲載先で扱う項目、本文の説明、実際の画像内容にそろえる。代替テキストは、その文脈で画像が伝える要点を示す。同じ文言へ機械的に統一したり、ファイル名・見た目の羅列だけで済ませたりせず、比較対象、指定する対象、位置・寸法・動き、表示される結果など、その画像で読者が確認する内容を合わせる。本文だけで説明している挙動や、図示していない結果を画像の説明へ混ぜない。長い説明が必要な場合は本文で補い、短い代替テキストへすべて詰め込まない
- 共用画像の代替テキストは掲載先の文脈に合わせ、画像内の説明も各参照元と矛盾させない。作成・使用・編集時には、承認された対象の画像と参照元で説明の対応を確認する。01・06を含む本文の変更権限は従来の規則に従い、説明の同期だけを理由に本文・コード・図の描画内容へ変更を広げない。全体点検は明示された場合に行い、通常作業で毎回全repoを走査しない

SVG内のtitle・descは[SVG規約](./03_SVG規約.md#svg内の代替説明)に従う。PNGの静止画にアニメーション自体の動きを図示済みとして説明しない。
