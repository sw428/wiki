# Wikiの運用思想

このフォルダは、このWikiで採用している運用思想の正本です。

公開向けのルートREADMEでは、何のWikiか、何を見ればよいか、公開範囲、参考元、権利関係、利用条件を中心に扱います。ここでは、ChatGPT / Codex / 自分の三者運用、Wikiの正本管理、目的別のチューニング、社会や教育システムとの距離感、利用プランやモデルの違いが認知支援へ与える影響の検証を扱います。

## 目的

このWikiは、会話ログを網羅的にそのまま保存する場所ではありません。ただし、AIがラフな入力をどう解釈したか、認識や運用判断がどう変化したかなど、対話過程自体に検証・提示する価値があるものは、正本と区別して root の `AI対話ログ` に原文を残します。この保存領域から、知識や判断を他のファイルへ自動反映しません。

実装中に生じた疑問、判断、認識の変化をもとに、再利用しやすい知識へ整理するための外部知識基盤です。

ChatGPTは現在の対話と判断を進める司令塔、Wikiは採用済み判断を保存する長期的な正本、Codexは既存状態を確認しながら正本へ安全に反映する実作業担当として分けます。

目標は、すべてを覚えることでも、すべてを細かく分類することでもありません。迷ったときに戻る場所を減らし、確認する順番と判断軸を絞り、実装へ戻りやすくすることです。

ChatGPT / Codex / 検索 / DevToolsを使う前提で、問題の入口、確認順、質問の立て方、回答を採用してよいかの判断、最終表示での確認を残します。すべてを自力で解くことではなく、外部ツールを使っても判断を雑にしないことを目指します。

## 基本方針

- ChatGPTは思考整理と方針確認を担当する
- Codexは知識の整理、統合、反映を担当する
- 自分は検証と最終判断を担当する
- 会話中の回答をそのまま正解として保存しない
- Wikiを長期的な知識と判断の正本にする
- 不確定な内容は無理に確定せず、保留として残す
- 一般的な知識とプロジェクト固有の判断を分ける
- AIの出力は、必要に応じて外部資料や実務上の評価と照合する
