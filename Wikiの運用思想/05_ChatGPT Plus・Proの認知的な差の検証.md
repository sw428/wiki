# ChatGPT Plus / Pro の認知的な差の検証

> [!IMPORTANT]
> このページは現時点の結論ではなく、1か月程度の比較を行うための仮説と検証計画である。契約プランを変えただけで認知支援の質が向上したと決めず、実際の使用条件と継続的な観測結果を分けて記録する。

## 目的

ChatGPT Proを一定期間使用し、Plusとの差が「処理できるタスク量」や「長大なタスクへの強さ」だけではなく、日常的な学習や判断そのものの質に現れるかを観測する。

今回特に確認したいのは、Proでより重い処理ができるかだけではない。実際に使用するモデルや推論設定などの条件が変わったとき、通常の質問や学習に対しても、次の要素に継続的な底上げがあるかを確認する。

- 問題への認知的なアプローチ
- 観点の選び方
- 分析の深さ
- 複数情報間の整合性
- 前提や例外の拾い方
- レビュー時の違和感検出
- 説明の組み立て方
- 自分の理解状態に合わせた説明調整
- 「何が分かっていないか」の特定
- 一見正しい回答からさらに一段掘る能力

## 比較前に分けて記録するもの

「PlusからProへ変更したこと」と「別のモデルや推論設定を使用したこと」は同じではない。差の原因を取り違えないため、少なくとも次を分ける。

| 条件       | 記録する内容                                                             |
| ---------- | ------------------------------------------------------------------------ |
| 契約プラン | Plus / Pro                                                               |
| 使用モデル | 画面や設定に表示されたモデル名                                           |
| 推論設定   | Light / Medium / High / Extra High / Max / Ultraなど、実際に選択した設定 |
| 会話条件   | 新規会話か、既存文脈を引き継いだ会話か                                   |
| 使用機能   | Web検索、ファイル参照、Codex、サブエージェントなど                       |
| 処理可能量 | 利用上限、長い文脈、再確認の回数によって得られた差                       |

現行のOpenAI資料では、PlusとProの両方にGPT-5.6 Solの利用枠が記載されている。また、モデル選択と推論レベルは別の項目として説明されている。そのため、「Pro契約へ変えると必ず別モデルになる」とは先に決めず、実際の表示と設定を記録して比較する。

なお、OpenAI APIで説明されている `Pro mode` は、選択中のGPT-5.6モデルにより多くの処理を行わせる実行モードであり、別のPro用モデル名へ切り替える仕組みではない。契約プランのProと、モデルの実行モードとしてのProを混同しない。

## 見たい差

重要なのは、一部の非常に難しいタスクだけで大差が出るかではない。

通常の学習全体に影響する要素が、それぞれ数％ずつでも改善するかを見る。

例えば、次のような小さな変化を対象にする。

- 問題の意図を少し正確に取れる
- 説明の順序が少し自分に合いやすい
- 前提の抜けに少し気付きやすい
- 比較対象の選び方が少し適切になる
- 矛盾を少し早く検出できる
- レビューで見落とす論点が少し減る
- 一般論ではなく、現在の疑問に必要な角度から入りやすい

小さな差でも、それが毎回発生するなら学習全体への影響は大きい。そのため、単純なベンチマーク上の性能差ではなく、**日常的な認知支援の質が継続的に変わるか**を主な評価対象にする。

## なぜ自分で比較するか

すでにPlusとCodexを継続的に使っているため、現在の回答傾向、説明の癖、分析の深さ、かみ合わない場面について、ある程度の基準ができている。

その状態でProを一定期間使えば、次のような変化が継続して発生した場合に気付きやすいと考える。

- いつもと違う観点が出る
- 説明の組み立てが変わる
- レビュー時の指摘が深くなる
- 今まで拾われなかった前提を拾う
- 同じ種類の質問でも納得感が上がる

ただし、これは現時点では仮説であり、実際に差があるかは使用して観測する。

## 検証方法

1か月程度Proを使用し、特別に重いタスクだけを試すのではなく、普段Plusで行っている学習をそのまま継続する。

対象には、次を含める。

- HTML / CSS / JavaScriptの理解
- 資格問題の解説
- 実装レビュー
- Wikiへの知識整理
- 概念同士の比較
- 自分が納得できていない説明の再構成
- 記憶しづらい内容の説明方法変更
- 複数の既存知識との整合性確認

### 日常利用と条件をそろえた比較を分ける

- 日常利用では、Proへ変えたあとの全体的な回答傾向を観測する。
- 条件をそろえた比較では、Plusで保存した質問と回答の一部を基準にし、Pro側でも同じ質問を新規会話で試す。
- 完全に同じ問題だけでなく、同じ種類で内容の異なる問題でも改善が再現するかを見る。
- 可能であれば、回答がPlusかProかを意識せずに先に内容だけを読み、あとから条件を確認する。

### 最小の記録項目

毎回詳細な採点表を作ること自体を負担にしない。差を感じた回答を中心に、次を短く残す。

```txt
日付:
質問の種類:
契約プラン:
使用モデル・推論設定:
会話条件・使用機能:
以前との差:
良くなった点 / 悪くなった点:
事実誤認や前提漏れ:
単なる長文化ではないと判断した理由:
```

同じ方向の差が複数回現れたときだけ、継続的な傾向の候補として扱う。

## 評価するときの注意

単発で非常に良い回答が出たことだけでは判断しない。見るのは、**複数の異なる学習場面で、同じ方向の改善が繰り返し観測されるか**である。

また、次の影響と、モデルや推論設定による質的な変化をできるだけ分けて考える。

- 自分自身の知識が増えた影響
- プロンプトの違い
- 会話コンテキストの違い
- 問題との偶然の相性
- 単なる回答の長文化
- 有料プランへ変更したことによる期待や先入観
- 検証期間中に行われたモデル更新
- Web検索やファイル参照など、使用できた機能の違い

文章が整っていることと、前提が正しいことも分ける。もっともらしい説明が増えても、事実誤認、過剰な一般化、例外の欠落が減っていなければ、認知支援の質が上がったとは判断しない。

## 運用判断

Proによって、複数種類の日常学習で小さくても同じ方向の改善が繰り返し確認できた場合、Proの価値を「難しい仕事をするときだけ使うもの」とは考えない。学習全体に対する認知支援の質を少しずつ底上げするものとして評価する。

一方で、Plusとの差が主に非常に重い処理、長い文脈、再確認できる回数などにしか現れない場合は、常時Proにする必要性は低い。

その場合は、**普段はPlusを使用し、必要な期間だけProを使ってWikiや理解状態を再評価する**運用も候補にする。

差が安定して観測できない場合は、モデルが違うはずだという期待だけでProを継続しない。費用、利用頻度、改善した場面を合わせて判断する。

## 現時点の仮説

現時点では、**Proの価値があるとすれば「できるタスクの量が増えること」だけではなく、普段の認知・分析・レビュー・整合性確認の質が少しずつ底上げされ、その差が長期学習全体へ累積することではないか**という仮説を持っている。

実際にその差が存在するかは、Proを一定期間日常利用したうえで判断する。
