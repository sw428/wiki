# 外部知識基盤と正本管理

## このページの役割

Wiki、ChatGPTのメモリ、会話ログの役割を分け、長期的に残す判断や設計原則をWikiへ集約する方針を扱います。

## 会話を正本にしない

会話そのものを正本にすると、途中の仮説、言い換え、採用しなかった案まで混ざり、あとから現在の判断を復元しにくくなります。

長期的に残したい判断や設計原則は、このWikiのファイルを正本にします。

ChatGPTのメモリは、知識そのものを大量に保持する場所ではなく、何を参照するか、どう判断するかの索引として扱います。

```txt
メモリ
-> 何を参照するか、どう判断するか

Wiki
-> 実際の知識、採用理由、現在状態

会話
-> 作業中の思考、検討、仮説
```

## 対話過程そのものを残す場合

会話を正本にはしないが、対話の流れ自体に検証・提示する価値があるものは、選択して [`AI対話ログ`](../AI対話ログ/00_AI対話ログ整理マップ.md) に残します。

ここでは、AIの回答だけでなく、ラフな日本語、誤字、言い直しを含む入力から意図がどう受け取られたかも確認対象にします。そのためログ本文は要約・校正せず、原文のまま保存します。

ログに含まれる説明を確認済み事実や現行ルールとは扱いません。また、ログから知識や判断を自動で抽出・反映しません。ユーザーが特定の内容の反映を明示した場合だけ、ログ保存とは別の作業として既存正本と照合します。モデル名や機能など変化する情報は、その作業時点で再確認します。

## 区切りで分類する

以下は通常の会話や実装内容をWikiへ統合する場合の処理であり、保存・提示専用の `AI対話ログ` には自動適用しません。

会話や実装の区切りでは、内容を次のように分けて確認します。

- 確定事項: 今回正式に採用したルール
- 一般原則: 別の案件でも再利用できる知識
- 一時情報: 現在の作業状態や仮の数値
- 破棄事項: 検討したが採用しなかった案

確定事項と一般原則は、適切なWikiの正本へ反映します。一時情報は必要な期間だけ残し、破棄事項は現在のルールと混ざらないようにします。

## 目指す状態

目指すのは、記憶を増やすことではなく、少ない情報から必要な文脈を再構成できる状態です。

そのために、次を優先します。

- 同じ話題の正本を複数作らない
- 現在の採用判断と、途中の仮説を分ける
- 判断の条件、理由、例外を残す
- 案件固有の条件と、再利用できる原則を分ける
- 不確定な内容を無理に恒久ルールへしない
