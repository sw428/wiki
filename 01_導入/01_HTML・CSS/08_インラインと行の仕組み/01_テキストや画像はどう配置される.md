# テキストや画像はどう配置される？

初学者が陥りやすい認識の一つに、

「タグごとに`display`が決まっているなら、その中身も同じ扱いになる」

というものがあります。

例えば`p`タグ。
```html
<p>こんにちは</p>
```

ブラウザの標準では、`p`要素は基本的にブロックとして扱われます。
```css
p {
  display: block;
}
```

つまり、`p`そのものは横方向に広がる箱です。
```text
p
┌──────────────────────────────┐
│ こんにちは                    │
└──────────────────────────────┘
```

ただし、その中にある「こんにちは」という文字までブロックになるわけではありません。

テキスト自体はHTML要素ではないので、厳密には「インライン要素」とは呼びません。

`p`の中にある文字は、**インライン方向に並ぶ内容**として配置されます。

つまり、
```text
ブロックの箱
└─ その中にインライン方向で並ぶ文字
```

という関係です。

画像を表す`img`要素も、ブラウザの標準では基本的にインラインレベルの要素として扱われます。

ここで大切なのは、

> 外側のタグがブロックだからといって、中にある内容まで全部ブロックになるわけではない

ということです。

---

## `text-align: center;`は何を中央にしている？

文字を中央にするとき、
```css
text-align: center;
```

を使います。

このとき、

「中央にしたい要素の親要素に`text-align: center;`を指定する」

と説明されることがあります。

この説明自体は間違いではありません。

ただし、「親要素」という言葉だけで覚えると、

「`p`をさらに`div`で囲まないといけないの？」

と考えてしまうことがあります。

例えば、
```html
<div>
  <p>こんにちは</p>
</div>
```

という構造があったとします。
```text
div
└─ p
   └─ 「こんにちは」
```

「こんにちは」という文字を直接入れている箱は`p`です。

なので、
```css
p {
  text-align: center;
}
```

と、`p`自身に指定して問題ありません。

わざわざ外側の`div`に指定しなければならないわけではありません。

---

## 実際に確認する
```html
<div>
  <p>こんにちは</p>
</div>
```
```css
div {
  width: 300px;
  border: 2px solid #333;
}

p {
  background: #eee;
  text-align: center;
}
```

表示のイメージはこうです。
```text
┌──────────────────────────────┐
│          こんにちは           │
└──────────────────────────────┘
```

ここで中央に移動しているのは、`p`そのものではありません。

`p`という箱はその場所にあるままです。

その**箱の中にある文字が中央揃えになっています。**

つまり、
```css
text-align: center;
```

は、
```text
指定した要素そのものを中央に移動する
```

ための指定ではありません。

その要素の中にある文字やインラインレベルの内容を、
```text
左寄せ
中央寄せ
右寄せ
```

のどこに配置するかを決める指定です。

---

## 外側の要素に指定しても中央になる

では、こちらはどうでしょう。
```html
<div>
  <p>こんにちは</p>
</div>
```
```css
div {
  width: 300px;
  border: 2px solid #333;
  text-align: center;
}
```

これでも文字は中央になります。

これは`text-align`が継承されるプロパティだからです。
```text
div
text-align: center;
    ↓ 継承
p
    ↓
「こんにちは」が中央になる
```

つまり、
```css
div {
  text-align: center;
}
```

と書くこともできますし、
```css
p {
  text-align: center;
}
```

と書くこともできます。

---

## では、どちらに書けばいい？

仕様上はどちらでもできます。

例えば、
```html
<p>こんにちは</p>
```

この文字だけを中央にしたいのであれば、
```css
p {
  text-align: center;
}
```

と直接指定する方が分かりやすいことがあります。

一方で、
```html
<div>
  <p>こんにちは</p>
  <span>お知らせ</span>
  <a href="#">詳しく見る</a>
</div>
```

この中身をまとめて中央寄せしたいのであれば、
```css
div {
  text-align: center;
}
```

と親側にまとめて指定する方法もあります。

---

## 学習用コードでは余計なルールを入れない

今回の目的は、

- ブロックの箱とは何か
- その中の文字はどう配置されるのか
- `text-align`がどこに効くのか

を理解することです。

そのため、サンプルコードではクラス名やBEMのようなCSS設計ルールは使っていません。

例えば、
```html
<div>
  <p>こんにちは</p>
</div>
```

のように、HTML要素だけで十分です。クラス名を加えると、今回の説明では、
```text
なぜこの名前なの？
これがないと動かないの？
```

という、本題とは関係ない疑問が増える可能性があります。

学習用のサンプルでは、

> 今説明していること以外は、できるだけ単純にする

という考え方が大切です。

BEMはCSS設計を学ぶときに改めて扱えば十分です。

---

## できることと、適切な書き方は別

ここまでの話は、あくまでCSSの仕様としてどう動くかという話です。
```css
p {
  text-align: center;
}
```

と書くこともできますし、
```css
div {
  text-align: center;
}
```

として継承させることもできます。

ただし、

> 書けるかどうか

と、

> 実際のプロジェクトでその書き方が適切かどうか

は別の話です。

実務では、

- どこまでスタイルを適用したいのか
- 他の要素へ影響しないか
- CSSを見たときに意図が分かるか
- 後から変更しやすいか
- プロジェクトのルールに合っているか

なども考えます。

まず最初は、
```text
pはブロックの箱

その中に文字が入っている

文字はインライン方向に配置される

text-alignは箱そのものではなく
その中の文字やインライン内容の揃え方を決める
```

ここまで理解できれば十分です。
