# widthが箱ごとに決まる流れ

基礎の[パーセント指定と包含ブロック](../../../02_基礎/01_HTML・CSS/05_ボックスとdisplay/08_パーセント指定と包含ブロック.md)を読む前に、親と子の幅が決まる順序を確認する。

## まず親の幅が決まる

```css
.parent {
  max-width: 380px;
}
```

通常フローのブロック要素では、`width`の初期値は`auto`である。`.parent`は外側の利用可能な幅に合わせて広がり、380pxを超える場合は`max-width`で止まる。

```text
外側が300px → .parentは300px
外側が500px → .parentは380pxで止まる
```

このような場合、親に`width: 100%`を書かなくても同じ見た目になることがある。ただし、`auto`と`100%`は同じ値ではない。

## 次に子の幅が決まる

```css
.child {
  width: 100%;
}
```

単純な親子では、幅が決まった`.parent`が`.child`の包含ブロックになる。子はその幅を基準に、自分の`width: 100%`を計算する。

```text
外側の利用可能な幅
↓
.parentの幅が決まる
↓
.childが.parentを基準に100%を計算する
```

親の`width`が子へ継承されたわけではない。**親と子が、それぞれ自分の幅を決めている。**

## `auto`の見え方は箱の種類で変わる

| 箱 | 最初に押さえること |
| --- | --- |
| 通常のblock | `width: auto`では利用可能な横幅を使うように決まりやすい |
| 通常のinline | `width`は基本的に適用されず、内容に沿って並ぶ |
| inline-block | `width`を指定でき、`auto`では内容に応じた幅になりやすい |
| `img`などの置換要素 | `auto`では固有サイズや縦横比も幅の決定に関係する |

そのため、`auto`を一律に「親いっぱい」や「中身幅」とは覚えない。

## まず見る順序

```text
① どの種類の箱か
↓
② その箱にwidthが効くか
↓
③ widthがauto・%・pxのどれか
↓
④ %なら基準になる包含ブロックはどれか
↓
⑤ max-width・min-widthで止まっていないか
```

`height`は通常の内容量から決まることが多いため、ここでは混ぜない。横幅の流れをつかんだら、基礎記事へ戻って割合指定の違いや包含ブロックが変わる条件を確認する。
