# 05_テンプレート階層

## 目的

WordPressがどのテンプレートファイルを使うかの優先順位を整理する。

## 最初に見る結論

テンプレート階層は、WordPressが表示に使うPHPファイルを選ぶ順番。

## 見るポイント

- より具体的なテンプレートが優先される
- なければ汎用的なテンプレートへ戻る
- 最後は `index.php` が受け皿になる

## 分岐として読む

テンプレート階層は、条件に応じて使うファイルが変わる分岐として見ると分かりやすい。

カテゴリページなら、たとえば次のように探す。

```txt
category-hotel.php がある
↓
使う

なければ category.php
↓
なければ archive.php
↓
なければ index.php
```

プログラムの形に近づけると、次のような優先順位の分岐になる。

```php
if (file_exists('category-hotel.php')) {
  use_template('category-hotel.php');
} elseif (file_exists('category.php')) {
  use_template('category.php');
} elseif (file_exists('archive.php')) {
  use_template('archive.php');
} else {
  use_template('index.php');
}
```

実際にこのコードを自分で書くという意味ではなく、WordPressが内部で「条件に合うテンプレートを順番に探している」と読むためのイメージ。

## 例

- トップページ: `front-page.php`
- 投稿詳細: `single.php`
- 固定ページ: `page.php`
- 最後の受け皿: `index.php`

## 自分の頭に残すこと

- テンプレート階層はフォルダ構造ではない。
- どのPHPファイルが使われるかの優先順位。
- `if` / `else` のように、条件に応じて使うテンプレートが変わる分岐として読む。
