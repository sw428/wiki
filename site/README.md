# Wikiサイトの開発

このフォルダだけでVitePressの設定・依存ライブラリ・ページ・生成物を管理します。元のWiki本文と画像は読み取り専用です。VitePressは安定版の1.6.4に固定しています。

## 起動する

**Windowsでは、このフォルダの`起動.cmd`をダブルクリックするだけで起動できます。** 開いた画面はそのままにして、`http://127.0.0.1:5173/`をブラウザで開きます。停止は、その画面で`Ctrl+C`です。

Node.js 22以降が必要です。依存ライブラリがない場合は初回起動時に自動でインストールします。起動に失敗した場合は、エラーを確認できるよう画面を残します。

ターミナルから起動する場合は、WindowsのPowerShellで次を実行します。

```powershell
cd site
npm.cmd ci
npm.cmd run dev
```

`cd site`はWikiのトップ階層から実行する場合だけ必要です。すでに依存ライブラリをインストールしていれば、次回からは`npm.cmd run dev`だけで起動できます。

ターミナルに表示される`http://127.0.0.1:5173/`をブラウザで開きます。停止は`Ctrl+C`です。Windows以外では`npm.cmd`を`npm`に読み替えてください。

開発中は、掲載対象の記事・画像、`publish.json`、`pages/`、`assets/`の変更を監視して再同期します。取り込み処理そのものを変更した場合は開発サーバーを再起動してください。すでに使用中のポートでは自動で別ポートへ切り替わらず、エラーになります。

## 普段編集する場所

| 対象 | 編集先 |
| --- | --- |
| 記事本文 | Wiki側の元のMarkdown |
| 本文の図 | Wiki側の`img/` |
| 掲載範囲 | `publish.json` |
| サイトのトップページ | `pages/index.md` |
| サイトの利用案内 | `pages/terms.md` |
| サイトのタイトル・メニュー・検索 | `.vitepress/config.mjs` |
| サイトの配色・文字・余白 | `.vitepress/theme/style.css` |
| 右上の配色切り替え | `.vitepress/theme/ColorPalette.vue`・`palettes.mjs` |
| 取り込みの動作 | `scripts/sync.mjs`・`scripts/markdown.mjs` |

`generated/`は自動生成物です。直接編集しません。掲載記事のMarkdownは元ファイルとバイト単位で一致させ、リンクの変換は描画時に行います。本文・コード・図の例示数値は変更しません。

## 掲載対象

初期設定では、HTML・CSSの導入・基礎・詳細を掲載します。`05_参照`のカードは、掲載記事から参照されるものだけを取り込みます。`00_`で始まる内部ルーター、`90_`で始まる移行用フォルダ、スニペットは対象外です。対話ログ・案件検証・運用文書は取り込みません。

`publish.json`の`collections`で、入力フォルダと公開URLを対応させています。入力元は`01_導入`・`02_基礎`・`03_詳細`・`05_参照`配下だけに制限し、`site/`やWikiの外を参照できないようにしています。新しい分野を掲載するときは、対応する設定を追加してビルドします。

トップと上部メニューは「導入・基礎・詳細・用語」の順にそろえています。`excludeSitePages`に指定したサイト用ページは生成せず、検索にも含めません。`pages/guide.md`はこの設定で掲載対象外にしています。

右上の配色は緑・黄色・水色・青・藍・紫・ピンク・オレンジの8色から選べます。選択はブラウザ内に保存し、外部へ送信しません。保存できない環境でも、その画面での切り替えは使えます。明るい配色と暗い配色の両方に対応しています。どちらのモードでも左上のカテゴリ名はパレット色、目次のリンク文字は通常は灰色、選択中やマウス・キーボードで操作中はパレット色になります。本文の見出しと記事一覧の説明文は、ダークモードでは白、白背景では濃い文字で表示します。

- 記事内の相対リンクは、掲載記事のURLへ変換します。
- 内部ルーターへの参照は、同じカテゴリの人間向け記事一覧へ変換します。
- 対象外や存在しないページへの参照は、本文中に参照名を残してリンクを外します。
- 元記事に存在しない見出しへの参照は、掲載記事の先頭へ接続します。
- 画像は参照されている`img/`内のファイルだけを取り込み、同じ図は共有します。
- 利用案内は`pages/terms.md`を掲載します。元のWikiのREADMEからは自動転記しません。

参照名のリンク解除と見出しの不一致は、`.vitepress/generated/report.json`に記録します。`reason: not-published`は存在するが掲載していない参照先、`reason: missing-source`は元のWikiでも存在しない参照先です。この処理は表示用の変換であり、元の参照切れを修正するものではありません。図の描画内容や本文の説明の正確性を、自動検査の成功だけで確認済みとは扱いません。

## ビルド・確認する

```powershell
npm.cmd run test
npm.cmd run build
npm.cmd run preview
```

`build`は記事と画像の同期、HTML生成、検査を順に実行します。生成先は`dist/`です。検査では、元の本文・画像との一致、生成HTMLの内部リンク・画像・見出し参照、日本語・英語による検索結果を確認します。追加で検査だけを実行する場合は`npm.cmd run check`を使います。

`preview`は生成したサイトを確認するためのサーバーです。表示されたURLをブラウザで開いてください。検索は生成サイトでも動作し、日本語の単語分割を使います。実際に語句で検索して確認してください。

## サブパスへ公開する場合

この作業では外部への公開やGitHubへの送信は行いません。公開先を決めた後、生成した`dist/`を静的サイトとして配置できます。

ドメイン直下ではなく、例えば`https://example.com/wiki/`へ配置する場合は、公開先と同じパスを指定してビルドします。

```powershell
npm.cmd run build -- --base /wiki/
npm.cmd run preview
```

`preview`はビルド時の公開パスを自動で使います。ドメイン直下の設定に戻す場合は`npm.cmd run build -- --base /`で再ビルドします。環境変数`SITE_BASE`で指定することもできます。公開パスは、ローカルの`site/`というフォルダ名とは別です。

## Gitで管理するもの

設定・スクリプト・トップページ・スタイル・`package-lock.json`を管理します。依存ライブラリ、キャッシュ、取り込んだ記事・画像、公開用HTMLは`site/.gitignore`で除外します。別のGitリポジトリは作りません。

仕組みの確認先: [VitePress公式ドキュメント](https://vuejs.github.io/vitepress/v1/guide/getting-started)
