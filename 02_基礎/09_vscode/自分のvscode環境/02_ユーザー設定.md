## ウィンドウが画面外にはみ出す時

VS Codeを開いたときに、前回のウィンドウ位置やサイズが復元されてモニター外にはみ出すことがある。

一時復旧は、まずWindows側のショートカットで戻す。

- `Windowsキー + ↑`: 最大化
- `Windowsキー + ←` / `Windowsキー + →`: 画面内へスナップ
- `Alt + Space` → 移動: 画面外ウィンドウをキーボードで戻す
- UIが大きすぎる場合: `Ctrl + -` で縮小、`Ctrl + 0` でリセット

現在の設定では、次を採用している。

```jsonc
{
  "window.restoreWindows": "none",
  "window.newWindowDimensions": "maximized"
}
```

- `window.restoreWindows: "none"`: 前回開いていたウィンドウ位置・状態を復元しない
- `window.newWindowDimensions: "maximized"`: 新しいウィンドウを最大化で開きやすくする

2026-10-24に提供された設定では採用済み。設定を変更するときは、[01_注意事項](./01_注意事項.md) の通り、1つずつ試して差分を見る。

## PHP色の採用判断

- `variable.other.php` は、`$html_tag` などのPHP変数を見やすくするために採用する。
- `support.function.construct.output.php` は、`echo` をHTML側の通常文字と区別しやすくするために採用する。
- `punctuation.section.embedded.begin.php` / `punctuation.section.embedded.end.php` は、HTML内に差し込まれたPHPの開始・終了を見やすくするために採用する。
- `text.html.php` は範囲が広すぎるため採用しない。HTML全体の通常文字やタグ周辺まで巻き込む可能性がある。
- `php.validate.executablePath` は空文字のままでは意味が薄いため、このメモには採用しない。
- `intelephense.environment.includePaths` は、2026-10-24に提供されたユーザー設定では `["wp-includes", "wp-admin"]` を採用している。以前はプロジェクト側で検討する候補としていたが、今回の記録は提供された採用設定に合わせる。
