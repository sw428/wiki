# キーボードショートカット

> [!NOTE]
> 自動同期ではなく、必要なときに実ファイルを確認して更新する。ショートカットの競合や拡張機能への依存は、一つずつ確認する。

## 全ファイル検索を `F4` で1件ずつ修正する

### 何が便利だったか

ワークスペース全体を検索すると、検索ビューの左側に結果がファイル単位でまとまり、各ファイルの一致件数と一致行を確認できる。

この状態では、検索結果を毎回マウスでクリックしなくても、`F4` で次の一致箇所へ移動できる。この環境では移動先がエディターに表示され、そのままカーソル位置を編集してから、再び `F4` で次へ進めた。

`F4` は単に「場所を探すキー」ではなく、**次に個別修正する検索結果へ順番に移動するキー**として使う。

### 操作手順

1. `Ctrl+Shift+F` で全ファイル検索を開く。
2. 変更候補のタグ、クラス名、文字列などを検索する。
3. 左側で、対象ファイルと一致件数が想定どおりか確認する。
4. `F4` で次の検索結果へ移動する。
5. エディター上で、その箇所だけを修正する。
6. 再び `F4` を押し、次の一致箇所へ進む。
7. 前の結果へ戻る場合は `Shift+F4` を使う。

同じファイルに複数の一致があれば、そのファイル内を順番に移動し、終わると次のファイルへ進む。左側の検索結果一覧へマウスを何度も往復せず、複数ファイルの変更候補を1件ずつ確認できる。

### エディターから左の検索・置換結果へ移る場合

`F4` は次の一致箇所へ移動する操作であり、左の検索結果一覧へフォーカスを戻す操作とは分けて考える。

| 目的 | 操作 |
|---|---|
| 検索ビューを開き、検索入力欄へ移る | `Ctrl+Shift+F` |
| 置換付きで検索ビューを開く | `Ctrl+Shift+H` |
| 表示中のプライマリサイドバーへ移る | `Ctrl+0` |
| 次 / 前の検索結果を開く | `F4` / `Shift+F4` |

検索ビューが表示中なら、右のエディターから左側へ戻る基本操作は `Ctrl+0`。ただし、サイドバー内のどの欄へ戻るかは直前のフォーカス状態にもよる。検索結果一覧そのものへ確実に移したい場合は、コマンドパレットで `Search: Focus Search List`（`search.action.focusSearchList`）を実行する。このコマンドには、確認した既定ショートカット一覧上で専用キーがないため、頻繁に使うならキーボードショートカット設定で任意のキーを割り当てる。

検索結果一覧へ入った後は、`↑` / `↓` で項目を選び、`Enter` で開く。つまり、用途は次のように分かれる。

```txt
左の検索ビューへ戻りたい -> Ctrl+0
検索条件を入力し直したい -> Ctrl+Shift+F
一致箇所を巡回して編集したい -> F4 / Shift+F4
結果一覧そのものへ確実に入りたい -> Search: Focus Search List
```

### 全置換との違い

| 操作 | 対象 | 向いている作業 |
|---|---|---|
| ページ内検索 | 開いている1ファイル | 1ファイル内の一致を確認する |
| 全ファイル検索 | 開いているフォルダ・ワークスペース | 複数ファイルの一致を一覧化し、個別に違う修正をする |
| 全置換 | 検索条件に一致した複数箇所 | すべてを同じ内容へ変更してよい時にまとめて置換する |

今回の使い方は全置換ではない。**全ファイル検索で候補を一覧化し、`F4` で巡回しながら手作業で個別修正する**方法である。

すべてを同じ文字列へ安全に変更できる場合は全置換も候補になる。ただし、箇所ごとにインデント、タグ、前後関係、変更内容が異なる場合は、`F4` で1件ずつ確認する方が意図しない変更を避けやすい。

### この環境での区別

- `F4`: VS Code既定の「次の検索結果にフォーカス」`search.action.focusNextSearchResult`
- `Shift+F4`: VS Code既定の「前の検索結果にフォーカス」`search.action.focusPreviousSearchResult`
- `Ctrl+9`: この環境では `editor.emmet.action.updateImageSize` に割り当てている。検索結果の巡回には `F4` / `Shift+F4` を使う

動画がなくても再現できるよう、まずこの文字手順を正本として残す。操作画面の記録が必要になった場合だけ、あとから動画を補助資料として追加する。

```jsonc
// 既定値を上書きするには、このファイル内にキーバインドを追加します
[
  // --------------------------------------------------
  // Ctrlキー
  // --------------------------------------------------

  // ターミナル：前のペインへ移動
  {
    "key": "ctrl+1",
    "command": "workbench.action.terminal.focusPreviousPane",
    "when": "terminalFocus && terminalHasBeenCreated || terminalFocus && terminalProcessSupported",
  },

  // ターミナル：次のペインへ移動
  {
    "key": "ctrl+2",
    "command": "workbench.action.terminal.focusNextPane",
    "when": "terminalFocus && terminalHasBeenCreated || terminalFocus && terminalProcessSupported",
  },

  // 今開いているファイルのエディタへ戻る
  {
    "key": "ctrl+4",
    "command": "workbench.action.focusActiveEditorGroup",
  },

  // 選択範囲を縮める
  {
    "key": "ctrl+5",
    "command": "editor.action.smartSelect.shrink",
    "when": "editorTextFocus",
  },

  // 選択範囲を広げる
  {
    "key": "ctrl+6",
    "command": "editor.action.smartSelect.expand",
    "when": "editorTextFocus",
```
