## 整理時に保つ関係

1. 01は操作の入口。詳細度の計算を始める前に、対象要素・出典ファイル・打ち消し線・Computedを確認できるようにする。
2. 02は、カスケード上のほかの優先条件が同じ場合に、ソース上の記述順で決まることを扱う。
3. 03は、セレクタの詳細度を比較する場合を扱う。
4. 04は、01・02・03で説明できない競合の確認先。全順位の暗記を入口へ戻さない。
5. 寸法と余白は[05](../05_ボックスとdisplay/01_ボックスとdisplayの読み方.md)、表示工程の観測は[07](../07_ブラウザ挙動と表示のズレ/90_移行元/01_ブラウザが表示を作る基本フロー.md)、CSSの分割方針は[CSS設計](../../07_設計/CSS設計/00_CSS設計整理マップ.md)へ分ける。

CSSファイルをどの責務で分け、どの順に読み込むかという採用方針は、[SCSSとCSS分割](../../07_設計/CSS設計/02_SCSSとCSS分割.md)で扱う。
