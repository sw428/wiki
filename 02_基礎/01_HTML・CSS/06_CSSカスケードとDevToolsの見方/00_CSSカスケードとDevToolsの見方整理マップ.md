## 整理時に保つ関係

1. 01は操作の入口。詳細度の計算を始める前に、対象要素・出典ファイル・打ち消し線・Computedを確認できるようにする。
2. 02は、よく使う二つの判断を扱う。同条件なら記述順、セレクタが違えば詳細度という順で説明する。
3. 03は、01・02で説明できない競合の確認先。全順位の暗記を入口へ戻さない。
4. 寸法と余白は[05](../05_ボックスとdisplay/01_ボックスとdisplayの読み方.md)、表示工程の観測は[07](../07_ブラウザ挙動と表示のズレ/01_ブラウザが表示を作る基本フロー.md)、CSSの分割方針は[CSS設計](../../07_設計/CSS設計/00_CSS設計整理マップ.md)へ分ける。
