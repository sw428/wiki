# 06_文字と要素の箱を中央に寄せる

ブロックの箱と中の文字の関係から確認する場合は、前提知識の[テキストや画像はどう配置される？](../../../01_前提知識/01_HTML・CSS/08_インラインと行の仕組み/01_テキストや画像はどう配置される.md)へ戻る。

中央寄せを選ぶときは、文字などのインライン内容を揃えるのか、要素の箱そのものを親の中で動かすのかを先に決める。

## 何を中央にするかで指定を選ぶ

| 中央へ置きたいもの | 主な指定 |
| --- | --- |
| 要素内の文字・インライン要素 | `text-align: center` |
| 幅が決まったブロックの箱 | `margin-inline: auto` |
| Flexコンテナ内の子要素 | `justify-content: center` など |

`text-align`は、指定した要素の内容領域内でインライン内容を揃える。テキストノードへ直接指定するのではない。

```html
<p class="lead">Hello</p>
```

```css
.lead {
  text-align: center;
}
```

この例では、`.lead`の内容領域を基準に `Hello`が中央へ配置される。

## 箱そのものはauto marginで中央へ置く

```css
.card {
  width: 300px;
  margin-inline: auto;
}
```

通常のブロックレイアウトで幅が決まった箱なら、`margin-inline: auto`は包含ブロックのインライン方向に残った幅を左右へ分ける。箱の配置は、包含ブロックの幅に「左margin＋子要素のborder boxの幅＋右margin」を収める関係で決まる。border boxはpaddingとborderも含む箱の幅で、CSSの`width`指定値と同じとは限らない。

```text
余り = 親の利用可能幅 - 子のborder boxの幅
左右のauto margin = 余り ÷ 2
```

親の利用可能幅が300px、子のborder boxの幅が210pxなら、余りの90pxが左右45pxずつに分かれる。親と子の幅が同じなら余りは0pxなので、指定が効いていても見た目は動かない。

`margin-inline: auto`は、基本的には通常のブロックの箱を中央へ置くときに使う。インライン要素を中央へ揃える場合は、親に`text-align: center`を指定する。

通常のインライン要素は文字などと一緒に行の中へ並ぶ。親の幅は行の折り返しなどに影響するが、その行の余りを個々のインライン要素の左右marginへ分配しない。左右の`auto` marginは使用時に0となる。`inline-block`も外側は行内に並ぶため、幅を指定できても左右の`auto` marginでは中央に寄らない。

確認するときは、対象要素だけでなく親の幅も見る。`margin-inline: auto`はページの中央へ直接移動する命令ではなく、親の中にある余りを分けた結果である。

## 短い文字幅の箱を中央へ置く

見出しやラベルの箱を内容に近い幅へ縮めてから中央へ置く場合は、`width: fit-content`と組み合わせられる。

```css
.heading {
  width: fit-content;
  margin-inline: auto;
}
```

長い本文や折り返し位置を設計する文章では、`fit-content`へ任せるより、`max-width`で読みやすい行長を決める方が扱いやすいことがある。

## 親子をFlexで中央へ置く

```css
.button {
  display: inline-flex;
  align-items: center;
  justify-content: center;
}
```

`justify-content`と `align-items`は、Flexコンテナの中で子要素を揃える。外側の親の中で `.button`自体を中央へ置く指定ではない。

Flexでも、コンテナ内に利用可能な余りがなければ、中央寄せを指定しても見た目はほとんど変わらない。たとえば文字だけを入れた`inline-flex`の箱が内容に近い幅なら、`justify-content: center`で文字を動かせる余りはほぼない。

中央に見えない場合は、次を順に確認する。

1. 中央へ置きたい対象は文字か、要素の箱か。
2. 基準にしている親の幅と高さはどれか。
3. 対象に利用可能な余りがあるか。
4. Flexなら主軸と交差軸のどちらを揃えているか。
5. 箱は中央でも、フォントの字形だけがずれて見えていないか。

最後の違いは[ベースラインと見た目のずれ](./04_ベースラインと見た目のずれ.md)で確認する。
