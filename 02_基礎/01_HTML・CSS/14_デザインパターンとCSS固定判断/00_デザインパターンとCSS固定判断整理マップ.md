## 整理時に保つ関係

1. プロパティ名から選ばず、何のUIか、何を固定するか、何を変えられるようにするかを先に決める。
2. 「固定」はすべてをpxにすることではない。崩れてほしくない比率、上限、操作範囲、関係を担当する箱へ持たせる。
3. 画像の意味・形式は10、表示寸法と比率は11、この章は部品からそれらを選ぶ入口として重複させない。
4. `gap`は同じ親内の項目間隔、外側余白は一覧やセクション、操作範囲はリンク・ボタン自身へ分ける。
5. 文字量、画像差し替え、画面幅、項目数を変え、「読める・切れない・操作できる」を確認する。
6. アクセシビリティの数値要件と、案件のデザイン上採用した寸法例を混同しない。
