# 04_ステップ番号を自動連番にする

順序のある手順は、まず`ol`で意味を表す。番号を大きく装飾し、項目の追加や並べ替えでも自動更新したい場合は、CSSカウンターを使う。

## 意味上の順序はHTMLへ持たせる

```html
<ol>
  <li>ログインする</li>
  <li>投稿を追加する</li>
  <li>公開する</li>
</ol>
```

これは内容として順序があるため、CSSで番号を生成する前に`ol > li`で表す。

## 装飾番号をCSSカウンターで作る

```html
<ol class="step-list">
  <li class="step-list__item">ログインする</li>
  <li class="step-list__item">投稿を追加する</li>
  <li class="step-list__item">公開する</li>
</ol>
```

```css
.step-list {
  counter-reset: step-counter;
  list-style: none;
}

.step-list__item {
  counter-increment: step-counter;
}

.step-list__item::before {
  content: counter(step-counter, decimal-leading-zero) ".";
}
```

- `counter-reset`: 親側でカウンターを用意する。
- `counter-increment`: 項目が出るたびに番号を進める。
- `counter()`: 現在の番号を表示する。
- `decimal-leading-zero`: 1桁を`01`、`02`のように表し、10以降は`10`、`11`と表す。
- `::before`: 項目本文の前に装飾番号を生成する。

以前の例では、`"0" counter(...)`と`:nth-of-type()`を組み合わせ、10個目以降で先頭の0を外していた。これは兄弟のタグ構成へ依存する。用意された`decimal-leading-zero`を使えば、ゼロ埋めの目的を直接表せる。

## 判断基準

- 意味として順序が大事: `ol`を使う。
- 番号がデザインパーツ: CSSカウンターを追加する。
- 項目の追加・削除で番号を更新したい: 手書き番号を重複させない。
- `STEP 01`など別の文字を加える: `content`内で固定文字と`counter()`を組み合わせる。
- 通常のリストマーカーで足りる: 疑似要素を増やさず、`list-style-type`を使う。

生成番号だけへ意味を任せず、HTMLの`ol`でも順序を保持する。カウンターの仕様は[CSS Lists and Counters Level 3](https://www.w3.org/TR/css-lists-3/#auto-numbering)、表示形式は[CSS Counter Styles Level 3](https://www.w3.org/TR/css-counter-styles-3/#decimal-leading-zero)で確認できる。

## 一言でいうと

順序は`ol`で表し、装飾番号の自動更新が必要なときだけCSSカウンターを重ねる。
