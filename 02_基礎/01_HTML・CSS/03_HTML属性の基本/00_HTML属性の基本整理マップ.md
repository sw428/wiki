## 反映先と確認順

1. 01は、属性一覧を暗記させるページではなく、参照先・識別・状態・関係など現在の役割を言葉にする入口とする。
2. `id`と`class`の命名方針は[CSS設計](../../07_設計/CSS設計/01_BEMとクラス命名.md)、セレクタの対象確認は[13](../13_セレクタと構造依存/00_セレクタと構造依存整理マップ.md)へ分担する。
3. `role`と`aria-*`は属性の使い方を04に残し、要素選択は[04](../04_HTMLの意味と構造/01_意味からHTML要素を選ぶ.md)、アクセシビリティツリーの仕組みは[03_詳細](../../../03_詳細/01_HTML・CSS/01_意味構造とアクセシビリティツリー.md)へつなぐ。
4. `data-*`は標準属性で表せないページ固有のデータに使う。標準の意味やブラウザ動作を置き換える用途へ広げない。
5. 更新時は、属性名の構文、属性値の規則、その属性が作る意味・動作を分ける。ブール属性の規則を列挙型属性へ当てはめない。
