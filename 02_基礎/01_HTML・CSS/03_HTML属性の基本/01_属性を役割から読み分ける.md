# 01_属性を役割から読み分ける

属性は、HTML要素の開始タグへ情報・状態・参照先・関係などを加える。属性名だけを暗記するのではなく、「この要素へ何を追加しているか」から読む。

## 一つの例から属性を探す

```html
<button
  type="button"
  class="menu-button"
  aria-expanded="false"
>
  メニュー
</button>
```

- `type="button"`はボタンの種類を決める。
- `class="menu-button"`はCSSやJavaScriptから選ぶための分類を付ける。
- `aria-expanded="false"`は、開閉対象が現在閉じている状態を支援技術へ伝える。

同じ書き方に見えても、属性ごとに値の候補や省略時の扱いが違う。

## まず役割を分類する

| 属性の役割 | 例 | 確認すること |
| --- | --- | --- |
| 参照先 | `src`、`href` | どのファイルや移動先を参照するか |
| 識別・分類 | `id`、`class` | 一つを識別するか、複数を分類するか |
| 状態 | `required`、`disabled`、`aria-expanded` | 属性の有無か、属性値のどちらで状態が決まるか |
| 入力・動作 | `type`、`autocomplete`、`contenteditable` | どの要素で、どの値が有効か |
| 名前・関係 | `for`、`aria-labelledby`、`aria-controls` | 参照先の`id`と対応しているか |
| ページ固有のデータ | `data-*` | 標準属性で表せない独自情報か |

ここでは全属性を覚えない。部品を実装するときに、その要素で属性が許可されるか、値を省略したとき何が起きるかを確認する。

## 属性値は引用符で囲む形を基本にする

HTML構文では、条件を満たせば引用符を省略できる属性値もある。ただし、空白や`"`、`'`、`=`、`<`、`>`、`` ` ``を含む値は引用符なしで書けない。

```html
<input type="email" autocomplete="email">
<section id="service-about">
```

値の境界を読みやすくし、後から空白などを含めても崩れにくくするため、このWikiの基本例では属性値を引用符で囲む。

## 属性名と属性値の大文字・小文字を分ける

`text/html`として解析されるHTMLでは、HTML要素のタグ名と属性名はASCIIの大文字・小文字を区別しない。一方、属性値の比較方法は属性ごとに決まる。

```html
<input type="text">
<input type="TeXt">
```

`input`の`type`は、大文字・小文字を区別しないキーワードとして扱われる。

```html
<div id="myId"></div>
<div id="MyID"></div>
```

この二つの`id`は別の識別子。CSSやJavaScriptから参照するときにずれないよう、属性名は小文字、識別子やクラス名は決めた表記へそろえる。XML構文のHTMLには、`text/html`の大文字・小文字規則をそのまま当てはめない。

## `style`属性は直接指定が必要か確認する

```html
<p style="color: red;">注意</p>
```

`style`属性は、その要素へCSS宣言を直接書く。値を要素ごとに動的生成する場合や小さな検証では使えるが、通常の共通スタイルまで各要素へ散らすと、再利用と上書きの確認が難しくなる。

繰り返し使う見た目は`class`とCSSファイルを基本候補にする。実際に適用された指定は[CSSカスケードとDevToolsの見方](../06_CSSカスケードとDevToolsの見方/01_DevToolsで適用されたCSSを確認する.md)で確認する。
