# 02_属性名と属性値の構文を読む

HTMLソースでは、属性名だけを書く場合と、属性名に値を指定する場合がある。

属性は、要素の開始タグの中に書く。

```html
<input required>
<input type="email">
<section id="service-about">
```

`required`のように属性名だけを書くものもあれば、`type="email"`や`id="service-about"`のように値を持つものもある。

属性ごとに値の取り方や省略時の扱いは異なるため、書き方と意味を分けて確認する。

## 属性値は引用符で囲む

HTMLでは、条件を満たせば属性値の引用符を省略できる。

```html
<input type=email>
```

ただし、このWikiでは基本的に属性値を引用符で囲む。

```html
<input type="email">
<section id="service-about">
```

引用符で囲むと値の範囲が分かりやすく、後から値に空白などが入った場合にも構造を読み取りやすい。

空白や`"`、`'`、`=`、`<`、`>`、`` ` ``を含む値は、引用符なしでは書けない。

## 属性名と属性値は別に考える

`text/html`として解析されるHTMLでは、HTML要素のタグ名と属性名はASCIIの大文字・小文字を区別しない。

```html
<input TYPE="email">
<input type="email">
```

一方、属性値の大文字・小文字を区別するかどうかは、属性ごとに異なる。

```html
<input type="text">
<input type="TeXt">
```

`input`の`type`では、この二つは同じキーワードとして扱われる。

しかし、すべての属性値が同じ規則ではない。

```html
<div id="myId"></div>
<div id="MyID"></div>
```

この二つの`id`は別の識別子として扱う。

そのため、

- 属性名の書き方
- 属性値として何を指定できるか
- 値の大文字・小文字を区別するか

を分けて確認する。

このWikiでは、属性名は小文字で書き、`id`や`class`などの識別子は決めた表記へそろえる。

この大文字・小文字の説明は、`text/html`として解析されるHTMLの範囲。XML構文へ同じ規則をそのまま当てはめない。

## void要素の末尾に`/`を付けない

このWikiでは、HTMLのvoid要素に不要な末尾の`/`を付けない。

```html
<input type="email">
<img src="photo.jpg" alt="">
```

引用符なしの属性値の直後へ空白を入れず`/`を書くと、その`/`が属性値の一部として解析される場合がある。

属性値を引用符で囲み、void要素には不要な末尾の`/`を付けない形へそろえる。void要素の構文は[void要素と終了タグを理解する](../01_HTMLの土台/05_void要素と終了タグを理解する.md)で扱う。

## 属性の意味は構文だけでは決まらない

同じように見える属性でも、値の扱いは異なる。

```html
<input required>
<input type="email">
```

`required`と`type`では、属性が状態を決める仕組みが違う。

その違いは[ブール属性と列挙型属性を区別する](./04_ブール属性と列挙型属性を区別する.md)で扱う。

## 一言でいうと

属性を書くときは、属性名と属性値を分けて読み、属性値は引用符で囲む形を基本にする。大文字・小文字や値の規則は属性ごとに確認する。
