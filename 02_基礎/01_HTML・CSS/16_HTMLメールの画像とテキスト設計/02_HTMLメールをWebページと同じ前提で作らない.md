# HTMLメールをWebページと同じ前提で作らない

HTMLメールは、通常のWebページと同じ範囲のHTML/CSSが必ず処理される前提では作らない。

## Webページと同じ前提にしない

メールクライアントは、通常のブラウザーと同じ範囲のHTML/CSSを必ず処理するわけではない。たとえばGmailは多くのCSSセレクタ・プロパティ・メディアクエリを扱うが、未対応のものは無視される場合がある。

通常のWebページで成立した実装をそのまま流用せず、配信先で必要な環境を先に決める。

実際の確認対象は[対象メールクライアントで表示を確認する](./06_対象メールクライアントで表示を確認する.md)で扱う。

## 確認先

- [Gmail - CSS Support](https://developers.google.com/workspace/gmail/design/css)

## 一言でいうと

HTMLメールは、Webページで動いた実装をそのまま使える前提にしない。
