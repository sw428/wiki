# 画像が表示されなくても内容と導線を残す

HTMLメールの外部画像は、受信側の設定、セキュリティ・プライバシー判断、管理者設定などによって表示されない場合がある。画像がない状態を例外ではなく、確認する表示状態の1つとして扱う。

## 外部画像が表示されない場合がある

- Gmailは通常画像を表示するが、利用者は外部画像を表示前に確認する設定を選べる。疑わしい送信元やメッセージでは自動表示されない場合がある。
- Classic Outlookは、インターネット上の画像を既定で自動ダウンロードしない設定になっている。
- OutlookのMac版やモバイル版にも外部画像のダウンロード設定があるが、初期動作や管理者設定は同じとは限らない。

「Outlookなら必ず非表示」「Gmailなら必ず表示」のように製品名だけで固定せず、対象にするアプリ・OS・版・設定を確認する。

画像へ本文やCTAをすべて焼き込むと、画像が読み込まれない時に内容と導線が同時に失われる。

## 画像内文字だけへ依存しない

画像内文字は、通常のHTMLテキストより、文字サイズ、色、行間などを利用者側で調整しにくい。ロゴなど見た目自体が重要な場合を除き、読ませる文章は実テキストを優先する。

`alt`は画像が表示されない場合や支援技術への代替になるが、長い本文を画像化してよい理由にはしない。

## 画像非表示で確認する

1. 画像を読み込まない状態でメールを開く。
2. 件名と本文から、何の案内か分かるか確認する。
3. 日時、価格、注意事項などの重要情報が残っているか確認する。
4. リンクの目的と移動先が分かるか確認する。
5. 画像が表示された時に、同じ文章が不必要に重複しないか確認する。

`alt`の内容は[altを画像の役割から決める](./05_altを画像の役割から決める.md)で扱う。

## 確認先

- [Gmail Help - Turn images on or off](https://support.google.com/mail/answer/145919)
- [Microsoft Support - Block or unblock automatic picture downloads](https://support.microsoft.com/en-us/outlook/block-or-unblock-automatic-picture-downloads-in-classic-outlook-email-messages)

## 一言でいうと

画像が表示されなくても、何の案内か、重要事項、操作先が分かる状態を残す。
