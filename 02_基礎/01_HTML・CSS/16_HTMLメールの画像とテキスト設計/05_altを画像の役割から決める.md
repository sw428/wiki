# altを画像の役割から決める

HTMLメールの`alt`は、画像の見た目ではなく、その画像がメールの中で何を担当しているかと、周囲のHTMLから決める。

## 画像の目的からaltを決める

| 画像の役割 | `alt`の考え方 |
| --- | --- |
| 情報画像 | 理解に必要な情報を短く伝える |
| 画像内の文字 | 原則として画像内と同じ言葉を伝える |
| リンクになっている画像 | 見た目ではなく、リンクの機能・移動先を伝える |
| 周囲のHTMLと同じ内容の装飾画像 | `alt=""`を使い、重複を避ける |

同じ画像でも、周囲の文脈とリンクの有無で適切な`alt`は変わる。ファイル名や「バナー画像」のような見た目の分類を、そのまま代替テキストにしない。

`alt`は画像が表示されない場合や支援技術への代替になるが、長い本文を画像化してよい理由にはしない。
