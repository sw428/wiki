# HTMLメールの画像とテキスト設計の選び方

HTMLメールでは、Webページと同じ前提で実装せず、画像に任せる見た目とHTMLへ残す内容を分ける。さらに、画像が表示されない状態と対象メールクライアントでの確認まで含めて考える。

## 何を確認したいか

| 疑問 | 読む先 |
| --- | --- |
| Webページで使えたHTML/CSSをそのまま使ってよいか | [HTMLメールをWebページと同じ前提で作らない](./02_HTMLメールをWebページと同じ前提で作らない.md) |
| 何を画像にして、何をHTMLテキストへ残すか | [HTMLメールで画像と実テキストを分ける](./03_HTMLメールで画像と実テキストを分ける.md) |
| 画像が読み込まれない時に何を残すか | [画像が表示されなくても内容と導線を残す](./04_画像が表示されなくても内容と導線を残す.md) |
| `alt`に何を書くか | [altを画像の役割から決める](./05_altを画像の役割から決める.md) |
| どの環境で確認するか | [対象メールクライアントで表示を確認する](./06_対象メールクライアントで表示を確認する.md) |

## 判断の順序

1. 対象にするメール環境を決める。
2. 見た目を画像へ任せる部分と、実テキスト・リンクとして残す内容を分ける。
3. 画像が表示されない状態でも、案内・重要事項・移動先が分かるようにする。
4. 画像の目的と周囲のHTMLから`alt`を決める。
5. 実際の対象環境で表示と操作を確認する。

## 一言でいうと

HTMLメールでは、見た目を画像へ任せる判断と、内容・導線をHTMLへ残す判断を分けて考える。
