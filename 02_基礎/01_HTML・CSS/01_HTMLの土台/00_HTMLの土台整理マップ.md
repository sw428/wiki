## この章に残す境界

1. この章は、HTMLソースを読み、タグから要素と構造が作られ、DOMツリーになるところまでを扱う。
2. 属性の具体的な使い分けは[03_HTML属性の基本](../03_HTML属性の基本/01_HTML属性の基本をつかむ.md)へ分ける。
3. 意味による要素選択は[04_HTMLの意味と構造](../04_HTMLの意味と構造/01_意味からHTML要素を選ぶ.md)へ分ける。
4. JavaScriptによるDOMの取得・変更は[JSのDOMとイベント](../../02_JS/02_DOMとイベント.md)へ分ける。
5. DOM・CSSOM・Layout・Paintの表示工程は[07_ブラウザ挙動と表示のズレ](../07_ブラウザ挙動と表示のズレ/01_ブラウザが表示を作る基本フロー.md)へ分ける。
6. void要素はHTML構文、置換要素はCSSの表示モデルに関する分類として混ぜない。
7. `img`、`input`、`video`などを一律に置換要素と断定せず、HTML Standardのレンダリング規則と、要素が現在何を表すかの条件を確認する。

## 整理時に保つ確認事項

- void要素の末尾スラッシュ、HTMLパーサーによる`tbody`補完、置換要素の条件は公式仕様と照合済み。
- 07では「HTMLソースとDOMが同じとは限らない」という基礎判断を扱い、パーサーの細かな補正規則を増やしすぎない。
- 章タイトル・記事数・他章への最終的な振り分けは、各章の整理後に行う全体再マッピングで再確認する。
