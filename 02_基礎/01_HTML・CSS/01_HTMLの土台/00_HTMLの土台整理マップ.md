# HTMLの土台の整理マップ

Codex用。基礎01の本文を、HTMLの読み方、DOMになる流れ、HTML構文とCSS表示上の分類に分ける。人間向けの入口は[01_タグと要素からHTMLを読む](./01_タグと要素からHTMLを読む.md)。本文からこの内部マップへ誘導しない。

| 本文 | 主に答える疑問 |
| --- | --- |
| [01_タグと要素からHTMLを読む](./01_タグと要素からHTMLを読む.md) | タグ、内容、要素、属性をどう分けて読むか |
| [02_HTMLがDOMツリーになる流れ](./02_HTMLがDOMツリーになる流れ.md) | HTMLソースはブラウザ内でどんな構造になり、CSSやJSの対象になるか |
| [03_void要素と置換要素を区別する](./03_void要素と置換要素を区別する.md) | 終了タグの有無と、CSSが内容を扱う方法はどう違うか |

## 反映先と確認順

1. 01は短いHTMLを読めるようにする入口。要素選びの具体例は[04](../04_HTMLの意味と構造/01_意味からHTML要素を選ぶ.md)、属性の種類と接続先は[03](../03_HTML属性の基本/00_HTML属性の基本整理マップ.md)へ分担する。
2. DOMのノード構造、HTMLパーサーによる構造の補完、JavaScriptが操作する対象は02へ置く。画面を作る工程全体は[07](../07_ブラウザ挙動と表示のズレ/01_ブラウザが表示を作る基本フロー.md)へ分担する。
3. void要素はHTML構文、置換要素はCSSの表示モデルに関する分類として03で区別する。画像の寸法・比率・候補選択は[11](../11_メディア設計/00_メディア設計整理マップ.md)へ戻す。
4. `img`、`input`、`video`などを一律に置換要素と断定しない。HTML Standardのレンダリング規則と、要素が現在何を表すかの条件を確認する。
5. 更新時は、入口だけで理解に必要な前提、DOMの仕組み、構文・表示分類のどれに答える説明かを確認する。別の疑問へ広がる説明は対応章へつなぐ。
