# 03_タグ・内容・要素を区別する

## このページの役割

HTMLを読んだときに、「タグ」「内容」「要素」がそれぞれどの部分を指しているのかを区別する。

まずは次の短いHTMLを読めればよい。

```html
<p>こんにちは</p>
```

## タグ・内容・要素は指している範囲が違う

このHTMLは、次のように分けられる。

```text
<p>        ← 開始タグ
こんにちは ← 内容
</p>       ← 終了タグ

<p>こんにちは</p>
↑                 ↑
└──── p要素全体 ────┘
```

それぞれが指しているものは違う。

| 名前 | この例 | 指しているもの |
| --- | --- | --- |
| 開始タグ | `<p>` | 要素の開始を表すタグ |
| 内容 | `こんにちは` | 要素の中に入っている内容 |
| 終了タグ | `</p>` | 要素の終了を表すタグ |
| 要素 | `<p>こんにちは</p>` | 開始タグ・内容・終了タグを合わせた全体 |

## タグはHTMLソースに書く印

`<p>`や`</p>`の部分がタグ。

```html
<p>
</p>
```

開始側が開始タグ。

```html
<p>
```

終了側が終了タグ。

```html
</p>
```

タグは、要素を作るためにHTMLソースへ書く記述の一部。

## 内容はタグの間にある

開始タグと終了タグの間に入っているものが内容。

```html
<p>こんにちは</p>
```

この例では、

```text
こんにちは
```

が内容になる。

内容には文字だけでなく、別のHTML要素が入ることもある。

その場合の入れ子や親子関係は、[要素の入れ子と親子関係を読む](./04_要素の入れ子と親子関係を読む.md)で扱う。

## 要素は全体を指す

次のHTMLでは、

```html
<p>こんにちは</p>
```

`p要素`と呼ぶ範囲は、

```text
開始タグ
+
内容
+
終了タグ
```

を合わせた全体。

```text
<p>こんにちは</p>
```

が1つの`p`要素になる。

## 「pタグ」と「p要素」

実装中の会話では、

```text
pタグ
aタグ
divタグ
```

のように呼ぶことも多い。

ただし、厳密に構造を確認するときは、

```text
<p>      → 開始タグ

</p>     → 終了タグ

<p>...</p>
         → p要素
```

と分けると、何を指しているのか分かりやすい。

普段の会話で「pタグ」と呼ぶこと自体を避ける必要はない。

重要なのは、必要なときにタグと要素を区別できること。

## 終了タグがない要素もある

すべての要素が、

```html
<開始タグ>内容</終了タグ>
```

という形になるわけではない。

たとえば`img`や`br`のように終了タグを持たない要素もある。

```html
<img src="image.jpg" alt="作業画面">
<br>
```

ここでは「例外がある」と分かればよい。

詳しい仕組みは、[void要素と終了タグを理解する](./05_void要素と終了タグを理解する.md)で扱う。

## 一言でいうと

タグはHTMLソースに書く記述の一部で、内容と合わせてできる全体が要素。
