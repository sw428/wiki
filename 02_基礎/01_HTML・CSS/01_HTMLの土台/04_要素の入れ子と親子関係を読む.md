# 04_要素の入れ子と親子関係を読む

## このページの役割

HTMLでは、要素の中に別の要素を入れて構造を作る。

このページでは、HTMLを見たときに、

```text
どの要素の中に
どの要素が入っているか
```

を読み取り、親・子・兄弟という関係を区別する。

## 要素の中に別の要素を入れられる

たとえば、次のHTMLがある。

```html
<section>
  <h2>料金</h2>
  <p>月額料金を紹介します。</p>
</section>
```

`section`要素の中に、`h2`要素と`p`要素が入っている。

構造だけを見ると、次のようになる。

```text
section
├─ h2
└─ p
```

このように、ある要素の中へ別の要素を入れる構造を入れ子として見ることができる。

## 外側が親、直接入っている要素が子

先ほどのHTMLでは、

```html
<section>
  <h2>料金</h2>
  <p>月額料金を紹介します。</p>
</section>
```

`section`の中へ`h2`と`p`が直接入っている。

```text
section  ← 親
├─ h2    ← 子
└─ p     ← 子
```

この場合、

```text
section
→ h2の親
→ pの親

h2
→ sectionの子

p
→ sectionの子
```

という関係になる。

親・子は、要素の種類そのものではなく、**HTML内での位置関係**を表している。

## 同じ親を持つ要素は兄弟

`h2`と`p`は、どちらも`section`の直接の子。

```text
section
├─ h2
└─ p
```

このように同じ親を持つ要素同士は、兄弟として見ることができる。

```text
h2 と p
→ 兄弟
```

## 入れ子はさらに深くできる

要素の中の要素へ、さらに別の要素を入れることもできる。

```html
<section>
  <div>
    <p>お知らせです。</p>
  </div>
</section>
```

構造は次のようになる。

```text
section
└─ div
   └─ p
```

ここでは、

```text
section
→ divの親

div
→ sectionの子
→ pの親

p
→ divの子
```

となる。

`p`は`section`の中には入っているが、`section`へ直接入っているわけではない。

```text
section
└─ div
   └─ p
```

そのため、

```text
section → div
```

は直接の親子関係だが、

```text
section → p
```

は直接の親子関係ではない。

## 見た目ではなくHTMLの構造を見る

親・子・兄弟は、画面上でどこに表示されているかではなく、HTMLでどの要素の中に書かれているかによって決まる。

たとえばCSSによって表示位置を変えても、HTML自体が次のままなら、

```html
<section>
  <h2>料金</h2>
  <p>月額料金を紹介します。</p>
</section>
```

構造は変わらない。

```text
section
├─ h2
└─ p
```

見た目の位置と、HTML上の親子関係は分けて考える。

## インデントすると構造を読みやすい

入れ子になったHTMLは、階層に合わせてインデントすると関係を確認しやすい。

```html
<section>
  <div>
    <h2>料金</h2>
    <p>月額料金を紹介します。</p>
  </div>
</section>
```

これを構造として見ると、

```text
section
└─ div
   ├─ h2
   └─ p
```

となる。

HTMLを読むときは、

```text
開始タグを見る
↓
その中に何が入っているかを見る
↓
終了タグがどこにあるかを見る
```

と追うと、入れ子を確認しやすい。

## この関係は後の学習でも使う

親・子・兄弟という考え方は、この先さまざまな場面で使う。

たとえば、

```text
CSSで特定の要素を選ぶ
要素をFlexやGridで並べる
JavaScriptで要素を探す
DOMツリーを読む
```

といったときにも、要素同士の位置関係が重要になる。

ここでは、それぞれの詳しい仕組みまでは扱わない。

まずはHTMLを見て、

```text
誰が親か
誰が子か
誰と誰が兄弟か
```

を読めればよい。

## 一言でいうと

要素の中に別の要素を入れると階層ができ、直接外側にある要素が親、直接内側にある要素が子、同じ親を持つ要素同士が兄弟になる。
