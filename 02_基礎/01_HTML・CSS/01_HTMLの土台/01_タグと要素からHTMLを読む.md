# 01_タグと要素からHTMLを読む

HTMLを読むときは、まず「タグ」「内容」「要素」「属性」を分ける。DOMのノード種類を暗記してから始める必要はない。

このページでは短いHTMLを指し分け、HTMLが構造と意味を担当することを確認する。ブラウザ内部の構造は[HTMLがDOMツリーになる流れ](./02_HTMLがDOMツリーになる流れ.md)へ分ける。

## タグと要素を分ける

```html
<p>こんにちは</p>
```

この1行は次のように分けられる。

```txt
<p>        -> 開始タグ
こんにちは -> 内容
</p>       -> 終了タグ

全体      -> p要素
```

タグはHTMLソースに書く印で、開始タグから終了タグまでを内容と合わせた全体が要素。実装時に「`p`タグ」と呼ぶことはあるが、構造を確認するときはタグと要素を区別すると話がずれにくい。

## 属性は開始タグに追加する情報

```html
<a href="#section">説明へ移動</a>
<img src="image.jpg" alt="作業画面の説明">
<input type="text">
```

- `href` はリンク先を示す。
- `src` は読み込む画像の場所を示す。
- `alt` は画像の代わりになるテキストを示す。
- `type` は入力欄の種類を示す。

属性は開始タグの中に書き、要素へ情報や機能を加える。`id`、`class`、`role`、`data-*`の役割は[HTML属性の基本](../03_HTML属性の基本/01_属性を役割から読み分ける.md)で扱う。

## HTMLは見た目より先に役割を書く

`h1`は「大きくしたい文字」ではなく、そのページの主見出しを表す。

```html
<h1>ページの主見出し</h1>
```

文字の大きさはCSSで調整する。

```css
h1 {
  font-size: 32px;
}
```

| 決めること | 主な担当 |
| --- | --- |
| 見出し、段落、リンクなどの構造と意味 | HTML |
| 文字サイズ、色、余白、配置 | CSS |
| 操作に応じて内容や状態を変える処理 | JavaScript |

どのHTML要素を選ぶかは[意味からHTML要素を選ぶ](../04_HTMLの意味と構造/01_意味からHTML要素を選ぶ.md)で具体例から確認する。

## ブラウザはHTMLを構造として読む

HTMLソースは、そのまま一枚の文章として表示処理へ渡るわけではない。

```txt
書いたHTML
-> ブラウザが解析する
-> DOMツリーになる
-> CSSやJavaScriptの処理対象になる
```

まずは短いHTMLを見て、開始タグ、内容、終了タグ、属性を指し分けられればよい。終了タグを持たない要素に出会ったら[void要素と置換要素を区別する](./03_void要素と置換要素を区別する.md)へ戻る。
