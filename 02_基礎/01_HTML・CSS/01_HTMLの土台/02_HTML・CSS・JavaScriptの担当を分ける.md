# 02_HTML・CSS・JavaScriptの担当を分ける

## このページの役割

Webページを作るときに、HTML・CSS・JavaScriptがそれぞれ何を担当するのかを分けて考える。

最初は細かい例外より、

```text
HTML       → 構造と意味
CSS        → 見た目
JavaScript → 動作や状態の変更
```

という基本の分担をつかむ。

## HTMLは構造と意味を担当する

HTMLでは、ページの中に何があり、それぞれがどんな役割を持つのかを書く。

```html
<h1>サービス紹介</h1>
<p>サービスの内容を紹介します。</p>
<a href="/contact/">お問い合わせ</a>
```

この例では、

```text
h1 → 主見出し
p  → 段落
a  → リンク
```

というように、内容の役割をHTMLで表している。

HTMLは、文字を大きくしたいから`h1`を使う、というように見た目だけで要素を選ぶものではない。

どの要素を選ぶかは、[意味からHTML要素を選ぶ](../04_HTMLの意味と構造/01_意味からHTML要素を選ぶ.md)で詳しく確認する。

## CSSは見た目を担当する

HTMLで作った要素に対して、文字サイズ、色、余白、幅、配置などを指定するのがCSS。

```css
h1 {
  font-size: 32px;
}

a {
  color: blue;
}
```

この指定によって見た目は変わるが、

```text
h1が主見出し
aがリンク
```

というHTML上の役割そのものが変わるわけではない。

同じHTMLでも、CSSを変えれば見た目を大きく変えられる。

## JavaScriptは動作や状態を変える

JavaScriptは、ユーザーの操作などに応じてページの内容や状態を変えるときに使う。

たとえば、

```text
ボタンを押す
↓
メニューを開く

ボタンを押す
↓
表示内容を切り替える

入力する
↓
条件に応じて表示を変える
```

といった処理。

JavaScriptは、HTMLで作られたページの構造を利用して、対象を探したり変更したりする。

DOMの詳しい仕組みやJavaScriptからの操作は、このページでは扱わない。

## 三つは別々ではなく組み合わせて使う

実際のWebページでは、HTML・CSS・JavaScriptを組み合わせて作る。

```html
<button class="menu-button">メニュー</button>
```

```css
.menu-button {
  width: 120px;
}
```

```js
// ボタンが押されたときの処理を書く
```

同じボタンでも、

```text
HTML
→ ボタンであることを書く

CSS
→ 大きさや見た目を決める

JavaScript
→ 押したときの動きを決める
```

というように担当が違う。

## 迷ったときの分け方

何をどこに書くのか迷ったら、まず次のように考える。

| やりたいこと | 主な担当 |
| --- | --- |
| 見出し、段落、リンクなどを作る | HTML |
| 内容の役割を表す | HTML |
| 色、文字サイズ、余白を変える | CSS |
| 横並びや配置を変える | CSS |
| クリック後に表示を変える | JavaScript |
| 状態に応じて内容を変更する | JavaScript |

ただし、実際の実装では三つが連携することも多い。

この表は「完全に独立している」という意味ではなく、最初に役割を整理するための基準として使う。

## 一言でいうと

HTMLは構造と意味、CSSは見た目、JavaScriptは動作や状態の変更を主に担当する。
