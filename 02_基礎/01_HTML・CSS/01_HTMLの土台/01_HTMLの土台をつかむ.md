# 01_HTMLの土台をつかむ

## このページの役割

HTMLを書くときに、これから何を理解していくのか全体像をつかむ。

この章では、タグや要素の読み方から、書いたHTMLがブラウザ内でDOMツリーになるところまでを順番に扱う。

細かいルールを最初から覚えるのではなく、まず次の流れをつかむ。

```text
HTMLを書く
↓
タグによって要素を作る
↓
要素を組み合わせて構造を作る
↓
ブラウザがHTMLを解析する
↓
DOMツリーになる
↓
CSSやJavaScriptがその構造を利用する
```

## HTMLはページの構造と意味を表す

HTMLでは、見出し、段落、リンク、画像など、その内容が文書の中で何を表しているのかを書いていく。

たとえば次のHTMLでは、`h1`で主見出し、`p`で段落を表している。

```html
<h1>サービス紹介</h1>
<p>サービスの内容を紹介します。</p>
```

文字を大きくする、色を変える、横に並べるといった見た目は、主にCSSが担当する。

CSSのセレクタは、DOMとして作られた文書構造から対象を選ぶ。JavaScriptは、DOMを取得・変更して内容や状態を動かせる。

HTML・CSS・JavaScriptの担当の違いは、[HTML・CSS・JavaScriptの担当を分ける](./02_HTML・CSS・JavaScriptの担当を分ける.md)で扱う。

## HTMLは要素を組み合わせて作る

HTMLでは、タグを使って要素を作る。

```html
<p>こんにちは</p>
```

この中には、開始タグ、内容、終了タグがある。

```text
<p>        ← 開始タグ
こんにちは ← 内容
</p>       ← 終了タグ

全体       ← p要素
```

まずは、タグと要素を同じものとして扱わず、それぞれ何を指しているのか分けて読めればよい。

詳しくは[タグ・内容・要素を区別する](./03_タグ・内容・要素を区別する.md)で扱う。

## 要素は入れ子にして構造を作る

HTMLでは、要素の中に別の要素を入れられる。

```html
<section>
  <h2>料金</h2>
  <p>月額料金を紹介します。</p>
</section>
```

要素だけを抜き出すと、この構造は次のように見ることができる。

```text
section
├─ h2
└─ p
```

要素同士の親子関係や入れ子の読み方は、[要素の入れ子と親子関係を読む](./04_要素の入れ子と親子関係を読む.md)で扱う。

## 終了タグを持たない要素もある

すべてのHTML要素が、開始タグと終了タグの組み合わせで書かれるわけではない。

たとえば`img`や`input`、`br`などは、HTML構文上、終了タグを持たないvoid要素。

```html
<img src="image.jpg" alt="作業画面">
<input type="text">
<br>
```

詳しくは[void要素と終了タグを理解する](./05_void要素と終了タグを理解する.md)で扱う。

## 書いたHTMLはブラウザによって解析される

HTMLファイルに書いた文字列を、CSSやJavaScriptがそのまま直接扱うわけではない。

ブラウザはHTMLを解析し、要素や文字をノードとして持つDOMツリーを作る。

```text
HTMLソース
↓
HTMLパーサーが解析する
↓
DOMツリー
```

CSSのセレクタはDOMとして作られた文書構造から対象を選び、JavaScriptはDOMを取得・変更する。

DOMツリーが作られる基本的な流れは、[06_HTMLからDOMツリーが作られる](./06_HTMLからDOMツリーが作られる.md)で扱う。

## HTMLソースとDOMは同じとは限らない

ブラウザはHTMLを構文規則に従って解析する。

そのため、HTMLファイルに書いた構造と、解析後に完成したDOMの構造が常に一対一になるとは限らない。

この違いは、[07_HTMLソースとDOMの違いを知る](./07_HTMLソースとDOMの違いを知る.md)で扱う。

## 一言でいうと

HTMLはタグを使って要素と文書構造を作り、ブラウザはそのHTMLを解析してDOMツリーにする。
