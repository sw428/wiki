# 05_void要素と終了タグを理解する

## このページの役割

HTML要素には、

```html
<p>こんにちは</p>
```

のように開始タグと終了タグを持つものだけでなく、

```html
<img src="image.jpg" alt="作業画面">
```

のように終了タグを持たないものもある。

このページでは、

```text
終了タグを持つ要素
void要素
```

の違いを確認する。

## 通常は開始タグと終了タグで囲む

たとえば`p`要素は、開始タグと終了タグを使って書く。

```html
<p>こんにちは</p>
```

分けると、

```text
<p>        ← 開始タグ
こんにちは ← 内容
</p>       ← 終了タグ
```

となる。

開始タグと終了タグの間に内容を持つ。

## void要素は終了タグを持たない

HTMLには、構文上、内容と終了タグを持たない要素がある。

これをvoid要素という。

代表例には、

```text
img
input
br
hr
meta
link
```

などがある。

```html
<img src="photo.jpg" alt="作業画面">
<input type="text">
<br>
<hr>
```

これらには、

```html
</img>
</input>
</br>
```

のような終了タグを書かない。

## void要素には子の内容を書かない

void要素は、開始タグの後ろへ内容を書き、その後に終了タグを書く形ではない。

`p`などは開始タグと終了タグの間に文字や要素を持てる。一方、`img`は、

```html
<img src="photo.jpg" alt="作業画面">
```

のように書き、

```html
<img>写真</img>
```

のように子の内容を入れる要素ではない。

画像そのものがCSSでどのように扱われるかは、void要素とは別の話であり、[置換要素の参照カード](../../../05_参照/置換要素（img・input・video）.md)で確認する。

## 末尾の`/`で閉じたり、void要素に変えたりはしない

次のような書き方を見ることがある。

```html
<img src="photo.jpg" alt="作業画面" />
```

HTMLでは、この末尾の`/`が`img`要素を閉じているわけではない。

`img`は最初からvoid要素なので、終了タグを必要としない。void要素では末尾の`/`を付けた書き方も許容されるが、`/`自体に要素を閉じる効果はない。

そのため、このWikiの基本例では、

```html
<img src="photo.jpg" alt="作業画面">
```

のように末尾の`/`を付けずに書く。

void要素かどうかは、書き方によって決めるものではない。

たとえば、

```html
<div />
```

と書いたからといって、`div`がvoid要素になるわけではない。

`div`はvoid要素ではないため、通常は、

```html
<div></div>
```

のように開始タグと終了タグを使う。

末尾に`/`を書いても、その要素がvoid要素になるわけではない。

## void要素はHTML構文上の分類

void要素という分類が答えるのは、

```text
この要素は
終了タグを持つのか
内容を持つのか
```

というHTML構文上の疑問。

たとえば`img`には、画像の大きさや比率といった別の特徴もある。

しかし、

```text
imgに終了タグがない
```

ことと、

```text
imgの画像がCSSでどのように扱われるか
```

は別の話。

このページでは、終了タグと内容を持つかどうかだけを扱う。

## ここまでの要素の読み方

通常の要素は開始タグ・内容・終了タグを合わせて読み、void要素は終了タグと子の内容を持たないものとして読む。

終了タグが見当たらないときは、

```text
終了タグが見当たらない
↓
書き忘れとは限らない
↓
void要素か確認する
```

と考える。

HTMLには、一部の非void要素でも終了タグを省略できる場合がある。これはvoid要素とは別の仕組みで、このWikiの基本例では終了タグを省略せずに書く。

## 一言でいうと

void要素は、HTML構文上、内容と終了タグを持たない要素。
