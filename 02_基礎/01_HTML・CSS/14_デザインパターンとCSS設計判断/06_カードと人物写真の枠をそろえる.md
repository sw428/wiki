# 06_カードと人物写真の枠をそろえる

カード一覧では、一覧全体の間隔、各カードの画像枠、可変の本文、下へそろえるメタ情報を分ける。人物写真も、画像そのものではなく外側の枠をそろえる。

## カードの責務を分ける

```html
<article class="card">
  <a class="card__media" href="#">
    <img src="thumb.jpg" alt="" />
  </a>
  <div class="card__body">
    <h3 class="card__title">Title</h3>
    <p class="card__text">Text</p>
    <p class="card__meta">2026.06.22</p>
  </div>
</article>
```

```css
.card {
  display: flex;
  flex-direction: column;
  height: 100%;
}

.card__media {
  display: block;
  aspect-ratio: 4 / 3;
  overflow: hidden;
}

.card__media > img {
  display: block;
  width: 100%;
  height: 100%;
  object-fit: cover;
}

.card__body {
  display: flex;
  flex: 1;
  flex-direction: column;
}

.card__meta {
  margin-top: auto;
}
```

- カード同士の間隔は、子カードのmarginより一覧親の`gap`を優先する。
- 画像比率は、画像そのものではなく`.card__media`へ持たせる。
- 文字量が変わるなら本文高さを固定せず、下寄せする要素だけ`margin-top: auto`で送る。
- カード全体をリンクにするか、個別リンクを持つかはHTMLの意味と操作範囲から決める。外側のリンク内へ別のリンクやボタンを入れない。
- カード画像が記事や商品の内容を伝える場合は、その内容に合う代替テキストを付ける。近くの見出しと同じ意味を重複させるだけの画像なら、空の`alt`も比較する。

## 人物写真を正方形へ収める

```css
.voice__image-wrap {
  width: 178px;
  aspect-ratio: 1 / 1;
  flex-shrink: 0;
  overflow: hidden;
}

.voice__image {
  display: block;
  width: 100%;
  height: 100%;
  object-fit: cover;
}
```

- 正方形の見た目を守る責務は、外側の枠へ持たせる。
- `height: 100%`だけでは画像の横幅まで枠へそろわない。切り抜くなら幅と高さを枠へ合わせる。
- `178px`固定が常に悪いわけではない。カンプ上で写真枠が固定寸法なら、枠として固定できる。
- SPで縮小する場合は、メディアクエリや`clamp()`で枠サイズを切り替える。
- 横並びで枠を潰したくない場合は、`flex-shrink: 0`が必要か確認する。

## 実装後に変える条件

1. タイトルと本文を長くする。
2. 縦横比の異なる写真へ差し替える。
3. カード数を増減する。
4. SP幅で一覧と写真枠を確認する。
5. 日付やボタンを下へそろえる必要が、本当に全カードへあるか確認する。

画像枠の仕組みは[比率の枠へ画像を収める](../11_メディア設計/01_レスポンシブ画像設計/03_同一比率フレーム型.md)、一覧の並べ方は[Gridの列幅と縮み方を調整する](../09_レイアウト/04_Gridの列幅と縮み方を調整する.md)へ戻る。

## 一言でいうと

一覧は親、画像比率はメディア枠、可変本文は本文箱、下寄せは最後の要素というように、そろえる対象を分ける。
