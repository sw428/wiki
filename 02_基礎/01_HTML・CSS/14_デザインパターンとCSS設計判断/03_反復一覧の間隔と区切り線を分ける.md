# 03_反復一覧の間隔と区切り線を分ける

記事一覧やArchiveでは、項目同士の間隔、一覧の外側余白、外枠、項目間の区切り線を別の責務として扱う。

## 反復項目の間隔を作る

親で一覧を束ねられるなら、項目間隔は親の`gap`へ持たせる。

```css
.article-list {
  display: grid;
  gap: 16px;
}
```

既存HTMLを変えにくく、2個目以降だけ空けるなら、隣接兄弟結合子を使える。

```css
.article + .article {
  margin-top: 16px;
}
```

- 子項目の`margin-bottom`は最後の項目にも効くため、同種反復の間隔には不要な外側余白が残ることがある。
- 一覧の次のブロックまでの距離は、項目間隔と混ぜず、一覧全体やセクションへ持たせる。
- `+`の一致条件は[隣接する兄弟要素を選ぶ](../13_セレクタと構造依存/02_隣接する兄弟要素を選ぶ.md)で確認する。

## Archiveの外側と内側の線を分ける

```html
<section class="p-archive">
  <h2 class="p-archive__title">Archive</h2>
  <ul class="p-archive__list">
    <li class="p-archive__item">
      <a class="p-archive__link" href="#">2026年7月</a>
    </li>
    <li class="p-archive__item">
      <a class="p-archive__link" href="#">2025年11月</a>
    </li>
  </ul>
</section>
```

```css
.p-archive__list {
  width: 220px;
  margin-inline: auto;
  padding: 0;
  list-style: none;
  border-block: 1px solid #777;
}

.p-archive__item + .p-archive__item {
  border-top: 1px solid #777;
}

.p-archive__link {
  display: block;
  padding: 20px;
  color: #333;
  text-decoration: none;
}
```

- 一覧全体の上下線は`.p-archive__list`へ持たせる。
- 項目間の線は、項目と項目の関係として`.p-archive__item + .p-archive__item`へ持たせる。
- 文字と線の距離は、クリックできるリンク自身の`padding`で作る。
- WordPressの`wp_get_archives()`を使っても、出力された`ul > li > a`へCSSを当てる判断はHTML/CSS側で行う。

## 一言でいうと

項目間は`gap`か隣接兄弟、一覧の外側は親、内側の線は項目同士、押せる余白はリンクへ分ける。
