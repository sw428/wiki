# 13_アウトライン文字のaltを決める

文字をアウトライン化した画像は、見た目が文字でもHTMLテキストではなく図形になる。画像内の文字しか内容を伝えないのか、周囲のHTMLに同じ内容があるのかで `alt` を決める。

- 画像内にしか文字がない: `alt` で同等の内容を伝える
- 同じ文字が周囲のHTMLにある: 画像は装飾として `alt=""` を検討し、読み上げの重複を避ける
- 画像がリンクやボタンの内容である: 見た目ではなく操作の目的や移動先を伝える
- 複雑な図版で短いaltだけでは足りない: 周囲の本文や説明への参照も用意する

```html
<h2>
  <img
    src="./img/title.svg"
    alt="サービスの特徴"
    width="320"
    height="80"
  >
</h2>
```

この例では、画像の代替テキストが見出し内容を伝える。別に同じ見出しテキストを置く設計なら、画像側を装飾として扱い `alt=""` にする。

```html
<h2>サービスの特徴</h2>
<img src="./img/decoration.svg" alt="" width="320" height="80">
```

画像だけをリンク内容にする場合は、画像の色や形ではなく、リンクの目的を`alt`で伝える。

```html
<a href="/contact/">
  <img src="./img/contact.svg" alt="お問い合わせ" width="240" height="64">
</a>
```

操作名をHTMLテキストとして実装できるなら、画像だけに操作名を持たせる前にその方法も検討する。

## 判断順

1. 画像が伝える文字内容と操作目的を確認する。
2. 同じ内容が周囲のHTMLに存在するか調べる。
3. 重複するなら空の`alt`、画像だけなら同等の内容を候補にする。
4. リンクやボタンなら、操作目的がアクセシブルネームになるか確認する。
5. 複雑な図版なら、短い`alt`とは別に本文で説明する。
6. 文字拡大、ズーム、狭い幅でも内容を確認できるか見る。

文字を画像にする判断自体は[文字を画像にする前に確認する](./12_文字を画像にする前に確認する.md)、意味に合う要素は[HTMLの意味と構造](../04_HTMLの意味と構造/01_意味からHTML要素を選ぶ.md)、図版の囲み方は[図版をfigureでまとめる](../04_HTMLの意味と構造/17_図版をfigureでまとめる.md)へ戻る。
