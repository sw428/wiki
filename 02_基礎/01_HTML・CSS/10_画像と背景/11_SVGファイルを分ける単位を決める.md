# 11_SVGファイルを分ける単位を決める

SVGを一つにまとめるか複数ファイルへ分けるかは、path数ではなく、位置・大きさ・表示条件・更新を一緒に変えるかで決める。

## 一緒に変える範囲を見る

- 常に同じ位置関係で表示し、一体として拡大縮小する固定図版: 一つのSVGが候補
- ロゴ、キャッチコピー、バッジなどを別々に移動・非表示・差し替えする: 別SVGが候補
- レスポンシブ対応で一部だけ位置や大きさを変える: その制御単位で分割を検討
- 複数ページで同じアイコンを再利用する: 単独ファイル、sprite、maskなど再利用方法を比較

案件から支給されたSVGは、内部のライセンス・命名・参照関係も含む素材として扱う。不要な最適化やpathの結合は、表示と権利・納品条件を確認してから行う。

## 確認順

1. 分割後の各SVGを独立して配置・更新するか。
2. 共通の`viewBox`や座標変換へ依存していないか。
3. `defs`、ID、グラデーション、maskなどの参照先を失わないか。
4. 同じ素材を複数ページで再利用するか。
5. ファイル数、キャッシュ、HTML量のどれが保守しやすいか。
6. 支給素材のライセンスと納品条件に反しないか。

HTMLへ外部画像として置くか、インライン化するかは[外部SVGとインラインSVGを使い分ける](./10_外部SVGとインラインSVGを使い分ける.md)で判断する。
