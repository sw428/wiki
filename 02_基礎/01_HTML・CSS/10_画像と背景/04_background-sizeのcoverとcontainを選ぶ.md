# 04_background-sizeのcoverとcontainを選ぶ

背景画像を枠へ収めるときは、領域全体を覆いたいのか、画像全体を見せたいのかで `cover` と `contain` を選ぶ。

## coverとcontainは切り取りの有無で選ぶ

| 指定 | 結果 | 向く場面 |
| --- | --- | --- |
| `background-size: cover` | 比率を保ち、領域全体を覆う。画像の一部が切れることがある | 写真背景など、余白を作りたくない |
| `background-size: contain` | 比率を保ち、画像全体が収まる。領域内に余白が残ることがある | 図柄全体を見せたい |
| `background-position` | 余白や切り取りが出るとき、どの位置を基準に見せるか決める | 人物やロゴなど見せたい位置がある |

`cover`と`contain`は画像の比率を保つ。画像と描画先の比率が違う場合、切り取りまたは余白のどちらかが生じる。

人物や商品のように残したい対象がある場合は、`background-position: center`を固定の正解にせず、画面幅を変えて見える範囲を確認する。

画像をHTML要素として枠へ収める場合は `object-fit` を使う。[比率の枠へ画像を収める](../12_レスポンシブ画像設計/03_同一比率フレーム型.md)で、描画先の枠と画像自身を分けて確認する。
