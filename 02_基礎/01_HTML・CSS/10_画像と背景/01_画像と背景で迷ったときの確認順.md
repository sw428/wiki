# 01_画像と背景で迷ったときの確認順

実装中に画像や背景で迷ったときは、目的や症状から確認先を選ぶ。

| 困っていること | 最初に確認すること | 詳細 |
| --- | --- | --- |
| `img`と背景のどちらにするか迷う | 画像自体が内容を伝えるか | [`img`と`background-image`を選ぶ](./02_imgとbackground-imageを選ぶ.md) |
| 背景画像を指定したのに見えない | 描画先のboxに幅と高さがあるか | [背景画像を描くboxを確認する](./03_背景画像を描くboxを確認する.md) |
| 背景画像が切れる・余白が出る | 全体を覆うか、全体を見せるか | [`cover`と`contain`を選ぶ](./04_background-sizeのcoverとcontainを選ぶ.md) |
| `background-image`と`mask-image`の違いが分からない | 何を描くか、どこを見せるか | [背景画像とマスクを区別する](./05_background-imageとmask-imageを区別する.md) |
| SVGアイコンの色をCSSで変えたい | 形だけをmaskとして使えるか | [maskで単色アイコンを作る](./06_mask-imageで単色アイコンを作る.md) |
| 画像や要素の端を徐々に消したい | マスクで見える量を変えるか | [要素の端をフェードさせる](./07_mask-imageで要素の端をフェードさせる.md) |
| SVGかPNG/JPEGか迷う | 図形か、画素の集まりか | [SVGとラスター画像を選ぶ](./08_SVGとラスター画像を選ぶ.md) |
| PNG/JPEG/WebP/AVIFのどれにするか迷う | 透過・写真・配信環境 | [ラスター画像の形式を選ぶ](./09_ラスター画像の形式を選ぶ.md) |
| SVGを外部ファイルかHTML内に置くか迷う | 内部pathを操作する必要があるか | [外部SVGとインラインSVGを使い分ける](./10_外部SVGとインラインSVGを使い分ける.md) |
| SVGを一つにまとめるか分けるか迷う | 位置・大きさ・表示条件を一緒に変えるか | [SVGファイルを分ける単位を決める](./11_SVGファイルを分ける単位を決める.md) |
| 見出しや文字を画像にしてよいか迷う | HTMLの意味・操作・更新を残す必要があるか | [文字を画像にする前に確認する](./12_文字を画像にする前に確認する.md) |
| アウトライン文字の`alt`が分からない | 同じ内容が周囲のHTMLにあるか | [アウトライン文字のaltを決める](./13_アウトライン文字のaltを決める.md) |

このページには長い説明やコード例を置かない。判断理由を確認したいときだけ詳細記事へ進む。
