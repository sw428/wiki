# 02_セレクタが選ぶ要素を確認する

セレクタは、HTMLから条件に一致する要素を選ぶ。クラス名の印象や画面上の位置ではなく、DOM上で確認できる条件を読む。

## 最初に確認すること

```css
.news-item time {
  color: #555;
}
```

このセレクタが最終的に選ぶ対象は、右端の`time`要素である。そのうち、祖先に`.news-item`を持つものだけが一致する。

「`.news-item`へ文字色を付ける」と読まず、次の順で確認する。

1. 右端にある対象要素を確認する。
2. 左側にある親・祖先・兄弟などの条件を確認する。
3. 実際のHTMLに、その関係があるか確認する。
4. DevToolsのStylesで、その要素にルールが一致したか確認する。

セレクタが一致した後に、どの宣言が最終的に使われるかはカスケードの問題である。[DevToolsで適用されたCSSを確認する](../06_CSSカスケードとDevToolsの見方/01_DevToolsで適用されたCSSを確認する.md)で分けて確認する。

## 属性を条件にしても選ばれるのは要素

```html
<button class="button" data-state="open">メニュー</button>
```

```css
.button {}
[data-state="open"] {}
```

`.button`は`class`属性にそのクラス名を持つ要素、`[data-state="open"]`は属性名と値が一致する要素を選ぶ。属性そのものへCSSが付くわけではない。

HTML属性の役割は[03_HTML属性の基本](../03_HTML属性の基本/01_HTML属性の基本をつかむ.md)へ戻る。
