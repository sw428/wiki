# 01_セレクタと構造依存で迷ったときの確認順

セレクタで迷ったときは、まず「何を選びたいのか」と「DOMのどの関係へ依存しているのか」を分ける。

| 困っていること | 最初に確認すること | 詳細 |
| --- | --- | --- |
| セレクタを見ても対象要素が分からない | 右端の対象と左側の条件を分ける | [セレクタが選ぶ要素を確認する](./02_セレクタが選ぶ要素を確認する.md) |
| 深い子孫セレクタが壊れやすい | 変更されやすい境界をクラスで固定できるか | [セレクタの影響範囲をクラスで固定する](./03_セレクタの影響範囲をクラスで固定する.md) |
| 2個目以降だけ線や余白を付けたい | 直前の兄弟との隣接関係が仕様か | [隣接する兄弟要素を選ぶ](./04_隣接する兄弟要素を選ぶ.md) |
| `nth-child`と`nth-of-type`の違いが分からない | 何を母集団として数えるか | [nth-childとnth-of-typeを使い分ける](./05_nth-childとnth-of-typeを使い分ける.md) |
| 同じクラスの中だけで1番目・2番目を選びたい | `of S`で先に対象を絞る必要があるか | [nth-childのof-Sで対象を絞って数える](./06_nth-childのof-Sで対象を絞って数える.md) |
| DOM順が変わると見た目の意味まで変わる | 順番ではなく役割をクラスへ出すべきか | [構造依存から明示クラスへ切り替える](./07_構造依存から明示クラスへ切り替える.md) |

ここには長い説明やコード例を置かず、実装上の疑問から詳細記事へ進む。
