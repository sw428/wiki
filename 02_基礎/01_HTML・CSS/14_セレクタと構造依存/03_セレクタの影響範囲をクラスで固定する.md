# 03_セレクタの影響範囲をクラスで固定する

セレクタを短くすること自体ではなく、変更されやすいDOM階層へ偶然依存しすぎないことを優先する。親セクションや繰り返し単位など、意味のある境界をクラスで固定する。

## 変更されやすい境界をクラスで固定する

親セクションと繰り返し単位をクラスで固定すれば、偶然の階層への依存を抑えられる。

```html
<section class="news">
  <h2>新着情報</h2>
  <div class="item">
    <time>2026-06-15</time>
    <p><a href="#">記事タイトル</a></p>
  </div>
</section>
```

```css
.news h2 {}
.news .item {}
.news .item time {}
.news .item a {}
```

- 親セクションで影響範囲を限定する。
- 繰り返し単位や変更されやすい箱には、短い役割クラスを付ける。
- 安定している子要素は、親クラス配下のタグ指定でもよい。
- `.voice div div p:first-child`のような深い階層指定は、途中に要素が増えるだけで意味が変わりやすい。

プロジェクト全体の命名方針は[BEMとクラス命名](../../07_設計/CSS設計/01_BEMとクラス命名.md)で扱う。
