# 02_隣接する兄弟要素を選ぶ

隣接兄弟結合子`+`は、同じ親を持つ兄弟のうち、指定した要素の直後にある要素を選ぶ。項目間の区切りのように、最初には付けず、2個目以降へ同じ処理をするときに使える。

## `+`が選ぶのは右側の要素

```css
.archive__item + .archive__item {
  border-top: 1px solid #777;
}
```

この例で選ばれるのは、直前にも`.archive__item`がある右側の`.archive__item`である。項目が連続していれば、2個目以降にだけ`border-top`が付く。

```html
<div class="archive__item">1個目</div>
<div class="archive__item">2個目</div>
<div class="archive__item">3個目</div>
```

| 要素 | 直前の兄弟 | 一致するか |
| --- | --- | --- |
| 1個目 | なし | 一致しない |
| 2個目 | `.archive__item` | 一致する |
| 3個目 | `.archive__item` | 一致する |

間に別の要素が入ると、隣接関係はそこで切れる。すべての項目間隔を管理したいだけなら、親の`gap`も比較する。構造が変わりやすく、特定項目だけへ意味のある区切りを付けるなら、明示クラスも検討する。

## 疑似要素を付けても選択対象は実要素

```css
.trail__item + .trail__item::before {
  margin-inline: 6px;
  content: ">";
}
```

読む順番は次になる。

1. 右側の`.trail__item`を見る。
2. 同じ親を持つ直前の要素も`.trail__item`なら、右側の要素が一致する。
3. 一致した右側要素の`::before`を生成する。

結果として、1個目には何も出さず、2個目以降の先頭に区切りを表示できる。`::before`はHTML上の兄弟要素ではないため、追加しても`+`が確認する兄弟関係は変わらない。

## 確認する条件

- 左右の要素が同じ親を持っているか。
- 右側の対象の直前に、左側の条件へ一致する要素があるか。
- 間へ見出しや広告などが入る可能性がないか。
- 区切りではなく間隔が目的なら、親の`gap`で表せないか。

W3C Selectors Level 4では、`E + F`を「`E`に直ちに先行される`F`」として定義している。左側の要素ではなく、右側の要素が対象になる。

## 仕様で確認する

- [Selectors Level 4 - Next-sibling combinator](https://www.w3.org/TR/selectors-4/#next-sibling-combinator)

## 一言でいうと

`A + B`は、同じ親のもとで`A`の直後にある`B`を選ぶ。連続が崩れる可能性も含めて使う。
