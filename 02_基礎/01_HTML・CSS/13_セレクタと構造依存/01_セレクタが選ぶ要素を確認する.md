# 01_セレクタが選ぶ要素を確認する

セレクタは、HTMLから条件に一致する要素を選ぶ。クラス名の印象や画面上の位置ではなく、要素・属性・親子関係・兄弟関係など、DOM上で確認できる条件を読む。

## 最初に確認すること

```css
.news-item time {
  color: #555;
}
```

このセレクタが最終的に選ぶ対象は、右端の`time`要素である。そのうち、祖先に`.news-item`を持つものだけが一致する。

「`.news-item`へ文字色を付ける」と読まず、次の順で確認する。

1. 右端にある対象要素を確認する。
2. 左側にある親・祖先・兄弟などの条件を確認する。
3. 実際のHTMLに、その関係があるか確認する。
4. DevToolsのStylesで、その要素にルールが一致したか確認する。

セレクタが一致した後に、どの宣言が最終的に使われるかはカスケードの問題である。[DevToolsで適用されたCSSを確認する](../06_CSSカスケードとDevToolsの見方/01_DevToolsで適用されたCSSを確認する.md)で分けて確認する。

## 属性を条件にしても選ばれるのは要素

```html
<button class="menu-button" data-state="open">メニュー</button>
```

```css
.menu-button {}
[data-state="open"] {}
```

`.menu-button`は`class`属性にそのクラス名を持つ要素、`[data-state="open"]`は属性名と値が一致する要素を選ぶ。属性そのものへCSSが付くわけではない。

HTML属性の役割は[03_HTML属性の基本](../03_HTML属性の基本/01_属性を役割から読み分ける.md)へ戻る。

## BEMを使わない場合も影響範囲を固定する

BEMを使わなくても、親セクションと繰り返し単位をクラスで固定すれば、偶然の階層への依存を抑えられる。

```html
<section class="news">
  <h2>新着情報</h2>
  <div class="news-item">
    <time>2026-06-15</time>
    <p><a href="#">記事タイトル</a></p>
  </div>
</section>
```

```css
.news h2 {}
.news-item {}
.news-item time {}
.news-item a {}
```

- 親セクションで影響範囲を限定する。
- 繰り返し単位や変更されやすい箱には、短い役割クラスを付ける。
- 安定している子要素は、親クラス配下のタグ指定でもよい。
- `.voice div div p:first-child`のような深い階層指定は、途中に要素が増えるだけで意味が変わりやすい。

BEMかどうかより、変更されやすい境界をクラスで固定し、偶然のDOM階層へ依存しすぎないことを優先する。プロジェクト全体の命名方針は[BEMとクラス命名](../../07_設計/CSS設計/01_BEMとクラス命名.md)で扱う。
