# 09_装飾アイコンとラベルを小さな部品として扱う

矢印・三角形などの装飾アイコンと、NEW・カテゴリ名などのラベルは、どちらも周囲の大きなレイアウトから分離して扱う小さな部品である。

## 装飾アイコンを疑似要素にする

単純な記号やCSSだけで作れる形なら、疑似要素を使える。

```css
.button-link::after {
  content: ">";
}
```

生成した文字が装飾として余計に読み上げられないか確認する。CSSの線やborderで表せる単純な形も候補になる。

## SVGなどを実要素で置く

独立した素材として寸法を調整する場合や、既存方針として状態と同期する部品を実要素で管理する場合は、HTMLへ置ける。

```html
<a class="button-link" href="/news/">
  一覧へ
  <span class="button-link__arrow">
    <img class="button-link__arrow-image" src="img/arrow.svg" alt="" />
  </span>
</a>
```

画像が装飾なら`alt=""`とする。素材を使うことと、必ずラッパーを増やすことは別に判断する。

状態連動のために実要素がCSS仕様上必須なわけではない。親の属性やクラスに応じて疑似要素の見た目も変えられる。「状態と同期する部品は実要素で管理する」という採用方針と、技術上できることを区別する。

アイコンだけのボタンにも操作名が必要である。[開閉UIの最小例](../../02_JS/03_UI実装パターン.md#最小テンプレアイコンだけの開閉ボタン)で、見た目、名前、状態をそろえる。

## ラベル・バッジは小さな意味表示に絞る

```css
.label {
  display: inline-flex;
  align-items: center;
  min-height: 24px;
  padding-inline: 8px;
  border-radius: 999px;
  line-height: 1;
}
```

- 文字周囲の余白: `padding`
- 小さな箱の高さ: `min-height`
- 角丸: `border-radius`
- 行内での配置: `inline-flex`

ラベルは一覧全体を並べる役ではない。ラベル同士やカード一覧の間隔は親へ持たせ、ラベル自身は小さな意味表示へ集中させる。

## 一言でいうと

単純な装飾は疑似要素、素材や採用方針上独立して扱うアイコンは実要素、ラベルは小さな意味表示として責務を絞る。
