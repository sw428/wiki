# 01_表示制御で迷ったときの確認順

表示・非表示で迷ったときは、まず「存在条件」「表示時のbox」「配置」「操作状態」のどこで困っているかを分ける。

| 困っていること | 最初に確認すること | 詳細 |
| --- | --- | --- |
| SPだけ・PCだけ表示したい | どの画面幅で存在させるか | [SPとPCで表示する要素を切り替える](./02_SPとPCで表示する要素を切り替える.md) |
| `sp-only` / `pc-only`へ何を書けばよいか | Utilityは存在条件だけを担当しているか | [表示制御Utilityに存在条件だけを持たせる](./03_表示制御Utilityに存在条件だけを持たせる.md) |
| `display: revert`で元のFlex/Gridへ戻らない | `revert`が何を巻き戻すか | [display-revertの戻り先を確認する](./04_display-revertの戻り先を確認する.md) |
| 表示後も`flex`や`grid`にしたい | 表示時の`display`をどう決めるか | [表示後もFlexとGridを保つ方法を選ぶ](./05_表示後もFlexとGridを保つ方法を選ぶ.md) |
| SP用とPC用で同じ情報を2つ置く | 内容の更新先が分裂していないか | [SPとPCで重複する情報を揃える](./06_SPとPCで重複する情報を揃える.md) |
| 表示されたが位置や並びが違う | 存在条件とレイアウトを混ぜていないか | [表示条件とレイアウトを分ける](./07_表示条件とレイアウトを分ける.md) |
| SP表示とメニュー開閉が混ざる | 画面幅と操作状態を別にしているか | [レスポンシブ表示と開閉状態を分ける](./08_レスポンシブ表示と開閉状態を分ける.md) |

このページには長いコード例を置かず、実装上の疑問から詳細記事へ進む。
