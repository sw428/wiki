# 08_レスポンシブ表示と開閉状態を分ける

画面幅による表示条件と、クリックによるメニュー開閉は別の状態である。同じクラスへ両方の意味を持たせない。

## 担当を分ける

| 状態 | 主な担当 |
| --- | --- |
| SP幅でメニューボタンを存在させる | media queryと表示制御Utility |
| ボタンを押す前はメニュー本文を閉じる | HTMLの初期状態とCSS・JS |
| 押した後に本文を開く | JSのclass・属性更新 |
| 開閉状態を支援技術へ伝える | `aria-expanded`など |

画面幅だけで切り替えるクラスへ、クリック後の開閉状態まで持たせない。開閉UIは[JSのUI実装パターン](../../02_JS/03_UI実装パターン.md#4役で見る最小記憶)で扱う。
