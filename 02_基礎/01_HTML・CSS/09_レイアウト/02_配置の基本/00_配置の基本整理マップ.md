# 配置の基本整理マップ

Codex用の内部ルーター。人間向けの入口は[配置の基本で確認したいことから読む](./01_配置の基本で確認したいことから読む.md)。

## 担当する内容

通常フロー、配置する親と直下の子、親子それぞれの役割、コンテンツ幅、余白の境界を扱う。Flex・Gridへ分かれる前後で共通して使う判断をここへ置く。

| 読者の疑問 | 反映先 |
| --- | --- |
| FlexやGridを指定する前は、どの規則で並ぶか | [02_通常フローを基準にする](./02_通常フローを基準にする.md) |
| どの親へFlex・Gridを書き、どちらを選ぶか | [03_FlexとGridで直下の子を並べる](./03_FlexとGridで直下の子を並べる.md) |
| 親の中で配置されることと、子が中身を並べることは何が違うか | [04_親子のレイアウト文脈を区別する](./04_親子のレイアウト文脈を区別する.md) |
| 背景は全幅、中身だけ最大幅にするには | [05_コンテンツの最大幅と左右余白を作る](./05_コンテンツの最大幅と左右余白を作る.md) |
| 要素間・別ブロック間・枠内の余白をどこへ指定するか | [06_gapとmarginとpaddingを使い分ける](./06_gapとmarginとpaddingを使い分ける.md) |
| 縦marginが足し算にならない場所をどう調べるか | [07_marginの相殺が起きる場所を確認する](./07_marginの相殺が起きる場所を確認する.md) |

## 隣接する担当

- 一つの箱の寸法・余白・包含ブロックの仕組みは[ボックスとdisplay](../../05_ボックスとdisplay/00_ボックスとdisplay整理マップ.md)を正本とし、ここでは配置時の使い分けに絞る。
- Flex固有の位置合わせ・伸縮は[Flex整理マップ](../03_Flex/00_Flex整理マップ.md)、Gridの列・行・配置は[Grid整理マップ](../04_Grid/00_Grid整理マップ.md)へ分ける。
- 配置を切り替える幅の判断は[ブレークポイントの記事](../05_配置が成立する幅でブレークポイントを決める.md)へ置く。
- marginの相殺は、通常フローで余白を確認するときの分岐とし、Flex・Gridへ進む前の必修通読にはしない。
