# 11_配置が成立する幅でブレークポイントを決める

ブレークポイントは、カンプが用意された幅や端末名だけで決めず、その配置が成立しなくなる境界から決める。

## 必要幅を見積もる

固定幅カードを横へ並べる場合は、必要な幅を分解する。

```text
必要幅 = 左右の安全余白 + カード幅 × 枚数 + gap × 間の数
```

たとえばカード幅240pxを3枚、`gap: 24px`、左右余白20pxずつで並べるなら、最低限の合計は808pxになる。

```text
40px + 240px × 3 + 24px × 2 = 808px
```

これはmedia queryへそのまま書く最終値ではなく、確認を始める基準である。

## 境界の前後を実際に確認する

1. 維持したい列数、部品の最低幅、`gap`、左右余白を決める。
2. 合計が入る最小幅を求める。
3. 文字量、スクロールバー、ズームを変えて確認する。
4. 境界の前後で見切れ、窮屈さ、操作しにくさがないかを見る。
5. 必要なら少し余裕を持つ値を採用する。

```css
/* 840px以上で三列が成立すると確認した場合 */
@media (min-width: 840px) {
  .list {
    grid-template-columns: repeat(3, minmax(0, 1fr));
  }
}
```

`840px`はこの例の部品寸法と確認結果から選ぶ値であり、すべての制作物へ使う共通値ではない。

## 配置変更と表示切替を分ける

media query内で列数や向きを変えることと、要素自体を表示・非表示にすることは別の判断である。

- 同じ内容を一列から三列へ変える：レイアウト変更
- 操作や情報の一部を別条件で表示する：表示条件

狭い画面で収まらないことだけを理由に、内容をすぐ非表示にしない。表示する要素自体を変える判断は[表示条件とレイアウトを分ける](../13_表示制御/03_表示条件とレイアウトを分ける.md)で確認する。

## このページのまとめ

- カンプ幅や端末名を固定の正解にしない。
- 部品、余白、文字量から配置に必要な幅を見積もる。
- 計算値だけで確定せず、境界の前後をブラウザで確認する。
