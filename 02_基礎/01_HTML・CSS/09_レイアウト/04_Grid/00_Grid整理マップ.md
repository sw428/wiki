## 比較条件と確認の区別

02〜04は親の内容幅510px・gap30pxを基準にし、02の固定列幅は150px。05・06の最低列幅も150pxを使い、固定列幅と最低列幅の担当の違いを本文で示す。例示値を変えるときは、本文・CSS・計算・SVGの値と座標を同期する。

文字の自動最小幅・折り返しの図は模式表示と実測を区別する。動く図には指定変更の待機と結果を見る時間を設け、動きを減らす設定では結果を静止表示する。規約の正本は[AGENTSの説明方針](../../../../AGENTS.md#読者の疑問から説明を組み立てる)と[画像規約ルーター](../../../../07_画像/image-rules/00_画像規約ルーター.md)。
