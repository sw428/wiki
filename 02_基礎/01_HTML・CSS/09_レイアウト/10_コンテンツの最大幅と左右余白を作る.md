# 10_コンテンツの最大幅と左右余白を作る

背景や罫線は画面幅まで伸ばし、中身だけを一定の最大幅へ収めたい場合は、全幅の外側と幅を制限する内側を分ける。

## 外側と内側へ役割を分ける

```html
<section class="band">
  <div class="inner">
    ...
  </div>
</section>
```

```css
.band {
  border-block-end: 1px solid #ccc;
  background-color: #eef6ff;
}

.inner {
  width: min(calc(100% - 40px), 960px);
  margin-inline: auto;
}
```

- 外側：背景、罫線、画面幅まで続く領域
- 内側：中身の最大幅、中央寄せ、狭い画面で残す左右余白

見出しや本文を狭くし、画像だけ広く見せたい場合は、同じコンテナへ無理に収めず、必要な表示幅ごとに内側の箱を分ける。

## カンプの左右余白を固定値にしない

カンプ幅1440px、中身幅960pxなら、左右240pxは次の計算結果である。

```text
(1440px - 960px) / 2 = 240px
```

この240pxを`padding-inline`として固定すると、狭い画面でも左右480pxを先に確保しようとする。

意図が「中身は最大960px、狭い画面では左右20px」であれば、最大幅を持つ中身を中央へ置く。広い画面の左右余白は、固定値ではなく残り幅から結果として生まれる。

## サイト外枠と本文幅を同じにしない

```css
.page {
  width: 100%;
  max-width: 1440px;
  min-height: 100vh;
  margin-inline: auto;
}

.inner {
  width: min(calc(100% - 40px), 960px);
  margin-inline: auto;
}
```

カンプが1440pxで作られていても、サイト全体を1440pxで止める要件とは限らない。

- カンプ幅：デザインを確認した一つの表示幅
- サイト外枠：背景やページ全体を止める上限
- 本文幅：文章や部品を読みやすく保つ上限

この三つを同じ値として扱わず、要件を確認してから上限を置く。

`width`と`max-width`が使われる順序は[CSSに書いた値と実際の寸法を分ける](../05_ボックスとdisplay/07_CSSに書いた値と実際の寸法を分ける.md)で確認する。

## このページのまとめ

- 全幅の背景と、最大幅を持つ中身を別の箱にする。
- カンプの左右余白を固定paddingとして写さない。
- カンプ幅、サイト外枠、本文幅を同じ上限として扱わない。
