# 10_コンテンツの最大幅と左右余白を作る

背景や罫線は画面幅まで伸ばし、中身だけを一定の最大幅へ収めたい場合は、全幅の外側と幅を制限する内側を分ける。

## 外側と内側へ役割を分ける

```html
<section class="band">
  <div class="inner">
    ...
  </div>
</section>
```

```css
.band {
  border-block-end: 1px solid #ccc;
  background-color: #eef6ff;
}

.inner {
  width: min(calc(100% - 50px), 1000px);
  margin-inline: auto;
}
```

- 外側：背景、罫線、画面幅まで続く領域
- 内側：中身の最大幅、中央寄せ、狭い画面で残す左右余白

見出しや本文を狭くし、画像だけ広く見せたい場合は、同じコンテナへ無理に収めず、必要な表示幅ごとに内側の箱を分ける。

## `width`と`padding`が変える範囲を分ける

`width`で箱そのものを狭くする方法と、`padding`で箱の中身を内側へ寄せる方法は、中身の位置が同じに見えることがある。ただし、変更している範囲は異なる。

```css
.inner {
  width: calc(100% - 50px);
  max-width: 1000px;
  margin-inline: auto;
}
```

この指定は、`.inner`自体を親より左右25pxずつ小さくする。背景やborderも、狭くなった`.inner`の端までになる。

```text
親400px
┌────────────────────────┐
│ 25px ┌──────────────┐ 25px │
│      │ .inner 350px │      │
│      └──────────────┘      │
└────────────────────────┘
```

一方、次は`.inner`自体の幅を使い、中身を左右25px内側へ入れる指定である。

```css
.inner {
  width: 100%;
  max-width: 1050px;
  margin-inline: auto;
  padding-inline: 25px;
}
```

```text
.inner 400px
┌────────────────────────┐
│ 25px ┌──────────────┐ 25px │
│      │  中身350px   │      │
│      └──────────────┘      │
└────────────────────────┘
```

この例は`box-sizing: border-box`を前提にしている。`max-width: 1050px`の中に左右のpaddingも含まれるため、中身の最大幅は1000pxになる。

```text
1050px - 25px - 25px = 1000px
```

| 作りたい状態 | 最初の候補 |
| --- | --- |
| 箱そのものを左右の端から離す | `width` / `max-width` |
| 背景やborderは端まで伸ばし、中身だけ内側へ入れる | `padding` |
| セクションの枠と中身の間に余白を作る | `padding` |

`width`は箱の大きさ、`padding`は箱の内側の余白を決める。`box-sizing`によって`width`へpaddingを含めるかは変わるため、詳しい計算は[box-sizingでwidthの範囲を決める](../05_ボックスとdisplay/04_box-sizingでwidthの範囲を決める.md)で確認する。

## カンプの左右余白を固定値にしない

カンプ幅1500px、中身幅1000pxなら、左右250pxは次の計算結果である。

```text
(1500px - 1000px) / 2 = 250px
```

この250pxを`padding-inline`として固定すると、狭い画面でも左右500pxを先に確保しようとする。

意図が「中身は最大1000px、狭い画面では左右25px」であれば、最大幅を持つ中身を中央へ置く。広い画面の左右余白は、固定値ではなく残り幅から結果として生まれる。

## サイト外枠と本文幅を同じにしない

```css
.page {
  width: 100%;
  max-width: 1500px;
  min-height: 100vh;
  margin-inline: auto;
}

.inner {
  width: min(calc(100% - 50px), 1000px);
  margin-inline: auto;
}
```

カンプが1500pxで作られていても、サイト全体を1500pxで止める要件とは限らない。

- カンプ幅：デザインを確認した一つの表示幅
- サイト外枠：背景やページ全体を止める上限
- 本文幅：文章や部品を読みやすく保つ上限

この三つを同じ値として扱わず、要件を確認してから上限を置く。

`width`と`max-width`が使われる順序は[CSSに書いた値と実際の寸法を分ける](../05_ボックスとdisplay/07_CSSに書いた値と実際の寸法を分ける.md)で確認する。

## このページのまとめ

- 全幅の背景と、最大幅を持つ中身を別の箱にする。
- 箱そのものを狭くするなら`width`、箱の中身を内側へ入れるなら`padding`を使う。
- カンプの左右余白を固定paddingとして写さない。
- カンプ幅、サイト外枠、本文幅を同じ上限として扱わない。
