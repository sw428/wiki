## 整理時に保つ関係

1. 05は一つの箱の種類・寸法・余白、08は文字と行内配置、09は親が直下の子をどう並べるかを主に扱う。
2. Flex / Gridの採用は機能の説明として09に置き、クラス名やレイアウト責務の採用方針は[CSS設計](../../07_設計/CSS設計/00_CSS設計整理マップ.md)へ分ける。
3. `min-width: 0` は要素側、`minmax(0, 1fr)` はGridトラック側を変える。似た症状でも対象を分ける。
4. デザインカンプの幅は観測値として扱う。ブレークポイントは、その配置が成立する幅を実装で確認して決める。
5. 表データにはHTMLの意味として `table` を残す。floatは文章を図版へ回り込ませる用途と、既存実装の保守で扱う。
6. 元の「初期認識メモ」は、仕様説明ではなく当時の理解として06に残す。現在の判断は各本文の条件を使う。
