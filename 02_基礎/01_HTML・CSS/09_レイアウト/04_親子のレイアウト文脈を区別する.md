# 04_親子のレイアウト文脈を区別する

親へ`display: flex`や`display: grid`を指定しても、同じ値が子へ継承されるわけではない。親の中で子がどう配置されるかと、子自身が中身をどう並べるかを分ける。

## 継承と、親の配置への参加は別

```css
.parent {
  display: grid;
}

.child {
  /* display: gridが自動で入るわけではない */
}
```

- `.parent`はGridコンテナになる。
- 直下の`.child`はGridアイテムとして配置される。
- `.child`の中身は、`.child`自身へ別の`display`を指定しない限りGridでは並ばない。

これは、プロパティ値が子へ伝わる「継承」ではなく、子が親の作ったレイアウトへ参加した結果である。

## 一つの箱に外側と内側の役割がある

```html
<header class="header">
  <h1 class="logo">...</h1>
  <div class="tools">
    <a href="#">電話</a>
    <a href="#">予約</a>
  </div>
</header>
```

```css
.header {
  display: flex;
  align-items: center;
  justify-content: space-between;
}

.tools {
  display: flex;
  gap: 12px;
}
```

`.tools`は、外側から見ると`.header`のFlexアイテムであり、内側から見ると二つのリンクを並べるFlexコンテナである。

同じ`display: flex`を入れ子へ書いても、配置する直下の子が違えば重複ではない。外側の`align-items`は、孫要素であるリンク同士の配置までは決めない。

## DevToolsで親子をたどる

1. 動かしたい要素を選ぶ。
2. その要素自身の`display`を確認する。
3. 一つ上の親を選び、Flex/Gridコンテナか確認する。
4. 対象が親の直下にあるか確認する。
5. 対象の中身も並べたい場合だけ、対象自身へ内側のレイアウトを指定する。

箱の外側でblockかinlineかは[blockとinlineの広がり方](../05_ボックスとdisplay/05_blockとinlineの広がり方.md)、割合寸法の基準は[パーセント指定と包含ブロック](../05_ボックスとdisplay/08_パーセント指定と包含ブロック.md)へ分けて確認する。

## 一言でいうと

一つの要素は、親のレイアウトではアイテムになり、自分の中では別のコンテナにもなれる。
