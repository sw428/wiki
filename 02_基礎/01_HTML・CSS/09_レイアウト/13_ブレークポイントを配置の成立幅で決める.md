# 13_ブレークポイントを配置の成立幅で決める

ブレークポイントは、端末名やカンプ幅だけで決めず、その配置が成立する最小幅から決める。

## ブレークポイントは配置が成立する境界で決める

固定幅カードを横並びにする場合は、必要幅を先に見積もる。

```txt
必要幅 = 左右の安全余白 + カード幅 × 枚数 + gap × 間の数
```

1. 維持したい列数、カード幅、`gap`、左右余白を決める。
2. 合計が入る最小幅を求める。
3. 文字量、スクロールバー、ズームなども考え、境界の前後で実際に確認する。
4. 必要なら運用しやすい候補値へ余裕を持たせる。
5. その幅から広い側へだけ、成立した配置を適用する。

```css
/* この配置が1024px以上で成立すると確認した場合 */
@media (min-width: 1024px) {
  .card-list {
    grid-template-columns: repeat(3, minmax(0, 1fr));
  }
}
```

`864px` や `1024px` のどちらかが常に正しいのではない。media queryの `width` はviewport幅を検査するが、その境界値を決めるのは制作物側の配置条件である。

一覧の列幅や配分はまず親側で確認する。子へ `width: 100%` を足す前に、親のレイアウト規則と既定の伸び方をDevToolsで確認する。
