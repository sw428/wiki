# 05_コンテナ幅とブレークポイントを決める

デザインカンプの左右余白をそのまま大きなpaddingへ置き換えると、画面が狭くなったときも固定値が残る。全幅の外側と、最大幅を持つ内側を分け、余白を計算結果として作る。

## 全幅の外側と、幅を制限する内側

背景色や罫線を画面幅まで伸ばし、中身だけ中央へ収める例。

```html
<section class="section-band">
  <div class="section-inner">
    ...
  </div>
</section>
```

```css
.section-band {
  border-bottom: 1px solid #ccc;
  background-color: #eef6ff;
}

.section-inner {
  width: min(calc(100% - 32px), 1080px);
  margin-inline: auto;
}
```

- 外側: 背景・罫線・全幅領域
- 内側: 中身の最大幅・中央寄せ・左右の安全余白

罫線だけを広くしたいなら罫線を外側へ持たせる。見出しや本文を狭く、ヒーロー画像を広くしたいなら、本文幅とメディア幅のコンテナも分ける。

## 固定paddingではなく、結果として余白を残す

カンプ幅1600px、中身幅1020pxなら、左右290pxは次の計算結果である。

```txt
(1600px - 1020px) / 2 = 290px
```

290pxを `padding-inline` に固定すると、狭い画面でも左右580pxを先に確保しようとする。意図が「中身は最大1020px、狭い画面では左右20px」なら、中身幅を制限して中央へ置く。

```css
.l-inner {
  width: min(calc(100% - 40px), 1020px);
  margin-inline: auto;
}
```

- 1600px幅では、左右290pxが結果として残る。
- 狭い画面では中身も縮み、左右20pxずつ残る。
- 連続的に変える最小値・推奨値・最大値が必要な場合は `clamp()` を検討する。

## サイト全体の外枠と中身幅を分ける

```css
body {
  margin: 0;
  background-color: #eee;
}

.l-page {
  width: 100%;
  max-width: 1600px;
  min-height: 100vh;
  margin-inline: auto;
  background-color: #fff;
}

.l-inner {
  width: min(calc(100% - 40px), 1000px);
  margin-inline: auto;
}
```

カンプが1600pxで作られていても、必ずサイト全体を1600pxで止めるとは限らない。カンプ幅は一つの表示例なのか、サイト外枠の上限なのかを分けて確認する。

## ブレークポイントは配置が成立する境界で決める

固定幅カードを横並びにする場合は、必要幅を先に見積もる。

```txt
必要幅 = 左右の安全余白 + カード幅 × 枚数 + gap × 間の数
```

1. 維持したい列数、カード幅、`gap`、左右余白を決める。
2. 合計が入る最小幅を求める。
3. 文字量、スクロールバー、ズームなども考え、境界の前後で実際に確認する。
4. 必要なら運用しやすい候補値へ余裕を持たせる。
5. その幅から広い側へだけ、成立した配置を適用する。

```css
/* この配置が1024px以上で成立すると確認した場合 */
@media (min-width: 1024px) {
  .card-list {
    grid-template-columns: repeat(3, minmax(0, 1fr));
  }
}
```

`864px` や `1024px` のどちらかが常に正しいのではない。media queryの `width` はviewport幅を検査するが、その境界値を決めるのは制作物側の配置条件である。

## 子のwidthを機械的に増やさない

一覧全体の列幅や配分は親へ集める。子の `width: 100%` は、リンクのクリック面など、セルいっぱいへ明示的に広げる意図があるときに使う。Gridアイテムやblockの既定の伸び方ですでに幅を埋めている場合もあるため、必要性をDevToolsで確認する。
