# 02_親子のレイアウト文脈を区別する

親へ `display: flex` や `display: grid` を指定したとき、子へ同じ値が継承されるわけではない。親の中で子がどう扱われるかと、子自身が中身をどう並べるかを分ける。

## displayの継承と、配置への参加は別

```css
.parent {
  display: grid;
}

.child {
  /* display: grid が自動で入るわけではない */
}
```

- `.parent` はGridコンテナになる。
- その直下の `.child` はGridアイテムとして配置される。
- `.child` 自身の中身は、`.child` に別の `display` を指定しない限りGridにはならない。

これは「プロパティ値の継承」と「親が作ったレイアウトへ直下の子が参加すること」の違いである。

## 外側の役割と内側の役割を見る

```html
<div class="header-body">
  <h1 class="header-logo">...</h1>
  <div class="header-actions">
    <a href="#">電話</a>
    <a href="#">予約</a>
  </div>
</div>
```

```css
.header-body {
  display: flex;
  align-items: center;
  justify-content: space-between;
}

.header-actions {
  display: flex;
  gap: 12px;
}
```

`.header-actions` には二つの見方がある。

| どこから見るか | `.header-actions` の役割 |
| --- | --- |
| `.header-body` から見る | 親の中で配置されるFlexアイテム |
| `.header-actions` の中を見る | リンクを並べるFlexコンテナ |

外側の `align-items` は、孫要素であるリンク同士の配置までは決めない。同じ `display: flex` を入れ子へ書いても、対象となる直下の子が違えば単純な重複ではない。

## displayが決める範囲

| 確認したいこと | 主な指定・参照先 |
| --- | --- |
| 親の外側でその箱がblockかinlineか | [一つの箱とdisplay](../05_ボックスとdisplay/01_一つの箱とdisplay.md) |
| 箱の中で直下の子をどう並べるか | `display: flex` / `grid`、この章 |
| 幅・高さとpaddingをどこまで含めるか | `box-sizing`、[ボックスモデル](../05_ボックスとdisplay/01_一つの箱とdisplay.md#ボックスモデルとbox-tree上のboxの関係) |
| 文字や画像が行の中でどう揃うか | [文字の行間と高さを確認する](../08_インラインと行の仕組み/01_文字の行間と高さを確認する.md) |

`display` は要素から作るboxの外側・内側のレイアウト型に関わる。FlexアイテムやGridアイテムになることは、親との関係から決まる。

## 位置や割合の基準箱も分ける

`width: 50%` や `position: absolute` は、基準となる包含ブロックに対して計算される。Flex/Gridコンテナであることと、絶対配置の包含ブロックになることは同じ条件ではない。

- 割合指定: [パーセント指定と包含ブロック](../05_ボックスとdisplay/03_パーセント指定と包含ブロック.md)
- 画像へ文字を重ねる実例: [メディアの表示枠と重ね配置](../11_メディアの表示枠と重ね配置/03_画像の上に文字や部品を重ねる.md#箱の中央に文字を重ねる)
- `inset` で広がる詳しい条件: [03_詳細](../../../03_詳細/01_HTML・CSS/03_insetで広がる条件を調べる.md)

## 幅が想定より広がるとき

1. その要素の外側の `display` は何か。
2. 親のどのレイアウトへ、何アイテムとして参加しているか。
3. `width` / `max-width` と、その包含ブロックは何か。
4. Flex/Gridの自動最小サイズで縮みが止まっていないか。
5. 子の `width: 100%`、padding、長い単語や画像が外側の幅を押していないか。

`aspect-ratio` は比率を示す指定であり、幅上限を止める指定ではない。実寸の上限は `width` / `max-width` 側で確認する。
