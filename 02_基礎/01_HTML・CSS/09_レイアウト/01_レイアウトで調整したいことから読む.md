# 01_レイアウトで調整したいことから読む

レイアウトを直すときは、最初からFlexやGridのプロパティを探すのではなく、**何をどの基準で動かしたいか**を決める。

## 困っていることから選ぶ

| 困っていること | 最初に確認すること | 読むページ |
| --- | --- | --- |
| CSSを追加していない要素が、なぜ縦や横へ並ぶのか知りたい | blockかinlineか、通常フローの中にいるか | [通常フローを基準にする](./02_通常フローを基準にする.md) |
| 複数の子を一列または複数列へ並べたい | 並べたい要素を直下の子として持つ親はどれか | [FlexとGridで直下の子を並べる](./03_FlexとGridで直下の子を並べる.md) |
| 入れ子のFlexやGridが重複に見える | 外側で配置される役割と、内側を配置する役割 | [親子のレイアウト文脈を区別する](./04_親子のレイアウト文脈を区別する.md) |
| Flexの子を中央、端、下側へ寄せたい | 主軸と交差軸のどちらを動かすか | [Flexで子の位置を揃える](./05_Flexで子の位置を揃える.md) |
| サイドは固定し、メインだけ残り幅を使いたい | 固定側、可変側、縮んでよい側はどれか | [Flexで固定幅と可変幅を組み合わせる](./06_Flexで固定幅と可変幅を組み合わせる.md) |
| Gridの列幅を固定または均等配分したい | 列を固定値にするか、利用可能幅を配るか | [Gridで固定列と可変列を作る](./07_Gridで固定列と可変列を作る.md) |

| 指定した縦marginが足し算にならない | 接している二つのmarginと通常フロー | [marginの相殺が起きる場所を確認する](./13_marginの相殺が起きる場所を確認する.md) |

## 最初の確認順

1. 動かしたい箱をDevToolsで選ぶ。
2. その箱自身を動かしたいのか、直下の子を並べたいのかを分ける。
3. 現在の`display`と、参加しているレイアウトを確認する。
4. 幅を変え、内容が増減しても配置が成立するかを見る。
5. 位置合わせだけでなく、HTMLの読み順や意味が保たれているか確認する。

FlexとGridの全プロパティを先に暗記する必要はない。現在の配置を作っている親と、動かしたい直下の子を特定してから、必要なページだけを読む。
