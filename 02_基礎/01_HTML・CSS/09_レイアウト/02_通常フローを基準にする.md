# 02_通常フローを基準にする

FlexやGridを指定していない箱にも配置規則がある。横書きの通常フローでは、block-levelの箱は主に縦へ並び、inline-levelの箱や文字は行の中へ並ぶ。

レイアウト指定を追加する前に、通常フローでどこまで目的を満たしているかを確認する。

## まず指定を追加しない状態を見る

```html
<section class="section">
  <h2>見出し</h2>
  <p>幅に合わせて折り返す本文です。</p>
</section>
```

通常フローでは、見出しと段落は主に縦へ並ぶ。本文は親の利用可能幅に合わせて折り返し、行数と内容量から高さが決まる。

通常の内容を持つ箱は、まず`height: auto`のまま扱う。文字や子要素の量とpaddingから必要な高さを作り、高さ自体が要件になる場合に`height`や`min-height`を検討する。

blockとinlineで箱の広がり方が違う理由は、[blockとinlineの広がり方](../05_ボックスとdisplay/05_blockとinlineの広がり方.md)で確認する。

## 配置指定の前後を比較する

```css
.list {
  display: grid;
  grid-template-columns: repeat(2, minmax(0, 1fr));
  gap: 24px;
}
```

この指定を追加すると、`.list`の内側にはGridのレイアウト文脈が作られ、直下の子はGridアイテムとして配置される。

確認するときは次を比べる。

1. `display`を無効にしたときの通常フローでの並び
2. `display`を有効にした後の直下の子の並び
3. 内容量と画面幅を変えたときの折り返しやはみ出し

変化の前後を比べると、HTML本来の並びと、Flex/Gridが追加した配置を混同しにくい。

## 通常フローを外れる要素を確認する

`position: absolute`やfloatなど、通常フローと異なる関係になる指定もある。周囲の要素がその箱の大きさを前提にできない場合は、まず対象が通常フロー内にいるかを確認する。

画像上へ文字を重ねる絶対配置は[画像の上に文字や部品を重ねる](../11_メディアの表示枠と重ね配置/05_画像の上に文字や部品を重ねる.md)、floatによる文章の回り込みは[floatで文章を図版に回り込ませる](../../../03_詳細/01_HTML・CSS/06_floatで文章を図版に回り込ませる.md)へ分ける。

## 一言でいうと

通常フローは、FlexやGridを使わない未完成な状態ではなく、配置変更の前後を比べる基準になる。
