# 12_gapとmarginとpaddingを使い分ける

見た目では同じ距離でも、一覧の項目間、別ブロック間、枠と中身の距離では余白の担当が違う。

## 余白を置く境界から選ぶ

| 作りたい距離 | 最初の候補 | 理由 |
| --- | --- | --- |
| 同じ親が並べる反復要素の間 | 親の`gap` | 最初と最後の外側へ余白を作らず、項目間だけを管理できる |
| 前後する別ブロックの間 | margin | その箱の外側にある別の内容との距離を表せる |
| 枠線や背景と中身の間 | padding | 箱の内側で中身との距離を作れる |

```css
.list {
  display: grid;
  gap: 16px;
}

.section {
  margin-block-end: 48px;
  padding-inline: 20px;
}
```

- `.list`の子同士：`gap`
- `.section`と次のブロック：margin
- `.section`の端と中身：padding

## 一覧を束ねられない場合

既存HTMLなどで親から反復間隔を管理できない場合は、隣接兄弟へmarginを付ける方法もある。

```css
.item + .item {
  margin-block-start: 16px;
}
```

各項目へ一律の`margin-block-end`を付けると、最後の項目にも余白が残る。必要な境界だけを選ぶ。

## 同じ距離を二重に作らない

`gap`と子のmarginを同じ項目間隔のために併用すると、どちらが距離を作っているか分かりにくくなる。

DevToolsで次を確認する。

1. 距離の両側にある要素は何か。
2. 同じ親が並べる兄弟か、別のブロックか。
3. 親の`gap`と子のmarginが重なっていないか。
4. 背景やクリック範囲へ含めたい距離ならpaddingではないか。

縦marginが指定値どおりの足し算にならない場合は、[marginの相殺が起きる場所を確認する](./13_marginの相殺が起きる場所を確認する.md)へ進む。プロジェクト全体の余白ルールは[レイアウトと余白](../../07_設計/CSS設計/04_レイアウトと余白.md)へ分ける。

## 一言でいうと

余白の数値ではなく、要素間・箱の外側・箱の内側のどこに距離を作るかで選ぶ。
