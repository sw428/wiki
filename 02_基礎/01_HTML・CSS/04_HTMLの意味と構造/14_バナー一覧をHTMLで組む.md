# 14_バナー一覧をHTMLで組む

## このページの役割

バナー一覧は、画像を横に並べるだけの構造ではない。

このページでは、

- バナー一覧全体をどう組むか
- `ul`・`li`・`a`をどう使うか
- 画像リンクの目的をどう伝えるか
- リンクの入れ子をどう避けるか

を整理する。

## この範囲の芯

複数のバナーが同じ種類の項目として並ぶなら、一覧として考える。

基本形は、

```html
<ul>
  <li>
    <a href="/campaign-a/">
      <img src="banner-a.jpg" alt="キャンペーンA">
    </a>
  </li>

  <li>
    <a href="/campaign-b/">
      <img src="banner-b.jpg" alt="キャンペーンB">
    </a>
  </li>
</ul>
```

役割を分けると、

```text
ul
→ バナー一覧

li
→ バナー1件

a
→ 移動

img
→ バナー画像
```

となる。

## まず一覧と移動を分けて考える

複数のバナーが、

```text
キャンペーンA
キャンペーンB
キャンペーンC
```

のように同じ種類の項目としてまとまっているなら、`ul`と`li`で一覧を表せる。

バナーを押して別ページへ移動するなら、各`li`の中に`a`を置く。

```html
<ul>
  <li>
    <a href="/campaign/">
      <img src="campaign.jpg" alt="春の入会キャンペーン">
    </a>
  </li>
</ul>
```

ここでは、

```text
バナーを押す
↓
キャンペーンページへ移動する
↓
a
```

と判断する。

見た目がボタンだから`button`にするわけではない。

一覧の親子構造は[一覧をul・ol・liで組む](./11_一覧をul・ol・liで組む.md)、移動と操作の違いは[リンクとボタンを使い分ける](./10_リンクとボタンを使い分ける.md)で扱う。

## 画像だけのリンクはaltで目的を伝える

画像だけでバナーを構成する場合、`img`の`alt`がリンクの目的を伝える名前になる。

```html
<a href="/campaign/">
  <img
    src="campaign.jpg"
    alt="春の入会キャンペーン：今なら入会金無料"
  >
</a>
```

画像が表示されなくても、どこへ移動するリンクか、選ぶために必要な情報は何かが分かる内容にする。

```text
alt="バナー"
→ 何のリンクか分からない

alt="春の入会キャンペーン：今なら入会金無料"
→ 移動先と重要な訴求内容が分かる
```

`alt`へ画像内の全文を機械的に写すのではなく、リンクの目的と、その画像だけが伝えている重要な情報を残す。

文字を画像へ含める前の判断は、[文字を画像にする前に確認する](../10_画像と背景/05_文字を画像にする前に確認する.md)で扱う。

## 同じリンク内のテキストで意味が足りる場合

画像だけではなく、見出しや説明を同じ`a`の中に置くバナーもある。

```html
<li>
  <a href="/course/">
    <img src="course.jpg" alt="">

    <strong>Web制作コース</strong>
    <span>HTMLとCSSを基礎から学びます。</span>
  </a>
</li>
```

この例では、同じリンク内のテキストだけで移動先の目的が分かる。

画像が同じ内容を視覚的に補うだけなら、重複を避けるため`alt=""`にできる。

```text
img
→ 視覚的な補助

リンク内のHTMLテキスト
→ リンクの目的を伝える
```

ただし、画像がテキストにない追加情報を伝えているなら、その情報に合う`alt`を付ける。

## 1件全体が一つの移動先なら一つのaでまとめる

バナー1件全体を押して同じページへ移動するなら、一つの`a`で内容をまとめられる。

```html
<li>
  <a href="/service/">
    <img src="service.jpg" alt="">
    <strong>サービス紹介</strong>
    <span>提供サービスを見る</span>
  </a>
</li>
```

この構造では、画像と文字が同じ移動先を持つ一つのリンクになる。

画像と見出しを同じ移動先への別々のリンクに分ける前に、一つのリンクへまとめられないか確認する。

## 一つのaの中に別の操作対象を入れない

一つのバナー全体を`a`で囲んでいる場合、その中に別の`a`や`button`を入れない。

```html
<a href="/service/">
  <img src="service.jpg" alt="サービス紹介">

  <a href="/contact/">
    お問い合わせ
  </a>
</a>
```

```html
<a href="/campaign/">
  <img src="campaign.jpg" alt="キャンペーン">

  <button type="button">
    お気に入りに追加
  </button>
</a>
```

どちらも外側のリンクの中に別の操作対象が入っている。

移動だけなら、表示上ボタンに見せたい文字も同じ`a`の内容として置く。

```html
<a href="/campaign/">
  <img src="campaign.jpg" alt="キャンペーン">
  <span>詳しく見る</span>
</a>
```

## 複数の移動先や操作があるなら分ける

1件の中に複数の移動先や、その場で行う操作があるなら、カード全体を一つの`a`で囲まない。

```html
<li>
  <img src="service.jpg" alt="">
  <h3>Web制作</h3>
  <p>Webサイト制作を行います。</p>

  <a href="/service/web/">
    詳細を見る
  </a>

  <a href="/contact/">
    お問い合わせ
  </a>
</li>
```

ここでは、

```text
カード全体
→ 一つのリンクではない

詳細を見る
→ 1つ目の移動

お問い合わせ
→ 2つ目の移動
```

として分けている。

お気に入り登録などの操作がある場合も、その`button`を全体リンクの外へ分ける。

## 単純な誘導バナーにarticleは必須ではない

バナー1件が単なる誘導リンクなら、

```html
<li>
  <a href="/campaign/">
    ...
  </a>
</li>
```

で役割を表せる。

見た目がカードだから`article`にする必要はない。1件が独立した内容として成立するかは、[カード1件のHTMLを決める](./12_カード1件のHTMLを決める.md)で判断する。

## サイズや横並びはCSS側で決める

HTMLでは、一覧、項目、移動、画像と文字の役割を決める。

次の内容は別の判断として扱う。

```text
バナー画像を自然比率で表示するか
固定比率の枠へ収めるか
何列で並べるか
リンクの操作範囲をどこまで広げるか
```

バナーの表示枠と画像は[バナーの枠と画像を分ける](../15_UI部品の実装判断/05_バナーの枠と画像を分ける.md)、リンクの操作範囲は[CTAとナビリンクの操作範囲を作る](../15_UI部品の実装判断/07_CTAとナビリンクの操作範囲を作る.md)で扱う。

## 判断するときの見方

バナー一覧を組むときは、順番に見る。

```text
1. 複数のバナーが一つの一覧か
   ↓
   Yes → ul + li

2. バナーを押すと移動するか
   ↓
   Yes → a

3. 画像だけでリンクの目的を伝えるか
   ↓
   Yes → imgのaltで目的と必要な情報を伝える

4. 同じaのテキストだけで目的が分かるか
   ↓
   Yes → 補助画像はalt=""を検討する

5. 1件に複数のリンクや操作があるか
   ↓
   Yes → カード全体を一つのaで囲まない
```

## このページのまとめ

- 同じ種類のバナーが並ぶなら一覧として扱う
- 一覧全体は`ul`、バナー1件は`li`で表せる
- 移動するバナーは`a`を使う
- 画像だけのリンクは`alt`で目的と重要な情報を伝える
- 同じリンク内のテキストで意味が足りる補助画像は`alt=""`にできる
- 1件全体が一つの移動先なら、一つの`a`でまとめられる
- 一つの`a`の中に別の`a`や`button`を入れない
- 複数の移動先や操作があるなら、それぞれの操作範囲を分ける
- 単純な誘導バナーは、見た目だけを理由に`article`へしない
- サイズ、列数、画像の収め方、操作面積はCSS側の判断と分ける
