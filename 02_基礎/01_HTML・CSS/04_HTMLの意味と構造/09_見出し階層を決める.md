# 09_見出し階層を決める

## このページの役割

`h1`〜`h6`は、文字を大きくしたり小さくしたりするための要素ではない。

このページでは、

- 見出しレベルを何で決めるか
- `h1`〜`h6`の数字が何を表すか
- 見た目と文書階層をどう分けるか

を整理する。

## この範囲の芯

見出しの数字は、**文書内の階層**を表す。

```html
<h1>サービス紹介</h1>

<section>
  <h2>料金</h2>

  <section>
    <h3>個人プラン</h3>
  </section>
</section>
```

この構造は、

```text
サービス紹介
└─ 料金
   └─ 個人プラン
```

という階層を表している。

大事なのは、

> 文字をどのくらい大きくしたいか

ではなく、

> この見出しは文書構造のどの階層にあるか

で選ぶこと。

## h1は最上位の見出し

`h1`は、その文書や内容の最上位の見出しとして使う。

```html
<main>
  <h1>HTMLの基本</h1>

  ...
</main>
```

ここでは、

```text
h1
→ このページの中心となる見出し
```

として読む。

通常のWebページでは、ページ全体を代表する見出しとして`h1`を置く構成が分かりやすい。

## h2はh1の下の章

`h1`の内容を複数の章に分けるなら、`h2`を使う。

```html
<h1>HTMLの基本</h1>

<section>
  <h2>HTMLとは</h2>
  ...
</section>

<section>
  <h2>要素とは</h2>
  ...
</section>
```

構造は、

```text
HTMLの基本
├─ HTMLとは
└─ 要素とは
```

となる。

## h3以降も同じ考え方

さらに下位の内容へ分けるなら、`h3`以降を使う。

```html
<h1>HTMLの基本</h1>

<section>
  <h2>フォーム</h2>

  <section>
    <h3>入力欄</h3>

    <section>
      <h4>テキスト入力</h4>
    </section>
  </section>
</section>
```

見るべきなのは数字そのものではなく、

```text
親の見出し
↓
その下の見出し
↓
さらにその下
```

という関係。

## 見た目で見出しレベルを決めない

たとえば、

```html
<h4>料金</h4>
```

としている理由が、

```text
h2だと文字が大きすぎるから
```

だけなら、HTMLの意味と見た目が混ざっている。

文書構造として`h2`なら、

```html
<h2 class="section-title">料金</h2>
```

として、文字サイズはCSSで調整する。

```css
.section-title {
  font-size: 1.5rem;
}
```

つまり、

```text
HTML
→ 階層を決める

CSS
→ 見た目を決める
```

と分ける。

## デザイン上小さくても上位見出しになる

見た目が小さい文字でも、文書構造上重要なら上位の見出しになることがある。

```html
<h2 class="small-title">重要なお知らせ</h2>
```

逆に、大きな文字だからといって見出しになるわけではない。

```html
<p class="large-text">期間限定キャンペーン</p>
```

これが単なる強調文なら、文字が大きくても`h1`〜`h6`にする必要はない。

つまり、

```text
文字サイズ
≠ 見出しレベル
```

となる。

## sectionと見出し階層を一緒に考える

`section`を使うときは、その範囲のテーマを示す見出しと一緒に考える。

```html
<section>
  <h2>料金</h2>

  <section>
    <h3>個人向け</h3>
  </section>

  <section>
    <h3>法人向け</h3>
  </section>
</section>
```

構造は、

```text
料金
├─ 個人向け
└─ 法人向け
```

となる。

`section`を作るたびに機械的に見出しレベルを1つ下げるのではなく、文書全体の親子関係を見る。

## articleの中にも見出し階層がある

`article`も一つの内容なので、その中に見出し構造を持てる。

```html
<article>
  <h2>新サービスを公開しました</h2>

  <section>
    <h3>サービスの特徴</h3>
    ...
  </section>

  <section>
    <h3>利用方法</h3>
    ...
  </section>
</article>
```

ここでは、

```text
記事タイトル
├─ サービスの特徴
└─ 利用方法
```

という構造になる。

## 見出しレベルを飛ばさない

基本的には、

```text
h1
↓
h2
↓
h3
```

のように、階層を順番に下げる。

たとえば、

```html
<h1>サービス</h1>
<h3>料金</h3>
```

のように、理由なく`h2`を飛ばすと文書構造が分かりにくくなる。

通常は、

```html
<h1>サービス</h1>
<h2>料金</h2>
```

とする。

ただし大事なのは数字を機械的に連番にすることではなく、**実際の文書階層と一致させること**。

## 見出しを装飾目的で使わない

たとえば、

```html
<h3>NEW</h3>
```

のように、単に文字を目立たせるためだけに見出し要素を使うのは避ける。

それが本当に内容の見出しでなければ、

```html
<span class="label">NEW</span>
```

など、役割に合う要素を使う。

見出し要素を使う基準は、

> この後の内容に名前を付ける見出しか

で考える。

## 見出しだけで文書構造を追えるようにする

見出しだけを抜き出しても、

```text
HTMLの基本
├─ HTMLとは
├─ 要素とは
│  ├─ 開始タグ
│  └─ 終了タグ
└─ 属性とは
```

のように、ページの構造がある程度分かる状態が理想。

これは、

```text
見出し
→ 文書構造の目印
```

として使えている状態。

## 見出しレベルとCSSクラスは別に考える

見出しレベルとデザイン名を一致させる必要はない。

```html
<h2 class="title-large">料金</h2>
<h3 class="title-large">個人プラン</h3>
```

のように、HTML上の階層が違っても、同じデザインを使うことはできる。

逆に、

```html
<h2 class="title-small">補足</h2>
```

のように、`h2`を小さく表示することもできる。

つまり、

```text
h1〜h6
→ 意味と階層

class
→ CSSやJavaScriptから分類・参照するための名前
```

と分ける。

## 判断するときの見方

どの見出しレベルを使うか迷ったら、

```text
この見出しの親となる見出しは何か
```

を見る。

たとえば、

```text
サービス紹介
└─ 料金
   └─ 個人プラン
```

なら、

```text
サービス紹介
→ h1

料金
→ h2

個人プラン
→ h3
```

と判断できる。

文字サイズやデザインツール上の名称から決めない。

## このページのまとめ

- `h1`〜`h6`は文書の見出し階層を表す
- 文字サイズで見出しレベルを決めない
- 最上位から下位へ親子関係で考える
- `section`や`article`の構造と一緒に考える
- 理由なく見出しレベルを飛ばさない
- 強調したいだけの文字に見出し要素を使わない
- 見た目はCSSで調整する
- 見出しだけを追っても文書構造が分かる状態を目指す
- 判断するときは「この見出しの親は何か」を見る
