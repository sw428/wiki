# 16_画像を段落に含めるか判断する

## このページの役割

`img`は`p`の中に置くことができる。

ただし、

```text
画像だからpに入れる
```

という意味ではない。

このページでは、

- `img`を`p`に含められる理由
- どんな画像を段落の一部として扱うか
- 独立した画像をどう分けるか

を整理する。

## この範囲の芯

判断するのは、

> その画像が、文章の段落の一部として読まれるものか

という点。

文章の途中に画像が組み込まれているなら、次のように`p`の中へ入れられる。

```html
<p>
  保存するときは
  <img src="save-icon.svg" alt="保存">
  を選択します。
</p>
```

一方、

```text
文章
↓
大きな写真
↓
文章
```

のように独立して置かれている画像なら、無理に`p`で囲む必要はない。

## pは文章の段落を表す

`p`は、文章の一つの段落を表す。

```html
<p>
  HTMLでは、内容の役割に合わせて要素を選びます。
</p>
```

`img`は文章の流れに含められるフレージングコンテンツなので、その段落の一部として自然なら`p`の中に置ける。

```html
<p>
  設定を開くには
  <img src="settings.svg" alt="設定">
  アイコンを押します。
</p>
```

この画像は、文章とは別の図版ではなく、文章の流れの一部として扱われている。

構造は次のようになる。

```text
p
├─ Text
├─ img
└─ Text
```

つまり、`p`の中には文字しか置けないわけではない。

## 独立した画像ならpは必要ない

記事中に写真を独立して置く場合は、`img`を段落の外へ置ける。

```html
<p>会場の様子を紹介します。</p>

<img src="event.jpg" alt="イベント会場の様子">

<p>当日は多くの来場者が訪れました。</p>
```

ここでは、

```text
p
→ 画像の前にある文章

img
→ 独立して置かれた画像

p
→ 画像の後にある文章
```

として分かれている。

次のように画像だけを`p`で囲むことが、構文上常に誤りというわけではない。

```html
<p>
  <img src="event.jpg" alt="イベント会場の様子">
</p>
```

ただし、通常の写真やバナーを機械的に`p`で囲まず、その画像を文章の段落として扱う理由があるかを見る。

## 見た目のためにpで囲まない

画像を中央寄せすることだけを理由に、`p`で囲む必要はない。

```html
<img
  class="article-image"
  src="event.jpg"
  alt="イベント会場の様子"
>
```

画像の幅が親要素より小さい場合、ブロックとして扱って左右の自動マージンを使える。

```css
.article-image {
  display: block;
  margin-inline: auto;
}
```

`img`は通常インラインとして配置されるため、`margin-inline: auto`だけを指定して中央寄せできるとは考えない。

```text
p
→ 段落という意味

CSS
→ 配置や見た目
```

と分ける。

## ロゴの囲いも役割から決める

サイトロゴを見出しから外したからといって、外側の要素が自動的に`p`になるわけではない。

トップページへのリンクとして独立していれば、リンクを直接置ける。

```html
<a class="site-logo" href="/">
  <img src="logo.svg" alt="ABC株式会社">
</a>
```

複数の要素を配置上まとめる必要があるなら、`div`などを検討する。

```text
文章の段落
→ p

意味を追加しない配置用のまとまり
→ div

追加の囲いが不要
→ aやimgを直接置く
```

と判断する。

## 説明付きの図版ならfigureを検討する

画像とその説明を、本文から参照できる自己完結した一つの図版としてまとめたい場合は`figure`を検討する。

画像があれば必ず`figure`にするわけでも、すべての`figure`へ`figcaption`を付けるわけでもない。詳しい判断は、[図版をfigureでまとめる](./17_図版をfigureでまとめる.md)で扱う。

## リンク画像でも段落との関係を見る

画像を押して別ページへ移動する場合は、`a`の中に`img`を置ける。

```html
<a href="/campaign/">
  <img src="campaign.jpg" alt="春のキャンペーン">
</a>
```

画像リンクが文章の一部なら、`p`の中へ入ることもある。

```html
<p>
  詳細は
  <a href="/campaign/">
    <img src="campaign-icon.svg" alt="キャンペーン">
  </a>
  から確認できます。
</p>
```

一方、独立したバナーなら`p`で囲む必要はない。バナー一覧の構造とリンクの範囲は、[バナー一覧をHTMLで組む](./14_バナー一覧をHTMLで組む.md)で扱う。

## レイアウト用のまとまりはdivを検討する

画像をレイアウト上まとめたいだけなら、`div`を使うこともある。

```html
<div class="image-area">
  <img src="photo-a.jpg" alt="教室A">
  <img src="photo-b.jpg" alt="教室B">
</div>
```

ここでは、

```text
div
→ レイアウト用のまとまり

img
→ 画像
```

となる。

文章の段落ではないため、`p`を使う理由はない。

## pの中に何でも入れられるわけではない

`p`の内容にできるのはフレージングコンテンツ。`img`を置けるからといって、自由にあらゆる構造を入れられるわけではない。

次のように`div`を`p`の中へ入れる構造にはしない。

```html
<p>
  説明文

  <div>
    内容
  </div>
</p>
```

ブラウザがこのHTMLを解析すると、`div`の開始タグより前で`p`が終了し、ソースに書いたとおりの親子関係にはならない。

```text
HTMLソースではpの中に見える
≠
完成したDOMでもpの中になる
```

HTMLソースと解析後の構造が異なる場合は、[HTMLソースとDOMの違いを知る](../01_HTMLの土台/07_HTMLソースとDOMの違いを知る.md)で扱う。

## 画像の表示方法は別に決める

このページで決めるのは、画像が段落の一部か、独立した内容かというHTML上の役割。

画像の幅・高さ・比率・枠内への収め方は、[レスポンシブ画像設計の選び方](../12_レスポンシブ画像設計/01_レスポンシブ画像設計の選び方.md)で扱う。

画像に含める文字や`alt`の判断は、[文字を画像にする前に確認する](../10_画像と背景/05_文字を画像にする前に確認する.md)で扱う。

## 判断するときの見方

画像を`p`に含めるか迷ったら、次の順で見る。

```text
1. 文章の段落の流れの一部か
   ↓
   pの中にimgを置ける

2. 文章から独立して置かれた画像か
   ↓
   imgを独立して置ける

3. 本文から参照できる独立した図版か
   ↓
   figureを検討する

4. 配置のためだけに囲いたいか
   ↓
   divまたは追加の囲いなしを検討する
```

## このページのまとめ

- `img`はフレージングコンテンツなので`p`の中に置ける
- 画像が文章の流れの一部なら、`p`に含められる
- 独立した画像を必ず`p`で囲む必要はない
- 中央寄せなど、見た目のためだけに`p`を使わない
- ロゴや画像のラッパーが自動的に`p`になるわけではない
- 独立した図版と説明をまとめるなら`figure`と`figcaption`を検討する
- `img`を置けても、`p`の中に何でも入れられるわけではない
- 判断するときは、その画像が文章の段落の一部かを見る
