# 05_独立した内容をarticleで囲む

## このページの役割

`article`は、見た目がカードになっている要素を囲むためのものではない。

このページでは、

- どんな内容を`article`にするか
- `section`とは何が違うか
- 一覧の1件を`article`にするかどう判断するか

を整理する。

## この範囲の芯

`article`は、**その部分だけを切り出しても一つの内容として成立するまとまり**を表す。

たとえば記事一覧の1件なら、

```html
<article>
  <h2>新サービスを公開しました</h2>
  <p>新しいサービスについてお知らせします。</p>
</article>
```

この部分だけを取り出しても、

「一つのお知らせ」

として内容が成立する。

判断するときは、

> この範囲だけを別の場所へ移しても、一つの内容として読めるか

を見る。

## articleを使いやすい内容

代表的には次のようなものがある。

```text
ブログ記事
ニュース記事
お知らせ1件
投稿1件
コメント1件
商品レビュー
フォーラムの投稿
```

共通しているのは、

```text
ページ全体の一部分ではある
↓
その部分だけでも一つの内容として成立する
```

という点。

## sectionとの違い

`section`と`article`は、どちらも意味のあるまとまりを表す。

ただし判断軸が違う。

```text
section
→ 文書の中の一つの章・テーマ

article
→ 単独で切り出しても成立する内容
```

たとえば、

```html
<section>
  <h2>お知らせ</h2>

  <article>
    <h3>新サービスを公開しました</h3>
    <p>...</p>
  </article>

  <article>
    <h3>営業時間を変更しました</h3>
    <p>...</p>
  </article>
</section>
```

ここでは、

```text
section
→ 「お知らせ」という章

article
→ お知らせ1件
```

という役割になる。

## 見た目がカードでもarticleとは限らない

次のようなデザインがあるとする。

```text
┌─────────────┐
│ 高品質       │
│ 説明文       │
└─────────────┘

┌─────────────┐
│ 低価格       │
│ 説明文       │
└─────────────┘
```

見た目はカードでも、

```text
サービスの特徴を3つ並べているだけ
```

なら、それぞれが独立した記事とは限らない。

```html
<ul>
  <li>
    <h3>高品質</h3>
    <p>...</p>
  </li>
  <li>
    <h3>低価格</h3>
    <p>...</p>
  </li>
</ul>
```

のように、`li`だけで十分な場合もある。

つまり、

```text
カードデザイン
≠ article
```

と考える。

## 一覧の1件でもarticleとは限らない

複数の項目が並んでいるからといって、各項目を必ず`article`にするわけではない。

```html
<ul>
  <li>HTML</li>
  <li>CSS</li>
  <li>JavaScript</li>
</ul>
```

これは単なる一覧なので、`article`は必要ない。

一方、

```html
<ul>
  <li>
    <article>
      <h2>HTMLの基礎</h2>
      <p>HTMLの基本を解説します。</p>
      <a href="/html/">続きを読む</a>
    </article>
  </li>

  <li>
    <article>
      <h2>CSSの基礎</h2>
      <p>CSSの基本を解説します。</p>
      <a href="/css/">続きを読む</a>
    </article>
  </li>
</ul>
```

なら、各項目が一つの記事を表しているため、`article`を使いやすい。

## liとarticleは役割が違う

一覧の中では、`li`と`article`を組み合わせることがある。

```html
<ul>
  <li>
    <article>
      <h2>記事タイトル</h2>
      <p>記事の概要です。</p>
    </article>
  </li>
</ul>
```

それぞれの役割は、

```text
ul
→ 一覧

li
→ 一覧の1項目

article
→ その項目の中にある独立した内容
```

となる。

`article`を使うから`li`が不要になるわけではない。

カード一覧の1件へ`li`・`article`・`div`・`a`を組み合わせる判断は、[カード1件のHTMLを決める](./12_カード1件のHTMLを決める.md)で扱う。

## articleには見出しを持たせる

`article`は一つの内容として成立する範囲なので、何についての内容なのか分かる見出しを持つ構造が基本になる。

```html
<article>
  <h2>夏季休業のお知らせ</h2>
  <p>8月10日から8月15日まで休業します。</p>
</article>
```

このように、

```text
article
↓
その内容を表す見出し
↓
本文
```

として読む。

記事内に見出しがあることと、`article`自体へ`aria-labelledby`で名前を付けることは別の判断。通常の`article`へ一律に追加せず、支援技術へ伝わる名前やランドマークの条件は[意味構造とアクセシビリティツリー](../../../03_詳細/01_HTML・CSS/02_意味構造とアクセシビリティツリー.md#章の区切りとランドマークは同じではない)で確認する。

## articleの中にheaderやfooterを置ける

`header`や`footer`はページ全体だけに使う要素ではない。

```html
<article>
  <header>
    <h2>新サービスを公開しました</h2>
    <time datetime="2026-09-22">2026年9月22日</time>
  </header>

  <p>新しいサービスについて説明します。</p>

  <footer>
    <p>投稿者: 山田</p>
  </footer>
</article>
```

ここでは、

```text
article
→ 一つの記事

header
→ その記事の導入情報

footer
→ その記事に関する補足情報
```

という関係になる。

`header`と`footer`の詳しい使い分けは後のページで扱う。

## articleの中にsectionを入れることもある

一つの記事の中に複数の章があるなら、`article`の中を`section`で分けられる。

```html
<article>
  <h1>HTMLの基本</h1>

  <section>
    <h2>HTMLとは</h2>
    ...
  </section>

  <section>
    <h2>要素とは</h2>
    ...
  </section>
</article>
```

構造としては、

```text
article
→ 一つの記事全体

section
→ その記事の中の各章
```

となる。

## sectionの中にarticleが入ることもある

逆に、

```html
<section>
  <h2>最新記事</h2>

  <article>
    ...
  </article>

  <article>
    ...
  </article>
</section>
```

のように、

```text
section
→ 「最新記事」というまとまり

article
→ 記事1件
```

とすることもできる。

`section`と`article`は上下関係が固定されているわけではなく、内容の役割で決める。

## 判断するときの見方

`article`を使うか迷ったら、

```text
この部分だけを切り出しても、
一つの内容として成立するか
```

を見る。

さらに、

```text
別ページに掲載しても成立するか
RSSや記事一覧の1件として扱えそうか
一つの投稿・記事・レビューとして名前を付けられるか
```

を考えると判断しやすい。

単にレイアウトのために囲いたいだけなら、`article`ではない。

章として分けたいなら、`section`を検討する。

一覧の1項目であることだけを表したいなら、`li`だけで足りることもある。

## このページのまとめ

- `article`は単独で切り出しても成立する内容を表す
- 見た目がカードだから`article`になるわけではない
- 一覧の1件だから必ず`article`になるわけでもない
- `section`は章やテーマ、`article`は独立した内容を表す
- `li`は一覧の1項目を表し、`article`とは役割が違う
- `article`には内容を表す見出しを持たせる
- `article`の中に`section`を置くことも、その逆もある
- 判断するときは「この部分だけで一つの内容として成立するか」を見る
