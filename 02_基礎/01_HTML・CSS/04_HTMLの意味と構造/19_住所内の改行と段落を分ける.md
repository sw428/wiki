# 19_住所内の改行と段落を分ける

## このページの役割

`address`の中に連絡先を書くとき、次のように複数の情報が並ぶことがある。

```text
会社名
郵便番号
住所
電話番号
メールアドレス
```

このページでは、

- 同じ内容の中で改行するなら`br`
- 別の段落として分けるなら`p`
- 複数の項目を一覧として並べるなら`ul`・`li`

という使い分けを整理する。

何を`address`で表すかは、[連絡先をaddressで表す](./18_連絡先をaddressで表す.md)で扱う。

## この範囲の芯

見た目を改行したいだけで要素を選ばず、情報同士の関係を見る。

```text
同じ内容の途中で改行
→ br

別の段落
→ p

同じ種類の項目の一覧
→ ul + li
```

## 同じ住所の中の改行ならbrを使える

郵便住所のように、一つの内容を複数行で表したい場合は`br`を使える。

```html
<address>
  ABC株式会社<br>
  〒100-0001<br>
  東京都千代田区○○1-2-3
</address>
```

ここでは、

```text
ABC株式会社
〒100-0001
東京都千代田区○○1-2-3
```

を、一つの連絡先の中で改行して表示している。

`br`は、同じ内容の中で改行することを表す。新しい段落を作る要素ではない。

## 画面幅による折り返しにbrを使わない

住所がカンプ上で2行に見えても、単に表示幅が狭くて折り返されている場合がある。

```text
東京都千代田区○○1-2-3
○○ビル3階
```

改行位置そのものが内容の一部ではないなら、HTMLへ`br`を固定せず、通常の折り返しとCSS上の幅に任せる。

```text
住所としてここで改行する
→ brを検討する

表示幅によって偶然ここで折り返す
→ brを入れない
```

と分ける。

## 別の段落ならpで分ける

郵便住所と、そのほかの連絡先を別のまとまりとして扱いたい場合は`p`で分けられる。

```html
<address>
  <p>
    ABC株式会社<br>
    〒100-0001<br>
    東京都千代田区○○1-2-3
  </p>

  <p>
    電話: 03-1234-5678
  </p>
</address>
```

ここでは、

```text
1つ目のp
→ 会社名と郵便住所

2つ目のp
→ 電話番号
```

として内容を分けている。

```text
行を変える
→ br

文章・内容のまとまりを分ける
→ p
```

と考える。

見た目を1行ずつにするためだけに、住所の各行を機械的に`p`へ分けない。

## 余白を作るためにbrを重ねない

段落同士の間隔を作るために`br`を重ねない。

```html
<address>
  ABC株式会社<br>
  東京都千代田区○○1-2-3
  <br>
  <br>
  電話: 03-1234-5678
</address>
```

内容のまとまりを`p`で分け、見た目の間隔はCSSで指定する。

```html
<address class="contact-address">
  <p>ABC株式会社<br>東京都千代田区○○1-2-3</p>
  <p>電話: 03-1234-5678</p>
</address>
```

```css
.contact-address p + p {
  margin-top: 16px;
}
```

```text
HTML
→ 情報の区切り

CSS
→ 見た目の間隔
```

と分ける。

## 複数の連絡方法を一覧として扱うならulを使える

電話・メール・問い合わせページなどを、連絡方法の一覧として示したい場合は`ul`を使える。

```html
<address>
  <ul>
    <li>
      電話:
      <a href="tel:+81312345678">
        03-1234-5678
      </a>
    </li>
    <li>
      メール:
      <a href="mailto:info@example.com">
        info@example.com
      </a>
    </li>
  </ul>
</address>
```

ここでは、

```text
address
→ 連絡先情報

ul
→ 連絡方法の一覧

li
→ 連絡方法1件
```

となる。

複数行だから`ul`にするのではなく、複数の項目が一つの一覧を作っているかを見る。

一覧の基本構造は、[一覧をul・ol・liで組む](./11_一覧をul・ol・liで組む.md)で扱う。

## 住所を1行ずつliにしない

次のように書くと、会社名、郵便番号、住所がそれぞれ独立した一覧項目として扱われる。

```html
<ul>
  <li>ABC株式会社</li>
  <li>〒100-0001</li>
  <li>東京都千代田区○○1-2-3</li>
</ul>
```

一つの郵便住所を複数行で表したいだけなら、次のように同じ内容の中で改行する方が自然。

```html
<p>
  ABC株式会社<br>
  〒100-0001<br>
  東京都千代田区○○1-2-3
</p>
```

## 一つのaddressの中で組み合わせられる

`br`・`p`・`ul`は、どれか一つだけを選ぶものではない。

```html
<address>
  <p>
    ABC株式会社<br>
    〒100-0001<br>
    東京都千代田区○○1-2-3
  </p>

  <ul>
    <li>
      電話:
      <a href="tel:+81312345678">
        03-1234-5678
      </a>
    </li>
    <li>
      メール:
      <a href="mailto:info@example.com">
        info@example.com
      </a>
    </li>
  </ul>
</address>
```

この場合、

```text
address
├─ p
│  ├─ 会社名
│  ├─ br
│  ├─ 郵便番号
│  ├─ br
│  └─ 住所
│
└─ ul
   ├─ li 電話
   └─ li メール
```

となる。

`address`は連絡先全体、`p`は内容のまとまり、`br`は同じ内容の中の改行、`ul`・`li`は連絡方法の一覧を担当している。

## 判断するときの見方

`address`の中をどう組むか迷ったら、情報同士の関係を見る。

```text
1. 同じ内容の途中で行を変える必要があるか
   ↓
   br

2. 別の文章・内容のまとまりか
   ↓
   p

3. 同じ種類の項目が複数並んでいるか
   ↓
   ul + li

4. カンプの幅で折り返しているだけか
   ↓
   HTMLへ改行を固定しない
```

見た目が何行あるかではなく、改行、段落、一覧のどれを表すかで判断する。

## このページのまとめ

- `br`は同じ内容の途中で改行するときに使う
- 表示幅による折り返しだけを理由に`br`を入れない
- `p`は別の文章・内容のまとまりを表す
- `ul`・`li`は複数の項目を一覧として扱う
- 一つの郵便住所を行ごとに`p`や`li`へ分ける必要はない
- 余白を作る目的で`br`を重ねない
- `br`・`p`・`ul`は、役割に応じて同じ`address`内で組み合わせられる
- 判断するときは、改行・段落・一覧のどれかを見る
