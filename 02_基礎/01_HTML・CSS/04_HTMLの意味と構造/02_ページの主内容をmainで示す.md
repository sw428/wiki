# 02_ページの主内容をmainで示す

## このページの役割

`main`要素は、そのページの中心となる内容を示すために使う。

ページ内にあるすべての内容を入れるのではなく、サイト内の他のページにも共通して繰り返される部分を除いた、そのページ固有の主内容をまとめる。

## `main`が表すもの

たとえばサイト全体が次のような構成になっているとする。

```html
<header>
  サイト共通のヘッダー
</header>

<main>
  このページの主内容
</main>

<footer>
  サイト共通のフッター
</footer>
```

この場合、

```html
<main>
```

の中に入るのは、そのページで中心となる内容。

`header`や`footer`のような共通部分とは役割が違う。

## 見た目で決めない

`main`は、

- 真ん中に表示されている
- 面積が大きい
- 一番目立っている

という見た目から選ぶ要素ではない。

判断するのは、

> このページで中心となる内容か

という役割。

## `section`との違い

`main`と`section`は役割が違う。

```text
main
→ ページ全体の主内容を示す

section
→ 内容の中にある、テーマごとのまとまりを示す
```

そのため、`main`の中に複数の`section`が入ることがある。

```html
<main>
  <section>
    <h2>コース紹介</h2>
  </section>

  <section>
    <h2>講師紹介</h2>
  </section>
</main>
```

ここでは、

```text
ページ全体の主内容
└ main

主内容の中のまとまり
├ section
└ section
```

という関係になる。

## 基本的な使い方

通常は、1ページの主内容を1つの`main`で示す。

```html
<body>
  <header>
    ...
  </header>

  <main>
    ...
  </main>

  <footer>
    ...
  </footer>
</body>
```

HTMLでは、`hidden`属性を持たない`main`を文書内に複数置かない。

複数の画面に対応する`main`をあらかじめ用意する場合も、現在の主内容以外には`hidden`を指定する。

また、`main`はページ全体の主内容を表すため、`article`、`aside`、`footer`、`header`、`nav`などの内側には置かない。

基本的には、`body`の中でページ全体の主内容をまとめる要素として使う。

重要なのは、

> ページのどこを主内容として扱うか

をHTML上で示すこと。

## このページのまとめ

- `main`は、そのページ固有の中心的な内容を示す
- サイト全体で繰り返される共通部分とは分けて考える
- 見た目や配置ではなく、ページ内での役割から選ぶ
- `section`はページ全体の主内容ではなく、その中のテーマごとのまとまりを表す
- `hidden`を持たない`main`は、文書内に複数置かない
- 基本的には、`body`の中でページ全体の主内容をまとめる
