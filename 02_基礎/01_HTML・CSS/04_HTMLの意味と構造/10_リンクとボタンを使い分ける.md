# 10_リンクとボタンを使い分ける

## このページの役割

`a`と`button`は、見た目が似ていても役割が違う。

このページでは、

- `a`を使う場面
- `button`を使う場面
- 見た目ではなく動作から選ぶ考え方

を整理する。

## この範囲の芯

基本は、

```text
移動する
→ a

その場で操作する
→ button
```

と考える。

たとえば別ページへ移動するなら、

```html
<a href="/contact/">お問い合わせ</a>
```

その場でメニューを開くなら、

```html
<button type="button">
  メニューを開く
</button>
```

を使う。

## aは移動を表す

`a`は、別ページ、同じページ内の位置、外部サイトなど、別の場所へ移動するために使う。

```html
<a href="/about/">会社情報</a>
```

```html
<a href="#price">料金を見る</a>

<section id="price">
  <h2>料金</h2>
</section>
```

```html
<a href="https://example.com/">
  公式サイト
</a>
```

同じサイトか外部サイトかではなく、移動先を持つかを見る。

## buttonはその場の操作を表す

`button`は、現在の画面上で何かを実行する操作に使う。

```html
<button type="button">
  メニューを開く
</button>
```

たとえば、

```text
メニューを開く
モーダルを開く
表示を切り替える
内容をコピーする
お気に入りに追加する
```

など。

この場合、別の場所へ移動することが中心ではない。

フォーム送信も、その場で実行する操作なので`button`を使う。

```html
<form>
  <input type="text" name="name">

  <button type="submit">
    送信する
  </button>
</form>
```

通常の操作では`type="button"`、フォームを送信する場合は`type="submit"`を使う。フォーム内で`type`を省略すると既定で送信ボタンになるため、送信以外の操作では`type="button"`を明示する。

## 見た目や実装方法で選ばない

デザイン上は同じボタンに見えても、押した結果が移動なら`a`、その場の操作なら`button`を使う。

```html
<a class="button" href="/trial/">
  無料体験はこちら
</a>

<button class="button" type="button">
  無料体験フォームを開く
</button>
```

どちらもCSSで同じ見た目にできる。JavaScriptを使うか、`href`を書けるか、CTAとして表示されるかではなく、利用者に何が起きるかで決める。

```text
移動させたい
→ aを使い、hrefに移動先を書く

その場で実行したい
→ buttonを使い、必要な処理をつなぐ
```

役割に合った要素を使うと、リンクまたはボタンとしてブラウザに扱われ、キーボード操作や支援技術にも役割が伝わりやすくなる。

## aの中にbuttonを入れない

次のような構造にはしない。

```html
<a href="/service/">
  <button type="button">
    詳しく見る
  </button>
</a>
```

`a`と`button`はどちらも利用者が操作する要素なので、重ねて使わない。

移動なら、

```html
<a href="/service/">
  詳しく見る
</a>
```

操作なら、

```html
<button type="button">
  詳しく見る
</button>
```

のように、一つの役割を一つの要素に担当させる。

## カード全体をリンクにする場合

記事カードなど、カード全体を押すと詳細ページへ移動する場合は、`a`を使う。

```html
<article>
  <a href="/article/html-basic/">
    <h2>HTMLの基本</h2>
    <p>HTMLの基本を解説します。</p>
  </a>
</article>
```

実装方法によってリンク範囲は変わるが、役割としては、

```text
記事詳細へ移動
→ a
```

になる。

カードだから`button`にするわけではない。

## 判断するときの見方

`a`と`button`で迷ったら、

```text
押したあと、
利用者は別の場所へ移動するのか
```

を見る。

移動するなら、

```text
a
```

を検討する。

移動せず、その場で何かを実行するなら、

```text
button
```

を検討する。

最初に見るのは、色や形ではなく動作。

## このページのまとめ

- `a`は移動を表す
- `button`はその場の操作を表す
- 別ページだけでなくページ内移動も`a`
- メニューやモーダルを開くなら`button`
- フォーム送信には`button`を使う
- 見た目がボタンでも、移動なら`a`
- `a`と`button`を入れ子にしない
- JavaScriptを使うかどうかではなく、役割で決める
- 判断するときは「移動か、操作か」を見る
