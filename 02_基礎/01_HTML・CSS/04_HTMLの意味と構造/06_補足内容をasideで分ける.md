# 06_補足内容をasideで分ける

## このページの役割

`aside`は、画面の横側に置くための要素ではない。

このページでは、

- どんな内容を`aside`にするか
- `section`や`div`とは何が違うか
- ページ全体に対する補足と、記事内の補足をどう考えるか

を整理する。

## この範囲の芯

`aside`は、**周囲の主な内容とは少し離れた、補足的な内容**を表す。

```html
<article>
  <h1>HTMLの基本</h1>

  <p>HTMLは文書の構造や意味を表す。</p>

  <aside>
    <h2>補足</h2>
    <p>HTMLという名前はHyperText Markup Languageの略。</p>
  </aside>
</article>
```

ここでは、

```text
article
→ 主な内容

aside
→ その内容に関連する補足
```

という関係になる。

大事なのは、

> 横に配置されているか

ではなく、

> 主な内容から少し外れても成立する補足か

で判断すること。

## 主内容と補足内容を分ける

たとえば記事の中に次の内容があるとする。

```text
CSSのボックスモデルについて説明する本文

関連する豆知識

参考になる別の記事

用語の補足
```

本文を理解するための中心部分ではなく、なくても本文そのものは成立する内容なら、`aside`を検討できる。

```html
<article>
  <h1>CSSのボックスモデル</h1>

  <p>ボックスモデルは...</p>

  <aside>
    <h2>関連用語</h2>
    <p>content boxやborder boxという呼び方も使われます。</p>
  </aside>
</article>
```

判断するときは、

> この補足を一度外しても、主な内容は成立するか

を見ると分かりやすい。

主内容と関係があるだけで`aside`になるわけではない。「利用方法」のようにページの中心となる説明なら、補足ではなく主内容として`section`などを検討する。

## sectionとの違い

`section`も`aside`も意味のある範囲を表す。

ただし役割が違う。

```text
section
→ 主な文書構造の中にある一つの章・テーマ

aside
→ 主内容に関連する補足的な内容
```

たとえば、

```html
<section>
  <h2>料金</h2>
  <p>料金について説明します。</p>
</section>
```

は、ページの主要な章なので`section`。

一方、

```html
<aside>
  <h2>料金に関する補足</h2>
  <p>キャンペーン期間中は割引があります。</p>
</aside>
```

のように、中心の説明とは別の補足なら`aside`を検討できる。

## divとの違い

`div`は、それ自体では意味を追加しない。

```html
<div>
  ...
</div>
```

これは単にレイアウト用の箱として使える。

一方、

```html
<aside>
  <h2>関連記事</h2>
  ...
</aside>
```

は、

「ここは主内容とは別の補足的な内容です」

という意味を追加する。

整理すると、

```text
aside
→ 補足という意味を持つ

div
→ 意味を追加せず範囲をまとめる
```

画面の右側にあるサイドバーでも、配置用の箱でしかなければ`div`でよいことがある。反対に、本文の途中にあっても、主内容から外して読める補足なら`aside`を検討できる。

## 何に対する補足かを確認する

冒頭の例のように`article`の中へ置けば、その記事に対する補足になる。`aside`を`article`の外へ置き、ページ全体の主内容に対する補足とすることもできる。

```html
<main>
  ...
</main>

<aside>
  <h2>関連記事</h2>
  ...
</aside>
```

のように、ページ全体の主内容に関連する補足として使うこともできる。

たとえば、

```text
関連記事
記事本体から離して読める著者紹介
関連リンク
補足的な案内
```

などが候補になる。

ただし、配置場所だけでは決めず、その`aside`がどの主内容に対する補足なのかを確認する。

## 見出しやnavとは役割を分ける

`aside`が何についての補足なのかを見出しで示し、その中のナビゲーションを`nav`で表すことがある。

```html
<aside>
  <h2>関連ページ</h2>

  <nav aria-label="関連ページ">
    <ul>
      <li><a href="/html/">HTML</a></li>
      <li><a href="/css/">CSS</a></li>
    </ul>
  </nav>
</aside>
```

このとき、

```text
aside
→ 補足的な範囲

h2
→ その補足の内容を示す見出し

nav
→ その中のナビゲーション

ul
→ 関連ページの一覧
```

`aside`があることを理由に、見出しや`nav`を省略しない。それぞれ別の役割を持つ。

## 判断するときの見方

`aside`を使うか迷ったら、次を見る。

```text
この内容は、
周囲の主な内容と関係しているか
```

そのうえで、

```text
この部分を取り除いても、
主な内容そのものは成立するか
```

を考える。

成立するなら、補足として`aside`を使える可能性がある。

ただし、

```text
右側にある
カードになっている
背景色が違う
```

といった見た目だけでは判断しない。

## このページのまとめ

- `aside`は主内容に関連する補足的な内容を表す
- 画面の横側にあるから`aside`になるわけではない
- `section`は主な章、`aside`は補足という役割の違いがある
- `div`は意味を追加せず、実装上の範囲をまとめる
- `article`の中にも外にも`aside`を置ける
- 関連しているだけで、何でも`aside`になるわけではない
- 判断するときは「これを外しても主内容は成立するか」を見る
