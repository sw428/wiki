# 15_日付をtimeで表す

## このページの役割

`time`は、日付や時刻として意味を持つ文字列を表す要素。

このページでは、

- どんな値を`time`で表すか
- 表示する文字列と`datetime`をどう分けるか
- 公開日や更新日をどう示すか
- 同じ日付を表示ごとに食い違わせないために何を確認するか

を整理する。

## この範囲の芯

利用者に見せる日付と、機械が解釈できる値を分けて書ける。

```html
<time datetime="2026-09-22">2026年9月22日</time>
```

ここでは、

```text
2026年9月22日
→ 利用者が読む表示

2026-09-22
→ 機械が解釈できる値
```

という役割になる。

## timeは日付や時刻を表す

記事の公開日なら、次のように書ける。

```html
<time datetime="2026-09-22">2026年9月22日</time>
```

画面上の表示を変えても、同じ日付を表せる。

```html
<time datetime="2026-09-22">2026.09.22</time>
```

```html
<time datetime="2026-09-22">9月22日</time>
```

つまり、

```text
time要素の内容
→ 文章やデザインに合う表示

datetime
→ その表示が表す日付・時刻
```

と分ける。

## datetimeに機械向けの値を書く

日付は、基本的に`年-月-日`の形で指定する。

```html
<time datetime="2026-09-22">2026年9月22日</time>
```

時刻だけを表すこともできる。

```html
<time datetime="18:30">18時30分</time>
```

日付と時刻をまとめる場合は、`T`でつなぐ。

```html
<time datetime="2026-09-22T18:30">
  2026年9月22日 18時30分
</time>
```

特定のタイムゾーンを含む日時として示す必要がある場合は、オフセットも指定できる。

```html
<time datetime="2026-09-22T18:30+09:00">
  2026年9月22日 18時30分
</time>
```

日付だけで足りるなら、意味のない時刻やタイムゾーンまで追加しない。必要な精度の値だけを書く。

## datetimeを省略できる場合

`datetime`を省略する場合は、`time`の文字列自体が機械向けの有効な形式である必要がある。

```html
<time>2026-09-22</time>
```

一方、次の表示は人には読みやすいが、機械向けの形式とは分けておく。

```html
<time datetime="2026-09-22">2026年9月22日</time>
```

このWikiでは、表示を日本語やドット区切りにする場合、何の日付かを明確にするため`datetime`を指定する。

## 公開日や更新日は周囲の文章で区別する

`time`だけでは、その日付が公開日、更新日、開催日のどれなのかまでは決まらない。

記事の公開日なら、記事の導入情報として置ける。

```html
<article>
  <header>
    <h2>新サービスを公開しました</h2>
    <p>
      公開日:
      <time datetime="2026-09-22">2026年9月22日</time>
    </p>
  </header>

  <p>新しいサービスについて説明します。</p>
</article>
```

更新日なら、周囲の文章で更新日だと分かるようにする。

```html
<p>
  最終更新:
  <time datetime="2026-09-22">2026年9月22日</time>
</p>
```

```text
time
→ 日付・時刻であることを表す

周囲の文章
→ 何の日付・時刻かを説明する
```

と役割を分ける。

## datetimeと表示内容を一致させる

次のように、表示と`datetime`が別の日付を指す状態にはしない。

```html
<time datetime="2026-09-21">2026年9月22日</time>
```

この例では、

```text
表示
→ 9月22日

datetime
→ 9月21日
```

となっている。

同じ日時を別の形式で表す状態にする。

```html
<time datetime="2026-09-22">2026年9月22日</time>
```

`20XX-09-22`などの仮値を、公開するHTMLへ残さないことも確認する。

## SPとPCで同じ日付データを使う

レイアウトの都合でSP用とPC用の表示を分けても、同じ記事の日付を別の事実にしない。

```text
SP表示
→ 2026.09.22

PC表示
→ 2026年9月22日

どちらも表す日付
→ 2026-09-22
```

表示形式を変える場合でも、`datetime`は同じ値にする。

カンプ間で日付が食い違う場合は、端末ごとに別の日付をそのまま実装せず、どれを正しいデータとするか確認する。

同じ情報を表示条件ごとに複製する場合の注意は、[SPとPCで表示する要素を切り替える](../13_表示制御/01_SPとPCで表示する要素を切り替える.md#同じ情報を2つ置く場合)で扱う。

## お知らせ一覧でも使える

お知らせ一覧では、各項目の日付を`time`で表せる。

```html
<ul>
  <li>
    <time datetime="2026-09-22">2026.09.22</time>
    <a href="/news/1/">新サービスを公開しました</a>
  </li>
  <li>
    <time datetime="2026-09-15">2026.09.15</time>
    <a href="/news/2/">営業時間変更のお知らせ</a>
  </li>
</ul>
```

ここでは、

```text
ul
→ お知らせ一覧

li
→ お知らせ1件

time
→ そのお知らせの日付

a
→ 詳細ページへの移動
```

と役割を分けている。

## 日付に見える文字すべてへ使うわけではない

文章中に年や数字があれば、必ず`time`を使うわけではない。

```html
<p>2026年度の目標を決めます。</p>
```

文章の一部として説明しているだけなら、`time`を使わなくてもよい。

判断するときは、

```text
この文字列自体を、
特定の日付や時刻として示したいか
```

を見る。

## timeとspanは意味が違う

次の二つは、ブラウザ上で同じように表示できる。

```html
<span>2026年9月22日</span>
```

```html
<time datetime="2026-09-22">2026年9月22日</time>
```

違うのはHTML上の役割。

```text
span
→ それ自体では日付・時刻という意味を追加しない

time
→ 日付・時刻として表す
```

見た目は、どちらの要素でもCSSから指定できる。

```html
<time class="article-date" datetime="2026-09-22">
  2026.09.22
</time>
```

```css
.article-date {
  font-size: 0.875rem;
}
```

## 判断するときの見方

`time`を使うか迷ったら、次の順で見る。

```text
1. 特定の日付や時刻を表しているか
   ↓
   timeを検討する

2. 表示文字列だけで機械向けの形式になるか
   ↓
   ならない場合はdatetimeを指定する

3. 公開日・更新日・開催日のどれか
   ↓
   周囲の文章で役割を示す

4. 表示とdatetimeは同じ日時か
   ↓
   食い違いと仮値がないか確認する
```

## このページのまとめ

- `time`は日付や時刻を表す
- 利用者向けの表示と、機械向けの`datetime`を分けて書ける
- `datetime`を省略する場合は、文字列自体を有効な機械向け形式にする
- 公開日・更新日・開催日などの違いは周囲の文章で示す
- 必要がなければ時刻やタイムゾーンまで含めない
- 表示と`datetime`は同じ日時を表すようにする
- SPとPCで表示形式を変えても、同じ日付データを使う
- 見た目ではなく、特定の日付や時刻として示すかで判断する
