# 13_パンくずをHTMLで組む

## このページの役割

パンくずは、現在のページまでの階層をたどるためのナビゲーション。

このページでは、

- パンくず全体を何で囲むか
- 階層を`ol`・`li`でどう表すか
- 上位ページと現在地をどう区別するか
- 区切り記号をどこで扱うか

を整理する。

## この範囲の芯

基本形は次のように考える。

```text
nav
→ パンくずというナビゲーション

ol
→ 現在地までの順序を持つ一覧

li
→ 階層の1項目

a
→ 上位ページへの移動

aria-current="page"
→ 現在のページ
```

```html
<nav aria-label="パンくず">
  <ol>
    <li><a href="/">ホーム</a></li>
    <li><a href="/service/">サービス</a></li>
    <li aria-current="page">Web制作</li>
  </ol>
</nav>
```

見た目を横並びにすることより先に、ナビゲーション、階層、移動先、現在地という役割をHTMLで表す。

## パンくず全体をnavで囲む

パンくずは、利用者が上位のページへ移動するためのナビゲーションなので、全体を`nav`で囲む。

```html
<nav aria-label="パンくず">
  ...
</nav>
```

ページ内に複数の`nav`がある場合でも目的を区別できるように、`aria-label`で名前を付ける。

表示される見出しがある場合は、その見出しの`id`を`aria-labelledby`から参照する方法もある。

```html
<h2 id="title">現在地</h2>

<nav aria-labelledby="title">
  ...
</nav>
```

見出しを画面に表示しない場合は、`aria-label="パンくず"`で目的を伝えればよい。

## 階層をolとliで表す

パンくずは、上位から現在地までを順に並べる。

```text
ホーム
↓
サービス
↓
Web制作
```

順序に意味があるため、一覧全体を`ol`で表し、階層の1項目ずつを`li`にする。

```html
<ol>
  <li>ホーム</li>
  <li>サービス</li>
  <li>Web制作</li>
</ol>
```

構造は次のようになる。

```text
ol
├─ li
├─ li
└─ li
```

`ol`の直接の子には`li`を置く。横並びや項目間の余白はCSSで調整する。

## 上位ページをリンクにする

現在地より前の項目は、その上位ページへ戻るための移動先になる。

```html
<ol>
  <li><a href="/">ホーム</a></li>
  <li><a href="/service/">サービス</a></li>
  <li>Web制作</li>
</ol>
```

ここでは、

```text
ホーム
→ サイトの入口へ移動

サービス
→ 上位のサービスページへ移動

Web制作
→ 現在地
```

という役割になる。

現在地まで機械的にすべてリンクへせず、どの項目が実際の移動先なのかを見る。

## 現在地とaria-currentを対応させる

現在のページを移動先にする必要がなければ、最後の項目をリンクにせず表示できる。

```html
<li aria-current="page">Web制作</li>
```

`aria-current="page"`は、この項目が現在のページであることを示す。

現在地が非リンクの場合、`aria-current`は必須ではない。ただし、現在地を明示するために付けることができる。

パンくず内で現在のページを表す項目は一つにする。

現在のページを再読み込みするなどの理由で現在地もリンクにする場合は、そのリンクへ`aria-current="page"`を付ける。

```html
<li>
  <a href="/service/web/" aria-current="page">Web制作</a>
</li>
```

この場合も、`aria-current`を付けるのは現在のページを表すリンクだけ。

```text
現在地をリンクにしない
→ liなど現在地を表す要素へaria-currentを付けられる

現在地もリンクにする
→ 現在のページを表すaへaria-currentを付ける
```

と分ける。

`aria-current="page"`は、現在地という状態を支援技術へ伝えるための指定。

付けただけで、文字色や太さが自動的に変わるわけではない。

見た目も変える場合はCSSで指定する。

```css
.breadcrumb [aria-current="page"] {
  font-weight: 700;
}
```

つまり、

```text
aria-current
→ 現在地という状態

CSS
→ 現在地の見た目
```

と役割を分ける。

## 区切り記号は階層の項目ではない

パンくずでは、項目の間へ`/`や`>`などを表示することがある。

```text
ホーム / サービス / Web制作
```

この区切り記号は移動先でも階層の項目でもなく、項目同士の境界を見せるための装飾。

そのため、各リンクの文字列へ含めず、CSSまたは装飾用の要素として分ける。

```html
<li>
  <span aria-hidden="true">/</span>
  <a href="/service/">サービス</a>
</li>
```

CSSの疑似要素で表示する場合は、区切り記号が項目名の一部として不要に読み上げられないか確認する。読み上げられる場合は、CSSの線や背景で形を作るか、`aria-hidden="true"`を持つ装飾用要素へ分ける。

区切り記号をリンクの中へ入れると、リンク名の一部として扱われやすい。

```html
<!-- 区切り記号までリンクへ含めない -->
<a href="/service/">サービス /</a>
```

パンくずの横並び、折り返し、空白、疑似要素の扱いは、[HTMLの空白と疑似要素を整える](../08_インラインと行の仕組み/05_HTMLの空白と疑似要素を整える.md)で確認する。

## パンくずの階層はページの関係から決める

パンくずは、URLを`/`で分割してそのまま表示するものとは限らない。

たとえばURLが、

```text
/products/123/
```

でも、利用者に示したい階層が、

```text
ホーム
↓
商品一覧
↓
商品名
```

なら、その関係をパンくずとして表す。

```text
URLの文字列
≠ 必ずパンくずの階層
```

ページがサイト内のどの位置にあり、利用者がどの上位ページへ戻れるとよいかから決める。

## パンくずはページ見出しの代わりではない

パンくずに現在のページ名があっても、本文の主見出しが不要になるわけではない。

```html
<nav aria-label="パンくず">
  <ol>
    <li><a href="/">ホーム</a></li>
    <li><a href="/service/">サービス</a></li>
    <li aria-current="page">Web制作</li>
  </ol>
</nav>

<main>
  <h1>Web制作</h1>
  ...
</main>
```

役割は次のように異なる。

```text
パンくず
→ 現在地までの移動経路

h1
→ ページ本文の主見出し
```

同じページ名を含むことはあるが、置き換えるものではない。

## 判断するときの見方

パンくずを組むときは、次の順で見る。

```text
1. 現在地までの移動経路か
   ↓
   nav

2. 上位から現在地までの順序があるか
   ↓
   ol + li

3. どの項目から移動できるか
   ↓
   上位ページをaにする

4. どれが現在のページか
   ↓
   aria-current="page"で示す

5. 区切り記号は内容か装飾か
   ↓
   リンクや項目の意味から分けて扱う
```

## この範囲のまとめ

- パンくずは現在地までの階層を示すナビゲーション
- 全体を名前付きの`nav`で囲む
- 上位から現在地までを`ol`、各階層を`li`で表す
- 上位ページへの移動には`a`を使う
- 現在地がリンクなら、その`a`へ`aria-current="page"`を付ける
- 現在地が非リンクなら、`aria-current`は必須ではないが明示できる
- 区切り記号は階層の項目やリンク名へ混ぜず、装飾として扱う
- URLの文字列ではなく、ページ同士の関係から階層を決める
- パンくずとページ本文の主見出しは別の役割を持つ
