# メディアの表示枠と重ね配置整理マップ

> [!NOTE]
> Codexが第11章内の反映先と境界を確認するための内部ルーター。人間向けの入口には01を使う。

## 章の核

第11章は、画像・動画を表示する枠と内容の役割を分け、読み込み前の領域、画像上の重ね方、動画と重ねる部品の枠を実装する。

- 表示枠と画像内容を分ける：01〜02
- 読み込み前の領域を作って確認する：03〜04
- 画像上へ内容を重ねる：05〜06
- 動画の表示枠と重ねる範囲を決める：07〜08

## 整理時に保つ関係

1. 絶対配置した要素は親の高さを作らない。
2. CLS対策は固定手順ではなく、実際の移動を観測して判断する。
3. 親の表示枠、画像要素の箱、画像内容を区別する。
4. 切り抜く範囲と、外側にはみ出してよい部品の配置範囲を区別する。
