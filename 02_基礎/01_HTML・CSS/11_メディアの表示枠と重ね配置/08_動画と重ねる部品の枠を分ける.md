# 08_動画と重ねる部品の枠を分ける

動画へ角丸を付けたり、再生ボタンや時間ラベルを重ねたりするときは、どこまでを同じ枠で切り抜くかを決める。

## 角丸と重ねる部品を管理する

- 動画単体だけを丸める: `video`自身へ`border-radius`
- 動画・再生ボタン・時間ラベルをまとめて切り抜く: 親へ`border-radius`と`overflow: hidden`
- 重ねる部品が親の外へ出る必要がある: 切り抜き用の内側枠と、配置用の外側要素を分ける

## 切り抜き用の枠を内側へ分ける

```html
<div class="player">
  <div class="clip">
    <video class="video" src="movie.mp4" controls></video>
  </div>
  <span class="label">03:15</span>
</div>
```

```css
.player {
  position: relative;
}

.clip {
  overflow: hidden;
  border-radius: 8px;
}

.video {
  display: block;
  width: 100%;
  aspect-ratio: 16 / 9;
  object-fit: cover;
}

.label {
  position: absolute;
  inset-inline-end: -8px;
  inset-block-end: 16px;
}
```

`.clip`だけが動画を切り抜き、`.player`は重ねる部品の配置基準になる。ラベルは`.clip`の外側にあるため、負の位置を使って枠外へ出しても`overflow: hidden`では切れない。

絶対配置の基本形は、[画像の上に文字や部品を重ねる](./05_画像の上に文字や部品を重ねる.md)と同じく、土台と重ねる子を分けて確認する。

## 確認順

1. `video`自身だけを切り抜くのか、重ねる部品まで同じ枠に含めるのか。
2. `overflow: hidden`で必要な部品まで切れていないか。
3. 外へ出す部品があるなら、切り抜き用の内側枠と配置用の外側要素を分ける。
4. 絶対配置する場合は、どの要素を包含ブロックにするか確認する。
