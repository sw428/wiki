# 05_画像の上に文字や部品を重ねる

画像の上に文字やラベルを重ねるときは、土台の高さを作る要素、重ねる範囲、重ねた箱の中身を分ける。

## 画像の上に文字を重ねる基本形

最初に画像のない箱で指定先を確かめ、その後で通常フローの画像を土台にする。

### 箱の中央に文字を重ねる

最初は画像を使わず、色付きの箱へ文字を重ねる。

```html
<div class="box">
  <p class="text">お知らせ</p>
</div>
```

```css
.box {
  position: relative;
  width: 300px;
  height: 180px;
  background: #dceeff;
}

.text {
  position: absolute;
  inset: 0;
  display: grid;
  place-items: center;
  margin: 0;
}
```

- `.box`: 表示する場所と大きさを作り、絶対配置の基準になる
- `position: absolute; inset: 0`: `p`の箱を基準領域の四辺へ合わせる
- `display: grid; place-items: center`: 広がった`p`の中で文字を中央へ置く

中央寄せの2行を一時的に外すと、`p`の箱は全面のまま、文字だけが左上へ戻る。箱を広げる指定と、中身を中央へ置く指定を分けて確認できる。

`inset: 0`で必ずすべての要素が全面へ広がるわけではない。幅・高さ、margin、置換要素かどうかなどの条件は[位置を指定しただけなのに、なぜ箱まで広がる？](../../../03_詳細/01_HTML・CSS/04_insetで広がる条件を調べる.md)で扱う。

### 画像を使って重ねる

```html
<div class="banner">
  <img class="image" src="banner.jpg" alt="" width="800" height="450">
  <p class="text">お知らせ</p>
</div>
```

```css
.banner {
  position: relative;
}

.image {
  display: block;
  width: 100%;
  height: auto;
}

.text {
  position: absolute;
  inset: 0;
  display: grid;
  place-items: center;
  margin: 0;
}
```

この例では、通常フローに残る画像が親の高さを作る。絶対配置した文字は親の高さを作らない。画像がなくても比率枠を維持したい場合は、親へ`aspect-ratio`を置き、画像を[比率の枠へ収める](../12_レスポンシブ画像設計/03_同一比率フレーム型.md)。

### 広がる箱と中の文字は別

`<p class="text">お知らせ <span>新着</span></p>`の場合、`absolute`と`inset`が操作するのは`p`の箱である。中の文字や`span`まで同じ大きさへ引き伸ばす指定ではない。

親の`position: relative`は、子を基準に合わせるためのもの。常にHTML上の直上要素が基準になるとは限らないため、DevToolsでは重ねる要素と、その包含ブロックの両方を確認する。

## 確認順

1. 土台の幅と高さをどの要素が作っているか確認する。
2. 重ねる子の包含ブロックを確認する。
3. `inset`が決める範囲と、Gridが整列する中身を分ける。
4. 絶対配置した子だけに親の高さを依存していないか確認する。
5. 画面幅や画像の切り替え後も、重ねた内容が対象を指しているか確認する。

absoluteの子がFlexコンテナ内で中央に見える特殊な条件は、[absoluteの子がFlexで中央に見える条件を調べる](../../../03_詳細/01_HTML・CSS/07_absoluteの子がFlexで中央に見える条件を調べる.md)へ分ける。
