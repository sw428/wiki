# 03_画像の読み込み前に表示領域を予約する

画像の読み込み後に後続内容が動かないよう、画像の比率またはデザイン上の枠を先に伝える。

## HTMLの寸法属性で画像比率を伝える

```html
<img
  class="photo"
  src="./img/card.jpg"
  alt=""
  width="800"
  height="450"
>
```

```css
.photo {
  display: block;
  width: 100%;
  height: auto;
}
```

`img`の`width` / `height`属性は寸法情報を持ち、レンダリングでは比率の計算にも使われる。CSSで表示幅を変えても、2値から得られる比率により、画像データを取得する前から高さを見積もれる。

属性値は実画像の寸法、または少なくとも縦横比と一致する値を使う。補完機能が入れた数値をそのまま信用せず、素材を確認する。

## デザイン上の枠はCSSで予約する

元画像の比率ではなく、正方形やカード固有の比率へ切り抜くなら、枠へ`aspect-ratio`を指定する。

```css
.frame {
  aspect-ratio: 4 / 3;
  overflow: hidden;
}

.image {
  width: 100%;
  height: 100%;
  object-fit: cover;
}
```

| 予約したいもの | 主な方法 |
| --- | --- |
| 画像本来の比率 | `img`の`width` / `height`属性 |
| 選ばれる画像候補ごとの比率 | `picture`内の`source`と`img`の寸法属性 |
| デザイン上の表示枠 | CSSの`aspect-ratio`、必要なら高さ・最小高さ |

同じ比率を理由なくHTMLとCSSへ二重管理しない。HTMLは素材の寸法、CSSは素材と異なるデザイン上の枠、という役割で分ける。
