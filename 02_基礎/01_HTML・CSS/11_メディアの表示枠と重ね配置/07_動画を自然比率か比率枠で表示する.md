# 07_動画を自然比率か比率枠で表示する

`video`も置換要素として、素材の自然比率で表示するか、デザイン上の決めた比率の枠へ収めるかを選ぶ。

## 動画全体を自然な比率で表示する

```html
<video
  class="movie"
  src="./video/interview.mp4"
  poster="./img/interview-poster.jpg"
  width="1280"
  height="720"
  controls
></video>
```

```css
.movie {
  display: block;
  width: 100%;
  height: auto;
}
```

映像全体を切らず、素材の比率で表示するならこの形から始める。`poster`は再生前などに表示する画像で、動画要素とは別のHTML要素を作らない。

## 決めた比率の枠へ収める

再生ボタン、時間ラベル、装飾などを同じ領域で管理する場合は親を枠にする。

```html
<div class="frame">
  <video
    class="video"
    src="./video/interview.mp4"
    poster="./img/interview-poster.jpg"
    controls
  ></video>
</div>
```

```css
.frame {
  aspect-ratio: 16 / 9;
  overflow: hidden;
  border-radius: 8px;
}

.video {
  display: block;
  width: 100%;
  height: 100%;
  object-fit: cover;
}
```

`cover`では映像の一部が切れる。操作UIや字幕まで切れると困る場合は、自然比率または`contain`を使う。ブラウザが表示する標準コントロールの見え方も実機で確認する。

## 確認順

1. 素材の自然比率で見せるか、デザイン上の枠へ収めるか決める。
2. 映像の切り取りを許容できるか確認する。
3. `video`自身と親のどちらが表示枠を担当するか確認する。
4. poster、映像、字幕、標準コントロールが必要な条件で見えるか確認する。
5. 重ねる部品を枠外へ出す場合は、[動画と重ねる部品の枠を分ける](./08_動画と重ねる部品の枠を分ける.md)へ進む。

## iframeとは分ける

`iframe`は外部文書や埋め込みプレイヤーを表示する要素で、`video`の`object-fit`と同じ方法では中身を制御できない。YouTubeなどの埋め込みは、[iframeの表示領域を作る](../15_UI部品の実装判断/12_iframeの表示領域を作る.md)へ分ける。
