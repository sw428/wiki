# 06_画像上の特定位置に部品を置く

地図ピンなどを画像の特定位置へ置くときは、親枠内のCSS座標へ部品を配置していることを確認する。

## 地図へピンを重ねる

```css
.frame {
  position: relative;
  aspect-ratio: 16 / 9;
  overflow: hidden;
}

.image {
  display: block;
  width: 100%;
  height: 100%;
  object-fit: cover;
}

.pin {
  position: absolute;
  left: 50%;
  top: 50%;
  transform: translate(-50%, -50%);
}
```

ピンは実際の緯度・経度を理解しておらず、親枠内のCSS座標へ置かれる。PC/SPで地図画像や`object-position`を変えると見える地図の範囲も変わるため、同じ場所を指すにはピン座標の再確認が必要になる。

## 確認順

1. ピンの包含ブロックになっている枠を確認する。
2. `left`と`top`が、その枠のどの位置を基準にしているか確認する。
3. `transform`でピン自身の中心を基準点へ合わせているか確認する。
4. 画像候補、切り取り、`object-position`を変えた画面幅でも位置を確認する。
