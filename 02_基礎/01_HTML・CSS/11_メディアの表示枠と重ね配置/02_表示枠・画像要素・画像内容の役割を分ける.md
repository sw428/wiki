# 02_表示枠・画像要素・画像内容の役割を分ける

画像を決めた大きさの領域へ表示するときは、親の表示枠、`img`要素の箱、画像ファイルの内容を分けて考える。このWikiでは、各指定が何を変えているか確認しやすいように、原則として親要素を表示枠にした基本形から説明する。

## 最初に3つの役割を分ける

```text
親の表示枠
→ レイアウト上の幅・高さ・比率を決める

img要素の箱
→ 表示枠と同じ大きさまで広げる

画像内容
→ img要素の箱の中で、全体を見せるか切り抜くかを決める
```

| 対象 | 主に使う指定 | 決まるもの |
| --- | --- | --- |
| 親の表示枠 | `width`、`height`、`min-height`、`aspect-ratio` | ページ上で画像を表示する領域 |
| `img`要素の箱 | `width`、`height` | 画像要素が占める大きさ |
| 画像内容 | `object-fit`、`object-position` | `img`要素の箱の中での描かれ方 |

`object-fit`は、親の表示枠の大きさを直接決める指定ではない。先に`img`要素の箱の大きさを決め、その箱の中で画像内容をどう描くかを指定する。

## 基本形では親を表示枠にする

```html
<div class="photo-frame">
  <img
    class="photo-frame__image"
    src="./img/landscape.jpg"
    alt="山と湖の風景"
    width="600"
    height="400"
  >
</div>
```

```css
.photo-frame {
  height: 400px;
}

.photo-frame__image {
  display: block;
  width: 100%;
  height: 100%;
  object-fit: cover;
}
```

この例では、次の順で表示が決まる。

1. `.photo-frame`の`height`が表示枠の高さを決める。
2. `.photo-frame__image`の`width`と`height`が、`img`要素の箱を親いっぱいに広げる。
3. `object-fit: cover`が、画像自身の比率を保ったまま画像内容で箱を埋める。

`cover`による切り抜きは`img`要素の箱の中で行われる。この実装では、画像内容を切り抜くためだけに親へ`overflow: hidden`を指定する必要はない。

## 親要素は必須ではない

単純な構造では、`img`自身に表示寸法を指定し、表示枠を兼ねてもよい。

```html
<img
  class="photo-image"
  src="./img/landscape.jpg"
  alt="山と湖の風景"
  width="600"
  height="400"
>
```

```css
.photo-image {
  display: block;
  width: 100%;
  height: 400px;
  object-fit: cover;
}
```

この場合は、`img`要素の箱がページ上の表示領域も兼ねる。親要素を追加すること自体が目的ではない。

基本形で親と画像を分けるのは、次の役割を確認しやすくするためである。

- 枠の比率や高さを変える指定
- 画像要素を枠へ合わせる指定
- 枠内で画像内容を見せる指定
- 後から文字や部品を重ねるときの基準

## `height: 100%`には基準となる高さが必要

画像へ`height: 100%`を指定しても、親の高さが常に自動で基準になるわけではない。基本形のように親の`height`が決まっていれば、画像要素をその高さへ合わせられる。

一方、親が`min-height`だけを持ち、実際の高さが内容量で決まる場合は、画像の`height: 100%`が期待どおり親の最終的な高さへ広がらないことがある。`height`と`min-height`を同じ実装として扱わず、画像も伸びる必要がある場合は、重ね配置など別のレイアウト方法を含めて確認する。

## レスポンシブ画像の各型へ当てはめる

| 表示領域の型 | 表示枠が担当すること | 画像側が担当すること |
| --- | --- | --- |
| 自然比率維持型 | 独立した枠を作らず、画像自身の比率を使う | 幅に合わせて画像要素自身が縮小・拡大する |
| 同一比率フレーム型 | `aspect-ratio`で一定の比率を保つ | 枠と同じ大きさになり、`object-fit`で見せ方を決める |
| 比率切替型 | ブレークポイントで`aspect-ratio`を切り替える | 枠と同じ大きさになり、`object-fit`で見せ方を決める |
| 高さ基準型 | `height`または`min-height`で高さを決める | 枠の作り方に合わせて大きさと見せ方を決める |

表示領域の型は[レスポンシブ画像設計の選び方](../12_レスポンシブ画像設計/01_レスポンシブ画像設計の選び方.md)で選ぶ。

## `picture`を使っても役割は変わらない

`picture`を使って画像ファイルを切り替えても、表示枠、画像要素の箱、画像内容の関係は変わらない。

```text
picture・source
→ 画像候補と選択条件をブラウザへ伝える

img
→ 選ばれた画像を実際に表示する要素

表示枠
→ レイアウト上の大きさと形を決める

object-fit
→ img要素の箱の中で画像内容を描画する
```

ブラウザが候補から選んだ画像は、`img`の`currentSrc`で確認できる。`picture`が表示領域の幅や高さを決めたり、`object-fit`の代わりに画像内容の収め方を決めたりするわけではない。

SPとPCなどで構図や画像内容を変える場合は[画像切替型](../12_レスポンシブ画像設計/06_画像切替型.md)、同じ画像内容から表示幅や表示密度に合う候補を選ばせる場合は[srcsetとsizesで画像候補を選ぶ](../12_レスポンシブ画像設計/07_srcsetとsizesで画像候補を選ぶ.md)で扱う。

## 確認すること

1. DevToolsで、親の表示枠と`img`要素の箱の大きさを別々に確認する。
2. `object-fit`を外したとき、表示枠ではなく画像内容の見え方が変わるか確認する。
3. 親を省略する場合は、`img`自身が表示領域を兼ねていることを確認する。
