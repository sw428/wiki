# 04_langで文書の言語を示す

## このページの役割

`lang`属性で、HTML文書の主な言語を示す方法を確認する。

```html
<html lang="ja">
```

日本語を主に使う文書では、基本的に`ja`を指定する。

## `lang`は文書の言語を示す

`lang`は、その要素の内容がどの言語で書かれているかを示す属性。

文書全体の主な言語は、`html`要素に指定する。

```html
<html lang="ja">
```

```text
html
└─ 文書全体の主な言語は日本語
```

英語を主に使う文書なら、

```html
<html lang="en">
```

のように、実際の内容に合わせて指定する。

## 見た目を変えるための指定ではない

`lang="ja"`は、文字色や文字サイズなどの見た目を直接指定する属性ではない。

`lang`は、

```text
この内容は何語なのか
```

をブラウザや支援技術などが判断するための情報として使われる。

たとえば、音声読み上げでの発音など、言語に応じた処理の手掛かりになる。言語に応じたフォント選択や組版によって表示へ影響する場合はあるが、目的は内容の言語を示すこと。

## 一部だけ別の言語にすることもできる

文書全体は日本語でも、一部だけ別の言語になることがある。

```html
<html lang="ja">
  <body>
    <p>料金について紹介します。</p>
    <p lang="en">Price Guide</p>
  </body>
</html>
```

この場合、

```text
html
→ 主な言語は日本語

p lang="en"
→ この部分は英語
```

として読む。

通常はまず`html`に文書全体の主な言語を指定し、必要な部分だけ個別に変更する。

## 一言でいうと

`lang`は内容がどの言語で書かれているかを示し、文書全体の主な言語は`html`要素に指定する。
