# 07_titleで文書の名前を付ける

## このページの役割

`title`要素で、HTML文書の名前を付ける方法を確認する。

```html
<title>料金案内 | サイト名</title>
```

`title`はページ本文に表示する見出しではなく、その文書自体を識別するための名前。

## `title`は`head`に書く

`title`要素は`head`の中に書く。

```html
<head>
  <title>料金案内 | サイト名</title>
</head>
```

通常のWeb文書では、一つの文書に一つの`title`を置く。

## 文書を識別する名前になる

`title`は、そのページが何の文書なのかを示す。

たとえば、

```html
<title>料金案内 | サイト名</title>
```

なら、

```text
料金案内
→ このページの内容

サイト名
→ どのサイトのページか
```

を識別できる。

ページ単独で見ても内容が分かる名前にする。

## ブラウザのUIでも使われる

`title`はページ本文の中だけで使われる情報ではない。

ブラウザでは、たとえば、

```text
タブ

履歴

ブックマーク
```

など、文書を識別する場所でも使われる。

そのため、

```html
<title>ページ</title>
```

のような曖昧な名前より、

```html
<title>料金案内 | サイト名</title>
```

のように、どのページか判断できる名前にする。

## `h1`とは役割が違う

`title`と`h1`は、どちらもページ名のような文字になることがあるが、役割は違う。

```html
<head>
  <title>料金案内 | サイト名</title>
</head>

<body>
  <h1>料金案内</h1>
</body>
```

```text
title
→ 文書そのものの名前

h1
→ ページ本文の主見出し
```

として分けて考える。

同じ言葉を含むことはあるが、同じ要素ではない。

## 一言でいうと

`title`は`head`に書く文書の名前で、ブラウザのタブや履歴などでもページを識別するために使われる。
