## 反映先と確認順

1. 01は、見本を変更してページを作り始める入口。各要素の細かな仕様を集めず、変更する場所と確認結果を結ぶ。
2. 文書についての情報は02、外部ファイルの取得・実行は03へ分ける。`head`に書けるという共通点だけで一つに戻さない。
3. CSSの競合は[06](../06_CSSカスケードとDevToolsの見方/00_CSSカスケードとDevToolsの見方整理マップ.md)、JavaScriptからDOMを操作する方法は[JS](../../02_JS/02_DOMとイベント.md)へ分担する。
4. `base`は通常の静的サイトに必須の骨格ではない。相対URL全体へ影響するため04に分け、使用を共通方針として自動採用しない。
5. 更新時は、HTML構文上の要件、一般的な制作テンプレート、検索やブラウザの実装依存を区別する。仕様上必須ではない項目を「常に必須」と断定しない。
