## この章に残す境界

1. 01は、人間向け概要と実装開始用の最小文書を兼ねる。各行の詳しい説明は02〜10へ委譲する。
2. 02〜07は、最小文書に現れる宣言・要素・属性を一つの疑問ずつ扱う。
3. CSSの参照は08、JavaScriptファイルの参照は09、HTML解析とJavaScriptの取得・実行タイミングは10へ分ける。
4. CSSの競合は[06_CSSカスケードとDevToolsの見方](../06_CSSカスケードとDevToolsの見方/01_DevToolsで適用されたCSSを確認する.md)、JavaScriptからDOMを操作する方法は[DOMとイベント](../../02_JS/02_DOMとイベント.md)へ分ける。
5. `base`は相対URL全体へ影響するため、11へ分けて必要な場合だけ読む。通常の静的サイトへ自動採用しない。
6. HTML構文上の要件、一般的な制作テンプレート、ブラウザの実装条件を区別し、仕様上必須ではない項目を「常に必須」と断定しない。
