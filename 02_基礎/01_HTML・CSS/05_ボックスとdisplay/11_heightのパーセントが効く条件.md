# heightのパーセントが効く条件

`height` の割合は、包含ブロックの高さを割合計算できる状態か確認する。

## 高さの割合は幅と同じ感覚で決めない

高さの `%` は、基準になる高さが内容に応じて決まる `auto` のままだと、割合を解決できない場合がある。

単純な通常フローでは、まず包含ブロック側の高さを割合計算できる状態かを見る。

通常の内容を持つ箱の高さは、文字や子要素の量から決まりやすい。

## autoの親と高さが決まった親を比べる

```css
.parent {
  height: auto;
}

.child {
  height: 50%;
}
```

単純な通常フローで親の高さが `auto` の場合、親の高さは子を含む内容から決まる。子の50%を計算するための高さが先に決まっていないため、この指定だけでは期待した半分の高さにならない。

```css
.parent {
  height: 240px;
}

.child {
  height: 50%;
}
```

同じ条件で親の高さが240pxと決まっていれば、子の使用高さは120pxになる。

これは単純な通常フローでの基本例である。FlexやGrid、絶対配置では高さの決まり方が異なるため、「割合を使うなら必ず親に固定の高さを書く」という共通ルールにはしない。

一般的な `height: auto` の扱いは[通常フローを基準にする](../09_レイアウト/06_通常フローと余白の関係を確認する.md#通常フローを基準にする)へ分ける。

`height: 50%` が予想と違うときは、[箱の大きさが予想と違うときの確認順](./12_箱の大きさが予想と違うときの確認順.md)も使う。
