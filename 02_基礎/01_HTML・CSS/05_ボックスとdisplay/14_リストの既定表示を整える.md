# リストの既定表示を整える

リストでは、`margin` を消しても字下げやマーカーが残ることがある。

## marginだけでは消えない表示を見る

```css
ul,
ol {
  margin: 0;
  padding: 0;
}
```

`padding` は `margin` とは別のプロパティなので、字下げの原因になっている場合は別に確認する。

マーカーを消す場合は `list-style` も別に確認する。

既定表示をどこまで消すかは、リストをどのように見せたいかで決める。

「リセットだから全部消す」と決めず、DevToolsで現在の `margin`、`padding`、マーカーを確認してから必要な指定を選ぶ。

bodyや見出し、段落などの既定marginは[既定の余白をどこまで消すか決める](./13_既定の余白をどこまで消すか決める.md)で扱う。
