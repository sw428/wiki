# 03_パーセント指定と包含ブロック

主な基礎：[一つの箱とdisplay](./01_一つの箱とdisplay.md)。親と子の幅が決まる順序から確認したい場合は、前提知識の[widthが箱ごとに決まる流れ](../../../01_前提知識/01_HTML・CSS/05_ボックスとdisplay/01_widthが箱ごとに決まる流れ.md)へ戻る。`50%`と書いたのに予想した大きさにならないとき、何を基準に計算しているかを確認する。

## `%`の基準はプロパティごとに違う

`%` は単独で「親に対する割合」を意味する単位ではない。何を基準に計算するかは、`%` を使うプロパティごとに決まる。

さらに、次の二つは別に確認する。

1. その `%` は何を参照して計算されるか
2. そのプロパティの値は子孫へ継承されるか

| 指定 | 主な参照先 | プロパティの継承 |
| --- | --- | --- |
| `width: 50%` | 包含ブロックの幅 | しない |
| `height: 50%` | 包含ブロックの高さ | しない |
| `font-size: 150%` | 親要素の文字サイズ | する |
| `line-height: 150%` | 指定した要素自身の文字サイズ | する |

親が `width: 800px` でも、その800pxが子へ継承されるわけではない。子自身に `width: 50%` を指定したとき、子の幅を計算するために包含ブロックの幅を参照する。

## `width: auto`と`width: 100%`は同じではない

単純な通常フローのブロックでは、どちらも親と同じ幅に見えることがある。ただし、幅の決まり方は異なる。

- `width: auto`: その箱のレイアウト規則と利用可能な空間から使用幅が決まる
- `width: 100%`: その要素自身の`width`を、包含ブロックの幅に対する100%として計算する

```css
.parent {
  max-width: 380px;
}

.child {
  width: 100%;
}
```

この`.parent`が通常フローのブロックなら、`width`の初期値`auto`によって利用可能な幅を使い、広い場合は`max-width: 380px`で止まる。そのため、同じ条件では`.parent`へ`width: 100%`を追加しなくても目的の表示になる場合がある。

この例では、まず`.parent`自身の幅が決まる。その後、通常の入れ子では`.parent`が子の包含ブロックになり、`.child`が自分の`width: 100%`を計算する。親の`width`が子へ継承されたのではなく、階層ごとに別の幅を決めている。

`width`が適用されるか、`auto`がどのような幅になるかは、生成される箱やレイアウトの種類によって変わる。最初は通常ブロックの例で区別し、inlineなどとの違いは[一つの箱とdisplay](./01_一つの箱とdisplay.md#blockとinlineで背景の広がり方を比べる)で確認する。

## DOM上の親と包含ブロックは同じとは限らない

通常フローの単純な入れ子では、直近の親要素が作る領域を基準に幅を計算することが多い。そのため、実務では「親幅の50%」という説明で結果が合う場面も多い。

ただし、正確な基準はDOM上の親という名前ではなく、その要素の**包含ブロック**である。絶対配置では、直近の親要素が基準にならないことがある。

```html
<div class="outer">
  <div class="parent">
    <div class="child"></div>
  </div>
</div>
```

```css
.outer {
  position: relative;
  width: 800px;
}

.child {
  position: absolute;
  width: 50%;
}
```

この例で `.child` のDOM上の親は `.parent` だが、絶対配置の基準を作っている祖先は `.outer` である。そのため、`.child` の幅は800pxの50%で400pxになる。

最初は、`position: relative` を持つ祖先が絶対配置の基準になる例を使えばよい。厳密には `transform` や `contain` などが包含ブロックを作る場合もあるため、すべてを「最も近い `position: relative` の祖先」とは決めない。

通常のブロックが外側と同じ幅へ広がって見えても、`width` を継承したわけではない。`width: auto` などのレイアウト規則によって、包含ブロック内の利用可能幅から寸法が決まっている。

## 高さの割合は別に確認する

高さの`%`は、基準になる高さが内容に応じて決まる`auto`のままだと、割合を解決できない場合がある。単純な通常フローでは、まず親側の高さが確定しているかを見る。

通常の内容を持つ箱の高さは、文字や子要素の量から決まりやすい。一般的な`height: auto`の扱いは[通常フローを基準にする](../09_レイアウト/06_通常フローと余白の関係を確認する.md#通常フローを基準にする)へ分ける。

## 実装時の確認順

1. DevToolsで対象要素の実寸を見る。
2. `display`を確認し、その箱に`width`が適用されるかを見る。
3. `width`が`auto`、`%`、長さのどれかを確認する。
4. `%`なら、基準となる包含ブロックと、その幅が確定しているかを見る。
5. `min-width`や`max-width`で使用幅が制限されていないかを見る。
6. DOM上の親と包含ブロックが同じか確認する。
7. 継承の問題と割合計算の問題を分ける。

`line-height`の継承方法は[line-heightの指定値と継承](../08_インラインと行の仕組み/02_line-heightの指定値と継承.md)で扱う。絶対配置で四辺の位置から幅・高さが決まる条件は[03のinset詳細](../../../03_詳細/01_HTML・CSS/03_insetで広がる条件を調べる.md)で確認できる。
