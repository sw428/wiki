# パーセント指定と包含ブロック

`%` は単独で「親に対する割合」を意味する単位ではない。

何を基準に計算するかは、`%` を使うプロパティごとに決まる。

## %の参照先はプロパティごとに違う

次の二つは別に確認する。

1. その `%` は何を参照して計算されるか
2. そのプロパティの値は子へ継承されるか

| 指定 | 主な参照先 | プロパティの継承 |
| --- | --- | --- |
| `width: 50%` | 包含ブロックの幅 | しない |
| `height: 50%` | 包含ブロックの高さ | しない |
| `font-size: 150%` | 親要素の文字サイズ | する |
| `line-height: 150%` | 指定した要素自身の文字サイズ | する |

`line-height: 150%` は、指定した要素自身の文字サイズから計算された長さが子へ継承される。子の文字サイズに合わせて150%を計算し直すわけではない。子ごとに文字サイズを基準に計算させたい場合は、単位なしの数値との違いを[line-heightの指定値と継承](../08_インラインと行の仕組み/02_line-heightの指定値と継承.md)で確認する。

親が `width: 800px` でも、その800pxが子へ継承されるわけではない。

子自身に `width: 50%` を指定したとき、子の幅を計算するために包含ブロックの幅を参照する。

## 通常の入れ子では親が基準になることが多い

通常フローの単純な入れ子では、直近の親要素が作る領域を基準に幅を計算することが多い。

そのため、実務では「親幅の50%」という説明で結果が合う場面も多い。

ただし、正確な基準はDOM上の親という名前ではなく、その要素の包含ブロックである。

DOM上の親と包含ブロックが一致しない例は、[DOM上の親と包含ブロックを区別する](./10_DOM上の親と包含ブロックを区別する.md)で確認する。

次は[widthのautoと100パーセントを比べる](./09_widthのautoと100パーセントを比べる.md)で、包含ブロックを使って幅が決まる例を見る。
