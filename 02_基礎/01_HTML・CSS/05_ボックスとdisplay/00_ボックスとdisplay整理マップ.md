> [!NOTE]
> Codexが第5章本体と補足記事の分担を確認するための内部ルーター。人間向けの必読ページではない。

## 章の核

第5章は、HTML要素が画面上の箱としてどう扱われ、その箱の大きさがどう決まるかを扱う。

- 箱を作る・読む：02〜06
- 箱の寸法が決まる：07〜11
- 予想と違うときに調べる：12
- ブラウザ既定の表示を整える：13〜14

## 整理時に保つ関係

- ブラウザが表示を作る工程そのものは第7章を主な説明先にする。
- line boxや文字の行は第8章を主な説明先にする。
- Flex/Gridの詳しい配置は第9章を主な説明先にする。
- 画像の比率枠はレスポンシブ画像設計を主な説明先にする。
- 他章が正本の内容は、第5章では必要な入口とリンクだけ残す。
- 記事を分ける単位は、用語やプロパティではなく「初心者が実装中に持つ一つの疑問」とする。
- 複数の概念が同じ疑問へ答えるために連続して必要なら一記事にまとめる。
- 一つの記事の途中で疑問が切り替わる場合は分ける。
