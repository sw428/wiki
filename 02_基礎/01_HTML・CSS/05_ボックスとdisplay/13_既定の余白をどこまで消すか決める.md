# 既定の余白をどこまで消すか決める

`body` だけの余白を消す場合と、見出しや段落などの既定余白も自分で管理する場合では、対象が違う。

## bodyだけを直す

ページ外周だけをなくしたいなら、`body` を対象にする。

```css
body {
  margin: 0;
}
```

これはページ外周に見えるbodyの既定marginを消す。

見出し、段落、リストなどの既定marginは残る。

## 見出しや段落の余白も消す

見出しや段落の既定marginも自分で管理するなら、必要な要素を指定する。

```css
h1,
h2,
h3,
p,
ul,
ol,
figure {
  margin: 0;
}
```

## 全消去と個別消去を目的から選ぶ

`* { margin: 0; }` と書けば、すべての要素のmarginが対象になる。

ただし、`padding` や `list-style` など、別のプロパティまで消えるわけではない。

全消去と個別消去のどちらか一方が常に正しいわけではない。

1. 画面上で不要な余白を見つける。
2. DevToolsで、その余白がどの要素の `margin` や `padding` か確認する。
3. サイト全体で消すか、その要素だけで消すか決める。
4. リストのマーカーなど、別の既定表示を残すか確認する。

リストの字下げやマーカーは、[リストの既定表示を整える](./14_リストの既定表示を整える.md)で分けて扱う。

`box-sizing: border-box` は余白を消す指定ではない。

`width` と `height` の計算範囲をそろえる話は、[box-sizingでwidthの範囲を決める](./04_box-sizingでwidthの範囲を決める.md)を正本にする。

複数のCSSで値が上書きされている場合は、[06_CSSカスケードとDevToolsの見方](../06_CSSカスケードとDevToolsの見方/01_DevToolsで適用されたCSSを確認する.md)へ進む。
