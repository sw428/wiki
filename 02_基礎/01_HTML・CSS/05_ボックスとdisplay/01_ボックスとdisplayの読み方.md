# ボックスとdisplayの読み方

HTML要素へCSSを指定すると、画面上では配置や寸法を持つ箱として扱われる。

第5章では、HTML要素が画面上の箱としてどう扱われ、その箱の大きさがどう決まるかを確認する。

疑問に合うまとまりから、必要な記事を選んで読む。

## 箱を作る・読む

### まず箱を作りたい

[一つの箱を作る](./02_一つの箱を作る.md)へ進む。

HTMLの要素をclassで選び、背景色や`padding`を付けて、CSSが画面へ反映されるところまで確認する。

### 箱の内側と外側を分けたい

[ボックスモデルの4領域](./03_ボックスモデルの4領域.md)へ進む。

`content / padding / border / margin` を分けて、どの領域が何の広さなのか確認する。

`width`や`height`が箱のどこまでを含むか分からない場合は、続けて[box-sizingでwidthの範囲を決める](./04_box-sizingでwidthの範囲を決める.md)を見る。

### blockとinlineの違いを見たい

[blockとinlineの広がり方](./05_blockとinlineの広がり方.md)へ進む。

通常フローの非置換blockで`width: auto`の場合と、通常の非置換inlineで、横方向の広がり方や寸法指定がどう違うか確認する。

### HTML要素と画面上の箱の関係を知りたい

[要素とCSSの箱の関係](./06_要素とCSSの箱の関係.md)へ進む。

HTML要素、CSS box、box tree、ボックスモデルを同じものとして扱わず、それぞれの関係を確認する。

## 箱の寸法が決まる

### CSSに書いた値と実際の寸法が合わない

[CSSに書いた値と実際の寸法を分ける](./07_CSSに書いた値と実際の寸法を分ける.md)へ進む。

DevToolsのボックスモデル図に出る値が、CSSファイルへ書いた文字列をそのまま表示しているわけではないことを確認する。

### `%`の基準が分からない

[パーセント指定と包含ブロック](./08_パーセント指定と包含ブロック.md)へ進む。

`%`は単独で「親に対する割合」を意味するのではなく、プロパティごとに参照先が決まる。

その後、[widthのautoと100パーセントを比べる](./09_widthのautoと100パーセントを比べる.md)で、見た目が似る場合でも幅の決まり方が違うことを確認する。

### DOM上の親と割合計算の基準が違う

[DOM上の親と包含ブロックを区別する](./10_DOM上の親と包含ブロックを区別する.md)へ進む。

絶対配置を使い、DOM上の親と包含ブロックが一致しない例を確認する。

### `height: 50%`が予想どおりにならない

[heightのパーセントが効く条件](./11_heightのパーセントが効く条件.md)へ進む。

包含ブロックの高さを割合計算できる状態か確認する。

## 予想と違うときに調べる

### 箱の大きさが予想と違う

[箱の大きさが予想と違うときの確認順](./12_箱の大きさが予想と違うときの確認順.md)へ進む。

DevToolsで対象、`display`、幅、高さ、ボックスモデル、割合の基準、`min-width`や`max-width`などを順に確認する。

## ブラウザ既定の表示を整える

### ブラウザ既定の余白を消したい

[既定の余白をどこまで消すか決める](./13_既定の余白をどこまで消すか決める.md)へ進む。

ページ外周だけを消すのか、見出しや段落も自分で管理するのかを分ける。

リストの字下げやマーカーまで整える場合は、[リストの既定表示を整える](./14_リストの既定表示を整える.md)を見る。
