# 04_リセットCSSで消す余白を選ぶ

主な基礎：[一つの箱とdisplay](./01_一つの箱とdisplay.md)。ページ外周や見出しの余白が残るとき、どの要素の既定スタイルを消しているか確認する。

## `body`だけを直す場合と全要素を直す場合

`body { margin: 0; }` と、全要素を対象にするリセットでは、消す範囲が違う。

| 指定 | 消えるもの | 残るもの |
| --- | --- | --- |
| `body { margin: 0; }` | ページ外周に見えるbodyの既定マージン | 見出し、段落、リストなどの既定マージン |
| `* { margin: 0; }` | すべての要素のマージン | `padding`や`list-style`など、別のプロパティ |

ページ外周だけをなくしたいなら、`body`を対象にする。

```css
body {
  margin: 0;
}
```

見出しや段落の既定マージンも自分で管理するなら、必要な要素を指定する。

```css
h1,
h2,
h3,
p,
ul,
ol,
figure {
  margin: 0;
}
```

リストでは、`margin`を消しても字下げやマーカーが残ることがある。`padding`と`list-style`は別に確認する。

```css
ul,
ol {
  margin: 0;
  padding: 0;
}
```

## `box-sizing`は余白のリセットではない

次の指定は、すべての要素と疑似要素で `width` と `height` の計算範囲をそろえるために使う。

```css
*,
*::before,
*::after {
  box-sizing: border-box;
}
```

これは `margin` や `padding` を0にする指定ではない。箱の外寸へpaddingとborderを含める計算方法を選んでいる。

## 消したい表示から対象を決める

全消去と個別消去のどちらか一方が常に正しいわけではない。

1. 画面上で不要な余白を見つける。
2. DevToolsで、その余白がどの要素の `margin` や `padding` か確認する。
3. サイト全体で消すか、その要素だけで消すか決める。
4. リストのマーカーなど、別の既定表示を残すか確認する。

複数のCSSで値が上書きされている場合は、[06_CSSカスケードとDevToolsの見方](../06_CSSカスケードとDevToolsの見方/01_DevToolsで適用されたCSSを確認する.md)へ進む。
