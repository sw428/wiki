# 04_比率切替型

## このページの役割

SPとPCなど、ブレークポイントによって表示領域の縦横比そのものを切り替える設計を扱う。

画像の大きさが変わるだけではなく、表示領域の「形」が変わる場合に使う。

## まず何を判断するか

確認するのは、

```text
この領域は
「縦横比」を維持したいのか
それとも
「高さ」を維持したいのか
```

である。

幅に応じて高さも連動することがデザイン意図なら、比率切替型を選ぶ。幅が変わっても高さを維持したい場合は、[高さ基準型](./05_高さ基準型.md)として考える。

## どういう設計か

たとえば、

```text
SP
375 × 400

PC
1920 × 500
```

というデザインなら、両者の比率は大きく違う。

```text
SP
┌────────┐
│        │
│        │
│        │
│        │
└────────┘

PC
┌──────────────────────────────┐
│                              │
└──────────────────────────────┘
```

SPは縦に近く、PCは非常に横長になる。

## 基本形

モバイルファーストなら、

```css
.mv__media {
  aspect-ratio: 375 / 400;
  overflow: hidden;
}

@media (min-width: 768px) {
  .mv__media {
    aspect-ratio: 1920 / 500;
  }
}
```

となる。

## 数字は固定サイズではない

```css
aspect-ratio: 375 / 400;
```

と書いても、

```css
width: 375px;
height: 400px;
```

に固定されるわけではない。

これは単なる比率である。

たとえば表示幅が300pxなら、

```text
375 : 400
=
300 : 高さ
```

という関係から高さが計算される。

PC側も同じで、

```css
aspect-ratio: 1920 / 500;
```

は幅1920pxへ固定する指定ではない。

## 同じ画像でも使える

比率切替型だからといって、必ずSP用画像とPC用画像を用意するわけではない。

同じ画像を使って、

```css
.mv__image {
  width: 100%;
  height: 100%;
  object-fit: cover;
}
```

とすれば、SPとPCで枠の形だけ切り替えられる。

## `picture`とは別の判断

比率切替型は、

```text
表示領域の形をどうするか
```

という判断である。

`picture`は、

```text
どの画像ファイルを使うか
```

という判断である。

そのため、

```text
比率切替型
+
同じ画像
```

もあれば、

```text
比率切替型
+
pictureでSP/PC画像を切替
```

もある。

## カンプだけでは断定しない

SPカンプが375×400、PCカンプが1920×500でも、それだけでは比率切替型と断定できない。

基準幅では、

```text
aspect-ratioで作った場合
```

と、

```text
height: 400px / 500pxで固定した場合
```

が同じ寸法になることがある。

違いが出るのは中間幅である。

比率切替型なら、

```text
幅が変わる
↓
高さも比率に従って変わる
```

高さ基準型なら、

```text
幅が変わる
↓
高さは基本的に変わらない
```

という違いになる。
