# 02_自然比率維持型

## このページの役割

画像自身が持っている縦横比をそのまま使い、幅の変化に合わせて画像全体を拡大・縮小する設計を扱う。

画像を切り抜いたり、CSS側で別の比率を作ったりする必要がない場合に使う。

## どういう設計か

自然比率維持型では、表示領域の形をCSSで新しく決めない。

画像自身が持っている比率を使って、

```text
幅が広がる
↓
高さも同じ比率で増える

幅が狭くなる
↓
高さも同じ比率で減る
```

という動きになる。

たとえば元画像が、

```text
420 × 190
```

なら、幅を210pxにしたときも同じ比率を維持して、およそ

```text
210 × 95
```

になる。

## 基本形

```css
.image {
  display: block;
  max-width: 210px;
  height: auto;
}
```

または、親より大きくならないようにしながら、通常は210pxまで使いたいなら、

```css
.image {
  display: block;
  width: min(100%, 210px);
  height: auto;
}
```

とできる。

## `height: auto`の役割

`height: auto`は、幅から高さを勝手に適当な値へ変える指定ではない。

画像が持っている縦横比を利用して、変更後の幅に対応する高さを計算する。

```text
元画像
420 × 190

width: 210px
↓
高さも半分
↓
210 × 95
```

となる。

## `aspect-ratio`は基本的に不要

この設計では、画像自身の比率を使いたい。

そのため、

```css
.image {
  aspect-ratio: 420 / 190;
}
```

と、同じ比率をCSSでもう一度指定する必要は基本的にない。

`aspect-ratio`は、画像自身の比率とは別に、CSS側で表示領域の比率を決めたい場合に使う。

## `max-width`と`width`の違い

```css
max-width: 210px;
```

は、

```text
210pxを超えない
```

という上限指定である。

常に210pxになるわけではない。

一方、

```css
width: 210px;
max-width: 100%;
```

なら、

```text
基本は210px
ただし親より大きくなる場合は縮む
```

という設計になる。

## 向いているもの

ロゴ、キャッチコピーSVG、装飾画像、通常の写真など、画像全体を切らずに見せたい場合に向いている。

特に、

```text
SPでもPCでも同じ画像
構図も同じ
縦横比も同じ
違うのは表示サイズだけ
```

なら、まず自然比率維持型を考える。

## 判断

次のような場合は自然比率維持型でよい。

```text
画像全体を見せたい
↓
画像自身の比率を変える必要がない
↓
表示幅だけ調整すればよい
↓
自然比率維持型
```

比率をCSS側で作る必要がなければ、`aspect-ratio`を追加しない。

## HTMLで画像の寸法情報を伝える

```html
<img
  class="article-image"
  src="./img/dog.jpg"
  alt="芝生に座っている犬"
  width="600"
  height="400"
>
```

```css
.article-image {
  display: block;
  max-width: 100%;
  height: auto;
}
```

- `width` / `height`属性: 画像の寸法と比率をブラウザへ伝える
- `max-width: 100%`: 親より大きい場合に縮める
- `height: auto`: 表示幅に対応する高さを画像の比率から計算する
- `display: block`: 行内画像のベースライン用スペースを避け、1個のブロックとして扱う

画像が内容を伝えるか、装飾かをまだ決めていない場合は、先に[imgとbackground-imageを選ぶ](../../10_画像と背景/01_imgとbackground-imageを選ぶ.md)へ戻る。

## 4種類の寸法を分ける

| 見ているもの | 例 | 意味 |
| --- | --- | --- |
| 画像データのピクセル寸法 | `1600 × 900px` | ファイルが持つ画素数 |
| HTMLの寸法属性 | `width="800" height="450"` | 要素へ渡す寸法情報。2値から比率も得られる |
| CSS計算後の表示寸法 | `600 × 337.5px` | レイアウトの結果、画面上で使われる大きさ |
| アスペクト比 | `16 / 9` | 幅と高さの関係。単独では表示幅を決めない |

`width="800" height="450"`の画像へ`width: 100%; height: auto;`を指定し、親の使用幅が600pxなら、ほかの制約がないときの表示は600 × 337.5pxになる。HTML属性が800 × 450であることと、表示がその寸法へ固定されることは別である。

「解像度」は画素数、PPI、画面密度など複数の意味で使われる。判断するときは「画像データのピクセル寸法」「表示寸法」「表示密度」のどれかを具体的に書く。

## SVGの比率を確認する

PC/SPで同じSVGを使い、比率も変わらないなら、CSSでは表示幅だけを切り替え、`height: auto`で高さを計算できる。SVGの`viewBox`は内部の座標範囲であり、画面上の表示寸法そのものではない。

## DevToolsで確認する

1. Elementsで対象の`img`を選ぶ。
2. ComputedまたはLayoutで画面上の幅と高さを見る。
3. Stylesで`width`、`max-width`、`height`のどれが効いているかを見る。
4. Consoleで必要なら`currentSrc`を確認し、想定した画像が選ばれたかを分けて見る。

`img[Attributes Style]`などの表示は、HTMLの寸法属性から来る。CSSファイルへ同じ宣言を書いたという意味ではない。属性がCSSで上書きされていても、読み込み前の比率予約には使われ得る。詳しくは[表示領域を予約する](../02_画像の読み込み前に表示領域を予約する.md)で扱う。
