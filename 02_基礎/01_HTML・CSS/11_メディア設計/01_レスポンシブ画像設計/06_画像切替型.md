# 06_画像切替型

> このWikiでいう**画像切替型**は、一般に[アートディレクション](../../../../05_参照/アートディレクション.md)と呼ばれる考え方にあたる。

## このページの役割

表示領域の形を決めたあと、SPとPCなどで画像内容を変える必要があるかを判断する。

画像切替型かどうかは、画像の大きさや縦横比ではなく、**画像内容を変えるか**で判断する。サイズ・比率・`object-fit`による見え方の変化だけなら、画像切替型には含めない。

この判断は、

- 自然比率維持型
- 同一比率フレーム型
- 比率切替型
- 高さ基準型

とは別に行う。

## 表示領域と画像は別問題

まず、

```text
表示領域
→ どんな形の箱を作るか
```

を決める。

そのあと、

```text
画像候補
→ その箱へ何を入れるか
```

を決める。

たとえば、

```text
比率切替型 + 同じ画像
比率切替型 + SP/PC別画像
高さ基準型 + 同じ画像
高さ基準型 + SP/PC別画像
```

のどれも成立する。

同じ写真を縮小・拡大したり、`object-fit`によって見える範囲が変わるだけなら、同じ画像として扱う。構図、人物や物の配置、文字入り・文字なしなどを変えるために別の画像を用意する場合は、画像切替型とする。

## 画像切替型ではない例

### 同じ素材を切らずに見せる

画像全体を表示したいなら、画像自身の自然比率を使う。

```css
.image {
  display: block;
  max-width: 100%;
  height: auto;
}
```

この場合は原則として画像をトリミングしない。

画像全体を見せることが優先される。

### 同じ素材を枠へ合わせて切り抜く

表示領域の形が先に決まっていて、その枠いっぱいに画像を表示したい場合は、

```css
.media {
  aspect-ratio: 3 / 2;
  overflow: hidden;
}

.media__image {
  width: 100%;
  height: 100%;
  object-fit: cover;
}
```

のようにする。

`cover`では画像全体が見えるとは限らない。

枠を完全に埋めるために一部が切り抜かれる。

### `object-position`

`object-fit: cover`で重要な場所が切れる場合は、`object-position`で画像のどこを優先して表示するか指定する。

```css
.image {
  object-fit: cover;
  object-position: center top;
}
```

なら、上側を優先しながら中央へ配置する。

人物の顔、ロゴ、文字、商品など、切れてはいけない場所がある場合に確認する。

## 画像内容を変える場合

SPとPCで構図や内容が異なるなら、`picture`を使って画像候補を切り替えられる。

```html
<picture>
  <source
    media="(min-width: 768px)"
    srcset="./img/mv/mv-pc.jpg"
  >
  <img
    src="./img/mv/mv-sp.jpg"
    alt=""
  >
</picture>
```

これは、

```text
SP
→ mv-sp.jpg

768px以上
→ mv-pc.jpg
```

という画像ファイルの選択を行う。

## `picture`は表示領域を決めない

`picture`を使っただけでは、

```text
SPは375:400
PCは1920:500
```

という表示領域にはならない。

`picture`が決めるのは、

```text
どの画像候補を使うか
```

だけである。

表示領域については別に、

```text
aspect-ratio
height
```

などで設計する。

## 具体例

たとえばMVが、

```text
SP
375:400の縦長表示
SP向けに人物を大きく切り取った画像

PC
1920:500の横長表示
背景まで広く写した画像
```

なら、

```text
表示領域
→ 比率切替型

画像候補
→ pictureでSP/PC画像を切替

表示方法
→ 必要ならobject-fit: cover
```

という組み合わせになる。

## 画像切替後の枠内表示を調整する

画像切替型を採用したあとも、選ばれた画像を表示領域へどう収めるかは別に決める。次の指定だけを変えても、画像内容が同じなら画像切替型にはならない。

| 指定 | 結果 | 向く素材 |
| --- | --- | --- |
| `object-fit: cover` | 枠を埋める。比率差があれば一部が切れる | 写真など、切り抜きを許容できる素材 |
| `object-fit: contain` | 全体を収める。比率差があれば余白ができる | ロゴ・商品全体・図版など |
| `object-position` | 枠の中で見せる位置を決める | 顔や注目箇所を残したいとき |

`object-position`は、置換要素の箱を移動する指定ではなく、箱の中で画像データを配置する指定である。切り取り位置の調整はまず`object-position`で行う。

## `picture`の候補へ寸法情報を付ける

```html
<picture>
  <source
    media="(min-width: 768px)"
    srcset="./img/mv-pc.jpg"
    width="1920"
    height="500"
  >
  <img
    class="mv__image"
    src="./img/mv-sp.jpg"
    alt=""
    width="375"
    height="400"
  >
</picture>
```

| 要素 | 担当すること |
| --- | --- |
| `picture` | 複数の画像候補を選ぶ文脈を作る |
| `source` | メディア条件、候補、候補の寸法情報を渡す |
| `img` | 選ばれた画像を実際に表示する。alt・class・CSSの対象になる |

`source`自身が画面上の箱になるわけではない。選択結果は`img`へ渡され、画面上の表示幅は`img`へ適用されたCSSと外側のレイアウトで決まる。

`source`の`width` / `height`が使える場合、選ばれた候補の寸法と比率をブラウザへ伝えられる。これらは「1920 × 500pxで固定表示する」という指定ではない。

## 仕様確認先

- [HTML Standard: The picture element](https://html.spec.whatwg.org/multipage/embedded-content.html#the-picture-element)
- [HTML Standard: Responsive images](https://html.spec.whatwg.org/multipage/images.html#responsive-images)

## 最後に確認すること

画像実装では、

1. 表示領域の形
2. 使用する画像候補
3. 切り抜き方法

を分けて確認する。

特に基準カンプだけを見るのではなく、中間幅でも、

```text
高さは意図通りか
構図は崩れていないか
重要部分が切れていないか
後続要素との距離は適切か
```

を確認する。
