# 05_高さ基準型

## このページの役割

画面幅ではなく、表示領域の高さを基準に設計する方法を扱う。

MVやヒーローなど、画面幅が変わっても一定の占有高さを保ちたい場合に使う。

## どういう設計か

たとえば、

```text
SPでは高さ400px
PCでは高さ500px
```

を維持する設計である。

```text
幅320px
┌──────────┐
│          │
│  400px   │
│          │
└──────────┘

幅375px
┌────────────┐
│            │
│   400px    │
│            │
└────────────┘
```

幅が変わっても高さ400pxは変わらない。

## 基本形

```css
.mv__media {
  height: 400px;
  overflow: hidden;
}

@media (min-width: 768px) {
  .mv__media {
    height: 500px;
  }
}
```

画像を全面へ表示するなら、

```css
.mv__image {
  width: 100%;
  height: 100%;
  object-fit: cover;
}
```

などを組み合わせる。

## 比率切替型との違い

比率切替型は、

```text
幅に応じて高さが変わる
```

設計である。

高さ基準型は、

```text
幅が変わっても高さを維持する
```

設計である。

たとえばSP基準が375×400の場合でも、

```text
幅300px
```

になったとき、比率切替型なら高さも小さくなる。

高さ基準型なら400pxのままである。

## なぜ高さを固定するのか

MVなどでは、

```text
ファーストビューで一定の存在感を持たせたい
次のセクションが見える位置をある程度一定にしたい
背景写真の見える高さを維持したい
```

など、高さそのものがデザイン上重要な場合がある。

その場合は`aspect-ratio`より`height`の方が設計意図に近い。

## `height`と`min-height`

中身のない画像領域なら固定`height`を使いやすい。

しかし文字などのコンテンツが入る領域では、

```css
height: 400px;
```

とすると、中身が増えたときにはみ出す可能性がある。

その場合、

```css
min-height: 400px;
```

を使えば、

```text
最低400px
内容が増えればそれ以上
```

という設計にできる。

## `cover`を使った場合

固定高さの枠へ、

```css
object-fit: cover;
```

で画像を入れると、画面幅によって切り抜かれる場所が変わる。

```text
幅が狭い
→ 左右が多く切れる可能性

幅が広い
→ 上下が切れる可能性
```

そのため、重要な人物、文字、商品などが切れないか確認する。

必要なら、

```css
object-position: center top;
```

などで表示位置を調整する。

## 判断

```text
この領域で重要なのは
縦横比か？
↓
NO

高さそのものか？
↓
YES

高さ基準型
```

と判断する。
