# レスポンシブ画像設計整理マップ

Codex用。レスポンシブ画像の設計判断を、「表示領域4種類」と「画像側の選び方1種類」に分けて管理する。

> [!IMPORTANT]
> `04_比率切替型`と`05_高さ基準型`は別の設計として保つ。`06_画像切替型`は表示領域とは別軸として保ち、内容を勝手に統合しない。

## 全ファイル共通の前提

1. まず表示領域をどう作るか決める。
2. そのあと画像をどう入れるか決める。

## 既存ノートとの分担

- このカテゴリ: 実際のデザインから、表示領域と画像候補の組み合わせを選ぶ
- [自然比率維持型](./02_自然比率維持型.md): `width`、`max-width`、`height: auto`、寸法属性、SVGの基本
- [同一比率フレーム型](./03_同一比率フレーム型.md): `aspect-ratio`と枠・画像の責務
- [比率切替型](./04_比率切替型.md) / [高さ基準型](./05_高さ基準型.md): 幅に連動する比率と高さ基準を分ける
- [画像切替型](./06_画像切替型.md): 構図、配置、元画像に含まれる範囲、文字の有無など、SPとPCで画像内容を変えるか判断する
- [srcsetとsizes](./07_srcsetとsizesで画像候補を選ぶ.md): 同じ構図の画像から表示密度・表示幅に合う候補を選ぶ
- [画像の読み込み前に表示領域を予約する](../02_画像の読み込み前に表示領域を予約する.md): 寸法属性とCLS対策
- [画像を使うUIの制御方法を選ぶ](../../14_デザインパターンとCSS設計判断/02_画像を使うUIの制御方法を選ぶ.md): バナーやカードなど、UI名から確認先を選ぶ入口
