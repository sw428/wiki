# 03_同一比率フレーム型

## このページの役割

画面幅によって大きさは変わるが、表示領域の縦横比は常に同じにする設計を扱う。

画像自身の自然な比率ではなく、デザインとして決められた「枠の形」を優先する。

## どういう設計か

たとえばカード画像を常に3:2で表示したい場合、

```text
600 × 400
450 × 300
300 × 200
```

のようにサイズは変わっても、すべて3:2になる。

```text
SP
┌────────────┐
│            │
│    3:2     │
└────────────┘

PC
┌──────────────────┐
│                  │
│       3:2        │
└──────────────────┘
```

幅は変わっているが、枠の形は変わらない。

## 基本形

```css
.card__media {
  aspect-ratio: 3 / 2;
  overflow: hidden;
}

.card__image {
  display: block;
  width: 100%;
  height: 100%;
  object-fit: cover;
}
```

## `aspect-ratio`が決めているもの

```css
aspect-ratio: 3 / 2;
```

は、

```text
width: 300px
↓
height: 200px

width: 600px
↓
height: 400px
```

のように、実際の幅から高さを計算するための比率を指定している。

300px × 200pxという固定サイズを指定しているわけではない。

## なぜ画像ではなく枠へ指定するのか

この設計で優先したいのは、

```text
画像本来の形
```

ではなく、

```text
デザイン上の表示領域の形
```

だからである。

画像が16:9でも4:3でも縦長でも、

```text
カード画像は全部3:2
```

という統一されたデザインにできる。

## `object-fit: cover`の役割

画像自身の比率と枠の比率が違う場合、

```css
width: 100%;
height: 100%;
```

だけでは画像が変形する可能性がある。

そこで、

```css
object-fit: cover;
```

を使う。

画像の縦横比を維持したまま枠全体を埋め、余った部分を切り抜く。

```text
元画像
┌─────────┐
│         │
│         │
│         │
│         │
└─────────┘

3:2の枠
┌──────────────┐
│    表示部分    │
└──────────────┘
```

## SPとPCで指定を分ける必要はない

SPでもPCでも3:2なら、

```css
.card__media {
  aspect-ratio: 3 / 2;
}
```

を共通指定へ1回書けばよい。

```css
@media (min-width: 768px) {
  .card__media {
    aspect-ratio: 3 / 2;
  }
}
```

と同じ指定をもう一度書く必要はない。

## 向いているもの

カード一覧、スタッフ写真、商品画像、記事サムネイルなど、複数の画像を同じ形にそろえたい場合に向いている。

判断基準は、

```text
画像自身の比率より
表示枠の統一を優先する
```

ことである。

## 外・枠・中身を分ける

| 対象 | 主な指定 | 答える疑問 |
| --- | --- | --- |
| 外側の配置 | Grid、Flex、margin、gap | どこに置くか |
| 表示する枠 | `width`、`max-width`、`height`、`aspect-ratio` | どの大きさ・形か |
| 画像や動画の中身 | `object-fit`、`object-position` | 枠の中でどう見せるか |

`object-fit`自体が画像要素の幅や高さを作るわけではない。画像要素の箱が自然比率のままなら、`cover`を付けても切り抜きが見えないことがある。

## 画像自身と親のどちらを枠にするか

画像1枚だけで表示が完結し、画像要素そのものがレイアウト上の枠を兼ねてよい場合は、画像自身へ指定できる。

```css
.hero__image {
  display: block;
  width: 100%;
  aspect-ratio: 375 / 400;
  object-fit: cover;
}
```

画像の有無に関係なく領域を残す、ローディング表示やバッジを重ねる、クリック範囲をまとめる場合は親を枠にする。

```css
.staff-card__media {
  aspect-ratio: 1;
  overflow: hidden;
}

.staff-card__image {
  display: block;
  width: 100%;
  height: 100%;
  object-fit: cover;
}
```

画像だから必ず`div`で囲むわけではない。「画像とは別に維持したい領域があるか」でラッパーの必要性を決める。

## 円形写真を分けて調整する

リング付きの円形写真では、外周・切り抜き枠・画像を分ける。

```css
.avatar__media {
  width: 12rem;
  aspect-ratio: 1;
  padding: 0.5rem;
  border-radius: 50%;
  background: #f1f1f1;
  box-sizing: border-box;
}

.avatar__frame {
  width: 100%;
  height: 100%;
  overflow: hidden;
  border-radius: 50%;
}

.avatar__image {
  display: block;
  width: 100%;
  height: 100%;
  object-fit: cover;
  object-position: center;
}
```

- 外周寸法を変える: `.avatar__media`
- リング幅を変える: 外側のpadding
- 写真を切り抜く範囲を変える: `.avatar__frame`
- 写真の見える位置を変える: `object-position`

画像だけを拡大する場合は、切り抜き枠の`overflow: hidden`を保ち、画像側の`transform: scale(...)`を使う。`scale()`は外周のレイアウト寸法を作り直さない。

## うまく埋まらないとき

- 親の高さがない: 親の幅・高さ・`aspect-ratio`を確認する
- 画像の下に空きがある: `img`が行内配置のままか確認し、必要なら`display: block`
- 画像が枠の高さへ届かない: 子が`height: auto`のままではないか確認する
- 写真が変形した: `width: 100%; height: 100%`だけで、`object-fit`がない可能性を確認する
- 顔が切れた: `object-position`で位置を調整するか、`contain`・別画像を選ぶ
