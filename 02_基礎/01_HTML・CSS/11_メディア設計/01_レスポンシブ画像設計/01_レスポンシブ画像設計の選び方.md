# 01_レスポンシブ画像設計の選び方

レスポンシブ画像を実装するときは、最初に表示領域をどう作るか決め、そのあとで使用する画像を切り替えるか決める。このカテゴリでは、その選択肢を役割ごとに分けている。

## 最初に分けること

```text
1. 表示領域をどう作るか
2. 使用する画像を切り替えるか
```

`aspect-ratio`をSP用かPC用かで分類するのではなく、幅の変化に対して表示領域の高さをどう決めたいかを見る。

## 表示領域を4種類から選ぶ

| 判断したいこと | 設計タイプ | 詳しい説明 |
| --- | --- | --- |
| 画像自身の比率を保ち、全体を切らずに見せたい | 自然比率維持型 | [02_自然比率維持型](./02_自然比率維持型.md) |
| 大きさが変わっても、枠の縦横比は同じにしたい | 同一比率フレーム型 | [03_同一比率フレーム型](./03_同一比率フレーム型.md) |
| SPとPCで枠の縦横比を切り替えたい | 比率切替型 | [04_比率切替型](./04_比率切替型.md) |
| 幅とは別に、一定高または最低限の高さを保ちたい | 高さ基準型 | [05_高さ基準型](./05_高さ基準型.md) |

表示領域と使用する画像は、次の順番で決める。

```text
【1. 表示領域を決める】

画像自身の比率を使う？
├─ YES → 自然比率維持型
└─ NO
   ↓
幅に応じた比率で高さを決める？
├─ YES
│  ├─ 比率は同じ → 同一比率フレーム型
│  └─ 比率を変える → 比率切替型
└─ NO → 高さ基準型


        ↓


【2. 使用する画像を決める】

SPとPCなどで、画像内容を変える？
├─ NO → 同じ画像を使う
└─ YES → 画像切替型
```

## 画像切替型を判断する基準

画像切替型かどうかは、画像の大きさや縦横比ではなく、**画像内容を変えるか**で判断する。

ここでいう画像内容の変化には、**サイズ・比率・`object-fit`による見え方の変化は含まない**。

同じ写真を縮小・拡大したり、`object-fit`によって見える範囲が変わるだけなら、同じ画像として扱う。

一方で、構図、人物や物の配置、[**元画像に含まれる範囲**](../../../../05_参照/アートディレクション.md)、文字入り・文字なしなどを変えるために別の画像を用意する場合は、画像切替型とする。

画像切替型は、自然比率維持型・同一比率フレーム型・比率切替型・高さ基準型のどれとも組み合わせられる。詳しい実装は[06_画像切替型](./06_画像切替型.md)で扱う。

## このカテゴリの読み方

- どの設計タイプか分からない場合は、このページの表と判断図から選ぶ。
- 設計タイプが決まっている場合は、該当する02〜05だけを読む。
- SPとPCなどで画像内容を変える場合は06を読む。
- 同じ画像内容のまま、表示密度や表示幅に合う候補を選ぶ場合は07を読む。

すべての記事を順番に読む必要はない。いま判断したい内容に対応するページへ進む。
