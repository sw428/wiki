# 01_メディア設計の選び方

メディア設計では、画像や動画について何を決めたいのかを先に分ける。このページで目的に合う入口を選び、詳しい実装は各ページで確認する。

## 何を決めたいかで選ぶ

| 確認したいこと | 読む場所 |
| --- | --- |
| 画像の表示領域を自然比率・比率枠・固定高などから選びたい | [レスポンシブ画像設計](./01_レスポンシブ画像設計/01_レスポンシブ画像設計の選び方.md) |
| 画像の読み込みで文章や後続要素が動くのを抑えたい | [画像の読み込み前に表示領域を予約する](./02_画像の読み込み前に表示領域を予約する.md) |
| 画像の上へ文字・ラベル・地図ピンを重ねたい | [画像の上に文字や部品を重ねる](./03_画像の上に文字や部品を重ねる.md) |
| `video`を比率の枠へ収めたい | [動画を比率の枠へ収める](./04_動画を比率の枠へ収める.md) |

## 画像を表示するまでの流れ

```text
画像の意味と形式を決める
↓
表示領域の形を決める
↓
画像候補と切り取り方を決める
↓
読み込み前の領域や重ねる部品を必要に応じて追加する
```

画像を`img`にするか背景にするか、SVGかラスター画像かをまだ決めていない場合は、先に[imgとbackground-imageを選ぶ](../10_画像と背景/01_imgとbackground-imageを選ぶ.md)を確認する。

表示領域と画像候補を選ぶ段階では、[レスポンシブ画像設計の選び方](./01_レスポンシブ画像設計/01_レスポンシブ画像設計の選び方.md)へ進む。

## この章の読み方

- すべてを順番に読む必要はない。
- 画像の寸法・比率・候補を決めたい場合は、レスポンシブ画像設計から始める。
- 読み込み後の位置ずれ、重ね配置、動画など、目的が決まっている場合は対応する記事へ直接進む。
