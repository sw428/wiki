# 04_動画を比率の枠へ収める

`video`も置換要素として、自然寸法で表示するか、決めた比率の枠へ収めるかを選ぶ。写真と同じく、要素の箱と映像の見え方を分ける。

## 動画全体を自然な比率で表示する

```html
<video
  class="movie"
  src="./video/interview.mp4"
  poster="./img/interview-poster.jpg"
  width="1280"
  height="720"
  controls
></video>
```

```css
.movie {
  display: block;
  width: 100%;
  height: auto;
}
```

映像全体を切らず、素材の比率で表示するならこの形から始める。`poster`は再生前などに表示する画像で、動画要素とは別のHTML要素を作らない。

## 決めた比率の枠へ収める

再生ボタン、時間ラベル、装飾などを同じ領域で管理する場合は親を枠にする。

```html
<div class="movie-frame">
  <video
    class="movie-frame__video"
    src="./video/interview.mp4"
    poster="./img/interview-poster.jpg"
    controls
  ></video>
</div>
```

```css
.movie-frame {
  aspect-ratio: 16 / 9;
  overflow: hidden;
  border-radius: 8px;
}

.movie-frame__video {
  display: block;
  width: 100%;
  height: 100%;
  object-fit: cover;
}
```

`cover`では映像の一部が切れる。操作UIや字幕まで切れると困る場合は、自然比率または`contain`を使う。ブラウザが表示する標準コントロールの見え方も実機で確認する。

## 角丸と重ねる部品を管理する

- 動画単体だけを丸める: `video`自身へ`border-radius`
- 動画・再生ボタン・時間ラベルをまとめて切り抜く: 親へ`border-radius`と`overflow: hidden`
- 重ねる部品が親の外へ出る必要がある: 切り抜き用の内側枠と、配置用の外側要素を分ける

絶対配置で部品を重ねる場合は、親へ`position: relative`を追加し、[画像の上に文字や部品を重ねる](./03_画像の上に文字や部品を重ねる.md)と同じく、土台と重ねる子を分ける。

## iframeとは分ける

`iframe`は外部文書や埋め込みプレイヤーを表示する要素で、`video`へ使う`object-fit`と同じ方法では中身を制御できない。YouTubeなどの埋め込みは、外側に比率を作り、iframeを`width: 100%; height: 100%`で合わせる。[MVとiframeの表示領域を作る](../14_デザインパターンとCSS設計判断/08_MVとiframeの表示領域を作る.md#iframeへ外部コンテンツを埋め込む)へ分ける。

## 確認順

1. 素材の自然比率で見せるか、デザイン上の枠へ収めるか。
2. 切り取りを許容できるか。
3. `video`自身と親のどちらが表示枠を担当するか。
4. poster・映像・操作UIが同じ条件で見えるか。
5. 角丸で必要な操作部品まで切れていないか。
