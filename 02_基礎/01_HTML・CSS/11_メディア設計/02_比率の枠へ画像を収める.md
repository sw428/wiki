# 02_比率の枠へ画像を収める

写真を正方形のカードや横長のヒーローへそろえるときは、先に枠の幅と比率を決め、その中で画像データをどう見せるかを決める。

## 自然比率か比率枠かを選ぶ

1. 画像全体を自然な比率で見せる: `width`または`max-width`と`height: auto`
2. 決めた比率の枠へ収める: 枠の`aspect-ratio`と、画像の`object-fit`

```css
.card__media {
  aspect-ratio: 1;
  overflow: hidden;
}

.card__image {
  display: block;
  width: 100%;
  height: 100%;
  object-fit: cover;
}
```

この例では`.card__media`が正方形を作り、`img`の箱を同じ大きさへ広げ、`object-fit`が画像データの描画方法を決める。

## 外・枠・中身を分ける

| 対象 | 主な指定 | 答える疑問 |
| --- | --- | --- |
| 外側の配置 | Grid、Flex、margin、gap | どこに置くか |
| 表示する枠 | `width`、`max-width`、`height`、`aspect-ratio` | どの大きさ・形か |
| 画像や動画の中身 | `object-fit`、`object-position` | 枠の中でどう見せるか |

`object-fit`自体が画像要素の幅や高さを作るわけではない。画像要素の箱が自然比率のままなら、`cover`を付けても切り抜きが見えないことがある。

## aspect-ratioが決めること

`aspect-ratio`は幅と高さの関係を決める。最大幅や絶対的な大きさは決めない。

```css
.media {
  width: 100%;
  max-width: 800px;
  aspect-ratio: 16 / 9;
}
```

- `width`と外側のレイアウト: 実際に使える幅を決める
- `max-width`: 800pxを上限にする
- `aspect-ratio`: 自動計算される高さを幅との比率から決める

`1600 / 900`、`800 / 450`、`16 / 9`は同じ比率である。数字を半分にしても表示サイズは半分にならない。幅と高さをCSSで両方固定した場合、`aspect-ratio`を足しても通常はその2値を置き換えない。

## 画像自身と親のどちらを枠にするか

画像1枚だけで表示が完結し、画像要素そのものがレイアウト上の枠を兼ねてよい場合は、画像自身へ指定できる。

```css
.hero__image {
  display: block;
  width: 100%;
  aspect-ratio: 375 / 400;
  object-fit: cover;
}
```

画像の有無に関係なく領域を残す、ローディング表示やバッジを重ねる、クリック範囲をまとめる場合は親を枠にする。

```css
.staff-card__media {
  aspect-ratio: 1;
  overflow: hidden;
}

.staff-card__image {
  display: block;
  width: 100%;
  height: 100%;
  object-fit: cover;
}
```

画像だから必ず`div`で囲むわけではない。「画像とは別に維持したい領域があるか」でラッパーの必要性を決める。

## cover・contain・positionを選ぶ

| 指定 | 結果 | 向く素材 |
| --- | --- | --- |
| `object-fit: cover` | 枠を埋める。比率差があれば一部が切れる | 写真など、切り抜きを許容できる素材 |
| `object-fit: contain` | 全体を収める。比率差があれば余白ができる | ロゴ・商品全体・図版など |
| `object-position` | 枠の中で見せる位置を決める | 顔や注目箇所を残したいとき |

`object-position`は、置換要素の箱を移動する指定ではなく、箱の中で画像データを配置する指定である。`transform`で画像を動かす方法は通常フローを再計算しないが、見た目のはみ出しや重なりを生むことがある。切り取り位置の調整はまず`object-position`で行う。

## 円形写真を分けて調整する

リング付きの円形写真では、外周・切り抜き枠・画像を分ける。

```css
.avatar__media {
  width: 12rem;
  aspect-ratio: 1;
  padding: 0.5rem;
  border-radius: 50%;
  background: #f1f1f1;
  box-sizing: border-box;
}

.avatar__frame {
  width: 100%;
  height: 100%;
  overflow: hidden;
  border-radius: 50%;
}

.avatar__image {
  display: block;
  width: 100%;
  height: 100%;
  object-fit: cover;
  object-position: center;
}
```

- 外周寸法を変える: `.avatar__media`
- リング幅を変える: 外側のpadding
- 写真を切り抜く範囲を変える: `.avatar__frame`
- 写真の見える位置を変える: `object-position`

画像だけを拡大する場合は、切り抜き枠の`overflow: hidden`を保ち、画像側の`transform: scale(...)`を使う。`scale()`は外周のレイアウト寸法を作り直さない。

## カンプから枠の意図を読む

1. 元画像の縦横比を確認する。
2. カンプ上の表示領域の縦横比を確認する。
3. 元画像の一部が切れているかを見る。
4. PC/SPなど別幅のカンプと中間幅も確認する。

1枚のカンプで`375 × 400`に見えても、固定高なのか`375 / 400`の比率なのかは断定できない。構図を優先するなら自然比率または`aspect-ratio`、ヒーローの占有高さを優先して切り抜きを許容するなら`height`や`min-height`も候補になる。確認できない場合は、何を優先した暫定案かを残す。

## うまく埋まらないとき

- 親の高さがない: 親の幅・高さ・`aspect-ratio`を確認する
- 画像の下に空きがある: `img`が行内配置のままか確認し、必要なら`display: block`
- 画像が枠の高さへ届かない: 子が`height: auto`のままではないか確認する
- 写真が変形した: `width: 100%; height: 100%`だけで、`object-fit`がない可能性を確認する
- 顔が切れた: `object-position`で位置を調整するか、`contain`・別画像を選ぶ
