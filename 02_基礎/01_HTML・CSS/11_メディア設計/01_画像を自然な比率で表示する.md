# 01_画像を自然な比率で表示する

画像1枚を変形させずに表示するなら、HTMLで画像の内容と元の寸法を伝え、CSSで画面上の幅を決めるところから始める。

## 最初の1枚を表示する

```html
<img
  class="article-image"
  src="./img/dog.jpg"
  alt="芝生に座っている犬"
  width="600"
  height="400"
>
```

```css
.article-image {
  display: block;
  max-width: 100%;
  height: auto;
}
```

- `width` / `height`属性: 画像の寸法と比率をブラウザへ伝える
- `max-width: 100%`: 親より大きい場合に縮める
- `height: auto`: 表示幅に対応する高さを画像の比率から計算する
- `display: block`: 行内画像のベースライン用スペースを避け、1個のブロックとして扱う

画像が内容を伝えるか、装飾かをまだ決めていない場合は、先に[imgとbackground-imageを選ぶ](../10_画像と背景/01_imgとbackground-imageを選ぶ.md)へ戻る。

## 親幅いっぱいに広げるかを決める

`max-width`は上限、`width`は表示幅の基準である。

| 指定 | 幅の決まり方 |
| --- | --- |
| `max-width: 100%` | 親より大きい画像を縮める。小さい画像を親幅まで自動では拡大しない |
| `width: 100%` | 親の利用可能幅を画像要素の表示幅にする |

カードやヒーロー画像を常に親幅へ合わせるなら、次のようにする。

```css
.hero__image {
  display: block;
  width: 100%;
  height: auto;
}
```

ロゴや小さな図版まで一律に`width: 100%`へ広げず、「縮小だけ許可するか」「親幅まで拡大するか」を素材ごとに決める。

## 4種類の寸法を分ける

| 見ているもの | 例 | 意味 |
| --- | --- | --- |
| 画像データのピクセル寸法 | `1600 × 900px` | ファイルが持つ画素数 |
| HTMLの寸法属性 | `width="800" height="450"` | 要素へ渡す寸法情報。2値から比率も得られる |
| CSS計算後の表示寸法 | `600 × 337.5px` | レイアウトの結果、画面上で使われる大きさ |
| アスペクト比 | `16 / 9` | 幅と高さの関係。単独では表示幅を決めない |

`width="800" height="450"`の画像へ`width: 100%; height: auto;`を指定し、親の使用幅が600pxなら、ほかの制約がないときの表示は600 × 337.5pxになる。HTML属性が800 × 450であることと、表示がその寸法へ固定されることは別である。

「解像度」は画素数、PPI、画面密度など複数の意味で使われる。判断するときは「画像データのピクセル寸法」「表示寸法」「表示密度」のどれかを具体的に書く。

## 切らずに見せる素材を確認する

ロゴ、文字入り画像、商品全体など、欠けると内容が変わる素材は自然な比率を優先する。

```css
.site-logo {
  display: block;
  width: min(100%, 200px);
  height: auto;
}
```

PC/SPで同じSVGを使い、比率も変わらないなら、CSSでは表示幅だけを切り替え、`height: auto`で高さを計算できる。SVGの`viewBox`は内部の座標範囲であり、画面上の表示寸法そのものではない。

画像を決まった形へ切り抜く必要がある場合は、自然比率を上書きする前に[比率の枠へ画像を収める](./02_比率の枠へ画像を収める.md)へ進む。

## DevToolsで確認する

1. Elementsで対象の`img`を選ぶ。
2. ComputedまたはLayoutで画面上の幅と高さを見る。
3. Stylesで`width`、`max-width`、`height`のどれが効いているかを見る。
4. Consoleで必要なら`currentSrc`を確認し、想定した画像が選ばれたかを分けて見る。

`img[Attributes Style]`などの表示は、HTMLの寸法属性から来る。CSSファイルへ同じ宣言を書いたという意味ではない。属性がCSSで上書きされていても、読み込み前の比率予約には使われ得る。詳しくは[表示領域を予約する](./04_画像の読み込み前に表示領域を予約する.md)で扱う。

**次へ進む目安**は、画像を親幅まで広げるか縮小だけにするかを選び、HTMLの寸法属性と画面上の表示寸法を区別して確認できること。
