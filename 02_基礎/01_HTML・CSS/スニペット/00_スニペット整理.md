# HTML・CSSスニペット整理

## このカテゴリの役割

HTML・CSS制作で繰り返し使うVS Codeスニペットの採用形を置く。

スニペットはHTMLやCSSの意味を省略するためではなく、決まった型の入力を安定させ、画像パスなど本当に変更する箇所へ集中するために使う。

## 現在の採用形

- [HTML基本スニペット](./01_HTML基本スニペット.md)
  - HTML文書の土台
  - PCファーストの`picture`
  - SPファーストの`picture`
  - CSS読み込み

## 整理基準

- 実際に採用したスニペットだけを載せる
- 同じ用途の旧版を並べず、現在の採用形を1つにする
- 固定する値と、Tabで変更する値を分ける
- プロジェクト固有の命名やブレークポイントがある場合は、その案件側の規則を優先する
- VS Code本体のスニペットファイルはユーザーが確認して変更し、このWikiには採用意図と正本コードを残す
