# 01_UIごとに固定と可変を分ける

デザインをHTML/CSSへ落とすときは、最初に「何のUIか」を決める。見た目に近いプロパティを足す前に、崩れてほしくない条件と、内容に合わせて変わってよい部分を分ける。

## 最初に分けること

1. 何のUIか。
2. 何を固定したいか。
3. 何を可変にしたいか。
4. 親・枠・画像・文字・リンクのどこが責務を持つか。

「固定する」は、すべてをpxで固めるという意味ではない。
