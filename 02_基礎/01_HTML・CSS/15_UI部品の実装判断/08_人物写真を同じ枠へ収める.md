# 08_人物写真を同じ枠へ収める

人物写真の見た目をそろえるときは、画像ファイルそのものではなく、外側の表示枠をそろえる。

```css
.frame {
  width: 180px;
  aspect-ratio: 1 / 1;
}

.frame img {
  display: block;
  width: 100%;
  height: 100%;
  object-fit: cover;
}
```

- 正方形を守る: 外側の枠
- 枠へ画像を合わせる: `width: 100%`と`height: 100%`
- 枠を埋めて切り抜く: `object-fit: cover`

`height: 100%`だけでは画像の横幅まで枠へそろわない。固定寸法が必要なら枠として固定する。SPで変える場合はメディアクエリや`clamp()`で枠サイズを切り替える。横並びで縮ませたくない場合だけ`flex-shrink`を検討する。

画像枠と切り抜きの選択は[同一比率フレーム型](../12_レスポンシブ画像設計/03_同一比率フレーム型.md)で確認する。
