## 整理時に保つ関係

1. プロパティ名から選ばず、UIの目的と崩れてほしくない条件から選ぶ。
2. 「固定」はすべてをpxにすることではない。
3. 10〜14章の仕組みを15章で重複説明しすぎない。
4. 項目間隔、外側余白、操作範囲、画像枠を分ける。
5. 文字量、画像、画面幅、項目数を変えて確認する。
