# 10_同じボタンを共通部品か差分として扱う

複数のボタンが似ているときは、別々の部品へする前に「同じ土台へ差分を足せるか」を確認する。

```html
<a class="button" href="#">詳しく見る</a>
<a class="button light" href="#">詳しく見る</a>
<a class="button compact" href="#">お問い合わせ</a>
```

## 分ける基準

- サイズ感・角丸・hoverなどの核が同じ: 共通クラスを候補にする。
- 色やサイズだけが違う: 差分クラスを候補にする。
- 役割や内部構造が違う: 別部品を検討する。
- そのページだけの余白や配置: ページ・レイアウト側へ分ける。

共通化を確定する前に、同じ核が何度も現れるか、違いが本当に差分だけかを確認する。プロジェクト全体の命名規則は[CSS設計](../../07_設計/CSS設計/00_CSS設計整理マップ.md)へ分ける。
