# 02_画像を使うUIの制御方法を選ぶ

画像を置くときは、最初に「画像そのものを自然な比率で見せるか」「UIの枠へ収めるか」を決める。切れてよい写真と、切れてはいけない文字・ロゴも分ける。

## 画像の役割から選ぶ

| 画像の役割 | 守ること | 基本候補 |
| --- | --- | --- |
| ロゴ、電話画像、文字入り画像 | 全体を切らずに見せる | `width`で上限を作り、`height: auto` |
| MV、カード写真、サムネイル | 枠を埋める。切り抜きを許容する | 親の`aspect-ratio`と子の`object-fit: cover` |
| 商品画像、全体を見せたい素材 | 切り抜かない。余白を許容する | `height: auto`または`object-fit: contain` |
| 完成済みバナー・画像ボタン | 自然比率か固定枠かを選ぶ | 自然比率なら`height: auto`、枠なら親で比率を作る |
| 単色アイコン・形抜き | 画像の中身ではなく形を使う | `background-color`と`mask-image` |
| YouTubeなどのiframe | 外部埋め込みの表示領域を保つ | 外側に`aspect-ratio`を持たせる |

画像の意味を`img`で持つか背景で持つかは[imgとbackground-imageを選ぶ](../10_画像と背景/01_imgとbackground-imageを選ぶ.md)、具体的な寸法・比率・収め方は[レスポンシブ画像設計の選び方](../12_レスポンシブ画像設計/01_レスポンシブ画像設計の選び方.md)で確認する。

## 自然比率で見せる例

```css
.image-link {
  display: block;
  width: min(335px, 100%);
}

.image-link img {
  display: block;
  width: 100%;
  height: auto;
}
```

小さく見せたいだけなら、`width`、`max-width`、`min()`で実寸上限を作る。`aspect-ratio`は縮小指定の代わりではない。

## 枠へ収める例

```css
.image-frame {
  aspect-ratio: 343 / 228;
  overflow: hidden;
}

.image-frame img {
  display: block;
  width: 100%;
  height: 100%;
  object-fit: cover;
}
```

枠いっぱいに見せるため、画像の一部が切れる。文字、ロゴ、商品全体など、切れると意味が変わる素材へ機械的に使わない。

## 個別調整へ入る前の確認順

1. そのまま見せる画像か、枠へ入れる画像か。
2. 切れてよい写真か、切れてはいけない文字・ロゴ・商品画像か。
3. 高さを作るのは画像自身か、親の比率枠か。
4. クリック範囲を持つなら、画像ではなくリンク側の箱も必要か。
5. SP/PCで構図が変わるなら、`cover`だけで粘らず`picture`や別画像を使うか。

SPとPCで比率・高さ・画像候補のどれを変えるかは、[レスポンシブ画像設計の選び方](../12_レスポンシブ画像設計/01_レスポンシブ画像設計の選び方.md)でまとめて判断する。

## 方針が曖昧なサイン

- `img`へ`width: 100%; height: 100%`だけを指定し、収め方を決めていない。
- `aspect-ratio`を複数階層へ付け、どの箱が比率を担当するか分からない。
- 画像の高さだけを固定し、比率維持か切り抜きか決めていない。
- `calc(100% - 132px)`のような微調整で、実寸上限の目的を隠している。
- PCは自然比率、SPは比率枠だが、切り替える理由を説明できない。

## 画像の形だけを使う場合

`mask-image`は、SVGやPNGの形を借りて色をCSSで変える単色アイコンや、端をグラデーションで消す表現に向く。

- 見える形: `mask-image`
- 大きさ: `mask-size`
- 位置: `mask-position`
- 実際に見える色: `background-color`

写真の収まりを調整する指定ではない。マスクの仕組みと適用範囲は[mask-imageで見える範囲を作る](../10_画像と背景/02_mask-imageで見える範囲を作る.md)で扱う。

## 一言でいうと

自然比率、固定枠、切り抜き可否、形だけの利用を先に分けてから、`width`、`aspect-ratio`、`object-fit`、`mask-image`を選ぶ。
