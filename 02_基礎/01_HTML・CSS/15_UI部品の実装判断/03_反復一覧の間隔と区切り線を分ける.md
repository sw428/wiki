# 03_反復一覧の間隔と区切り線を分ける

反復一覧では、項目同士の間隔、一覧の外側余白、一覧全体の外枠、項目間の区切り線を分ける。

## 項目同士の間隔を作る

```css
.list {
  display: grid;
  gap: 16px;
}
```

親で束ねられるなら、同じ親内の項目間隔は`gap`を先に検討する。

既存HTMLを変えにくく、2個目以降だけ空けるなら隣接兄弟も使える。

```css
.item + .item {
  margin-top: 16px;
}
```

- 項目間: `gap`または隣接兄弟
- 一覧の次のブロックまで: 一覧全体やセクションの外側余白
- 各項目の`margin-bottom`: 最後の項目にも不要な余白が残らないか確認する

## 外枠と区切り線を作る

```css
.list {
  border-block: 1px solid #777;
}

.item + .item {
  border-top: 1px solid #777;
}

.link {
  display: block;
  padding: 20px;
}
```

- 一覧全体の上下線: 一覧親
- 項目間の線: 項目同士の関係
- 文字と線の距離・押せる余白: リンク自身

WordPressなどで生成された一覧でも、出力されたHTMLを見て同じ責務分離を使う。`+`の一致条件は[隣接する兄弟要素を選ぶ](../14_セレクタと構造依存/04_隣接する兄弟要素を選ぶ.md)で確認する。
