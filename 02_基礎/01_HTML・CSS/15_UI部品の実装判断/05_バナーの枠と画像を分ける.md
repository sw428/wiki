# 05_バナーの枠と画像を分ける

バナーでは、リンクとして押せる面、画像の表示方法、HTMLで伝える文字を分ける。完成画像を自然比率で出す場合と、決まった比率の枠へ写真を収める場合も区別する。

## 画像とHTMLテキストを重ねる

```html
<a class="banner" href="#">
  <img class="banner__img" src="banner.jpg" alt="" />
  <span class="banner__text">Campaign</span>
</a>
```

```css
.banner {
  position: relative;
  display: block;
  aspect-ratio: 16 / 5;
  overflow: hidden;
  border-radius: 8px;
}

.banner__img {
  display: block;
  width: 100%;
  height: 100%;
  object-fit: cover;
}

.banner__text {
  position: absolute;
  inset: 0;
  display: grid;
  place-items: center;
}
```

- リンク面と重ねる基準箱: `.banner`
- 枠を埋める写真: `.banner__img`
- HTMLで伝える文字: `.banner__text`

画像にしかない情報がある場合は`alt`または表示テキストで伝える。同じ意味をHTMLテキストで伝えている装飾画像なら、空の`alt`を使える。

## 背景画像をリンク面へ置く

画像が装飾で、リンクの意味をHTMLの文字で伝えられるなら、`a`自身へ背景画像を置ける。

```html
<a class="image-link" href="#">リンク名</a>
```

```css
.image-link {
  display: grid;
  place-items: center;
  min-height: var(--link-height);
  background: url("../img/link-bg.jpg") center / cover no-repeat;
}
```

背景画像はリンクの面積を作らない。`min-height`、`aspect-ratio`、`padding`などをリンク側へ指定し、文字の周辺も押せる面にする。画像自体が情報を持つ場合は、背景ではなく`img`と代替テキストを使う。[imgとbackground-imageを選ぶ](../10_画像と背景/01_imgとbackground-imageを選ぶ.md)で区別する。

## 完成画像と固定比率の枠を分ける

完成済み画像をそのまま縮小する場合は、画像の自然比率を使う。

```css
.sidebar__banner img {
  display: block;
  width: 100%;
  height: auto;
}
```

「バナー枠は常に258/94」と決まっている場合は、親へ比率を持たせる。

```css
.sidebar__banner {
  aspect-ratio: 258 / 94;
  overflow: hidden;
}

.sidebar__banner img {
  display: block;
  width: 100%;
  height: 100%;
  object-fit: cover;
}
```

後者は画像を切り抜く可能性がある。文字入り画像、ロゴ、商品全体などを`cover`で切らない。素材の比率とカンプの測定値が少し違う場合は、実装で変形して吸収せず、まず素材比率を保った表示を確認する。

## 判断基準

- 写真を決まった面へ収める: `aspect-ratio`と`object-fit: cover`。
- 完成画像をそのまま見せる: `width`と`height: auto`。
- 文字や商品全体を切らない: 自然比率か`contain`を検討する。
- HTMLテキストを重ねる: 画像は高さ、親は基準箱、文字は重ねる役へ分ける。
- 画像のない面へ文字だけ重ねる: 親の`aspect-ratio`、`min-height`、`padding`で高さを作る。

画像の比率と収め方は[レスポンシブ画像設計](../12_レスポンシブ画像設計/00_レスポンシブ画像設計整理マップ.md)、画像上の重ね方は[メディアの表示枠と重ね配置](../11_メディアの表示枠と重ね配置/00_メディアの表示枠と重ね配置整理マップ.md)で詳しく確認する。

## 一言でいうと

バナー全体をリンク面にし、自然比率の完成画像か、切り抜きを許容する固定枠かを先に選ぶ。
