# 02_画像を自然比率か表示枠へ収めるか選ぶ

画像を使うUIでは、最初に「画像そのものの比率で見せるか」「UI側の表示枠へ収めるか」を決める。

| 画像の役割 | 守ること | 基本候補 |
| --- | --- | --- |
| ロゴ・文字入り画像 | 全体を切らずに見せる | `width`で上限を作り、`height: auto` |
| 写真・サムネイル | 枠を埋め、切り抜きを許容する | 親の`aspect-ratio`と子の`object-fit: cover` |
| 商品など全体を見せる素材 | 切り抜かず、枠内の余白を許容する | `height: auto`または`object-fit: contain` |

## 自然比率

```css
.image img {
  display: block;
  width: 100%;
  height: auto;
}
```

ロゴ、文字入り画像、商品全体など、切れると意味が変わる素材は画像自身の比率を保つ方法を先に検討する。

小さく見せたいだけなら、`width`、`max-width`、`min()`などで実寸の上限を作る。`aspect-ratio`は縮小指定の代わりではない。

## 表示枠へ収める

```css
.frame {
  aspect-ratio: 3 / 2;
  overflow: hidden;
}

.frame img {
  display: block;
  width: 100%;
  height: 100%;
  object-fit: cover;
}
```

`cover`では一部が切れる。写真やサムネイルなど、切り抜きを許容できる場合に使う。

## 判断順

1. 画像全体を見せる必要があるか。
2. 枠を優先して切り抜いてよいか。
3. 高さを作るのは画像自身か、外側の枠か。
4. SP/PCで構図を変える必要があるか。

次の状態では、どの箱が比率を担当するかを確認し直す。

- `img`へ`width: 100%`と`height: 100%`だけを指定し、収め方を決めていない。
- `aspect-ratio`を複数階層へ付けている。
- 高さだけを固定し、比率維持か切り抜きかを決めていない。
- SPとPCで方法を変えているが、切り替える理由を説明できない。

`img`と背景画像の選択は[imgとbackground-imageを選ぶ](../10_画像と背景/02_imgとbackground-imageを選ぶ.md)、表示領域と画像候補の選択は[レスポンシブ画像設計の選び方](../12_レスポンシブ画像設計/01_レスポンシブ画像設計の選び方.md)へ戻る。形だけを使う場合は[background-imageとmask-imageを区別する](../10_画像と背景/05_background-imageとmask-imageを区別する.md)で別問題として扱う。
