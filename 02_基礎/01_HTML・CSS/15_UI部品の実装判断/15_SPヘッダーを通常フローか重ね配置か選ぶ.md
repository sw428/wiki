# 15_SPヘッダーを通常フローか重ね配置か選ぶ

SPヘッダーでは、「SPだけ存在するか」と「表示された後にどこへ置くか」を分ける。このページでは表示後の配置方法を選ぶ。

## 通常フローで置く

写真より前のヘッダー行や色付き帯なら、HTML上でもMVより前に置き、通常フローやFlexで配置する。

```html
<div class="header">
  <button class="button" type="button" aria-label="メニューを開く">
    <span class="line"></span>
    <span class="line"></span>
    <span class="line"></span>
  </button>
</div>
```

```css
.header {
  display: flex;
  justify-content: flex-end;
}

.button {
  display: grid;
  place-content: center;
  gap: 6px;
  width: 44px;
  height: 44px;
}
```

## MVへ重ねる

写真の上へ重ねるデザインなら、重ねる基準となる親を用意し、必要に応じて絶対配置を使う。

SP専用という理由だけで`position: absolute`へしない。通常フローで成立するなら、まず通常フローを使う。

表示制御用のクラスへ位置や余白まで持たせず、存在条件と表示後の配置を別の担当へ分ける。

## 分担

- SPで存在する条件: [SPとPCで表示する要素を切り替える](../13_表示制御/02_SPとPCで表示する要素を切り替える.md)
- 表示後の位置: このページ
- ボタン自身の操作範囲: [CTAとナビリンクの操作範囲を作る](./09_CTAとナビリンクの操作範囲を作る.md)
- クリック後の開閉状態と`aria-expanded`: [JSのUI実装パターン](../../02_JS/03_UI実装パターン.md)

ヘッダー全体に不要な横paddingを入れず、実際に余白が必要な内側の行へ持たせる。

実装後は、SPのどの幅で存在するか、ボタン自身の操作範囲、開閉状態と表示の同期、キーボード操作とフォーカス、閉じる操作を確認する。
