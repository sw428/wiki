# 14_ラベルを小さな意味表示として作る

NEWやカテゴリ名などのラベルは、一覧全体を並べる箱ではなく、小さな意味表示として責務を絞る。

```css
.label {
  display: inline-flex;
  align-items: center;
  min-height: 24px;
  padding-inline: 8px;
  border-radius: 999px;
  line-height: 1;
}
```

- 文字周囲の余白: `padding`
- 小さな箱の高さ: `min-height`
- 角丸: `border-radius`
- 行内での配置: `inline-flex`

ラベル同士やカード一覧全体の間隔は、ラベル自身ではなく親へ持たせる。
