# 05_バナーの実装方法を選ぶ

バナーでは、画像と文字の役割から実装方法を選ぶ。完成画像をそのまま見せる、画像とHTMLテキストを重ねる、装飾画像を背景にする、の三つを先に分ける。

## 完成画像をそのまま見せる

```css
.banner img {
  display: block;
  width: 100%;
  height: auto;
}
```

文字入り画像など、全体を見せる必要がある場合は自然比率を保つ。

決まった比率の枠へ収める場合は、切り抜いても意味が変わらないかを確認する。

```css
.banner {
  aspect-ratio: 3 / 1;
  overflow: hidden;
}

.banner img {
  width: 100%;
  height: 100%;
  object-fit: cover;
}
```

`cover`は画像を切り抜く可能性がある。文字、ロゴ、商品全体などを機械的に切らない。

## 画像とHTMLテキストを重ねる

リンク面、画像、文字の三つへ責務を分ける。

```html
<a class="banner" href="#">
  <img class="image" src="banner.jpg" alt="">
  <span class="text">Campaign</span>
</a>
```

```css
.banner {
  position: relative;
  display: block;
  aspect-ratio: 16 / 5;
  overflow: hidden;
}

.image {
  display: block;
  width: 100%;
  height: 100%;
  object-fit: cover;
}

.text {
  position: absolute;
  inset: 0;
  display: grid;
  place-items: center;
}
```

- リンク面と重ねる基準箱: `.banner`
- 枠を埋める画像: `.image`
- HTMLで伝える文字: `.text`

同じ意味をHTMLテキストで伝えている装飾画像なら、空の`alt`を検討する。

## 装飾画像を背景にする

画像が装飾で、リンクの意味をHTMLテキストだけで伝えられる場合は、リンク面へ背景画像を置ける。

```html
<a class="link" href="#">リンク名</a>
```

```css
.link {
  display: grid;
  place-items: center;
  min-height: var(--height);
  background: url("../img/banner.jpg") center / cover no-repeat;
}
```

背景画像はリンクの面積を作らない。高さや`padding`はリンク自身へ持たせる。画像自体が情報を持つ場合は、背景ではなく`img`と代替テキストを使う。

## 選択の目安

- 完成画像を切らずに見せる: 自然比率の`img`
- 写真を決まった面へ収める: 比率枠と`object-fit: cover`
- 画像とHTMLテキストを重ねる: リンク面を基準箱にし、画像と文字の責務を分ける
- 装飾画像の上へHTMLテキストを置く: リンク自身の背景画像にする
- 文字・ロゴ・商品全体を切れない: `cover`を避け、自然比率か`contain`を検討する
