# 13_装飾アイコンを疑似要素か実要素で作る

矢印などの装飾アイコンは、単純な形として付けるのか、独立した素材として扱うのかで実装を分ける。

## 疑似要素で足りる場合

```css
.link::after {
  content: ">";
}
```

単純な記号やCSSの線・`border`で作れる形なら疑似要素を候補にできる。ただし、`content`で生成した文字が支援技術にどう扱われるかは実装環境によって確認し、意味のある情報を疑似要素だけへ任せない。

## 実要素として置く場合

```html
<a class="link" href="/news/">
  一覧へ
  <span class="icon">
    <img src="img/arrow.svg" alt="">
  </span>
</a>
```

独立した素材として寸法を調整する場合や、プロジェクトの方針として実要素で管理する場合はHTMLへ置ける。装飾画像なら空の`alt`を使う。素材を実要素にすることと、必ずラッパーを増やすことは別に判断する。

状態と同期するからという理由だけで、実要素がCSS仕様上必須になるわけではない。親の属性やクラスに応じて疑似要素の見た目を変えることもできる。

アイコンだけのボタンにも操作名が必要である。[開閉UIの最小例](../../02_JS/03_UI実装パターン.md#最小テンプレアイコンだけの開閉ボタン)で、見た目、名前、状態をそろえる。
