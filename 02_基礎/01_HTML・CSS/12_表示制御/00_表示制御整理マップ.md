# 表示制御整理マップ

Codex用。画面幅による表示条件、`revert`の戻り先、表示時の配置を別の疑問として扱う。人間向けの入口は[01_SPとPCで表示する要素を切り替える](./01_SPとPCで表示する要素を切り替える.md)。

## この章の入口

- SPだけ・PCだけ表示する要素を作る: [01_SPとPCで表示する要素を切り替える](./01_SPとPCで表示する要素を切り替える.md)

## 整理時に保つ関係

1. `display: none`は要素のboxを生成しない。要素の場所を移動したり、並び方だけを変えたりする指定ではない。
2. `sp-only` / `pc-only`は存在条件を表す。余白、位置、Flex・Gridまで表示制御クラスへ持たせない。
3. `display: revert`は、直前の自作値ではなく、現在のカスケード出所を巻き戻す。自作の`flex`や`grid`を保存・復元しない。
4. 表示時に固有の`display`が必要なら、必要な値を明示するか、表示する範囲では非表示Utilityが競合しない構成を検討する。
5. PC/SPで文言を重複させる場合も、日時・価格・リンク先など意味上のデータを別々の値へずらさない。
