## 整理時に保つ関係

1. 01はレンダリング工程の入口。内部実装の詳しさより、要素・指定・表示を対応させる。
2. 02は位置ずれの原因と対策を一続きにし、Layout ShiftとScroll Anchoringを同じ現象として扱わない。
3. 03はカンプの数値をCSSへ移すときの比較対象をそろえる。フォント差も見た目だけで決めず、レンダリングフォントを確認する。
4. 04は観測手段を扱う。CSSの勝敗は[06](../../06_CSSカスケードとDevToolsの見方/00_CSSカスケードとDevToolsの見方整理マップ.md)、箱の寸法は[05](../../05_ボックスとdisplay/00_ボックスとdisplay整理マップ.md)へ分ける。
5. transform後の外接矩形の計算は[03_詳細](../../../../03_詳細/01_HTML・CSS/03_transform後の外接矩形.md)、CSSネストとSassの選択は[CSS設計](../../../07_設計/CSS設計/02_SCSSとCSS分割.md)へ置く。
