## 整理時に保つ関係

1. 01はレンダリング工程の入口。内部実装の詳しさより、要素・指定・表示を対応させる。
2. 02は位置ずれの原因と対策を一続きにし、Layout ShiftとScroll Anchoringを同じ現象として扱わない。
3. 03はカンプの数値をCSSへ移すとき、選択枠・字形・ブラウザの箱という比較対象をそろえる。
4. 04はフォント差を見た目だけで決めず、指定フォントとレンダリングフォントを分けて確認する。
5. 05〜08はDevToolsで何を確認したいかによって記事を分ける。CSS宣言の勝敗は[06](../06_CSSカスケードとDevToolsの見方/00_CSSカスケードとDevToolsの見方整理マップ.md)、箱の寸法の仕組みは[05](../05_ボックスとdisplay/00_ボックスとdisplay整理マップ.md)へ分ける。
6. transform後の外接矩形の計算は[03_詳細](../../../03_詳細/01_HTML・CSS/03_transform後の外接矩形.md)、CSSネストとSassの選択は[CSS設計](../../07_設計/CSS設計/02_SCSSとCSS分割.md)へ置く。
