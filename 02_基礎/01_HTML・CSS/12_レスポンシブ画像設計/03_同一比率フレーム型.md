# 03_同一比率フレーム型

画像自身の比率ではなく、CSSで決めた一定比率の枠を使って表示する設計を扱う。

| 担当 | 決まるもの |
| --- | --- |
| [レイアウト](../09_レイアウト/02_親子のレイアウト文脈を区別する.md#幅が想定より広がるとき) | 枠の幅 |
| 枠のCSS | 表示領域の比率 |
| 画像のCSS | 枠内での見せ方 |

## この型を選ぶ条件

次の条件に合う場合は、同一比率フレーム型を選ぶ。

- 画像の表示サイズは画面幅に応じて変えたい
- 表示領域の縦横比は常に同じにしたい
- 画像自身の比率より、デザイン上の枠の形を優先したい
- カード画像などを同じ形にそろえたい

画像自身の比率をそのまま使う場合は、[自然比率維持型](./02_自然比率維持型.md)を使う。

## 最小の実装

```html
<div class="card__media">
  <img
    class="card__image"
    src="./img/dog.jpg"
    alt="芝生に座っている犬"
    width="600"
    height="400"
  >
</div>
```

```css
.card__media {
  aspect-ratio: 3 / 2;
}

.card__image {
  display: block;
  width: 100%;
  height: 100%;
  object-fit: cover;
}
```

- `aspect-ratio: 3 / 2`は、表示領域の比率を3:2にする
- `width: 100%; height: 100%`は、画像要素の箱を枠いっぱいの大きさにする
- `object-fit: cover`は、画像自身の比率を保ったまま画像内容で枠全体を埋める

`object-fit`で調整された画像内容は、画像要素の内容領域で切り取られる。この実装では、切り抜きのために親へ`overflow: hidden`を指定する必要はない。

## `aspect-ratio`は枠の比率を決める

`aspect-ratio`だけで幅は決まらない。この例では、レイアウトで決まった枠の幅と`3 / 2`の比率から、高さが計算される。

```text
幅 600px → 高さ 400px
幅 450px → 高さ 300px
幅 300px → 高さ 200px
```

固定された幅と高さを指定するのではなく、幅が変わっても同じ形を維持する。

## 枠と画像の役割を分ける

`aspect-ratio`は枠の比率を決め、`object-fit`は決まった画像要素の箱の中で画像内容をどう見せるかを決める。`object-fit`だけでは、表示領域の幅や高さは作られない。

画像自身の比率と枠の比率が違う場合は、見せ方を選ぶ。

- `object-fit: cover`: 画像の比率を保ったまま枠全体を埋め、余る部分を切り抜く
- `object-fit: contain`: 画像全体を切らずに収め、比率差による空きを残す
- `object-position`: 枠内で画像内容を配置する位置を調整する。`cover`では、どの部分を優先して見せるかの調整に使う

## SPとPCで比率が同じなら共通指定にする

SPでもPCでも3:2なら、`aspect-ratio: 3 / 2`を共通指定へ1回書く。

SPとPCで比率そのものを変える場合は、[比率切替型](./04_比率切替型.md)を使う。

## 確認すること

1. DevToolsで枠の幅と高さが指定した比率になっているか確認する。
2. 画像要素の箱が枠いっぱいに広がっているか確認する。
3. `object-fit`で意図した範囲が見えているか、位置を調整した場合は`object-position`も確認する。

カード一覧や人物写真で枠の責務を分ける実装は、[カードと人物写真の枠をそろえる](../15_UI部品の実装判断/06_カードと人物写真の枠をそろえる.md)で扱う。
