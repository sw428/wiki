# 04_比率切替型

SPとPCなどで、表示領域の縦横比そのものを切り替える設計を扱う。

```text
ブレークポイントで変える → 枠の比率
枠の幅と比率から決まる   → 枠の高さ
```

## この型を選ぶ条件

次の条件に合う場合は、比率切替型を選ぶ。

- SPとPCで表示領域の形を変えたい
- それぞれの画面幅で、幅に応じて高さも変化させたい
- 一定の高さではなく、縦横比を基準に表示領域を作りたい

SPとPCで比率が同じ場合は、[同一比率フレーム型](./03_同一比率フレーム型.md)を使う。

幅が変わっても高さを一定に保ちたい場合は、[高さ基準型](./05_高さ基準型.md)を使う。

## 最小の実装

たとえば、SPでは`375 / 400`、PCでは`1920 / 500`の比率へ切り替える。

```css
.media-frame {
  aspect-ratio: 375 / 400;
}

@media (min-width: 768px) {
  .media-frame {
    aspect-ratio: 1920 / 500;
  }
}
```

SPでは縦に近い形、PCでは横長の形になる。

## 数字は固定サイズではない

`aspect-ratio: 375 / 400`は、幅を375px、高さを400pxへ固定する指定ではない。実際の枠の幅と`375 / 400`の比率から高さが決まる。

## 枠の比率と画像切替は別に考える

比率切替型が決めるのは、SPとPCで表示領域をどの形にするかである。使用する画像ファイルを変えるかどうかは別に判断する。

```text
比率切替型 ＋ 同じ画像
比率切替型 ＋ SPとPCで別画像
```

画像内容そのものを切り替える場合は、[画像切替型](./06_画像切替型.md)で扱う。同じ画像を枠いっぱいに表示する場合は、画像側で`object-fit`などの見せ方を決める。

## カンプの寸法だけでは決めない

SPカンプが`375 × 400`、PCカンプが`1920 × 500`でも、その寸法だけでは比率切替型とは断定できない。基準幅では、`aspect-ratio`で高さを決める場合と、`height`で高さを固定する場合が同じ見た目になることがある。

違いは、画面幅が変わったときに現れる。

```text
比率切替型
幅が変わる → 高さも比率に従って変わる

高さ基準型
幅が変わる → 高さは基本的に維持される
```

そのため、カンプの基準寸法だけでなく、中間幅で高さをどう変化させたいかまで見て判断する。

## 確認すること

1. SPとPCで意図した比率へ切り替わっているか確認する。
2. 中間幅で、幅に応じて高さも変化しているか確認する。
3. 高さを固定する設計と混同していないか確認する。
