# 01_レスポンシブ画像設計の選び方

画像を実装するときは、まず次の二つを分けて考える。

1. 画像を表示する領域の大きさ・形をどう決めるか
2. その領域の中で画像をどう見せるか

表示領域を作ることと、画像を切り抜くことは別の判断である。`aspect-ratio`や`height`だけで画像がトリミングされるわけではない。

## 表示領域をどう決めるか

```text
画像自身の比率で高さを決める
└─ 画像全体を自然比率で表示する → 02

画像ファイルの自然比率とは別に表示領域の形を決める
├─ 幅に応じて高さも変えたい → 04 比率で表示領域を作る
└─ 高さそのものを決めたい → 05 高さで表示領域を作る
```

ロゴやバッジなど、画像の端まで見せて大きさだけ調整する場合は[画像全体を自然比率で表示する](./02_画像全体を自然比率で表示する.md)を読む。決められた形の枠へ画像を入れる場合は、幅が変わったときに高さも比率に従って変えるか、高さを保つかで04・05を選ぶ。基準のSP・PCカンプだけで決めず、中間幅でどう変化させたいかも確認する。

## 枠の中で画像をどう見せるか

表示領域を決めたあと、その中で画像全体を見せるか、領域いっぱいに埋めるかを選ぶ。

```text
全体を残す           → object-fit: contain
領域いっぱいに埋める → object-fit: cover
                       画像と領域の比率が違えば一部が切れる
見せる位置を調整する → object-position
```

選び方と最小例は[決めた表示領域に画像を合わせる](./03_決めた表示領域に画像を合わせる.md)で扱う。親の表示枠、`img`要素の箱、画像内容の詳しい関係や、親と`img`のどちらに寸法を持たせるかは[表示枠・画像要素・画像内容の役割を分ける](../11_メディアの表示枠と重ね配置/02_表示枠・画像要素・画像内容の役割を分ける.md)で確認する。

## 画像そのものや画像候補を変えるか

SPとPCなどで構図や画像内容を変える場合は、表示領域の作り方とは別に[画像切替](./06_画像切替.md)を判断する。画像を切り替えた後も、自然比率で見せるか、決めた領域に収めるかは選べる。

内容や構図は同じで、表示幅や画面密度に合うファイルをブラウザへ選ばせる場合は[`srcset`と`sizes`で画像候補を選ぶ](./07_srcsetとsizesで画像候補を選ぶ.md)を読む。すべての記事を番号順に読む必要はない。

画像ファイルの書き出し寸法と、CSS上の表示領域は別である。Figmaで書き出し高さを判断する場合は[画像レイヤーから書き出し寸法を求める](../../12_Figma/02_画像レイヤーから書き出し寸法を求める.md)で扱う。
