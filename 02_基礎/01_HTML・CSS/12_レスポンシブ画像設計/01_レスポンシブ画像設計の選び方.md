# 01_レスポンシブ画像設計の選び方

レスポンシブ画像を実装するときは、表示領域、画像内容、枠内での見せ方、画像候補を分けて決める。このカテゴリでは、必要な判断だけを組み合わせられるように、選択肢を役割ごとに分けている。

## 最初に分けること

```text
1. 表示領域をどう作るか
2. SPとPCなどで画像内容を切り替えるか
3. 枠の中で画像全体を見せるか、切り抜いて埋めるか
4. 同じ画像内容から表示幅や表示密度に合う候補を選ぶか
```

`aspect-ratio`をSP用かPC用かで分類するのではなく、幅の変化に対して表示領域の高さをどう決めたいかを見る。

## 表示領域を4種類から選ぶ

| 判断したいこと | 設計タイプ | 詳しい説明 |
| --- | --- | --- |
| 画像自身の比率を保ち、全体を切らずに見せたい | 自然比率維持型 | [02_自然比率維持型](./02_自然比率維持型.md) |
| 大きさが変わっても、枠の縦横比は同じにしたい | 同一比率フレーム型 | [03_同一比率フレーム型](./03_同一比率フレーム型.md) |
| SPとPCで枠の縦横比を切り替えたい | 比率切替型 | [04_比率切替型](./04_比率切替型.md) |
| 幅とは別に、一定高または最低限の高さを保ちたい | 高さ基準型 | [05_高さ基準型](./05_高さ基準型.md) |

表示領域を決めた後、必要な画像側の判断を組み合わせる。

```text
【1. 表示領域を決める】

画像自身の比率を使う？
├─ YES → 自然比率維持型
└─ NO
   ↓
幅に応じた比率で高さを決める？
├─ YES
│  ├─ 比率は同じ → 同一比率フレーム型
│  └─ 比率を変える → 比率切替型
└─ NO → 高さ基準型


        ↓


【2. 使用する画像を決める】

SPとPCなどで、画像内容を変える？
├─ NO → 同じ画像を使う
└─ YES → 画像切替型


        ↓


【3. 枠の中での見せ方を決める】

比率差のある枠へ画像を入れる？
├─ NO → 自然な比率、または同じ比率のまま表示する
└─ YES
   ├─ 画像全体を見せる → object-fit: contain
   └─ 枠を埋める → object-fit: cover
      └─ 見せる位置を変える → object-position


        ↓


【4. 同じ画像内容の候補を選ぶ】

表示幅や表示密度に合う画像ファイルを選ばせる？
├─ NO → 一つの画像ファイルを使う
└─ YES → srcsetとsizes
```

## 画像切替型を判断する基準

画像切替型かどうかは、画像の大きさや縦横比ではなく、**画像内容を変えるか**で判断する。

ここでいう画像内容の変化には、**サイズ・比率・`object-fit`による見え方の変化は含まない**。

同じ写真を縮小・拡大したり、`object-fit`によって見える範囲が変わるだけなら、同じ画像として扱う。

一方で、構図、人物や物の配置、[**元画像に含まれる範囲**](../../../05_参照/アートディレクション.md)、文字入り・文字なしなどを変えるために別の画像を用意する場合は、画像切替型とする。

画像切替型は、自然比率維持型・同一比率フレーム型・比率切替型・高さ基準型のどれとも組み合わせられる。詳しい実装は[06_画像切替型](./06_画像切替型.md)で扱う。

## 枠内での見せ方を決める

表示領域と画像の比率が異なる場合は、`object-fit`で画像全体を見せるか、切り抜いて枠を埋めるかを決める。`object-position`は枠内で画像内容を配置する位置を調整し、`cover`ではどの部分を優先して見せるかの調整に使う。

`object-fit`は表示領域の幅や高さを作る指定ではない。先に表示領域を決め、その枠へ画像を収める。枠と画像の責務は[03_同一比率フレーム型](./03_同一比率フレーム型.md)で確認する。

## 同じ画像内容の候補を選ぶ

構図や内容は変えず、表示幅や表示密度に合う画像ファイルをブラウザに選ばせる場合は、画像切替型ではなく[srcsetとsizesで画像候補を選ぶ](./07_srcsetとsizesで画像候補を選ぶ.md)で扱う。

## このカテゴリの読み方

- どの設計タイプか分からない場合は、このページの表と判断図から選ぶ。
- 設計タイプが決まっている場合は、該当する02〜05だけを読む。
- SPとPCなどで画像内容を変える場合は06を読む。
- 比率差のある枠へ画像を収める場合は、選んだ設計タイプの記事で`object-fit`と`object-position`を確認する。
- 同じ画像内容のまま、表示密度や表示幅に合う候補を選ぶ場合は07を読む。

すべての記事を順番に読む必要はない。いま判断したい内容に対応するページへ進む。
