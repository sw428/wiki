# 04_比率で表示領域を作る

表示領域の幅に応じて高さも変え、決めた縦横比を保ちたい場合は`aspect-ratio`を使う。同じ比率をSP・PCで使う場合も、画面幅に応じて比率を切り替える場合も、表示領域を比率から作る方法である。

## 比率を使う条件

- 画像の表示幅がレイアウトに応じて変わる
- その幅に合わせて高さも変えたい
- 画像自身の自然比率より、デザイン上の表示領域の形を優先したい

カード画像などを同じ形にそろえるときにも使う。幅が変わっても高さそのものを保ちたい場合は[高さで表示領域を作る](./05_高さで表示領域を作る.md)方法を選ぶ。画像自身の比率を使うなら[画像全体を自然比率で表示する](./02_画像全体を自然比率で表示する.md)へ戻る。

## 同じ比率の表示領域を使う

次の例では、自然比率が4:3の画像について、`img`自身の表示領域を3:2にする。画像ファイルの寸法は例として800×600とする。

```html
<img
  class="image"
  src="./img/landscape.jpg"
  alt="山と湖の風景"
  width="800"
  height="600"
>
```

```css
.image {
  display: block;
  width: 100%;
  aspect-ratio: 3 / 2;
  object-fit: cover;
}
```

`width: 100%`では画像要素の幅が親に従う。`aspect-ratio`は、その幅と高さの関係を3:2にする。`aspect-ratio`だけで幅や最大幅が決まるわけではない。

```text
表示幅 600px → 高さ 400px
表示幅 450px → 高さ 300px
表示幅 300px → 高さ 200px
```

SPでもPCでも同じ比率を保つなら、`aspect-ratio`は共通指定へ一度書けばよい。枠が画像自身と異なる比率でも、`aspect-ratio`だけが画像を切るわけではない。この例の`object-fit: cover`は枠を埋めるための別の指定であり、全体を残す場合は[枠内での見せ方](./03_決めた表示領域に画像を合わせる.md)を選び直す。

画像に文字や部品を重ねるなど、親要素を独立した表示枠にする場合もある。親の枠と`img`の箱の関係は[表示枠・画像要素・画像内容の役割を分ける](../11_メディアの表示枠と重ね配置/02_表示枠・画像要素・画像内容の役割を分ける.md)で扱う。

## 画面幅で比率を切り替える

SPでは縦に近い形、PCでは横長の形にしたい場合は、同じ要素の`aspect-ratio`の値をメディアクエリで変える。

```css
.image {
  width: 100%;
  aspect-ratio: 4 / 5;
  object-fit: cover;
}

@media (min-width: 800px) {
  .image {
    aspect-ratio: 16 / 5;
  }
}
```

```text
SP → 枠の比率 4:5
PC → 枠の比率 16:5
```

比率の数字は固定寸法ではない。例えば`4 / 5`は幅400px・高さ500pxへ固定する指定ではなく、実際の表示幅に対応する高さを決める。切り替えるのは表示領域の形であり、画像ファイルを変えるかどうかは別の判断になる。同じ画像を使う場合も、[画像切替](./06_画像切替.md)を組み合わせる場合もある。

## カンプの寸法だけでは決めない

SPカンプが`400 × 500`、PCカンプが`1600 × 500`でも、比率を切り替える設計とは断定できない。基準幅では、`aspect-ratio`から高さを決めても、`height`で高さを指定しても同じ寸法になり得る。

```text
比率を切り替える → 同じブレークポイント内でも、幅に従って高さが変わる
高さを指定する   → 同じブレークポイント内では、高さの指定値を保つ
```

中間幅で高さをどう変化させたいかを確認して選ぶ。

## 確認すること

1. DevToolsで表示領域の幅と高さが、意図した比率になっているか確認する。
2. 比率を切り替える場合は、SP・PCだけでなく中間幅でも高さの変化を確認する。
3. `object-fit`による見え方と、画像ファイルの切替を比率の変更と混同していないか確認する。
