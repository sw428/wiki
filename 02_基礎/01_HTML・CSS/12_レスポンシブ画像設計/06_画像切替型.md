# 06_画像切替型

SPとPCなどで、使用する画像内容そのものを切り替える設計を扱う。

このWikiでいう画像切替型は、一般に[アートディレクション](../../../05_参照/アートディレクション.md)と呼ばれる考え方にあたる。

```text
表示領域の型が決める → どんな形の枠にするか
画像切替型が決める   → その枠でどの画像を使うか
```

## この型を選ぶ条件

次のように、同じ意味・目的を保ったまま、SPとPCなどで画像内容を変える場合は画像切替型を選ぶ。

- 構図を変える
- 人物や物の配置を変える
- 元画像に含める範囲を変える
- 画面ごとに別の切り抜きや素材を使う

文字入り・文字なしの違いも、画像が同じ役割を保ち、必要な情報をHTMLや`alt`で等しく伝えられる場合に限り、アートディレクションの例になり得る。画像の意味やメッセージそのものを変える場合は、一つの`picture`で切り替える候補として扱わない。

同じ画像を拡大・縮小したり、`object-fit`によって見える範囲が変わるだけなら、画像切替型ではない。

同じ意味・同じ構図のまま、解像度や必要な表示幅に合うファイルを選ぶ場合は、[srcsetとsizesで画像候補を選ぶ](./07_srcsetとsizesで画像候補を選ぶ.md)で扱う。

画像切替型は、次の表示領域の型とは別に判断する。

- [自然比率維持型](./02_自然比率維持型.md)
- [同一比率フレーム型](./03_同一比率フレーム型.md)
- [比率切替型](./04_比率切替型.md)
- [高さ基準型](./05_高さ基準型.md)

## 最小の実装

SPでは近くから見せた画像、PCでは背景まで含む画像を使う。

```html
<picture>
  <source
    media="(min-width: 768px)"
    srcset="./img/dog-wide.jpg"
    width="1200"
    height="500"
  >
  <img
    src="./img/dog-close.jpg"
    alt="芝生に座っている犬"
    width="600"
    height="800"
  >
</picture>
```

```text
768px未満 → dog-close.jpg
768px以上 → dog-wide.jpg
```

`width`と`height`には、それぞれの候補画像の実際の寸法を指定する。表示をそのピクセル数へ固定する指定ではない。読み込み前の寸法情報については、[画像の読み込み前に表示領域を予約する](../11_メディアの表示枠と重ね配置/02_画像の読み込み前に表示領域を予約する.md)で扱う。

## `picture`は表示領域を決めない

`picture`が決めるのは、どの画像候補を内側の`img`で使うかである。`picture`自体が画像として表示されるわけではない。

```text
picture / source
→ 使用する画像候補を決める

imgのCSSと外側のレイアウト
→ 表示領域の幅や形を決める
```

そのため、次のどれも成立する。

```text
比率切替型 ＋ 同じ画像
比率切替型 ＋ SPとPCで別画像

高さ基準型 ＋ 同じ画像
高さ基準型 ＋ SPとPCで別画像
```

## 枠内での見せ方は別に決める

選ばれた画像を枠の中でどう表示するかは、画像切替とは別の判断になる。

`object-fit`や`object-position`による見せ方は、[同一比率フレーム型](./03_同一比率フレーム型.md)と同じ考え方で決める。

## 具体例

たとえば、次の画像と表示領域を組み合わせる。

```text
SP
→ 縦長の表示領域
→ 人物を近くから見せた画像

PC
→ 横長の表示領域
→ 背景まで広く写した画像
```

この場合は、二つの判断を組み合わせている。

```text
表示領域 → 比率切替型
画像内容 → 画像切替型
```

## 確認すること

1. 切り替える画像が、どちらも同じ意味・目的を伝え、`img`の`alt`が両方に適しているか確認する。
2. 構図や含める範囲を変えるのか、同じ構図から解像度・表示幅に合う候補を選ぶだけなのか確認する。
3. 表示領域の変更と画像ファイルの変更を混同していないか確認する。
4. 切り替え後も、重要な人物・文字・商品などが意図した位置に見えているか確認する。
