# 05_高さ基準型

表示領域の比率ではなく、高さを基準にして表示領域を作る設計を扱う。

```text
CSSで指定する       → 枠の高さ
レイアウトで決まる → 枠の幅
```

## この型を選ぶ条件

次の条件に合う場合は、高さ基準型を選ぶ。

- 画面幅が変わっても一定の高さを保ちたい
- 縦横比より、高さそのものを優先したい
- MVやヒーローなどで一定の占有高さを確保したい

幅に応じて高さも比率で変化させる場合は、[比率切替型](./04_比率切替型.md)として考える。

## 最小の実装

たとえば、SPでは450px、PCでは600pxの高さにする。

```html
<div class="media-frame">
  <img
    class="media-frame__image"
    src="./img/landscape.jpg"
    alt="山と湖の風景"
    width="600"
    height="400"
  >
</div>
```

```css
.media-frame {
  height: 450px;
}

.media-frame__image {
  display: block;
  width: 100%;
  height: 100%;
  object-fit: cover;
}

@media (min-width: 800px) {
  .media-frame {
    height: 600px;
  }
}
```

この場合、同じブレークポイント内では幅が変わっても高さは維持される。

親の表示枠と画像側の指定を分ける理由と、`img`自身が表示領域を兼ねる簡略形は、[表示枠・画像要素・画像内容の役割を分ける](../11_メディアの表示枠と重ね配置/02_表示枠・画像要素・画像内容の役割を分ける.md)で扱う。

```text
幅 400px → 高さ 450px
幅 600px → 高さ 450px
```

## 比率切替型との違い

違いは、幅が変わったときに高さをどうするかで判断する。

```text
比率切替型
幅が変わる
→ 高さも比率に従って変わる
```

```text
高さ基準型
幅が変わる
→ 高さは基準値を維持する
```

たとえば基準カンプが`400 × 450`でも、その寸法だけではどちらの型か決められない。中間幅で高さをどう変化させたいかまで見て判断する。

## `height`と`min-height`

高さを固定したい場合は、`height`を使う。

```css
.media-frame {
  height: 450px;
}
```

文字などの内容が入り、内容量によって高さを増やす必要がある場合は、`min-height`を使う。

```css
.media-frame {
  min-height: 450px;
}
```

```text
height     → 高さを450pxにする
min-height → 最低450pxを確保し、必要ならそれ以上になる
```

どちらも、縦横比ではなく高さを基準にする点は同じである。

ただし、親が`min-height`だけを持つ場合、画像の`height: 100%`が親の最終的な高さへそのまま広がるとは限らない。画像も内容に応じて伸びる枠全体を覆う必要がある場合は、重ね配置など別のレイアウト方法を含めて確認する。

## 枠内の画像の見せ方は別に決める

高さ基準型が決めるのは、表示領域の高さである。画像をその枠へどう収めるかは別に判断する。

`object-fit: cover`や`object-position`による見せ方は、[同一比率フレーム型](./03_同一比率フレーム型.md)と同じ考え方で決める。

## 確認すること

1. `height`なら指定した高さ、`min-height`なら最低限の高さが意図どおり維持されているか確認する。
2. `height`と`min-height`のどちらがデザイン意図に合うか確認する。
3. 比率に応じて高さを変える設計と混同していないか確認する。
