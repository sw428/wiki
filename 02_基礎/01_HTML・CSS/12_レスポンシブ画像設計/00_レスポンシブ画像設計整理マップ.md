# レスポンシブ画像設計整理マップ

Codex用。表示領域の決め方、枠内での見せ方、画像内容の切替、同じ内容からの画像候補選択を分け、反映先を確認する。人間向け入口は[レスポンシブ画像設計の選び方](./01_レスポンシブ画像設計の選び方.md)。

## 反映先と境界

| 疑問・判断 | 正本 |
| --- | --- |
| 画像の表示方針をどこから選ぶか | [01_レスポンシブ画像設計の選び方](./01_レスポンシブ画像設計の選び方.md) |
| 画像自身の比率を保ち、幅を調整して全体を見せる | [02_画像全体を自然比率で表示する](./02_画像全体を自然比率で表示する.md) |
| 決めた表示領域で全体を残すか、埋めるか、見せる位置を変えるか | [03_決めた表示領域に画像を合わせる](./03_決めた表示領域に画像を合わせる.md) |
| 幅に応じて高さを比率で決める。同じ比率を保つか、画面幅で比率を切り替える | [04_比率で表示領域を作る](./04_比率で表示領域を作る.md) |
| 高さそのもの、または最低限の高さを決める | [05_高さで表示領域を作る](./05_高さで表示領域を作る.md) |
| SPとPCなどで画像内容・構図を変える | [06_画像切替](./06_画像切替.md) |
| 同じ内容・構図から表示幅や画面密度に合うファイルを選ばせる | [07_srcsetとsizesで画像候補を選ぶ](./07_srcsetとsizesで画像候補を選ぶ.md) |

枠を比率・高さで作る指定と、枠内の`object-fit`による見せ方を混同しない。`06`の画像内容切替と`07`の同内容からの候補選択も別の判断として扱う。比率切替は`04`の追加条件であり、別の表示型にはしない。
