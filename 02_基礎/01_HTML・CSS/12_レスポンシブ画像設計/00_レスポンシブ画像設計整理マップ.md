# レスポンシブ画像設計整理マップ

Codex用。レスポンシブ画像の設計判断を、表示領域、画像内容、枠内での見せ方、画像候補に分けて管理する。

> [!IMPORTANT]
> `04_比率切替型`と`05_高さ基準型`は、表示領域の高さを決める基準が異なるため別の設計として保つ。`06_画像切替型`は画像内容を変える判断であり、表示領域の4種類とは別軸として扱う。

## 判断の順序

1. [レスポンシブ画像設計の選び方](./01_レスポンシブ画像設計の選び方.md)で、表示領域を02〜05から一つ選ぶ。
2. SPとPCなどで画像内容を変える場合は、表示領域の種類と組み合わせて[画像切替型](./06_画像切替型.md)を使う。
3. 比率差のある枠へ収める場合は、`object-fit`で全体を見せるか切り抜くかを決め、必要なら`object-position`で見せる位置を調整する。
4. 同じ画像内容のまま表示密度や表示幅に合うファイルを配信する場合は、[srcsetとsizes](./07_srcsetとsizesで画像候補を選ぶ.md)を使う。

すべての記事を番号順に読む必要はない。入口で判断した後、対応する表示領域の記事と、必要な画像側の判断だけを読む。

## 各ファイルと既存ノートの分担

- このカテゴリ: 実際のデザインから、表示領域、画像内容、枠内での見せ方、画像候補の組み合わせを選ぶ
- [自然比率維持型](./02_自然比率維持型.md): `width`、`max-width`、`height: auto`、寸法属性、SVGの基本
- [同一比率フレーム型](./03_同一比率フレーム型.md): `aspect-ratio`と枠・画像の責務
- [比率切替型](./04_比率切替型.md) / [高さ基準型](./05_高さ基準型.md): 幅に連動する比率と高さ基準を分ける
- [画像切替型](./06_画像切替型.md): 構図、配置、元画像に含まれる範囲、文字の有無など、SPとPCで画像内容を変えるか判断する
- [srcsetとsizes](./07_srcsetとsizesで画像候補を選ぶ.md): 同じ構図の画像から表示密度・表示幅に合う候補を選ぶ
- [画像の読み込み前に表示領域を予約する](../11_メディア設計/02_画像の読み込み前に表示領域を予約する.md): 寸法属性とCLS対策
- [画像を使うUIの制御方法を選ぶ](../15_デザインパターンとCSS設計判断/02_画像を使うUIの制御方法を選ぶ.md): バナーやカードなど、UI名から確認先を選ぶ入口

## 整理時に保つ関係

1. 画像データのピクセル寸法、HTMLの寸法属性、CSS計算後の表示寸法、アスペクト比を同じ数値として扱わない。
2. `aspect-ratio`は比率を決める。最大幅や固定寸法を決める指定ではない。
3. `object-fit`は、先に決まった置換要素の箱の中で画像をどう描くかを決める。画像要素の箱自体の幅・高さは別に確認する。
4. `<picture>`と`srcset`は画像候補を選ぶ。画面上の表示幅・表示枠は`img`とCSSが決める。
5. 表示領域の形と画像候補の切替は別軸であり、必要なら組み合わせる。
