# 03_決めた表示領域に画像を合わせる

デザイン上の表示領域が先に決まっている場合は、領域の大きさ・形と、その中で画像をどう見せるかを分けて選ぶ。

```text
表示領域の形 → 比率で決めるか、高さを指定するか
枠内の見せ方 → 全体を残すか、領域いっぱいに埋めるか
```

領域の高さを幅に連動させるなら[比率で表示領域を作る](./04_比率で表示領域を作る.md)、高さそのものを指定するなら[高さで表示領域を作る](./05_高さで表示領域を作る.md)を読む。どちらを選んでも、枠内の見せ方は別に決める。

## 全体を残すか、領域を埋めるか

`object-fit`は、寸法が決まった`img`要素の箱の中で、画像内容をどう描くかを決める。

| 見せたい状態 | 指定 | 比率が違うとき |
| --- | --- | --- |
| 画像の端まで見せたい | `object-fit: contain` | 領域内に空きが残る |
| 領域いっぱいに画像を見せたい | `object-fit: cover` | 画像内容の一部が切れる |

例えば、元画像が4:3で、`img`の表示幅が400pxなら、高さ200pxの表示領域は2:1の横長になる。次は`img`自身を表示領域にする最小例である。

```html
<img
  class="image"
  src="./img/landscape.jpg"
  alt="山と湖の風景"
  width="800"
  height="600"
>
```

```css
.image {
  display: block;
  width: 100%;
  height: 200px;
  object-fit: cover;
}
```

この例では`width`と`height`が画像要素の箱を作り、`cover`が画像内容でその箱を埋める。画像全体を残したい場合は`object-fit: contain`へ変える。`contain`でも箱の幅・高さは変わらない。空いた部分には`img`要素の背景が見える。

`aspect-ratio`や`height`だけでトリミングが起きるわけではない。また、`cover`でも元画像と表示領域の比率が同じなら、比率差による切り抜きは起きない。

## 見せる位置を調整する

`cover`で必要な部分が切れる場合は、`object-position`で画像内容を箱のどこに寄せるか調整する。

```css
.image {
  object-fit: cover;
  object-position: center top;
}
```

これで上側を優先して見せる。初期位置は中央である。左・右などの方向でも調整でき、必要なら百分率で細かく指定する。`object-position`は表示領域の大きさや画像ファイルを変えない。

位置調整だけでは必要な構図を作れない場合は、[画像切替](./06_画像切替.md)を検討する。親の表示枠、`img`要素の箱、画像内容の詳しい関係や、親を表示枠にする場合は[表示枠・画像要素・画像内容の役割を分ける](../11_メディアの表示枠と重ね配置/02_表示枠・画像要素・画像内容の役割を分ける.md)で確認する。

## 確認すること

1. `img`要素の箱が意図した幅・高さか確認する。
2. `contain`なら画像全体と空き、`cover`なら見える範囲を確認する。
3. `object-position`を変えた場合は、残したい部分が見えるか確認する。
