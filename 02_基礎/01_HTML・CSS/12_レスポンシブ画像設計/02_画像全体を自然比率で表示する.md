# 02_画像全体を自然比率で表示する

画像の端まで見せ、画像自身の縦横比を保ったまま大きさを調整する場合は、別の比率を持つ表示枠を作らない。

```text
CSSで決める       → 表示する幅
画像自身に任せる → その幅に対応する高さ
```

ロゴ、バッジ、人物写真などで、内容を切らずに大きさだけ変えたいときに使う。先に決めた形の領域へ収めたい場合は、[決めた表示領域に画像を合わせる](./03_決めた表示領域に画像を合わせる.md)へ進む。

## 最小の実装

```html
<img
  class="image"
  src="./img/dog.jpg"
  alt="芝生に座っている犬"
  width="600"
  height="400"
>
```

```css
.image {
  display: block;
  max-width: 100%;
  height: auto;
}
```

- `max-width: 100%`は、画像が親より大きいときに表示幅を縮める
- `height: auto`は、表示幅に対応する高さを画像自身の比率から決める
- `display: block`は、行内画像のベースラインに由来する下側の隙間を避ける
- HTMLの`width`・`height`属性は画像の寸法と比率を伝える。画像ファイルと対応する値を使う

画像をさらに小さくしたい場合は、必要な対象の`width`や`max-width`を調整する。部品全体の幅を変えるのか、`img`だけを変えるのかはHTMLの構造と配置方法も含めて決める。

## `aspect-ratio`を重ねる必要はない

画像自身の比率で表示するだけなら、同じ比率をCSSの`aspect-ratio`でもう一度指定する必要は基本的にない。画像自身の比率とは別に表示領域を決めたい場合は、[決めた表示領域に画像を合わせる](./03_決めた表示領域に画像を合わせる.md)へ進み、比率で作るか高さを指定するか選ぶ。

自然比率で表示するときは、通常`object-fit: cover`も必要ない。画像を切らずに見せることと、別の枠の中で`contain`を使って全体を見せることは別の設計である。

## 確認すること

1. DevToolsで`img`の表示幅と高さを確認する。
2. 幅を変えたとき、高さも画像自身の比率に沿って変わるか確認する。
3. `max-width`と`height: auto`が意図した要素へ適用されているか確認する。

HTMLの寸法属性による読み込み前の領域予約は、[画像の読み込み前に表示領域を予約する](../11_メディアの表示枠と重ね配置/03_画像の読み込み前に表示領域を予約する.md)で扱う。`img`と背景のどちらで使うか決まっていない場合は、[imgとbackground-imageを選ぶ](../10_画像と背景/02_imgとbackground-imageを選ぶ.md)へ戻る。
