# 02_自然比率維持型

画像全体を切らず、画像自身の縦横比を保ったまま、表示幅に合わせて拡大・縮小する設計を扱う。

```text
CSSで決める → 表示する幅
画像自身に任せる → 幅に対応する高さ
```

## この型を選ぶ条件

次の条件に合う場合は、自然比率維持型を選ぶ。

- 画像全体を見せたい
- 画像自身の縦横比を変えない
- CSSで別の比率を持つ枠を作る必要がない
- 画面幅に応じて表示幅だけを変えたい

固定比率の枠へ画像を収める場合は、[同一比率フレーム型](./03_同一比率フレーム型.md)を使う。

## 最小の実装

```html
<img
  class="article-image"
  src="./img/dog.jpg"
  alt="芝生に座っている犬"
  width="600"
  height="400"
>
```

```css
.article-image {
  display: block;
  max-width: 100%;
  height: auto;
}
```

- `width` / `height`属性は、画像の寸法と比率をブラウザへ伝える。実画像と同じ比率の値を使う
- `max-width: 100%`は、親より画像が大きい場合に縮める
- `height: auto`は、表示幅に対応する高さを画像自身の比率から計算する
- `display: block`は、行内画像のベースライン用スペースを避ける

## `aspect-ratio`を重ねない

画像自身の比率を使うため、同じ比率を`aspect-ratio`でもう一度指定する必要は基本的にない。

```css
/* 自然比率を使うだけなら追加しない */
.article-image {
  aspect-ratio: 3 / 2;
}
```

画像自身とは異なる比率の表示領域を作りたい場合は、自然比率維持型ではなく、枠を作る設計として分ける。

## 確認すること

1. DevToolsで対象の`img`を選ぶ。
2. ComputedまたはLayoutで、表示幅と高さを確認する。
3. Stylesで`max-width`と`height: auto`が適用されているか確認する。

HTMLの寸法属性による読み込み前の領域予約は、[画像の読み込み前に表示領域を予約する](../11_メディア設計/02_画像の読み込み前に表示領域を予約する.md)で扱う。画像を`img`と背景のどちらで使うか決まっていない場合は、[imgとbackground-imageを選ぶ](../10_画像と背景/01_imgとbackground-imageを選ぶ.md)へ戻る。
