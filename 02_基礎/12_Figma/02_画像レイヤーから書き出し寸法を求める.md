# 02_画像レイヤーから書き出し寸法を求める

画像の書き出し幅だけが指定されている場合、その数字だけでは高さは決まらない。書き出す画像レイヤーのW・Hから比率を確認し、その比率を保って高さを求める。

## 最初に書き出す対象を決める

Figmaでは、表示フレーム、マスク、画像レイヤーが異なる寸法を持つことがある。

| 選択対象 | 数値が表すもの | 書き出し比率に使う場合 |
| --- | --- | --- |
| 表示フレーム | カンプ上で見せる領域 | 表示領域そのものを書き出す場合 |
| マスク | 画像を見せる範囲 | マスク後の見た目を書き出す場合 |
| 画像レイヤー | 配置された画像レイヤーの範囲 | 画像レイヤー自体を書き出す場合 |
| グループ | 含まれるレイヤー全体の外接範囲 | グループ全体を書き出す場合 |

親フレームの寸法を見ただけでは、子の画像レイヤーの比率は分からない。仕様が画像レイヤー自体の書き出しを求めているなら、画像レイヤーを選択してW・Hを確認する。

## 幅から高さを求める

次は、元の教材や案件とは関係のない一般例である。

```text
仕様の書き出し幅
1800px

Figmaの表示フレーム
1200 × 600

Figmaの画像レイヤー
1200 × 800
```

書き出す対象が画像レイヤーなら、使う比率は`1200 : 800`である。表示フレームの`1200 : 600`は、カンプ上で見せる範囲なので使わない。

```text
1200 : 800 = 1800 : x

x = 800 × 1800 ÷ 1200
  = 1200
```

したがって、書き出し寸法は次のようになる。

```text
Figmaの画像レイヤー
1200 × 800

同じ比率で幅1800pxへ変更
↓

書き出しファイル
1800 × 1200
```

## 「元画像のピクセル寸法」とは区別する

Figmaの右パネルに表示されるW・Hは、Figma上に配置されたレイヤーの寸法である。画像ファイルが元から持っていたピクセル寸法と常に同じとは限らない。

```text
元画像ファイルのピクセル寸法
→ 読み込む前の画像ファイルが持つ寸法

Figma上の画像レイヤー寸法
→ カンプ内で配置・拡大縮小されたレイヤーの寸法

書き出しファイルのピクセル寸法
→ Figmaの書き出し設定から生成されたファイルの寸法

Web上の表示寸法
→ HTML・CSSとレイアウト計算で決まる寸法
```

「幅1800pxで書き出す」という指定は、元画像が最初から幅1800pxだったことを意味しない。書き出し後の目標幅である。

## 判断手順

1. 仕様から、書き出し対象と指定済みの幅を確認する。
2. Figmaで表示フレーム、マスク、画像レイヤーの階層を確認する。
3. 実際に書き出すレイヤーを選択し、そのW・Hを確認する。
4. 書き出し対象の比率を保って、指定幅から高さを計算する。
5. 書き出したファイルのピクセル寸法と比率を確認する。
6. Web上の表示領域は、書き出し寸法とは別にHTML・CSSで決める。

## レイヤー寸法だけでは判断できない場合

次の場合は、表示されているW・Hだけで決めない。

- 長方形の塗りとして画像が設定され、クロップ状態になっている
- グループに文字や装飾が含まれている
- マスク後の見た目と、マスク前の画像のどちらを書き出すか不明
- 元画像の解像度が不足し、指定幅へ拡大すると画質が落ちる
- 書き出し倍率や最終用途が仕様から分からない

この場合は、どの範囲を画像ファイルとして必要としているか確認する。画面上の表示領域の作り方は[レスポンシブ画像設計の選び方](../01_HTML・CSS/12_レスポンシブ画像設計/01_レスポンシブ画像設計の選び方.md)へ分ける。

## このページのまとめ

- 幅だけの指定では、書き出し高さはまだ決まらない。
- 表示フレームではなく、実際に書き出す対象のW・Hから比率を確認する。
- Figmaのレイヤー寸法を、元画像ファイルのピクセル寸法と同一視しない。
- 書き出しファイルの寸法と、Web上の表示寸法を分ける。
