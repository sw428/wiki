# 01_Figmaから実装情報を読み取る

Figmaのカンプから実装情報を読むときは、選択したレイヤーの数値をそのままCSSや書き出し設定へ移さない。まず、その数値が表示領域、画像レイヤー、マスク、文字の選択枠のどれを表しているか確認する。

## 確認したいことから選ぶ

| 確認したいこと | 読む場所 |
| --- | --- |
| 書き出し幅だけ指定され、高さをどう決めるか分からない | [画像レイヤーから書き出し寸法を求める](./02_画像レイヤーから書き出し寸法を求める.md) |
| 書き出した画像を自然比率・比率枠・固定高のどれで表示するか決めたい | [レスポンシブ画像設計の選び方](../01_HTML・CSS/12_レスポンシブ画像設計/01_レスポンシブ画像設計の選び方.md) |
| Figmaとブラウザで文字や箱の寸法が違う理由を確認したい | [カンプとブラウザの寸法を比べる](../01_HTML・CSS/07_ブラウザ挙動と表示のズレ/90_移行元/03_カンプとブラウザの寸法を比べる.md) |

## 最初に数値の対象を確認する

```text
Figmaで選択したものは何か
├─ 表示フレーム・マスク
│  → 見せる範囲の大きさ
├─ 画像レイヤー
│  → 配置された画像レイヤーの大きさと比率
├─ グループ
│  → 複数レイヤーを含む外接範囲
└─ 文字レイヤー
   → 文字の選択枠。ブラウザの行ボックスとは別
```

同じ場所を選んでいるように見えても、親フレームと子の画像レイヤーではW・Hが違うことがある。どのレイヤーを書き出すのか、どの領域をWeb上で再現するのかを先に分ける。

## FigmaとHTML・CSSの担当を分ける

```text
Figma
→ 素材の範囲、レイヤーの比率、書き出し対象を確認する

画像ファイル
→ 書き出されたピクセル寸法と画像内容を持つ

HTML・CSS
→ Web上の表示領域と、枠内での見せ方を決める
```

Figma上の画像を書き出した寸法と、Web上で表示する幅・高さは別である。書き出し画像が大きくても、CSSの表示領域が同じ大きさになるとは限らない。

## この分野で扱わないこと

Figmaの操作一覧や全機能を順番に説明する分野にはしない。実装時に判断が必要になった内容から、対象、数値、書き出しを分けて追加する。
