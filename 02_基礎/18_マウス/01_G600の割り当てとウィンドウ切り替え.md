# G600の割り当てとウィンドウ切り替え

G600では、**作業用ウィンドウを呼び出すキー列をボタンへ割り当て、普段の切り替えを少ない操作で行う。** ウィンドウの順番と用途がずれたときは、Chromeのタブをまとめて移して整理し直す方法と組み合わせる。

ここには、自分が採用した使い方と、その理由を記録する。G600全機能の説明や、全ボタンの設定一覧にはしない。

## この割り当てにした理由

目的は、用途ごとに分けたウィンドウを、マウス操作中にボタンから呼び出せるようにすること。キーの組み合わせを毎回手で入力する操作や、複数の候補から選ぶ操作を、マクロとしてまとめる。

この運用では、呼び出すウィンドウに、使いたい作業用のタブがまとまっていることが大切になる。起動後などに呼び出し先と用途の対応がずれても、ChromeではCtrlとクリックで複数のタブを選び、まとめて移せる。ユーザーは、これで短時間に整理し直せることも、この割り当てを使う理由としている。

整理するときの操作と、元のウィンドウを消す場合の注意点は、[Windows記事の複数タブをまとめて移す手順](../17_Windows/01_ウィンドウの切り替えと並び順.md#複数タブをまとめて移して呼び出し先の用途をそろえる)を参照する。呼び出し方と、ずれたときの戻し方を一緒に持っておくための割り当てである。

## 設定画面で確認できるChrome_3

提供された設定画面には、`Chrome_3`という名前で次のキー列が登録されている。

```text
左Windowsキーを押す
  「1」を押す → 離す
  「1」を押す → 離す
  「1」を押す → 離す
左Windowsキーを離す
```

最初にWindowsキーを押し、数字キーの操作が終わるまで保持している。Windowsキーを押したまま同じ数字を繰り返し押すと、タスクバーのその位置にあるアプリの複数ウィンドウを巡回できる。[Microsoft Pressのタスクバー操作の説明](https://www.microsoftpressstore.com/articles/article.aspx?p=3178893&seqNum=4)

| 設定画面で確認できる項目 | 内容 |
| --- | --- |
| マクロ名 | `Chrome_3` |
| 保持する修飾キー | Left Windows |
| 送信する数字 | `1` |
| 数字キーの押下・解放 | 3回 |
| 標準の遅延 | 使用する。表示値は50ミリ秒 |
| キーを押す・離すの表示 | 有効 |

ここにある名前・数字・回数・遅延は、提供された設定画面の実値である。別の例示値へ置き換えると設定の記録にならないため、そのまま残している。

## 数字と押す回数を分けて考える

このマクロの`1`は、タスクバー上のアプリ位置を選ぶ。Chromeを呼び出すには、Chromeがその位置にある必要がある。名前を`Chrome_3`にするだけで、マクロがChromeを識別するわけではない。

数字を繰り返す回数は、そのアプリのウィンドウを巡回するためのもの。`Chrome_3`は、Chromeの狙った呼び出し先へ切り替えるためのマクロとして記録する。実際に選ばれるウィンドウは実行後に確認し、特定のウィンドウに永久に同じ番号が付いたとは考えない。

この違いと、タブの移動で順番が変わる関係は、[Windows記事のキーが選ぶ対象](../17_Windows/01_ウィンドウの切り替えと並び順.md#まずキーが何を選んでいるかを分ける)で確認する。タスクバーのアプリ位置、ウィンドウの数や順番が変わった場合は、マクロと用途の対応を確かめる。

## ボタンへの割り当てと確認

G600は、対応する設定ソフトでキーストロークやマクロをボタンへ割り当てられる。[LogitechのG600セットアップガイド](https://www.logitech.com/assets/44964/g600-mmo-gaming-mouse-quickstart-guide.pdf)

この運用を設定するときは、Windowsキーの押下から解放までを含むキー列をマクロとして保存し、使うボタンへ割り当てる。割り当てたボタンを押して、目的のアプリ・作業ウィンドウへ切り替わるかを確かめる。意図した中身が開かなければ、タスクバーのアプリ位置と呼び出されたウィンドウを確認し、必要に応じてタブをまとめて整理する。

提供された画像には物理ボタン番号や、ほかのマクロの一覧は写っていない。そのため、どのGボタンが`Chrome_3`か、他のボタンに何を設定しているかは未確認として残す。画像からキー列を読めたことと、Codexが実機でマクロを実行できたことも区別する。

## このページのまとめ

- G600の割り当ては、作業ウィンドウへの切り替えを少ない操作で行うために使う。
- 設定画面の`Chrome_3`は、Windowsキーを保持したまま`1`を3回押して離すキー列になっている。
- 数字はタスクバーのアプリ位置、押す回数は同じアプリ内での巡回に使う。
- 呼び出し先と用途がずれた場合は、複数タブの一括移動で整理し直す方法と組み合わせる。
