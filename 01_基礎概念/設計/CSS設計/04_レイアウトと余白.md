## Layout接頭辞の運用

`l-` は、CSSに配置指定があることを表す接頭辞ではない。

FlexやGridを使用していても、特定のBlock内部の配置であれば、そのBlockのElementとして扱う。

```css
.staff__list {
  display: grid;
  gap: 24px;
}
```

当面、Layout接頭辞は `.l-page` と `.l-inner` の2つに限定する。

## `.l-page`

ページ全体の外枠を管理する。

```css
.l-page {
  width: 100%;
}
```

最大幅やページ全体の表示制御が不要な場合は、使用自体を再検討する。

## `.l-inner`

複数のBlockで共通するコンテンツ幅を管理する。

担当するのは、最大幅、中央寄せ、共通の左右余白。

```css
.l-inner {
  width: 100%;
  max-width: 1200px;
  margin-inline: auto;
  padding-inline: 20px;
}
```

`.l-inner` は、すべてを同じ外枠へ閉じ込めるためのクラスではない。
Heroのようにページ幅いっぱいへ見せたい領域と、本文やカード一覧のように中身幅を制限したい領域を分ける。

`inner` は、単に「外側の要素の中にある」という意味では使用しない。横幅管理をしない内部要素には、`__body`、`__content`、`__media` など、実際の役割を表す名前を使用する。

## Mixによる責務分離

共通横幅とBlock固有の配置を同じ要素が担当する場合は、クラスを併用する。

```html
<header class="header">
  <div class="header__body l-inner">
    ...
  </div>
</header>
```

```css
.l-inner {
  max-width: 1200px;
  margin-inline: auto;
  padding-inline: 20px;
}

.header__body {
  display: flex;
  align-items: center;
  justify-content: space-between;
}
```

Block固有の指定がない場合は、`.l-inner` だけを使用する。

```html
<header class="header">
  <div class="l-inner">
    ...
  </div>
</header>
```

## 親が子の配置を決める

レイアウト崩れの多くは、子Block自身に外側配置まで持たせることから始まる。

- 親: トラック、幅、配置、子同士の間隔を決める
- 子: 自分の内部構造と見た目を決める

```css
.staff__list {
  display: grid;
  gap: 40px 20px;
}

.staff-card {
  /* カード内部の配置と見た目 */
}
```

配置責務そのものは [コンポーネントと責務](./03_コンポーネントと責務.md) も参照する。

## `margin` / `padding` / `gap` の使い分け

- `gap`: 同じ親に属する反復要素同士の間隔
- `margin`: 別Blockとの距離、文脈側の外側余白
- `padding`: 線・背景・箱の内側に必要な余白

```txt
カード同士の間隔      -> 親一覧の gap
セクション間の距離    -> セクション側の margin-bottom
線と本文の距離        -> 内側の padding-top / padding-bottom
```

## Block間の余白

BlockとBlockの間隔は、原則として上のBlockの `margin-bottom` で管理する。

`margin-top` はページ文脈・例外調整にのみ使う。
上下両方から余白を持たせると、マージン相殺や二重余白の原因になる。

## 横方向マージンの扱い

- 横方向の `margin` は相殺されない（縦方向のcollapse前提を持ち込まない）
- 要素間スペースを `margin-left` と `margin-right` の両方で作らない
- 「左だけ」または「右だけ」の片側固定で運用する
- レスポンシブで `row -> column` / `column -> row` が起きる箇所は `gap` で管理する

```css
/* OK: 片側固定 */
.card + .card {
  margin-left: 16px;
}

/* 推奨: レスポンシブ切替を含む並びは gap で統一 */
.card-list {
  display: flex;
  gap: 16px;
}
```

## 文章（pタグ）の扱い

### 基本方針

- `p`タグ自体には余白を持たせない
- 文章の余白は親（レイアウト or Block）で制御する

```css
p {
  margin: 0;
}
```

### 文章ブロック例（汎用）

```html
<div class="richtext">
  <p>...</p>
  <p>...</p>
</div>
```

```css
.richtext > * + * {
  margin-top: 1em;
}
```

### 大きな段差が必要な場合

余白量に意味が生じた時点で、構造として扱う。
`p`にModifierや専用クラスを付けて段差を作らない。

```html
<div class="l-text">
  <p>通常段落</p>

  <div class="l-section-break">
    <p>次の話題</p>
  </div>

  <p>続き</p>
</div>
```

## Flex / Grid の並びと間隔

- 1方向の並び中心: Flex
- 行列を同時に設計: Grid
- 同一親内の反復間隔: `gap`
- 幅が想定より広がる、縮まない、はみ出す場合: [07_レイアウト](../../HTML・CSS/07_レイアウト.md) の `min-width: 0` / `flex-basis + padding` を確認する

## まとめ

- レイアウトは親が並びと幅を決める
- 子Blockは内部構造と見た目に集中する
- 反復間隔はまず `gap`
- Block間距離は文脈側の `margin`
- 箱の内側距離は `padding`
