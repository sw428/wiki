## レイアウトは別クラスに分離する

### 方針

- 並び・余白・配置はレイアウト用クラスが担当する
- BEM Blockは「意味・見た目」に集中させる
- 名前は並び方ではなく役割で付ける

```html
<div class="l-list">
  <article class="card"></article>
  <article class="card"></article>
</div>
```

```css
.l-list {
  display: flex;
  flex-direction: column;
  gap: 1rem;
}
```

## `.l-page` と `.l-inner`

ページ全体の外枠と、各Block内部の中身幅は分けて扱う。

- `.l-page`: サイト全体の最大幅、中央寄せ、ページ背景
- `.l-inner`: 各Block内部の共通横幅、左右の安全余白、中央寄せ

```css
.l-page {
  width: 100%;
  max-width: 1600px;
  margin-inline: auto;
}

.l-inner {
  width: min(calc(100% - 40px), 1000px);
  margin-inline: auto;
}
```

```html
<div class="l-page">
  <header class="header">
    <div class="header__inner l-inner">...</div>
  </header>

  <main>
    <div class="hero">...</div>

    <section class="staff">
      <div class="staff__inner l-inner">...</div>
    </section>
  </main>
</div>
```

`.l-inner` は、すべてを同じ外枠へ閉じ込めるためのクラスではない。
Heroのようにページ幅いっぱいへ見せたい領域と、本文やカード一覧のように中身幅を制限したい領域を分ける。

## 親が子の配置を決める

レイアウト崩れの多くは、子Block自身に外側配置まで持たせることから始まる。

- 親: トラック、幅、配置、子同士の間隔を決める
- 子: 自分の内部構造と見た目を決める

```css
.staff__list {
  display: grid;
  gap: 40px 20px;
}

.staff-card {
  /* カード内部の配置と見た目 */
}
```

配置責務そのものは [コンポーネントと責務](./03_コンポーネントと責務.md) も参照する。

## `margin` / `padding` / `gap` の使い分け

- `gap`: 同じ親に属する反復要素同士の間隔
- `margin`: 別Blockとの距離、文脈側の外側余白
- `padding`: 線・背景・箱の内側に必要な余白

```txt
カード同士の間隔      -> 親一覧の gap
セクション間の距離    -> セクション側の margin-bottom
線と本文の距離        -> 内側の padding-top / padding-bottom
```

## Block間の余白

BlockとBlockの間隔は、原則として上のBlockの `margin-bottom` で管理する。

`margin-top` はページ文脈・例外調整にのみ使う。
上下両方から余白を持たせると、マージン相殺や二重余白の原因になる。

## 横方向マージンの扱い

- 横方向の `margin` は相殺されない（縦方向のcollapse前提を持ち込まない）
- 要素間スペースを `margin-left` と `margin-right` の両方で作らない
- 「左だけ」または「右だけ」の片側固定で運用する
- レスポンシブで `row -> column` / `column -> row` が起きる箇所は `gap` で管理する

```css
/* OK: 片側固定 */
.card + .card {
  margin-left: 16px;
}

/* 推奨: レスポンシブ切替を含む並びは gap で統一 */
.card-list {
  display: flex;
  gap: 16px;
}
```

## 文章（pタグ）の扱い

### 基本方針

- `p`タグ自体には余白を持たせない
- 文章の余白は親（レイアウト or Block）で制御する

```css
p {
  margin: 0;
}
```

### 文章ブロック例（汎用）

```html
<div class="richtext">
  <p>...</p>
  <p>...</p>
</div>
```

```css
.richtext > * + * {
  margin-top: 1em;
}
```

### 大きな段差が必要な場合

余白量に意味が生じた時点で、構造として扱う。
`p`にModifierや専用クラスを付けて段差を作らない。

```html
<div class="l-text">
  <p>通常段落</p>

  <div class="l-section-break">
    <p>次の話題</p>
  </div>

  <p>続き</p>
</div>
```

## Flex / Grid の並びと間隔

- 1方向の並び中心: Flex
- 行列を同時に設計: Grid
- 同一親内の反復間隔: `gap`
- 幅が想定より広がる、縮まない、はみ出す場合: [07_レイアウト](../../HTML・CSS/07_レイアウト.md) の `min-width: 0` / `flex-basis + padding` を確認する

## まとめ

- レイアウトは親が並びと幅を決める
- 子Blockは内部構造と見た目に集中する
- 反復間隔はまず `gap`
- Block間距離は文脈側の `margin`
- 箱の内側距離は `padding`
