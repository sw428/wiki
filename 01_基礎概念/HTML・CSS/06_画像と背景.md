# 06_画像と背景

## 目的

- `<img>` と `background-image` の役割差を混同せずに判断できるようにする。
- 「背景が見えない」を、画像ファイルの問題ではなく `box` 面積の問題として切り分けられるようにする。
- 装飾画像の形式選定（`SVG` / `PNG`）を再利用しやすい判断軸で固定する。
- `mask-image` を、背景画像や `object-fit` と混同せずに使えるようにする。

## 最初に押さえる結論

1. `<img>` は文書内の意味を持つ画像要素（`alt` を持つ）。
2. `background-image` は既にある box への背景描画で、画像自体は box を作らない。
3. 背景が見えない時は、まず「背景を描く box に面積があるか」を確認する。
4. `mask-image` は画像を表示する指定ではなく、要素の見える形を抜く指定。

## 背景画像と描画ボックス

- `background-image` は、既存要素の `box` に背景として描画される。
- 背景画像は DOM に意味を追加しない。
- 背景画像は要素サイズ（面積）を作らない。
- そのため、要素側に `width` / `height` / `padding` / テキストなどの面積がないと見えにくい。

| 観点 | `<img>` | `background-image` |
|---|---|---|
| 役割 | 意味画像（文書内容） | 装飾背景（見た目） |
| DOM上の扱い | 要素として存在する | 新しい要素は増えない |
| セマンティクス | あり（`alt`） | なし |
| box面積への寄与 | 自身が描画対象になる | 背景画像だけでは面積を作らない |

## 背景が見えない時の確認順

1. 背景を描く要素に面積があるか（`width` / `height` / `padding` / テキスト）
2. `display: inline` の空要素になっていないか
3. 画像URLが正しいか
4. `background-size` / `background-position` が意図どおりか

補足:
- `display: block` / `inline-block` は面積を作りやすいが、高さ指定も内容もないと高さ `0` になり得る。

## 装飾背景の描画ルール

| プロパティ | 意味 |
|---|---|
| `background-size: cover` | 要素全体を覆う（比率維持、切り取りあり） |
| `background-size: contain` | 要素内に収める（比率維持、余白あり） |
| `background-position` | 切り取り時にどこを見せるかを決める |

## `mask-image` と背景画像の違い

`background-image` は「何を背景として塗るか」を決める。
`mask-image` は「要素のどの部分を見せるか」を決める。

見た目はどちらも画像を使うので混ざりやすいが、責務は逆に近い。

| 観点 | `background-image` | `mask-image` |
|---|---|---|
| 主な役割 | 背景として画像を表示する | 画像の透明度や形で見える範囲を決める |
| 色 | 画像側が色を持つ | 要素側の `background-color` などが色を持つ |
| よく使う場面 | 装飾背景、模様、写真背景 | 単色アイコン、形抜き、フェード表現 |
| 意味 | DOM上の意味は追加しない | DOM上の意味は追加しない |
| 注意点 | box に面積がないと見えない | 要素本体に色や背景がないと見えない |

### 単色アイコンで使う例

アイコン画像の「形」だけを借りて、色はCSSで変えたい時に使う。

```css
.icon-mask {
  display: inline-block;
  width: 24px;
  height: 24px;
  background-color: currentColor;
  mask-image: url("../img/icon-arrow.svg");
  mask-repeat: no-repeat;
  mask-position: center;
  mask-size: contain;
}
```

この場合、`icon-arrow.svg` は表示する画像そのものというより、見える形を決める型として使っている。
実際に見える色は `background-color: currentColor` 側が持つ。

### 背景をグラデーションで消す例

端だけ少しずつ透明にしたい時は、マスクにグラデーションを使う。

```css
.fade-image {
  background-image: url("../img/photo.jpg");
  background-size: cover;
  background-position: center;
  mask-image: linear-gradient(to bottom, #000 70%, transparent 100%);
}
```

この例では、写真は `background-image` が表示している。
`mask-image` は、その背景を含む要素全体の見える範囲を下方向へ薄く消している。

### 何をしているか

- `mask-image`: どの画像・グラデーションをマスクとして使うかを決める。
- `mask-size`: マスク画像を要素内でどう収めるかを決める。
- `mask-position`: マスク画像をどこに置くかを決める。
- `mask-repeat`: マスクを繰り返すかを決める。
- `background-color`: 単色アイコンでは、マスク越しに見える色になる。

`mask-image` は「画像を縮小する」「画像を枠に収める」指定ではない。
画像の収まりは `object-fit` / `background-size`、見える形の制御は `mask-image` と分ける。

### 使う判断基準

- 単色アイコンの色をCSSで変えたい: `background-color` + `mask-image` が候補。
- SVGやPNGの形だけ借りたい: `mask-image` が候補。
- 画像の端をフェードさせたい: グラデーションの `mask-image` が候補。
- 写真や商品画像をそのまま見せたい: `img` / `background-image` を優先する。
- 写真を枠に収めたい: `object-fit` / `aspect-ratio` / `background-size` を優先する。
- 意味のあるアイコンなら、マスクだけで終わらせず、テキストや `aria-label` など意味の伝達も別に考える。

## `<img>` と `background-image` の選択基準

- 意味画像として読ませる必要があるなら `<img>` を使う。
- 見た目の演出・装飾なら `background-image` を使う。
- 同じ見た目でも、意味の有無で選択を分ける。

補足:
- `object-fit` / `aspect-ratio` を使った「枠の安定化」は 10 側で扱う。

## `SVG` と `PNG` の使い分け（装飾画像）

- `SVG` が向く:
  - アイコン、ロゴ、単純図形、線画
  - 拡大縮小しても劣化しにくい素材
- `PNG` が向く:
  - 透過が必要なラスター画像
  - 写真的でないが、ピクセル表現を固定したい素材

補足:
- 写真は配信効率の観点で `WebP` / `AVIF` を優先検討し、`PNG` 常用は避ける。

## 判断基準

1. これは意味画像か、装飾背景か
2. 装飾背景なら、背景を描く box に面積があるか
3. 装飾画像の形式は `SVG` / `PNG` のどちらが適切か
4. 形だけ借りて色や見える範囲をCSSで制御したいなら、`mask-image` を検討する
5. 実装安定化（`object-fit` / `aspect-ratio` / CLS）は 10 で設計する

## 一言でいうと

意味がある画像は `<img>`、装飾なら `background-image`。
形だけ借りたい時は `mask-image`、背景が見えない時はまず描画先の box 面積を見る。
