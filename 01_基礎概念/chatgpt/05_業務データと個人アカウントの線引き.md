# 業務データと個人アカウントの線引き

## 目的

仕事でChatGPTを使うときに、「仕事で得た技能を個人でも使うこと」と「会社の情報を個人環境へ持ち出すこと」を分ける。

## 基本の線引き

### 個人でも再利用しやすいもの

- Excelの一般的な関数や表の分け方
- PowerPointで情報を整理する一般的な順序
- ミスを減らす確認方法
- AIへ条件を伝える順番
- 公開情報から学んだ一般的な操作
- 自分で用意した架空データを使い、ゼロから作り直した練習物

これは「会社の成果物を持ち出す」のではなく、自分が身につけた一般的な技能として扱う。

ただし、「一般的に見えるから必ず自由に使える」とは断定しない。契約、就業規則、派遣元・派遣先の情報管理ルール、秘密保持契約が優先される。

### 個人環境へ持ち出さないもの

- 会社や顧客の実ファイル
- 顧客名、会社名、担当者名、金額、個人情報
- 未公開の仕様、業務手順、計算条件
- 会社独自のテンプレート、数式、マクロ、ソースコード
- 社外秘・関係者限定として管理されている情報
- 会社の情報を復元できる具体的な数値や組み合わせ

名前を消すだけでは十分とは限らない。数値、構造、条件の組み合わせから元の案件や会社を推測できる場合も、個人アカウントへ入れない。

## ChatGPTのモデル改善設定との区別

個人向けChatGPTでは、「すべての人のためにモデルを改善する」をオフにすると、新しい会話をモデル改善へ使わない設定にできる。Business、Enterprise、Eduなどの業務向けサービスでは、入出力は既定でモデル学習に使われない。

- [Data Controls FAQ（OpenAI Help Center）](https://help.openai.com/en/articles/7730893-data-controls-faq)
- [How your data is used to improve model performance（OpenAI Help Center）](https://help.openai.com/en/articles/5722486-how-your-data-is-used-to-improve-model-performance)

ただし、モデル改善をオフにしても、会社が個人アカウントへの入力を許可したことにはならない。次の2つは別々に確認する。

1. OpenAI側でデータがどう扱われるか
2. 会社・派遣元・派遣先が、その環境への入力を許可しているか

## 接続アプリのデータも同じように確認する

Gmailなどの接続アプリは、通常のコピペ入力とデータの扱いが同じとは限らない。Googleアプリから直接同期されたデータについては、OpenAIが一般モデルの学習に使わない扱いと例外が説明されている。

- [Google App for ChatGPT - Data Controls FAQ（OpenAI Help Center）](https://help.openai.com/en/articles/10408842-google-app-for-chatgpt-data-controls-faq)

それでも、会社アカウントの接続は会社の許可、Google Workspace側の権限、ChatGPTワークスペース管理者の設定を先に確認する。

## 方法論を個人用に戻す手順

1. 会社名、顧客名、実数値、固有条件を使わずに説明できる原理か確認する
2. 元ファイルをコピーせず、空のファイルから作る
3. 架空データへ置き換える
4. 会社独自の手順ではなく、一般的な判断として自分の言葉で書く
5. 元の業務情報を知らなくても成立する内容か確認する
6. 判断が微妙なら、派遣元と派遣先の両方へ確認する

## 法律だけで決めない

著作権では、具体的な創作的表現と、アイデアや方法は区別される。一方で、会社の情報は著作権だけでなく、契約上の秘密保持や営業秘密として問題になる可能性がある。

経済産業省は、営業秘密の要件を「秘密管理性・有用性・非公知性」の3つとしている。厚生労働省の資料にも、派遣スタッフが業務上知り得た秘密を漏らさないことや、情報を目的外利用しないことを定める就業規則例がある。

- [営業秘密について（経済産業省）](https://www.meti.go.jp/policy/economy/chizai/chiteki/trade-secret.html)
- [派遣先での勤務態度、服務規定の遵守（厚生労働省）](https://www.mhlw.go.jp/new-info/kobetu/roudou/gyousei/kantoku/dl/syugyo_04.pdf)
- [著作権に関する相談窓口の説明（文化庁）](https://www.bunka.go.jp/seisaku/chosakuken/kaizoku/contact.html)

## 最終判断

安全側の基準は次の通り。

- 身についた一般技能は、架空データでゼロから再構成する
- 会社固有の情報・ファイル・独自ルールは持ち出さない
- 個人アカウントを使いたいという希望と、会社データを入力してよいかは分ける
- 業務利用は、費用負担より先にアカウント、入力可能範囲、接続権限を確認する
