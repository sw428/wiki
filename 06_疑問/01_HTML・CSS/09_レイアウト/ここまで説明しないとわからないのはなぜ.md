# ここまで説明しないとわからないのはなぜ

元の記事：[下へ寄せるときはどの箱の余った高さを使うか](../../../01_理解の土台/01_HTML・CSS/09_レイアウト/01_下へ寄せるときはどの箱の余った高さを使うか.md)

たぶん理由は、flex: 1 が**見た目以上に前提を何個も圧縮している指定**だから。

コードは1行だけど、理解するには実際は、

`誰の子なのか ↓ 親はFlexか ↓ 縦並びか横並びか ↓ 親に余りがあるか ↓ どの子がその余りを使うのか ↓ 伸びるのは文字ではなく箱そのもの`

まで頭の中でつながってないと、「flex: 1 = なんか伸びる」になりやすい。

しかも教材ではよく、
```css
.body {
  flex: 1;
}
```

とだけ出てきて、「**何が・どこから・どの方向へ伸びるのか**」を図にしない。だからコード自体は真似できても、少しHTML構造が変わると分からなくなる。

今回あなたが時間をかけたのも、flex: 1 という単語が難しいというより、

> .body という箱が、親 .card の余った縦の空間を使って伸びる

という**空間の変化を頭の中で見える形にする必要があった**からだと思う。

一度そこが絵としてつながれば、次からはここまで説明はいらなくなる。

`.card が縦Flex ↓ .body はその子 ↓ 親に余りがある ↓ flex: 1 で .body が伸びる`

まで一気に読めるようになる。

だから今やっている01は、まさにこの「普通の教材だと省略される途中の1〜2段」を埋める場所として機能してる。
