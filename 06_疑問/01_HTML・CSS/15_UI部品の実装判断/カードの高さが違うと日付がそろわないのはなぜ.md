# カードの高さが違うと、日付がそろわないのはなぜ？

元の記事：[カードの可変本文と下寄せ要素を両立する](../../../02_基礎/01_HTML・CSS/15_UI部品の実装判断/07_カードの可変本文と下寄せ要素を両立する.md)

同じ行で、上端をそろえて並べるカードの例。

> カードごとに本文量が違っても、日付やボタンなど特定の要素だけを下へそろえたい場合は、本文全体を固定高にしない。
>
> 先に、一覧側で同じ行のカードが同じ高さを受け取る構造になっているか確認する。カード内部だけへ`margin-top: auto`を指定しても、カード自身の高さが異なれば一覧全体ではそろわない。

この2文は、かなり簡単にするとこういう意味。

> **カードの下をそろえたいなら、まずカード自体の高さがそろっている必要がある。**

たとえば、

```text
カードA             カードB
┌──────────┐        ┌──────────┐
│ タイトル │        │ タイトル │
│ 本文     │        │ 本文     │
│          │        │ 本文     │
│ 日付     │        │ 本文     │
└──────────┘        │ 日付     │
                    └──────────┘
```

この状態だと、カードAとカードBの高さが違う。

ここでそれぞれのカードの中で、

```css
.date {
  margin-top: auto;
}
```

としても、**それぞれのカードの一番下に行くだけ**。

```text
カードA             カードB
┌──────────┐        ┌──────────┐
│ タイトル │        │ タイトル │
│ 本文     │        │ 本文     │
│          │        │ 本文     │
│ 日付     │        │ 本文     │
└──────────┘        │          │
                    │ 日付     │
                    └──────────┘
```

だから横から見ると、日付の高さはそろわない。

先に一覧側でカード自体を、

```text
┌────────┐        ┌────────┐
│        │        │        │
│        │        │        │
│        │        │        │
│        │        │        │
└────────┘        └────────┘
```

同じ高さにしておく。

そのうえでカード内部の余りを使って、

```text
┌──────────┐        ┌──────────┐
│ タイトル │        │ タイトル │
│ 本文     │        │ 本文     │
│          │        │ 本文     │
│          │        │ 本文     │
│ 日付     │        │ 日付     │
└──────────┘        └──────────┘
```

とすると、日付が横にそろう。

だからこの記事の最初は、もっと小学生向けなら、

> **日付をそろえる前に、まずカードの箱の高さがそろっているかを見る。カードの高さが違うと、それぞれの「一番下」も違う。**

くらいでもいい。

そのあとで、

> カードの高さがそろっていれば、margin-top: auto で余った高さを日付の上に入れて、下へそろえられる。

と続けるとかなり分かりやすい。
