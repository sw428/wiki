# ペイン

## 意味

ペイン（pane）は、アプリの画面内を区切った表示領域・枠を指す。

DevTools上に「Stylesペイン」という一つの名前が表示されているわけではない。`Styles` は画面に表示される名前であり、その内容が表示される区切られた領域を、説明上「Stylesペイン」と呼ぶ。

```txt
Styles = 表示名
ペイン = その内容を表示する区切られた領域
```

「タブ」は表示を切り替える見出し・操作部分、「ペイン」は選択した内容が表示される領域として分ける。
