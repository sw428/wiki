# HTML・CSSの箱と余白を図示する規約

通常フローの親子・兄弟要素、margin・padding・borderを図示するときに読みます。CSSの説明本文を置き換えず、既存の指定・成立条件・結果を図へ対応させるための規約です。

## 親要素

HTML・CSSの箱や親子関係を説明するSVGでは、親要素の表示を次の値にそろえる。

| 対象 | 共通の指定 |
| --- | --- |
| 親要素の背景 | `fill: #f5f5f5` |
| 親要素のラベル・上端を示す文字 | `fill: #444444` |
| 親要素の範囲を示す補助線 | `stroke: #666666`、`stroke-width: 2`、`stroke-dasharray: 8 7` |

- 補助線は説明用の点線とし、実際のCSSのborderではないことを図または本文で示す。実際のborderを説明する線と混同しないようにする
- この共通指定は親の背景・ラベル・範囲の補助線だけに適用する。子要素、margin、padding、矢印、実際のborder、文字の書体・大きさ、図の寸法や配置には、このルールだけを理由に変更を加えない

## 領域色・外枠・要素の識別

- marginの説明用の領域はオレンジ `fill: #f9cc9d`、borderの説明用の領域は少し鮮やかさを抑えた黄色 `#f2ed20` とする。領域の色と、その余白を持つ要素を示す表記の色を分ける。borderを表す線・領域は必ずこの黄色で示し、黒など以前の色を残す例外は設けない。図内のコードと参照元本文でborder色を指定している場合は、`#f2ed20` に同期する。黄色のborderを線で図示するときは`stroke-width: 6`、細い帯で図示するときは厚さ5にそろえる。これは図の視認性のための太さとし、CSS例のborder指定値や距離の計算値は変更しない
- 要素の外枠は、その要素の背景・ラベルに対応する色系統で縁取る。例えば青系の前の要素は青、赤系の子要素は赤にする。親の範囲を示す補助線は上記の灰色の共通指定を保ち、要素を識別する外枠と実際のCSSのborderを混同しない
- 要素が重なった面積を示す場合は、その範囲を灰色 `stroke: #666666` の点線で囲む。重なりの面積を示す説明用の補助線とし、実際のCSSのborder、要素を識別する外枠、marginの指定値・移動矢印とは区別する
- 要素を識別する基本色は青（背景 `#cfe4ff`・外枠 `#315fa0`）と赤（背景 `#f8cfd6`・外枠 `#c93030`）とする。さらに色が必要な場合は紫（背景 `#e9ddff`・外枠 `#7c3aed`）、紅色（背景 `#fbe0eb`・外枠 `#be185d`）、紅紫（背景 `#f3dcf7`・外枠 `#a21caf`）を順に使う。親の共通表示は上記の灰色を保つ
- 子要素の中にある子孫の箱にも、外側や同じ図の別の要素と区別できる色を割り当てる。青・赤だけを交互に使う規則にはせず、必要な色を上記の追加色から選ぶ。比較図では同じ要素・子孫の色を維持する。例：子Aは青、子Bは赤、子Cは紫、子Bの子は紅色、子Cの子は紅紫
- marginの指定値の文字・数値と、負のmarginによる移動の矢印・矢印に添える移動量の文字・数値は、その指定または移動対象の要素の色系統でそろえる。青系の前の要素のmargin-bottomは青、赤系の子要素のmargin-top・margin-bottomは赤にする
- 負のmarginによる移動を描く場合は、通常位置から移動先へ向く片矢印にする。例えば `margin-top: -150px` は通常位置から150px上へ向く矢印（↑）とし、両矢印で移動を表さない。後続の兄弟が上に詰まる動きも片矢印で示す。先端は小さな開いた形とし、`markerUnits="userSpaceOnUse"` で線幅による拡大を避ける
- `top` / `bottom` はmarginを指定する側であり、移動方向ではない。通常フローのブロック配置で、ほかのmarginとの相殺や位置指定が配置へ影響しない最小例では、`margin-top: -40px` は指定した要素自身と後続要素が上へ詰まり、`margin-bottom: -40px` は指定した要素自身の位置を保ったまま後続要素が上へ詰まる。負のmargin-bottomを図示するときは、指定元の下側にその要素色のmargin表記を置き、移動する後続要素へ上向きの片矢印（↑）を描く。margin表記の色は指定元、移動矢印の色は移動対象に対応させる。条件が違う図では、指定名から矢印の向きを決めず、実際の配置への影響を確認する
- 正のmarginは該当側のオレンジの余白領域と、持ち主の要素色の表記・数値で示し、移動方向の矢印を付けない。例えば `margin-bottom: 60px` は要素の下側の余白として示す。paddingの寸法表示は下記の緑を保つ

## paddingと例示数値の関係

- 緑はpaddingの説明専用とし、要素や子孫の識別色には使わない。paddingの領域を説明用に着色する場合は薄緑 `fill: #cae6d1`、padding領域のラベル・数値・寸法線・矢印は濃い緑 `#26724a` にそろえる。親の範囲を示す点線は上記の灰色のままとし、paddingの線と区別する
- 実際の `background-color` がcontentとpaddingに付くことを説明する図では、その背景色を保ち、paddingを示す寸法線・矢印・数値を緑にする。説明用の着色と実際のCSSの背景色を混同させない
- 図を作成・使用するときは、前の要素のmargin、親のpadding、子のmarginなど、異なる役割の例示値が基本的に重ならないようにする。値の選び方は[例示数値の置換](../../AGENTS.md#例示数値の置換)に従い、可能なら結果や補助的な寸法とも重ねない
- 同じ条件で比較する例、等しいmarginの相殺など、同じ値であることが説明に必要な場合はそろえる。計算結果を重複回避のために変えない
